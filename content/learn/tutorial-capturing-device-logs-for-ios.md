## 1. Overview

Q&A (0)

*In this tutorial, you will learn how to capture iOS device logs using Xcode. Capturing device logs allows you to troubleshoot your app’s behavior in the mobile device.*

Before you begin, you will need a MacOS computer with Xcode installed and updated to the latest version. You can download XCode from the [Apple Developer site](https://developer.apple.com/xcode/resources/) or through the App Store.

!IMPORTANT: If you are collecting logs for an issue you have reported, please ensure that you are able to reproduce the reported issue.
