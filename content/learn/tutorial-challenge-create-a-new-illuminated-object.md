## 4. Create and configure the illuminated object

Q&A (0)

To create an illuminated object:

**1.**  In the Learning Scene, select the **Container_Tube_Large_Tutorial** Prefab.

[Image: image]

**2.**  Open **Container_Tube_Large_Tutorial** in Prefab Mode and select the **Container_Tube_Large_Lod00** GameObject.

[Image: image]

**3.** Illuminate and configure the object. If you need to, review [Create and calibrate an illuminated object using HDRP](https://learn.unity.com/tutorial/create-and-calibrate-an-illuminated-object-using-hdrp).

**4.**  Save the updated Prefab, and instantiate it throughout the learning Scene.

**5.**  Evaluate the effect when you:

- Place multiple illuminated tube Prefabs in one area
- Create a repeating sequence of illuminated tubes
- Use two Prefabs to draw attention to particular details in the room

Consider the impact these options could have on a player exploring the room in the learning Scene, or an enlarged space. Can you identify a placement that contributes to a consistent environment which balances detail with focus?

#### Next steps

If you’d like to extend the challenge, try adjusting the location and calibration of the illuminated tubes within the demo Scene itself. This will enable you to evaluate the impact of these lights on atmosphere and the high fidelity visual environment in more depth.
