## 2. Installing ProGrids

Q&A (0)

To start, install ProGrids from the Unity Package Manager.

1. Go to the Window drop-down and click **Package Manager**.
2. Ensure the drop-down in the top left of the window is set to **All Packages**.
3. Click the **Advanced**dropdown and select **Show Preview Packages**.
4. Select **ProGrids**from the list on the left side of the window.
5. Click **Install**in the bottom right.

If you’re running a pre-2018 version of Unity, you can install ProGrids from the Unity Asset Store.

1. Open the Asset Store by clicking **Window**> **Asset Store**.
2. In the Asset Store search bar, type *ProGrids*.
3. Select **ProGrids**in the search results.
4. Click the **Download**button.

After Unity has downloaded the package, click the **Import**button.

## 4. Using ProGrids

Q&A (0)

Once you’ve opened ProGrids, you’ll see a grid overlay in the Scene window. Your Scene will now have grids enabled and your GameObjects will automatically snap to the grid (**Figure 02**).

[Image: image]

You can change several settings to adjust how ProGrids behaves from the overlay in the top left of the Scene view. They’re numbered to make it easier to step through each possible setting (**Figure 03**).

[Image: image]

The ProGrids buttons are:

1. Opens a new window called Snap Settings that allows you to adjust the size of the grid and line increments, snap on scale, and snap as groups. Snap on Scale allows you to snap to the grid when scaling objects. Snap as Group allows multiple selected objects to retain their relative position to one another when moved. You can also change snap angles, and toggle the predictive grid. The predictive grid allows ProGrids to automatically set the rendering grid plane according to an object’s movement (**Figure 04**).

[Image: image]

2. Button 2 toggles the display of the drawing of the grid guidelines in the active Scene window.

3. This toggles the snap to grid functionality.

4. This snaps all selected objects to the grid.

5. This locks the center of the grid in perspective space.

6. This renders the grid on the x-axis plane.

7. This renders the grid on the y-axis plane.

8. This renders the grid on the z-axis plane.

9. This renders a 3D grid in perspective mode in your Scene window. This means the grid will remain stationary when you move your perspective camera around in the Scene.

Additional settings for ProGrids can be found in Unity Preferences. To open these settings:

1. Click **Edit**> **Preferences**on Windows or **Unity**> **Preferences** on Mac

2. On the left side of the Preferences window, click **ProGrids**. This will reveal the additional settings (**Figure 05**).

[Image: image]

In Preferences, you can change grid colors per axis, adjust the line alpha, and more. You can also set keyboard shortcuts. All the settings are clearly labeled and allow you to further customize ProGrids.
