[Image: ビジュアルスクリプティングでのカスタムイベント]Summary

プログラミングでは、イベントは発生、つまり、起こることです。イベントを利用することで、「いつ」「何時」「何をしたら」という状況に対応したゲームの仕組みを設計することができます。ビジュアルスクリプティングでは、2つのユニットだけでカスタムイベントを使用することができます - C# よりもはるかに簡単なプロセスです。このチュートリアルでは、カスタムイベントを使って、猫のクライブに何かを起こさせます。

このチュートリアルを終える頃には、以下のことができるようになります：

- 新しいカスタムイベントトリガーをビジュアルスクリプトに追加する
- カスタムイベントに応答するビジュアルスクリプトを作成する
- カスタムイベントを利用して、あるスクリプトから別のスクリプトにゲームオブジェクトを渡す
- Project ウィンドウでビジュアルスクリプトをコピーする
- ビジュアルスクリプトを別の目的に適応させる
- 既存のスーパーユニットにデータ入力を追加する

## 1. 概要

Q&A (0)

**Events**(**イベント**)とは、プロジェクト内で発生する現象で、これを検知してスクリプトで処理することができます。ユーザーの入力、コリダーの衝突、プレイヤーの移動などは、イベントの一例に過ぎません。

イベントはブロードキャストメッセージのようなものだと考えてください。 Visual Scripting では、**イベント**の**ユニット**はこれらのメッセージの「レシーバー (receivers)」であり、イベントに対応して物事を実現するスクリプトを開始します。イベントユニットの事例として、新しい GameObject コンポーネントのスクリプトに表示される Start と Update のユニットや、クライブの小部屋への侵入を制御するために既に使用したスクリプト化されたイベントなどがあります。

このチュートリアルでは、カスタムイベントを使ってスクリプトを書き、ゲームオブジェクト同士を相互に作用させます。イベントは、いつ、何が起こるかを制御できる強力なプログラミングツールです。

## 2. ボタンでドアを開ける

Q&A (0)

クライブが FirstDoor を通過すると、新しい部屋になっていて、その中の 1つの小部屋にボタンがあります。このゲームオブジェクトは DoorButton である。この部屋では、クライブが DoorButton を押さないとドアが開かないように、SecondDoor をプログラムします。

このドアの違いは、クライブが DoorButton に近づくまで開かない前のドアとは異なり、クライブが DoorButton を押すとすぐに開くことです。

このためには、ボタンが押されたことを検知するカスタムイベントを使用します。DoorButton のスクリプトは、ボタンが押されたとき（Cliveがその小部屋に入ったとき）にイベントを呼び出し、SecondDoor のスクリプトは、そのイベントに即座に反応してドアを開けるシーケンスを実行します。

## 3. ボタンのカスタムイベントトリガーのスクリプティング

Q&A (0)

まず、DoorButton のイベントトリガーを作成しましょう。

**1.**Hierarchy で**ObjectRoot > DoorButton** と選択し、DoorButtonScript という名前のビジュアルスクリプトを持つ新しい Script Machine を追加します。これを **Assets > VisualScriptingTutorial > Tutorial > VisualScripts**の順に保存します。

**2.**Start と Update のユニットが存在する場合は削除します。

**3. Enter Cell** イベントユニットを追加して、Moving Object が小部屋に入ったときに発生するイベントを検出して処理します。

**4. Trigger Custom Event**ユニットを追加して、新しいカスタムイベントを作成します。このイベントを **DoorButtonPushed**と名付けます。このユニットは、ドア用のスクリプトに「broadcast message」を送信します。

**5.**Custom Event Trigger ユニットを調べます。このユニットには GameObject 入力があり、デフォルトは Self で、ここでは DoorButton となっています。ただし、このイベントを受け取る側のスクリプトは、ボタンではなく、開けたいドアを必要としています。このイベントユニットには、SecondDoor ゲームオブジェクトを Object 変数で渡します。(カスタムイベントについては、スーパーユニットの場合と同じように、受け取るスクリプトに値を渡すことができます)

**6. DoorToOpen**という名前の Object 変数を、Type を**GameObject**にして作成し、その **Value**をゲームオブジェクトの SecondDoor に設定します。このユニットを Custom Event Trigger の入力に接続します。**ヒント：**SecondDoor は Hierarchy からドラッグできます。

**ヒント：**この Object 変数は Inspector に表示されるので、あなたやあなたのプロジェクトの他の開発者が、このボタンで開く別のドアを簡単に選択できるようになります。(次のステップで作成するように、そのドアにイベント用のスクリプトがあることを確認してください。)

## 4. ビジュアルスクリプトのコピー

Q&A (0)

次に、SecondDoor のスクリプトを作ってみましょう。このスクリプトは FirstDoorScript をベースにしていますので、これまでの作業をもとに作成することができます。

**1.**Project ウィンドウで、VisualScripts フォルダーに移動し、Ctrl+D / Cmd+D を使って FirstDoorScript を複製します。

**2.**コピーした SecondDoorScript の名前を変更します。

**3.**Hierarchy 内で **ObjectRoot > SecndDoor**と選択し、そのコンポーネントを Inspector に表示します。

**4.**Project ウィンドウから、Script Machine コンポーネントの Graph プロパティに新しいファイルSecondDoorScript をドラッグして、BaseDoorScript を置き換えます。

このスクリプトを新しいゲームの仕組みに適応させることができます。

## 5. ドアのカスタムイベントのスクリプティング

Q&A (0)

**1.**このスクリプトには、Object 変数 IsOpen が必要です。Blackboard の Object タブを使って、SecondDoor にその変数を追加します。

**2.**この新しいドアには適用されないユニットが 2 セットあります。

- 鍵をチェックするユニット
- クライブが通り抜けた後にドアを閉めるユニット（ドアが閉まってしまうと、クライブは戻れなくなってしまうため）

スクリプトからこれらのユニットを削除します。残されたものは以下のようになるはずです：

[Image: image]

このビジュアルスクリプトには、2 つのイベントに対するフローが必要です。最初に検出するイベントは、クライブがドアを通ろうとしたときです。スクリプトはクライブをドアに通すか、前に見たように彼の動きをキャンセルします。このイベントフローは完了しています。

検出する 2つ目のイベントは、ボタンが押されたときで、それが起こると DoorButtonScript は DoorButtonPushed イベントをトリガーします。

**3.**このイベントを検出するには、**Custom Event**ユニットを追加し、DoorButtonPushed という名前を入力します。

**4.**このイベントをスクリプトに接続し、イベントが検出されるとドアが開くようにします。

**5.** 作業内容を保存（**Ctrl + S / Cmd + S**）します。

**6.** 再生でテストを行います。Script Graph ウィンドウを開いたまま、Value ボタンを有効にして、これらの 2つのイベントがいつトリガーされるかを確認します。

## 7. 次は何？

Q&A (0)

イベントのおかげで、クライブは地下室の 2つの部屋を通り抜けられるようになりました。ビルトインイベント、C# で書かれたカスタムイベント、そして Visual Scripting で作成したカスタムイベントを使用しました。イベントは、あるゲームオブジェクトに起こったことが、別のゲームオブジェクトに影響を与えたり、プレイヤーのスコアやダメージを修正したり、その他の条件を変更したりする様々な場面で使用できます。

次回のチュートリアルでは、State Machines について学びます。ステートマシンは、イベントの使用方法を飛躍的に向上させ、ゲームプレイを思いのままに複雑化することができます。ただし、その前に、クライブの地下室に、彼が制御できるデバイスをいくつか視覚的にスクリプティングすることで、機能性とミステリー性を高めます。
