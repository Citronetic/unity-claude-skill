## 1. 소개

Q&A (0)

Unity는 프로젝트 관리자가 Reflect 프로젝트를 다른 사용자에게 라이선스 할당을 하지 않고도 공유할 수 있도록 지원합니다. 이를 통해 클라이언트에게 프로젝트를 공유할 수 있으며, 클라이언트는 무료 Reflect 뷰어를 사용해 자신의 기기에서 프로젝트를 열어볼 수 있습니다. 클라이언트는 Reflect 라이선스 없이 자신의 사용자 이름으로 할당된 프로젝트를 모든 Reflect 뷰어 버전에서 열어서 확인할 수 있지만 BIM 모델을 편집할 수는 없습니다.

Unity 계정 페이지에서 조직 관리 섹션을 통해 다른 사용자를 Reflect 프로젝트로 초대할 수 있습니다.

이 튜토리얼에 필요한 사항

- Unity 계정의 조직에 대한 관리자 수준 액세스
- 초대하려는 사용자의 Unity 계정
- 조직 계정에 활성화된 Reflect 라이선스

## 2. Unity 프로젝트 관리 페이지에 사용자 추가

Q&A (0)

**1.** Unity 계정에 로그인합니다(**그림 01**).

[Image: image]

**2.** 계정 대시보드 화면에서 왼쪽의 **Projects** 옵션을 선택합니다(**그림 02**).

[Image: image]

**3.** 화면 상단 오른쪽의 **Account**옵션에서 조직을 정확히 선택했는지 확인합니다. 드롭다운 메뉴에서 **Switch organization**을 선택합니다(**그림 03**). 새로 표시된 메뉴에서 Reflect 프로젝트가 생성된 조직을 선택할 수 있습니다.

[Image: image]

**4.** 이제 프로젝트 목록이 표시됩니다. 프로젝트 이름이나 **View**버튼을 선택하여 공유할 프로젝트를 선택합니다(**그림 04**).

[Image: image]

**5.** 프로젝트 관리 페이지에서 왼쪽 메뉴의 **Settings**를 선택한 다음 **Users**를 선택합니다(**그림 05**).

[Image: image]

**6.** 사용자 관리 페이지에서 **Add User or Group** 박스에 새 사용자의 이메일 주소를 입력하고 **Add**를 클릭하여 새 사용자를 추가합니다(**그림** **06**). 사용자는 프로젝트에 추가한 이메일 주소로 생성한 Unity 계정이 있어야 합니다.

[Image: image]

**7.** 이제 프로젝트의 사용자 목록에 새 사용자가 포함됩니다(**그림 07**). 액세스를 부여하려는 사용자는 기본값으로 Access level이 user로 설정되어 있어야 합니다. **Remove**버튼을 클릭하여 프로젝트에서 사용자를 제거할 수도 있습니다 .

[Image: image]

**8.** 초대된 사용자에게 프로젝트 초대 이메일이 발송됩니다(**그림 08**).

[Image: image]

**9.** 초대된 사용자는 이제 프로젝트에 할당된 이메일 주소로 Reflect 뷰어에 로그인할 수 있으며 해당 주소로 할당된 프로젝트를 볼 수 있습니다(**그림 09**).
