## 6. ヒントとソリューションについてのまとめ

Q&A (0)

**ヒント：**

- Easy（簡単/やさしい）： Obstacle Pyramids（障害物を積む）

- Rigidbody の使用を忘れずに！
- Medium（普通）：Oncoming vehicles（対向車を走らせる）

- transform.Translate を使って他の車両を動かしてみてください。
- Hard（難しい）：Camera switcher（カメラ視点を切り替える）

- 2 台目のカメラを追加し、キー操作でカメラの有効/無効を切り替えることができます。
- Expert（エキスパート/上級）：Local multiplayer（画面を２分割し別のカメラを使い、 マルチプレイヤーゲームを作る）

- Input Manager と Camera の Viewport Rect の W (Width ; 幅) プロパティを編集する必要があります。

**ソリューションを構築するチュートリアル**

どうしても解決できない場合は、[ステップバイステップのソリューションを提供するチュートリアル](https://connect-prd-cdn.unity.com/20210504/93a938b7-ee56-488f-b0b3-8b956c0a31fd/Unit%201%20-%20Bonus%20Features%20Solutions.pdf?_ga=2.199681006.1186801097.1620052249-59568313.1601905412)をダウンロードしてください。

なお、これらの機能を実装する方法は多数あると思われますが、これはあくまで一つの提案に過ぎません。
