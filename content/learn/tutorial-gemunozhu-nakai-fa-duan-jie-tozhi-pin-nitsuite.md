## 2. 主な開発段階

Q&A (0)

このコースを受講されている方は、モバイルゲームを開発している最中か、近い将来に開発を開始したいと考えているはずです。

このコースの大半は、開発プロセスのさまざまな部分を中心に構成されているので、必要なツールや製品、方法論について、いつ、どこで考える必要があるのかがわかりやすくなっています。

[Image: image]

**コンセプト / プリプロダクション**

この段階では、モバイルゲームを成功させるための準備を行います。ビジネスの観点から、この段階での目標は、市場調査を行い、潜在的なオーディエンスを特定し、競合他社を理解することです。

これにより、誰に向けてゲームを作っているのか、市場の類似ゲームと比べてどのように改善できるのか、競争力を高めるためにはどのような機能が必要なのかを明確に把握した上で制作に入ることができます。

**制作**

この時期には、モバイルゲームに不可欠なビジネスツールやサービスの構築を開始します。多くの開発者は、Analytics、Ads、IAP などを開発プロセスの後半で統合するという間違いを犯しています。この間違いは、ゲームのプレイヤーを維持し、収益を上げる能力を著しく阻害します。

この段階での目標は、中核となるゲームループにマネタイゼーション機能を組み込み、プレイヤーがゲーム内をどのように移動するかを把握するための追跡フレームワークを確保することです。

**ローンチ**

当社では、発売を「ソフトローンチ」と「ワールドワイドローンチ」という2つの異なる取り組みとして捉えています。ソフトローンチでは、モバイルゲームをテストし、オーディエンスを見つけることが目的です。ワールドワイドローンチは、一般的に「ローンチ」という言葉でイメージされるもので、最大のインパクトを与えるものです。

**ライブ運用**

ゲームをローンチした後は、適切なプレイヤーを獲得し、彼らの関心を維持し、成功を測定する必要があります。目標は、ゲームを効率的なマシンに最適化し、優れたプレイヤー体験を提供すると同時に、さらなる開発のための十分な収益を得ることです。

## 3. 必須ツールとサービスについて

Q&A (0)

インディー開発者にとって、仕事に適したツールを見つけることは大変なことです。多くの主要な製品やサービスは、高価であったり、導入や維持が困難であったり、単に小規模なスタジオには適していません。

このリストには、モバイル市場での競争力を高めるために設計された Unity と独立したリソースが混在しており、コースを通して詳細に検討されるすべての製品とサービスが含まれています。

[Image: image]

**マネタイゼーション（収益化）**

- **Unity Ads：**モバイルゲームに広告を組み込むための包括的な SDK です。また、Unity Ads は、複数の広告ネットワークに対応しており、バナー、インタースティシャル広告、リワード広告をゲームにシームレスに組み込む最も簡単な方法です。
- **Unity IAP：**この SDK を使えば、プレミアムコンテンツからコスメティックアイテムまで、ゲームにアプリ内課金を簡単に組み込むことができます。Unity の IAP システムにより、複数のプラットフォームでゲームの経済性をシームレスに構築することができます。

**Analytics と Insights**

- **Unity Analytics：**リテンションの測定から、ユーザーのインストールやエンゲージメントの追跡まで、モバイルゲームで使用される主な解析のデータプラットフォームです。
- **deltaDNA：**このツールを使えば、ゲーム内の特定のイベントを追跡し、A/B テストから難易度のバランス調整まで、あらゆる設定を行うことができます。Unity Analytics と組み合わせることで、deltaDNA はプレイヤーがゲーム内でどのように動いているかを理解するための完璧なツールとなります。
- **Remote Config：**このツールは、アプリケーションの設定をリモートでリアルタイムに変更することができ、イテレーションのスピードを高め、ソフトウェアのデプロイとチューニングを容易にします。
