## 1. 概要

Q&A (0)

「Arm と Unity：モバイルアプリケーションのための 3D アートの最適化」にようこそ！

スマートフォンはポケットに入れて持ち運べるスーパーコンピューターと、よく表現されます。クリエイターとして、Unity も外出中でも利用できるような没入型の体験や有用なツールを開発しようと、懸命に取り組んでいます。スマートフォンというものは 3D ゲームなどの複雑なアプリケーションを実行できる優れたハードウェアですが、一方でそれぞれ限界もあるものです。

このコースでは、さまざまなタイプの 3D アセットの作成、そして高度な部分も含めたモバイル開発のプロファイリング/最適化ワークフローについての理解を促進するための、ベストプラクティスを数点学んでいきます。ここで学習したことを応用すれば、アプリケーションの速度と効率性を高め、これまでより質の高い体験を対象となるユーザーへ提供できるようになります。

## 3. サンプルデモの利用方法

Q&A (0)

このコースでは、各セクションの重要な最適化を扱ったサンプルデモを 5 つご用意しています。これらのデモは、Unity 2019 LTS（Unity 2019.4.10f1）を使用してテストされています。このプロジェクトは[こちら](https://connect-prd-cdn.unity.com/20210111/c313396b-3519-48b0-af40-3b8d852354f2/ARMUnityMobileOptimization.zip?_ga=2.247292868.1300965009.1610309756-1588052204.1590585134)からダウンロードできます。

サンプルプロジェクトを開くと、各サンプルデモにすばやくアクセスできる README が表示されます。Unity エディターもこれらのデモ用にカスタマイズされており、組み込みの**プロファイラー**や**フレームデバッガー**ビューがすでに固定された状態なので、簡単にアクセスできます。

入門用の README（「**Tools**」＞「**Show Read Me**」）や、プロファイリングビュー（「**WIndow**」＞「**Analysis**」）が必要な場合は、Unity エディターのメニューバーからアクセスできます。

**重要な注意事項：**サンプルデモを含む Unity プロジェクトをダウンロードしたら、SRP Batcher がオフにトグルされていることをご確認ください。ユニバーサルレンダーパイプライン対応のプロジェクトでは、この機能がデフォルトでオンになっています。この機能については、後ほど説明します。

「**Assets**」＞「**Content**」＞「**Settings**」に移動し、「*UniversalRenderPipelineAsset*」をクリックすると、インスペクターにそのプロパティーが表示されます。「**SRP Batcher**」のオンオフを切り替えるトグルは、「**Advanced**」セクションにあります。
