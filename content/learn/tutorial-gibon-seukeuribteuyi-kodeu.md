## 2. 기본 스크립트

Q&A (0)

새 스크립트를 생성하면 **MonoBehaviour**라는 빌트인 클래스에서 파생된 public 클래스도 생성됩니다. 컴포넌트에 이름을 지정했을 때, 이 클래스와 스크립트의 파일 이름에 동일한 이름이 적용되었습니다. 이러한 이름이 일치하는 것이 중요합니다.

코드에서 **public class**가 이미 설정된 것을 볼 수 있습니다. 이 클래스는 이름이 'HelloWorld'이고 스크립트와 이름이 동일합니다. 이러한 이름은 항상 동일해야 하며, 스크립트의 이름을 변경하면 이 클래스의 이름도 변경해야 합니다.

또한 이 스크립트에는 `Start()` 및 `Update()`라는 두 개의 **함수**가 포함되어 있습니다.

[Image: image]

Start 함수는 게임이 시작될 때 한 번 실행되고, Update 함수는 게임의 모든 프레임에서 실행됩니다. 프레임에 대해서는 나중에 자세히 알아보겠습니다.

## 3. Start 함수 편집

Q&A (0)

**1.**Start 함수의 두 {} 괄호 사이에 다음 코드를 추가합니다.

```csharp
Debug.Log("Hello World");
```

[Image: image]

**2.**Ctrl+S(Windows) 또는 Cmd+S(Mac) 키를 사용하여 스크립트를 저장합니다.

**3.**Unity 에디터에 콘솔 창이 표시되지 않는 경우 Ctrl+Shift+C(Windows) 또는 Cmd+Shift+C(Mac)를 사용하여 엽니다. **콘솔 창**에서는 스크립트가 실행될 때 스크립트에서 발생하는 오류 및 경고 등의 메시지를 읽을 수 있습니다.

**4.**게임을 플레이하면서 콘솔 창을 살펴봅니다. 콘솔 창에 'Hello World'라는 메시지가 표시됩니다.

## 4. Update 함수 편집

Q&A (0)

**1.**스크립트를 다시 열고 Debug.Log 라인을 Update 함수로 옮깁니다.

[Image: image]

**2.**Ctrl+S(Windows) 또는 Cmd+S(Mac) 키를 사용하여 스크립트를 저장합니다.

**3.**콘솔 창에서 **Collapse** 옵션을 선택합니다(아직 선택하지 않은 경우). 이 옵션을 선택하면 다음 단계가 진행되는 동안 디스플레이가 간소화됩니다.

**4.**게임을 플레이하면서 콘솔 창을 살펴봅니다. 이번에는 'Hello World' 메시지 옆에 카운터가 나타납니다. 이 카운터는 스크립트가 실행되고 메시지가 표시된 횟수를 나타냅니다.

[Image: image]

이제 스크립트가 Update 함수의 내부에 있으므로 게임의 각 프레임마다 스크립트가 한 번씩 실행됩니다. **프레임**은 영화 필름의 프레임과 같이 화면에 움직임을 만들어 내는 일련의 단일 이미지입니다. **Play**버튼을 누르고 게임 뷰에서 게임을 보면 Update 함수가 여러 번 계속해서 실행되고 있습니다.

## 5. 변수를 사용하여 프로퍼티 추가

Q&A (0)

스크립터블 컴포넌트의 개념을 설명하기 위해 스크립트에 변수를 추가하고 인스펙터 창에서 해당 값을 변경해 보겠습니다. **변수**는 변할 수 있는 값을 담고 있습니다. 가장 많이 접할 유형의 값으로는 int(정수), float(부동 소수점 숫자, 즉 소수점이 포함될 수 있는 숫자), string(텍스트) 및 Boolean(true 또는 false 값) 등이 있습니다. 앞서 사용했던 Transform 컴포넌트에서 스케일 X, Y 및 Z에 대한 플로트 값이 변수에 해당됩니다. 이 스크립트에서는 'Hello, World!' 메시지를 인스펙터 창에서 HelloWorld 컴포넌트를 통해 변경할 수 있는 문자열 변수로 대체할 것입니다. 이 변수를 통해 게임 오브젝트는 Unity 에디터에서 조작할 수 있는 프로퍼티를 갖게 됩니다.

**1.**Visual Studio에서 스크립트를 다시 엽니다.

**2.**아래와 같이 새 변수를 추가합니다.

```csharp
public string myMessage;
```

**3.**다음과 같이 Debug.Log 커맨드를 변경합니다.

```csharp
Debug.Log(myMessage);
```

[Image: image]

**4.**스크립트를 저장합니다(Ctrl+S/Cmd+S).

**5.**Unity 에디터에서 ScriptObject 게임 오브젝트를 선택한 다음 인스펙터에서 HelloWorld 컴포넌트를 봅니다. 커스텀 메시지를 입력할 수 있는 새 프로퍼티가 나타납니다.

[Image: image]

원하는 메시지를 입력하세요.

**6.**게임을 실행하고 콘솔 창을 확인합니다. 이제 커스텀 메시지가 나타납니다.
