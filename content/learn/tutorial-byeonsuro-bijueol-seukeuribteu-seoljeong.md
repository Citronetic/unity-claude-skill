[Image: 변수로 비주얼 스크립트 설정]Summary

변수는 프로그래밍 툴에 필수적입니다. 변수를 사용하면 스크립트 유닛에 대한 입력 값의 저장과 계산, 조작 등이 가능합니다.

이 튜토리얼에서는 비주얼 스크립팅을 사용하여 범위와 용도가 다른 여러 종류의 변수를 만들고 관리하는 방법을 알아보겠습니다. 이 튜토리얼에서 배울 내용은 다음과 같습니다.

- 그래프, 오브젝트, 씬 변수 생성 및 용도 설명
- 블랙보드를 사용하여 그래프에 'Get Variable' 유닛 추가
- 인스펙터 창에서 변수를 변경할 수 있도록 설정
- 씬과 게임 뷰에서 변수 값 조정 문제 해결
- 비주얼 스크립트로 프로젝트의 계층 구조에 나타나는 씬 변수 오브젝트 설명

## 2. 블랙보드에서 변수 생성

Q&A (0)

블랙보드에서는 여러 유형의 변수를 정리할 수 있습니다. 이 튜토리얼에서는 제작한 그래프와 큐브 게임 오브젝트, 씬 등과 관련된 변수만 사용하지만 전체 프로젝트에 변수를 적용할 수도 있습니다.

**그래프 변수**로 시작하겠습니다. 해당 변수가 정의된 그래프에만 관련된 변수입니다.

**C#  스크립트 사용자 참고 사항:**그래프 변수는 C#  스크립트의 private 변수와 같습니다. 하지만 비주얼 스크립팅을 사용하면 C#  코드에 없는 그래프 변수 값을 유연하게 실험할 수 있습니다.

이제 새로운 그래프 변수를 만들어 보겠습니다.

**1.**Transform:Rotate 유닛에서 세 값을 모두 다시 0으로 바꿉니다.

**2.**Blackboard에서 **Graph**탭을 선택합니다.

**3. (New Variable Name)** 프롬프트에 XRotate를 입력하고 **+** 버튼을 선택합니다. 그러면 **Type** 및 **Value** 필드가 새로 나타납니다.

**4. Type**에서 **Float**(부동 소수점 숫자 또는 소수)를 선택합니다.

**5. Value**에는 **1**을 입력합니다.

**6.**XRotate의 정의 왼쪽에서 이중 바 기호를 찾고, 해당 기호를 그래프로 드래그합니다. 그러면 'Graph'와 같은 변수가 선택된 Get Variable 유닛이 생성됩니다.

## 3. 오브젝트 유형

Q&A (0)

이제 **오브젝트 유형**에 대해 설명하겠습니다. 변수를 생성할 때 이 드롭다운 목록에서 **Type**을 지정하라는 메시지가 나타납니다.

[Image: image]

다음은 자주 사용하는 오브젝트 유형입니다.

- Float: 23.456 또는 -0.9와 같은 소수
- Integer: 23 또는 -1과 같은 정수
- Boolean: 참 또는 거짓
- String: 'hello, world!'와 같은 일련의 영숫자 문자
- Vector3: 3D 공간에서 작업할 때 필요한 X, Y, Z 3개의 부동 소수점 세트
- Vector2: 2D 공간에서 작업할 때 필요한 2개의 부동 소수점 X, Y 세트
- GameObject: 씬의 오브젝트

위 드롭다운에 표시된 아이콘은 각 오브젝트 유형을 의미합니다. Transform:Rotate와 같이 입력이 필요한 유닛의 경우 위 메뉴에 나와 있는 표시기로 오브젝트 유형을 지정하면 됩니다.

일반적으로 정확한 오브젝트 유형을 제공하는 것이 중요합니다. 예를 들어, 유닛이 참 또는 거짓인지 여부를 찾는 상황에서 숫자를 제공한다면 오류나 예기치 않은 결과가 발생할 수 있습니다.

하지만 비주얼 스크립팅은 다른 스크립팅 언어만큼 오브젝트 유형에 대해 엄격하지 않습니다. 예를 들어 Float와 Integer는 모두 파란색 점을 사용하고 있는데, 비주얼 스크립팅에서 이러한 유형은 서로 바꿔 사용할 수 있습니다. 대부분의 다른 프로그래밍 언어에서는 서로 바꿔 사용하면 오류가 발생합니다.

초록색 점이 보이면 비주얼 스크립팅은 둘 이상의 데이터 유형을 허용하고 가능한 경우에는 전환을 적용합니다.

[오브젝트 유형에 대한 보다 포괄적인 목록과 설명은 Unity 매뉴얼에서 볼 수 있습니다.](https://www.google.com/url?q=https://docs.unity3d.com/Packages/com.unity.visualscripting@1.5/manual/vs-object-types.html&sa=D&source=editors&ust=1615469139963000&usg=AOvVaw2w2AlBehJNrrh3csT65U9a) 비주얼 스크립팅에서 볼 수 있는 다른 오브젝트 유형을 식별하려면 Graph Inspector를 사용해 보세요.

## 4. 그래프 변수 조작

Q&A (0)

이번에는 새로운 변수가 작동하는 방식과 더불어 해당 변수의 값을 변경하면 어떻게 되는지 알아보겠습니다.

**1. 플레이** 버튼을 선택하고 큐브가 X 차원을 기준으로 회전하는 것을 확인합니다.

**2.**Graph 창 상단의 메뉴에서 **Values**버튼을 활성화합니다. 그러면 커넥터에 오브젝트 유형 표시기와 변수 값이 표시됩니다.

[Image: image]

**3.**블랙보드에서 **XRotate**값을 **3**으로 변경하고 변경 사항을 확인합니다. 커넥터에 3이 표시되고 큐브가 더 빨리 회전합니다.

**4.**플레이 모드를 종료합니다. **XRotate**의 값은 플레이 모드를 시작하기 전에 입력한 마지막 기본값인 **1**로 변경됩니다. 플레이 모드에서 변경된 변수 값은 기본값으로 다시 돌아오며, 플레이 모드에서는 변경된 인라인 값만 저장됩니다.

그래프 변수는 하나의 그래프 내에서 값을 조작해야 할 때 사용하기 좋습니다. 또한 그래프 변수는 다른 종류의 변수와 달리 다른 그래프에서 액세스할 수 없습니다. 이번 프로젝트의 뒷부분에서 이 그래프를 더 복잡하게 구현해 보고, 그래프 변수를 유용하게 활용하는 방법을 살펴보겠습니다.

## 5. 오브젝트 변수 생성

Q&A (0)

제작 중인 스크립트가 팀의 아티스트를 위한 것이라고 가정해 보겠습니다. 아티스트가 이 스크립트를 편집하지 않고 큐브의 회전을 제어할 수 있게 하려면 어떻게 해야 할까요? 오브젝트 변수를 사용하면 아티스트가 인스펙터에서 값을 변경할 수 있습니다. **오브젝트 변수**는 게임 오브젝트에 연결되며, 게임 오브젝트가 선택되면 인스펙터에서 변경할 수 있습니다.

**C#  스크립트 사용자 참고 사항:**오브젝트 변수는 C# 컴포넌트 스크립트의 public 변수와 같습니다.

오브젝트 변수를 생성해 보겠습니다.

**1.**Blackboard에서 **Object**탭을 선택합니다.

**2. (New Variable Name)** 프롬프트에 YRotate를 입력하고 **+** 버튼을 선택합니다. 그러면 **Type** 및 **Value** 필드가 새로 나타납니다.

**3. Type**에서 Float(부동 소수점 숫자 또는 소수)를 선택합니다.

**4. Value**에는 1을 입력합니다.

**5.**YRotate의 정의 왼쪽에서 이중 바 기호를 찾아서 그래프로 드래그합니다. 그러면 “Object”와 같은 변수가 선택된 Get Variable 유닛이 생성됩니다. 이 유닛은 Transform:Rotate 유닛과 마찬가지로 'Self'로 작동하여 이 스크립트가 연결된 모든 게임 오브젝트를 참조합니다.

**6.**새 유닛의 출력부를 Transform:Rotate 유닛의 **Y Angle** 입력부에 연결합니다.

## 6. 오브젝트 변수 조작

Q&A (0)

그래프 변수에서와 마찬가지로 오브젝트 변수의 값을 변경하고 어떤 결과가 발생하는지 보겠습니다.

**1.**씬 뷰에서 큐브를 선택하고 인스펙터 창을 확인합니다. 이름이 **Variables**인 섹션을 봅니다.

**2.**씬 뷰에 있는 동안 인스펙터에서 **YRotate** 값을 **3**으로 변경합니다. Blackboard(Object 탭)에서도 값이 변경되었음을 알 수 있습니다. Blackboard와 인스펙터에서 이 값은 항상 동일하게 표시됩니다.

**3.**플레이 버튼을 선택하고 큐브가 회전하는 것을 확인합니다.

**4.**플레이 모드에 있는 동안, 인스펙터에서 **YRotate** 값을 다시 **1**로 바꾸고 씬 뷰와 블랙보드의 변경 사항을 확인합니다.

**5.**플레이 모드를 종료합니다. 플레이 모드를 시작하기 전에 입력한 마지막 기본값은 3이므로 **YRotate**의 값이 다시 **3**으로 돌아옵니다.

**6.**저장합니다(Ctrl/Cmd + S키).

오브젝트 변수의 값은 씬 뷰와 게임 뷰에서 변경할 수 있지만, 씬 뷰에서 설정한 값은 유지되고 게임 뷰에서 변경한 내용은 사라집니다.

오브젝트 변수는 그래프가 아니라 게임 오브젝트에 '속한다'는 점을 꼭 기억하세요.

## 7. 하나의 그래프, 두 개의 게임 오브젝트

Q&A (0)

종합해서, 스크립트가 여러 게임 오브젝트에서 사용될 때 변수가 어떻게 작동하는지 자세히 살펴보겠습니다.

**1.**그래프에서 값을 아래와 같이 설정합니다.

- Blackboard의 **Graph**탭에서 XRotate를 0으로 설정합니다.
- Blackboard의 **Object**탭에서 YRotate를 0으로 설정합니다.
- 그래프의 Transform:Rotate 유닛에서 **Z Angle**을 **3**으로 설정합니다.

**2.**큐브를 복제합니다. 플레이 모드에서 두 큐브를 모두 볼 수 있도록 새 큐브의 위치를 메인 카메라 앞으로 지정합니다.

**3.**두 큐브를 구분하려면 샘플 씬과 함께 제공되는 머티리얼을 사용하여 서로 다른 컬러를 지정합니다. 여기서는 기존 큐브에 Plastic_Yellow_Mat를 사용하고 새 큐브에 Plastic_WhiteMat를 사용했습니다(**Assets**> **ExampleAssets**> **Materials** 폴더). 그리고 각각 Cube1 및 Cube2로 이름을 변경했습니다.

[Image: image]

**4.**두 큐브 게임 오브젝트는 모두 Rotate라는 이름의 동일한 그래프를 사용합니다. 또한 두 게임 오브젝트 모두 YRotate 변수가 적용됩니다.

**5.**큐브 중 하나에서(둘 다는 아님) **YRotate** 값을 변경합니다.

**6.**플레이 모드를 실행하고, 한 큐브를 선택한 다음 다른 큐브를 선택하며 그래프를 살펴봅니다. 같은 그래프이지만 각 게임 오브젝트에 고유한 YRotate 변수가 있어서 Y Angle에 대한 커넥터에 다른 값이 적용됨을 알 수 있습니다. 커넥터에 기호와 숫자가 표시되지 않으면 **Values** 버튼을 활성화합니다. 인스펙터 또는 Blackboard의 **Object**탭에서 **YRotate** 값을 변경하며 테스트해 보세요.

**7.**플레이 모드를 실행한 상태로, Blackboard의 **Graph**탭에서 **XRotate** 값을 변경하며 테스트합니다. 각 큐브에 다른 XRotate 값을 적용할 수 없는 이유는 각 게임 오브젝트에 대해 별도의 그래프 **인스턴스**가 실행되기 때문입니다.

**8.**플레이 모드를 종료하면 그래프에 하드 코딩된 Z Angle 값을 변경한 경우를 제외하고 모든 값이 다시 기본값으로 바뀝니다.

이 연습의 목적은 변수 값으로 실험하는 방법을 직접 실행해 보고, 해당 결과가 발생한 이유를 설명하는 것입니다.

- 그래프 변수는 그래프에 속합니다. Blackboard에서는 기본 값을 설정했습니다. 플레이 모드에서는 프로젝트를 플레이할 때 별도의 인스턴스가 실행되고, 각 게임 오브젝트에 대해 별도로 그래프 변수의 기본값을 일시적으로 바꿀 수 있습니다.
- 오브젝트 변수는 게임 오브젝트에 속합니다. 씬 뷰에서 각 게임 오브젝트에 대해 다른 기본값을 설정하고, 플레이 모드에서 이러한 값을 일시적으로 바꿀 수 있습니다.

## 8. 변수 테스트

직접 연습하면서 비주얼 스크립팅의 변수에 대해 얼마나 알고 있는지 테스트해 보세요.

#### Z Angle 값에 대해 씬 변수 생성

**씬 변수**를 생성할 경우 다른 변수의 경우와 같이 Blackboard의 Scene 탭을 사용합니다. 그래프에서 Z Angle 프로퍼티를 제어하는 씬 변수를 생성하세요. 이미 아시겠지만 씬 변수는 씬에 속합니다.
