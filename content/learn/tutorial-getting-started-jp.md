**概要**

Unity をまだコンピューターにインストールされていない場合は、コースを始める前にまず Unity をインストールする必要があります。インストールに先立って、まだ Unity ID を持っていない場合は、同時に Unity ID の作成も行います。インストールするソフトウェアとしては、Unity のインストールとプロジェクトの管理を行う Unity Hub、Unity エンジン本体、それから、C# でコードを書くときに使う統合開発環境（IDE）である Visual Studio があります。

**このプロジェクトの到達点**

Unity Hub、Unity Editor、Visual Studio がコンピューターにインストールされていること。

## 2. Unity Hub のダウンロードとインストール

Q&A (0)

*コンピューター上で最も効率よく Unity をダウンロード、インストール、管理を行うには、Unity Hub と呼ばれるものを使います。*

1. ブラウザーの新しいタブで、「Unity Hub をダウンロード」と検索してヒットするページを開くか、直接 [https://unity3d.com/jp/get-unity/download](https://unity3d.com/jp/get-unity/download?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774956095085) にアクセスします。開いたページで「**Unity Hub をダウンロード**」をクリックします。
2. ダウンロード先のフォルダーで、**Unity Hub のセットアップ**ファイルを**ダブルクリック**して、インストールを開始します。 （**Mac** の場合、アプリケーション（Applications）フォルダーにドラッグして、ダブルクリックします）
3. Unity のサービス利用規約に同意し、説明にしたがって Unity Hub をインストールします。
4. Unity Hub を**開き**、左側にある**プロジェクト、使い方を学ぶ、インストール**タブをクリックします。

## 3. 新しいバージョンの Unity をインストールする

Q&A (0)

*Unity Hub がインストールされたので、新しいバージョンの Unity と、コードエディターの Visual Studio をインストールしましょう。*

**1.** **インストール**タブで、**インストール**ボタンをクリックして新しい Unity バージョンを追加します

**2.**「**2020.3～**」となっているバージョンから選択して（より古いバージョンを使う場合は、2019.4～または 2018.4～ のバージョンを選択してください）、次へをクリックします。LTS とは「長期サポート」の意味で、これが付いているバージョンは 2 年間サポートされる安定バージョンの Unity です

[Image: image]

**3. モジュールをインストールに加える**画面で、**Visual Studio**（Mac または PC 版）を選択します。
これはコードを編集するために使うソフトウェアです。すでに Visual Studio がインストールされている場合は、この画面に Visual Studio をインストールするオプションは表示されません

[Image: image]

**4.**利用規約に同意して、インストールを開始します

[Image: image]ステップを完了としてマーク

## 4. Unity ID にサインイン、または新しい Unity ID を作成する

Q&A (0)

*Unity アセットストアをはじめとした重要な Unity サービスを利用するには、Unity ID でサインインする必要があります。*

1. Unity Hub の**アカウント**メニューの**サインイン**をクリックします
2. すでに Unity ID アカウントをお持ちの場合は**サインイン**を選択してください。Unity ID アカウントをお持ちでない場合は、**Google** または **Facebook** でサインインしていただくか、**新しく Unity ID を作成**してください。
