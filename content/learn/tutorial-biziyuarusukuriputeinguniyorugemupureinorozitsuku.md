スクリプティングはロジックがすべてです。論理的なシーケンスを考案し、そのシーケンスをスクリプトにコーディングします。このチュートリアルでは、このゲームに欠かせないスクリプト化されたオブジェクトである「ドア」から始めて、その開閉を行うための論理的なシーケンスを説明します。

このチュートリアルの主な目的は、これらの論理的シーケンスを自分でコーディングできるようにすることです。ステップバイステップで説明していますので、必要に応じて従ったり、読み飛ばしたりしてください。

このチュートリアルを終える頃には、以下のことができるようになっています：

- Script Machine のビジュアルスクリプトを置き換える
- Boolean 値と分岐をビジュアルスクリプトに適用する
- ビジュアルスクリプトで変数の値を取得して設定する
- 既存のイベントをビジュアルスクリプトに適用する
- スーパーユニットをビジュアルスクリプトに適用する。
- 望ましい結果が得られたら、適切なビジュアルスクリプトをコーディングする

## 1. 概要

Q&A (0)

ビジュアルスクリプティングであれ、C# であれ、Unity でのスクリプティングは、Unity プロジェクトでのゲームプレイを可能にします。スクリプトでは、プロジェクトの論理構造を作成します。このチュートリアルでは、クライブがドアを開けるような簡単なゲームプレイの仕組みのロジックを作り、そのロジックをビジュアルスクリプトで適用します。

## 2. このゲームでのスクリプト化されたイベント

Q&A (0)

このプロトタイプには、C# で書かれたいくつかのスクリプト化されたイベントが含まれており、これらを使ってゲーム内で動くオブジェクトをチェックしたり制御したりします。これらを暗記する必要はありませんが、名前で仕組みを理解しておけば、これらのチュートリアルを通して、使い方を理解することができます。

#### セルのゲームオブジェクトに発生するイベント

このゲームは、1x1 のセルのグリッドで構成されています。グリッドの各セルでは、ねこのクライブや彼の木箱などの動くゲームオブジェクトが、そのセルに入ったり出たりすると、以下のようなイベントが発生します：

- **Want To Enter Cell** は、動いているゲームオブジェクトがセルの中に入りたいと思った時に発生するイベントです。このイベントは、そのオブジェクトが入ることを許可するかどうかを決定するスクリプトで使用できます。
- **Enter Cell** は、動いているゲームオブジェクトがセルの中に入りたいと思った時に発生するイベントです。このイベントは、そのオブジェクトが入ることを許可するかどうかを決定するスクリプトで使用できます。
- **Want To Exit Cell** は、動いているゲームオブジェクトがセルから出ようとした時に発生します。このイベントを利用して、そのオブジェクトが退出できるかどうかを判断することができます。
- **Exit Cell** は、動いているゲームオブジェクトがセルから出た時にトリガーされます。このイベントを利用して、次に何が起こるかを決めることができます。

#### エッジゲームオブジェクトのイベント

ドアなどのオブジェクトがこれらのイベントのトリガーとなります：

- **Want To Cross Edge** は、動いているゲームオブジェクトがエッジを通り抜けようとしたり、越えようとした時に発生します。このイベントを利用して、そのオブジェクトの横断が許可されているかどうかを判断することができます。
- **Crossing Edge** は、動いているゲームオブジェクトがエッジを越えた時にトリガーされます。このイベントを利用して、次に何が起こるかを決めることができます。

## 3.  閉じられたドアのスクリプトのチェック

Q&A (0)

最初のドアを制御するビジュアルスクリプトを見て、何が起こっているのかを確認してみましょう。

**1. ObjectRoot**> **FirstDoor**と選択します。

**2.**Inspector で、AnimAndFX スクリプトの入った Script Machine コンポーネントを削除します（このスクリプトのテストは終了です）。Component セクションの 3つのドットを選択して、**Remove Component**を選択します。

**3.**残りの Script Machine コンポーネントには、**BaseDoorScript**というビジュアルスクリプトがアタッチされています。このスクリプトは複数のドアにアタッチされていますので、編集しないでください。 代わりに、Project ウィンドウで BaseDoorScript を選択し、Ctrl+D / Cmd+D を押して複製します。

**4.**複製した**FirstDoorScript** の名前を変更します。

**5.**FirstDoorScript を Script Machine の **Graph**プロパティにドラッグし、BaseDoorScript を置き換えます。

**6. Edit Graph** ボタンを選択します。

**7.**Script Graph ウィンドウの Value ボタンを有効にします。

Script Graph ウィンドウは、下の画像のようになります。

[Image: image]

**8.**Script Graph ウィンドウを開いた状態でこのレベルを再生してください。クライブがスタートした部屋の右側にあるドアからクライブを動かしてみましょう。通過できないことがわかり、試すたびにこのスクリプトが実行されるのがわかります。

**9.**Graph で何が起こっているかを確認するには、Want To Cross Edge ユニットを選択して、Graph Inspector を見ます。このユニットの出力は **Moving Object**と呼ばれるオブジェクトで、C# コードではユーザーがこのエッジを越えて移動させたいゲームオブジェクトとして定義されています。

**10.**Cancel Movement ユニットを選択します。これは、入力された Moving Object に作用して、その移動を停止させる C# ユニット（コーダーの皆さんにとってはメソッド）です。

つまり、クライブがこのエッジを越えようとすると、その動きはキャンセルされます。このドアはロックされています。

## 4. クライブをドアから通す

Q&A (0)

変数を使って、このドアのロックを解除してみましょう。IsOpen という名前のオブジェクト変数を使って、ドアが開いているかどうかを指定し、Inspector でその値を制御します。スクリプトは次のように動作します：

クライブがドアを通り抜けたいと思ったら：

- ドアが開いている場合は、クライブに普通に進めさせます（何もしない）。
- ドアが閉まっている場合は、クライブの動きをキャンセルします。

この流れを自分で作ってみましょう。必要に応じて、次のステップの画像を使って自分の作業を確認してください。作業内容は必ず保存 (**Ctrl + S** / **Cmd + S**) してください。

次に Play モードに入り、ビジュアルスクリプトをテストします。Inspector のオブジェクト変数設定を使って、IsOpen  変数の値を変更します (その後、Game ビューウィンドウを選択してゲームにフォーカスを戻します)。

IsOpen が True の場合、クライブは鉄製ドアをすぐに飛び越えます。これは理想的ではありませんが、スタート地点です！

## 5. クライブをドアから通してあげる（手順）

Q&A (0)

ここでは、クライブを最初のドアから通すための手順を説明します：

**1.**Type が Boolean、Value が False（チェックされていない）の IsOpen という名前の Object 変数を作成します。

**2.**Blackboard の Object タブにある IsOpen 変数をスクリプトにドラッグして、Get Variable ユニットを作成します。

**3.**IsOpen が True かどうかを確認するために、If ユニットを追加し、Get Variable から If ユニットの入力へのコネクタを追加します。

**4.**Want To Cross Edge ユニットから Cancel Movement ユニットへのフローコネクタ（矢印）を外し、代わりに Want To Cross Edge から If ユニットへの接続を行います。

**5.**Moving Object のデータ出力コネクタ (dots) を Want To Cross Edge ユニットから Cancel Movement ユニットにつなぎます ー これは Cancel Movement にどのゲームオブジェクトの動きをキャンセルするかを伝えるものです。

**6.**If ユニットの False フロー出力から Cancel Movement ユニットへのフローを継続します。

**7.**この場合は何も起こらない（動作がキャンセルされない）ので、If ユニットの True 出力からのフローを接続しないでください。

**8.** 作業内容を保存 (**Ctrl + S / Cmd + S**) します。

## 7. クライブにドアを開けさせよう（手順）

Q&A (0)

クライブにドアを開けさせるためのステップバイステップの手順は以下のとおり：

**1.**Set Object Variable ユニットを追加し、IsOpen という変数を指定します。

**2.**Cancel Movement から Set Variable へのフローをつなぎます。

**3.**Boolean リテラルオブジェクトを追加し、チェックボックスにチェックを入れて値 True を作成します。

**4.**その Boolean 値を Set Variable 入力に接続します。

**5.** 作業内容を保存 (**Ctrl + S / Cmd + S**) します。
