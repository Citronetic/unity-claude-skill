## 1. Authentication

Q&A (0)

#### Do you want to create a smooth personalized user experience in your app or game?

To do this, you need to do is be able to identify and remember a user and what they have done. Having a user sign-in and be authenticated allows Unity products and Unity games to capture user information. This allows for:

1. A means to identify a player and store player game data (for example, saving game state and recording in-app purchases)
2. Consistent game experiences for the player (for example, points for leaderboards and suggested in-app purchases)
3. Insight about the player’s game behavior across multiple devices
4. Multiplayer features on various platforms

Unity Authentication provides anonymous and platform-specific authentication to allow you to create this seamless experience.

[Image: image]

Anonymous authentication is commonly used to allow users to try out a Unity application or game without having to go through the hassle of creating an account or logging in. Once set up anonymous authentication will happen automatically.

The disadvantage is that this authentication will not work across platforms so the user will have to use the same device if they are to be recognized a second time.

[Image: image]

Platform-specific authentication is a feature that allows users to log into a Unity application using their credentials from a specific platform, such as Google, Facebook, Steam or Apple. This method will allow you to use the user's data across multiple platforms to allow for a seamless experience.

#### **Pro Tip**

Use anonymous authentication at first to get users engaged without any sign-in barrier. Then encourage them to move to platform-specific authentication.
