## 1. Descripción general

Q&A (0)

El sistema de componentes de entidad (ECS) es parte de la nueva pila de tecnología basada en datos (DOTS) y representa una forma completamente nueva de pensar en la programación.

En este nuevo marco, en lugar de estar estructurado con base en objetos (p. ej., Enemy, Obstacle) o componentes (p. ej., MoveForward, DestroyOnCollision), el código se estructura con base en piezas claves de datos (p. ej., MoveSpeed, PlayerHealth).

El beneficio de este nuevo sistema es que permite una extrema mejora del rendimiento y la optimización que antes se consideraba imposible.

## 3. Resumen

Q&A (0)

En este tutorial aprendiste:

- El propósito de DOTS y ECS.
- La diferencia entre el diseño orientado a datos y el diseño orientado a objetos y componentes.
- Cómo reconocer una clase que utiliza ECS:

- Utiliza diferentes declaraciones «using» (p. ej., using Unity.Entities;).
- Hereda elementos de clases además de Monobehaviour (p. ej., JobComponentSystem).
- La estructuración del código alrededor de los datos (p. ej., MoveSpeed) en lugar de con base en objetos o componentes.
