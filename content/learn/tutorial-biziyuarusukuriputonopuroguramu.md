## 2. Start 関数と Update 関数

Q&A (0)

Script Machine コンポーネントの **New** ボタンを使ったので、Start イベントと Update イベントはすでに Graph に含まれています (C# を使って新しいスクリプトコンポーネントを作成すると、同じように Start メソッドと Update メソッドが含まれます)。

[Image: image]

グラフの各 Rectangle ノードを**ユニット**(**unit**)****と呼びます。ユニットとは、命令やイベント（何かが起こること）のことです。ユニットがノードと呼ばれることもあります。

このチュートリアルでは、Play モードで発生したフレーム（画面更新）ごとにトリガー（実行）される Update イベントを扱います。Graph は、フレームごとに一定の角度でキューブを回転させます。

Start イベントは、Play モードが開始されると一度だけトリガーされます。このチュートリアルのビジュアルスクリプトではこのイベントを使用しません。Start ユニットを選択し、Delete キーを押して削除します。

## 3. Fuzzy Finder の表示

Q&A (0)

Graph にユニットを追加するには、Graph ウィンドウの背景を右クリックします。**Unit**コンテキストメニュー（通称：**Fuzzy Finder**）が表示されます。

[Image: image]

**Fuzzy Finder**は、Unity Scripting API 全体を含む、あらゆるタイプのユニットを含むマルチレベルのメニューです！Fuzzy Finder では、任意のユニットを名前で検索したり、カテゴリーに基づいて選択したりすることができます。

## 4. 必要なユニットを探す

Q&A (0)

必要なユニットを見つけるには、Unity API にある程度精通している必要がありますが、経験を積むことでその精通度は高まります。このタスクでは、必要なユニットは「Transform.Rotate」と呼ばれます。

Fuzzy Finder の検索バーに「rotate」と入力します。

[Image: image]

いくつかの「Transform:Rotate」ユニットの中から選ぶことができます。これを**オーバーロード**と呼びます。同じユニットの各オーバーロードは同じことを行いますが、それぞれが異なる入力パラメーターのセットを必要とします。この演習では、**Transform: Rotate (X Angle, Y angle, Z angle)**を選択します。このユニットは、ゲームオブジェクトの Transform コンポーネントの Rotate 設定を制御します。

## 5. ユニットの検証

Q&A (0)

この新しいユニットをじっくりと見てみましょう。ユニットを選択すると、そのユニットを検証することができます。

[Image: image]

- このユニットのヘッダーはグレーで、命令であることを示しています（グラフの中でユニットを識別するために、他にもいくつかの色が表示されています）。
- 赤、青、緑 の Rotate シンボルは、あなたや他の人がグラフを解釈するのに役立つ数多くのユニットインジケーターの一つです。
- **Self**は、このユニットが Machine を介して、このグラフにアタッチされたゲームオブジェクトを制御することを意味します。
- **フロー矢印**は、ユニットからユニットへのフローの順番を示しています。すぐにこれらをつなげて、グラフが実行される順序を示します。
- ユニットの左側にある丸いものが**入力**です。また、他のユニットの右側にも丸がありますが、これは**出力**です。これらは、ユニットからユニットへと値やオブジェクトを移動させるために使われます。

X アングル、Y アングル、Z アングルの横にある記号は、各入力の**オブジェクト型**の**インジケーター**です。このケースでは、青い点は浮動小数点数を表しています (オブジェクト型については後ほど説明します）。

## 7. ユニットの設定

Q&A (0)

ユニットがまだ作業フローに接続されていないときは、選択されていない限り、グレー表示されます。この機能は、**Dim** ボタンのオン / オフで制御できます。

[Image: image]

Update ユニットの右側にあるフロー矢印を Rotate ユニットの左側にあるフロー矢印にドラッグして、Transform:Rotate ユニットをこの Graph のフローに接続します。入力の上に薄い青い四角形が表示されるので、その四角形の中のどこかに矢印をドロップします。

フロー矢印を削除するには、コネクターの始点 (左端) を右クリックします。

[Image: image]

これで、完全なビジュアルスクリプトのユニットが揃いました！イベントで始まり、イベントが発生したときに実行される命令で終わります。

**Play** ボタンを選択すると、ビジュアルスクリプトが実行されます。

Graph ウィンドウでは、コネクタに沿ってビーズが動き、フローを示しています。なぜなら、Transform:Rotate ユニットの 0 の値を変更して、どれだけ回転させるかを指示していないからです。

## 8. グラフ内のインライン値の変更

Q&A (0)

キューブを回転させるには、ユニット自体の入力フィールドである **inline**(インライン)****の**値**を変更する方法があります。

**1.**Play モードを終了します。

**2.**Transform:Rotate ユニットの **X Angle**と書かれた inline の値を **1**に変更します。

**3.**再び Play モードを開始します。キューブはフレーム毎に 1 度ずつ、X 次元で回転します。

**4.**Play モードの状態で、**X Angle**の値を 3 に変更し、さらに**Y Angle**、**Z Angle**の値を望む結果になるまで変更していきます。

**5.**3 つの値が変更された状態で、Play モードを終了します。設定した値はユニットに残ります。

シーンを保存 (Ctrl / Cmd S) します。Scene ファイルと、シーンで使用されたグラフの .asset ファイルが保存されます。

これが C# スクリプトであれば、キューブの回転に必要な値を見つけるまで、再生、停止、スクリプトの編集を繰り返す必要がありました。C# のスクリプティングでは、実行中にコードを編集することはできませんが、Visual Scripting では可能です。

C# でスクリプトを書いたことがある方は、コード内で値を直接指定すると、その値が「ハードコード」されてしまうことをご存知でしょう。ここでは、Transform:Rotate ユニットのハードコードされた値を変更しています。
