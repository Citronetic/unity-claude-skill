- リアルタイムプロジェクトに見られる主なオーディオの種類を説明する。

## 1. 概要

Q&A (0)

オーディオは、インタラクティブな開発において最も見落とされがちな要素のひとつですが、下手をするとユーザーの没入感を損ねたり、最悪の場合、完全に忘れられてしまう可能性があるもののひとつでもあるのです。聴覚に障害がある場合、音はあなたの一挙手一投足についてきますし、あなたが意識しているかどうかにかかわらず、あらゆる環境の一部となっています。私たちは、この無意識の期待をインタラクティブな体験の中に取り込み、何かが正しく聞こえるか、間違って聞こえるかを即座に判断することができるのです。

このプロジェクトでは、オーディオエフェクトを使って、シーンに命を吹き込みます。オーディオのさまざまな表現方法を学び、アンビエントサウンドやイベントベースのサウンドを実装します。また、オーディオに関するアクセシビリティへの考慮点やクローズドキャプションを導入することで、より包括的な体験を構築する方法についても学びます。

このプロジェクトの終了時には、基本的なオーディオエフェクトをプロジェクトに実装するために必要なすべてのスキルが身に付いています。

## 2. はじめる前に

Q&A (0)

#### Unity は初めてですか。

Unity を初めてお使いになる方、ようこそ！[**Unity Essentials ラーニングパスウェイ**](https://learn.unity.com/pathway/unity-essentials)は、Unity エディターで制作するためのセットアップと準備を支援するために設計されています。「Creative Core：オーディオ」に進まれる前に、このパスウェイを完了させることをお勧めします。

#### Unity Hub のアップデート

Unity プロジェクトのセットアップを開始する前に、Unity Hub を最新リリースに更新することを検討してください。旧バージョンの Hub をお使いの場合、提供されている手引きとご自身の体験に違いがある可能性があります。

#### Unity エディターの基本をおさらい

Unity エディターの基本的な知識を再確認したい場合は、いつでも [**Explore the Unity Editor**](https://learn.unity.com/tutorial/explore-the-unity-editor-1) を見直すことができます。

#### Unity プロジェクトの設定

Unity プロジェクトの設定に関する手順：

**1.**  [**Unity 2020.3 LTS**](https://learn.unity.com/tutorial/project-setup-processes#60ed7a3fedbc2a001f71f1aa) をインストールします（インストールしていない場合）

**2.** この学習体験のための[プロジェクト](https://connect-prd-cdn.unity.com/20211207/4165ef46-d1c1-4b80-89ea-3718eb49f3cc/CC_Cameras.zip?_ga=2.5672055.536878422.1638785511-1816326788.1628512656)をダウンロードします。

**3.**  コンピューター上の適当な場所を特定し、そこにプロジェクトフォルダーを解凍してください。Unity のプロジェクトフォルダーを空の親フォルダーから削除します。

**4.**  [Unity プロジェクトを Unity Hub へ追加](https://learn.unity.com/tutorial/project-setup-processes#60ed7a5aedbc2a002520b6ea)します。

**5.**  Unity Hub からプロジェクトを開きます。

**6.**  Unity エディターの Project ウィンドウで、Scenes フォルダーを探し、**Audio_Outdoor_Scene** を開きます。

**7.** コンピューターのシステムオーディオがオンで、快適な音量であることを確認します。

**8.**Unity の Game ビューで、右上の「Mute Audio」が選択されていないことを確認し、オーディオがミュートされていないことを確かめます。

[Image: image]

**9.** プレイテストを行います。

音声がないことは、エディターで作業しているときは必ずしも違和感がないのですが、今このシーンを公開すると、ユーザーは不完全燃焼のように感じてしまうでしょう。

**10.** Play モードを終了します。

これで、サウンドスケープの作成に取りかかる準備が整いました。

## 3. ようこそ！「Creative Core：オーディオ」の世界へ

Q&A (0)

#### 「Creative Core：オーディオ」の目指すところは？

この学習体験の目標は、Unity でインタラクティブな体験のためのオーディオを作成するために使用する中心となるツールを紹介することです。このプロジェクトで身につけたスキルは、自分のプロジェクトで魅力的なオーディオのサウンドスケープを作るのに役立ち、あらゆるクリエイティブな業界で応用が可能です。

#### この学習体験で何をするのか？

このチュートリアルを進めていくと、屋外シーンのための完全なサウンドスケープを最初に作成することができます。シーンにおけるオーディオのニーズを見極め、重要なサウンドソースを特定する方法を学びます。次に、イベントでオーディオをトリガーする方法を理解し、カスタマイズされたオーディオソースを作成する方法に進みます。サウンドスケープを構築しながら、環境のビジュアルを反映させるための様々なエフェクトを適用し、最終的にはオーディオのアクセシビリティを考慮したサウンドスケープを構築します。このプロジェクトでは、全く新しいシーンのために、ゼロから独自のオーディオのサウンドスケープを作成することで完成します。

#### 私の学習成果はどうなるの？

この学習体験が終わるころには、Unity の主要なオーディオコンポーネントをすべて使用できるようになり、ご自身のプロジェクトでさまざまな体験のためのオーディオエフェクトを自信をもって作成できるようになります。

これらのスキルを応用して、選択したガイド付きプロジェクトや自主プロジェクト（**Creative Core**パスウェイを完了した場合）、または Unity で作成したその他のプロトタイプのリアルタイム体験にオーディオを追加することができるようになります。

## 4. オーディオエンジニアの仕事とは？

Q&A (0)

#### バックグラウンド

オーディオエンジニアが扱う音には、大きく分けて **diegetic** (物語世界) と **non-diegetic** (非物語世界) の 2 種類があります。**Diegetic** サウンドは、体験の世界の中に存在する音で、キャラクターが話す音から、彼らがいる環境のアンビエントサウンドまで、あらゆるものが含まれます。**Non-diegetic** オーディオは、サウンドトラックのように、オーディエンスのために体験の上に追加されるものです。diegetic でも non-diegetic でも、オーディオエンジニアはインタラクティブな体験における音に関するすべての責任を負っています。音が出れば、オーディオエンジニアはそれについて知っています。

#### 役割

オーディオエンジニアは、体験の中ですべてが良い音で聞こえるようにする責任がありますが、その音がどこから来るのかについても責任があります。既存のサウンドライブラリを利用することも、ゼロから自分でエフェクトを作ることもできます。そのため、オーディオエンジニアはサウンドデザイン、特に音楽やフォーリー制作の経験を持っていることがほとんどです。

#### ツール

オーディオエンジニアは、Unity の他にも、サウンドエフェクトの制作や編集に他のソフトウェアを使用することが多いようです。これに含まれるものは：

- **[Wwise Spatial Audio](https://www.audiokinetic.com/products/wwise/)：**より高度な 空間的情報を備えたオーディオエフェクトのためのプラグインで、インディーズから AAA スタジオまで幅広く使用されています。
- **[Audacity](https://www.audacityteam.org/)：**オーディオエフェクトを録音および編集することができるオープンソースのオーディオアプリケーションです。特に、既存のサウンドにちょっとした編集を加えるのに便利です。
- **[Beepbox](https://www.beepbox.co/)：**楽器のメロディーを作成するための無料のオンラインツールです。

## 5. Unity のオーディオはどのように動作するの？

Q&A (0)

Unity のオーディオは、Audio Listener (オーディオリスナー) と Audio Source (オーディオソース) という 2 つのコンポーネントの相互作用がその核心となります。

[Image: image]

AudioListener (オーディオリスナー) は、インタラクティブな体験において、ユーザーの耳となります。リスナーは Passive コンポーネントなので、何も設定する必要がなく、カメラに自動的に含まれます。リスナーがカメラと結びつくのは、カメラがインタラクティブな体験におけるユーザーの目であり、ユーザーの耳と対になることに意味があるためです。オーディオリスナーがオーディオソースの範囲に入ると、オーディオソースは割り当てられたオーディオクリップを再生します。オーディオリスナーは 1 つのシーンに 1 つしか存在できないので、カメラを追加する場合は、リスナーを削除する必要があります。

オーディオソースは、Scene ビューでオーディオファイルを保持するコンポーネントです。オーディオソースは、オーディオリスナーがどのようにサウンドを認識するか、また、サウンドを聞くことができる範囲を定義します。シーン内のオーディオソースの数に制限はないので、音を出す必要のあるすべてのオブジェクトがオーディオソースを持つことができます。

## 7. どんな音がする？

Q&A (0)

もし、あなたが聴こえる人なら、本当の意味での静寂を体験することはないでしょう。無音室（音を出さないように開発された特殊な部屋）でも、やがて自分の心音や静脈を流れる血液の音まで聞こえるようになったと報告されています。

ただし、私たちはしばしば、完全な、あるいはそれに近い静寂を体験していると思っています。もしかしたら、あなたは今、無音だと思っている部屋でこれを読んでいるかもしれません。その理由は、私たちが重要でないと考えるノイズをフィルターにかける機能があるためです。これは自動的に起こることで、とても幸運なことです。私たちはとても騒がしい世界に住んでいるのですから！

下のオーディオクリップを聴いてみてください。晩秋の午後、静かな通りを散歩したときの短い記録です。

[Image: image]

どんな音が聞こえますか？静かな散歩は、実は静かではないのです。ここでは、さまざまな音に耳を傾けてみましょう：

- 足音
- 鳥の鳴き声
- 風
- 通り過ぎる車
- 風になびく金属製のフェンス
- 遠くのおしゃべり
- 近くの人の会話

オーディオデザインのスキルを向上させるには、時折、ノイズに耳を傾ける習慣をつけるとよいでしょう。誰もいない部屋はどんな音なのか？駅前はどうでしょう？夜の自宅の裏庭は？など

ではここで、あなたの周りの部屋の様子に耳を傾けてみてください。何が聞こえてきますか？たとえ静かな場所でも、最初は気づかなかった何かが聞こえてくるはずです。どこかで扇風機が回っていないか？壁の中のパイプはどうでしょう？外を走る車の音は聞こえますか？上空に飛行機は？

この瞬間に聞こえるものすべてをリストに書き出し、書いたものを振り返ってみてください。あなたが作成したリストは、あなたの環境に関する最初の考慮点と比較してどうでしょうか？静かだと思った人は、今もそう思っているのでしょうか？

新人オーディオデザイナーの場合、表面的な音だけで終わってしまうことがよくあります。より深く掘り下げ、どのような種類の音が環境に適しているかを見極めることで、より充実した、よりリアルな体験を生み出すことができるのです。

自由に動き回れる場所ではないのでしょうか？このアンビエントホームオフィスオーディオを学習のための参考としてお使いください！！
