[Image: 뷰어에서 실시간 동기화 사용하기]Summary

Unity Reflect는 CAD/BIM 애플리케이션과 실시간 연결(라이브 링크)을 유지하며 Reflect 뷰어는 애플리케이션 간의 실시간 업데이트를 지원합니다.

이 튜토리얼에서는 Unity Reflect가 제공하는 실시간 동기화 기능을 알아봅니다.

## 1. 소개

Q&A (0)

Reflect 뷰어의 라이브 링크 기능은 Revit에서 수정한 사항을 Reflect 뷰어에서 뷰 모드에 상관 없이 즉시 확인할 수 있게 해 줍니다. 이를 통해 다음 작업이 가능합니다.

- 클라이언트와 모델을 검토하면서 즉각적으로 디자인 반복 작업 진행
- 클릭 한 번으로 프로젝트의 여러 단계를 원활하게 검토

#### 시작 전에 준비할 사항

이 튜토리얼에는 다음이 필요합니다.

- Revit용 Reflect 플러그인
- 설치된 Reflect 뷰어
- Unity 계정
- 사용할 Unity 계정에 할당된 Reflect 프로젝트

## 3. 실시간 동기화가 작동하지 않는 경우

Q&A (0)

실시간 동기화가 작동하지 않는 경우가 있을 수 있습니다. 프로젝트를 Reflect 뷰어에서 열었을 때 Reflect 서버가 실행되고 있지 않으면 이런 현상이 발생합니다. 서버와 라이브 링크를 활성화하는 절차는 간단합니다.

**1.** Revit에서 프로젝트가 열려 있지 않은 경우 프로젝트를 엽니다. Unity 탭 아래에 표시되는 **Start**를 선택합니다(**그림 05**).

[Image: image]

**2.** Reflect 프로젝트 창에서 프로젝트를 선택하고 **EXPORT**를 클릭합니다(**그림 06**).

[Image: image]

**3.** Reflect 뷰어에서 프로젝트가 열려 있지 않은 경우 프로젝트를 열고 **새로 고침** 버튼을 클릭합니다(**그림** **07**).

[Image: image]

**4.** 이제 라이브 링크가 활성화될 것입니다. Revit에서 변경한 사항은 모두 Reflect 뷰어에서 즉시 동기화될 것입니다.

## 4. 다음 단계

Q&A (0)

이제 Unity Reflect가 제공하는 라이브 링크 기능을 어떻게 사용하는지 이해하셨을 것입니다. 이 기능을 워크플로에 적용하면 클라이언트와 원활하게 소통하며 디자인 피드백을 적용하고 반복 작업을 할 수 있으며, 변경 내용과 그 효과를 뷰어에서 실시간으로 보여줄 수 있습니다. 이렇게 하면 시간이 절약되어 디자인 검토 과정에서 보다 다양한 옵션을 확인해볼 수 있습니다.
