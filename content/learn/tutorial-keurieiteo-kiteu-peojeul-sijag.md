## 1. 개요

Q&A (0)

크리에이터 키트: 퍼즐에 오신 것을 환영합니다. Unity에서 물리를 사용하여 간단한 퍼즐을 만들고 가까운 친구들과 함께 즐겨 보세요. 코드를 작성할 필요가 없습니다. 구슬을 목적지까지 옮기기만 하면 됩니다. 참 쉽죠?

이 단계별 학습 프로젝트에서 배울 내용은 다음과 같습니다.

- Unity 에디터 인터페이스를 탐색합니다.
- 다양한 오브젝트와 장애물을 사용한 물리 기반 퍼즐을 디자인합니다.
- 게임플레이에 따라 레벨의 잠금을 해제하고 액세스하는 시퀀스를 생성합니다.

이 프로젝트를 완료하면 직접 제작한 게임을 친구들과 공유하고 원하는 대로 개선할 수 있습니다.

## 2. 시작하기 전에

Q&A (0)

#### Unity를 처음 사용하시나요?

이 학습 과정은 여러분이 Unity 에디터에 익숙하다는 가정하에 진행됩니다. Unity를 처음 사용한다면 [Unity 필수 과정 학습 길잡이](https://learn.unity.com/pathway/unity-essentials)를 통해 기초를 다지고 Unity 에디터에서 제작을 시작할 수 있습니다.

#### Unity Hub 업데이트

Unity 프로젝트 설정을 시작하기 전에 Unity Hub를 최신 릴리스로 업데이트하는 것이 좋습니다. 이전 버전의 Hub를 사용할 경우 제공된 지침과 실제 경험하는 내용에 차이가 있을 수 있습니다.

#### Unity 에디터 기초 확인

Unity 에디터의 기본 사항을 다시 확인하고 싶을 때는 언제든지 [**Unity 에디터 둘러보기**](https://learn.unity.com/tutorial/explore-the-unity-editor-1)를 살펴보세요.

#### Unity 프로젝트 설정

Unity 프로젝트를 설정하는 방법은 다음과 같습니다.

**1.**  **Unity Hub**를 엽니다.

**2.** [새로운 Unity 프로젝트](https://learn.unity.com/tutorial/project-setup-processes#60f6aedeedbc2a7e96802196)를 **주요 템플릿**(2D 또는 3D)을 통해 생성합니다.  임포트하는 패키지가 기본 템플릿 설정을 오버라이드할 것이므로 어떤 주요 템플릿을 선택해도 좋습니다.

**3.**  Unity 에셋 스토어의 [**Creator Kit: Puzzle** 에셋](https://assetstore.unity.com/packages/templates/tutorials/creator-kit-puzzle-149311)으로 이동합니다.

**4.** [에셋을 다운로드하고 Unity 프로젝트로 임포트합니다](https://learn.unity.com/tutorial/project-setup-processes#60ed7a86edbc2a002520b6f4).

## 3. 게임 테스트

Q&A (0)

이제 퍼즐을 시작할 준비가 되었습니다.

우선 예제 게임이 있는 씬을 엽니다.

**1.**프로젝트(Project) 창에서 *Assets/Creator Kit - Puzzle/Scenes/ExampleScenes*로 이동합니다.

**2.  ExampleMenu** 씬 아이콘을 더블 클릭합니다.

[Image: image]

**3.**씬이 열리면 게임을 테스트할 수 있습니다. 툴바에서 **플레이** 버튼을 클릭하여 시작합니다.

[Image: image]

다음과 같이 테스트할 수 있습니다.

- **스페이스바**를 눌러 인터랙티브 퍼즐 조각을 사용합니다.
- **R** 키를 눌러 레벨을 재시작합니다.
- 별을 충분히 모으면 새로운 레벨로 이동합니다.

[Image: image]

**4.**예제 게임 테스트를 마치면 플레이 버튼을 다시 클릭하여 플레이 모드를 종료합니다.

## 4. Unity 2019.1용 크리에이터 키트: 퍼즐 릴리스 노트

Q&A (0)

이 크리에이터 키트는 Unity의 최신 릴리스에 최적화되어 있습니다. 튜토리얼 진행 도중 기술적인 문제가 발생하면 포럼을 통해 알려 주세요.

이 크리에이터 키트에서 버그가 하나 발견되었습니다.

- 플레이 모드에서 처음으로 레벨 로드 시 메뉴를 통해 레벨에 액세스하는 경우 불이 꺼진 상태로 나타납니다. 로드와 플레이를 거치고 나면 메뉴를 통해 액세스해도 불이 꺼진 상태로 나타나지 않습니다.

이 문제는 게임의 빌드에 영향을 미치지 않으며 앞으로 출시될 버전의 Unity 에디터에서는 이미 수정되었습니다.
