### What are 2D DCCs?

2D Digital Content Creation tools (DCCs), such as Adobe [Photoshop](https://www.adobe.com/products/photoshop.html), [Illustrator](https://www.adobe.com/products/illustrator.html), [Substance Painter](https://www.substance3d.com/products/substance-painter/), and [Gimp](https://www.gimp.org/), allow artists to create textures, backgrounds, and user interface (UI) elements in two dimensions.

In these programs, artists **draw** or **paint** images as they would on paper; create **vector art** that can be scaled with no loss of quality; **edit** and **enhance**existing images with layers, filters, and effects; and **design** **interfaces** or layouts including menus, buttons and text.

### Other resources for 2D Assets in Unity

Unity has built-in tools specifically designed for working with 2D assets. For example, the [2D Tilemap Editor](https://docs.unity3d.com/Manual/class-Tilemap.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774955782883) helps quickly design 2D levels, and the [Sprite Editor](https://docs.unity3d.com/Manual/SpriteEditor.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774955782883) manages the various images (“Sprites”) that go into 2D animations. There are specialized systems for [2D physics](https://docs.unity3d.com/Manual/class-Physics2DManager.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774955782883), [2D lights](https://docs.unity3d.com/Packages/com.unity.render-pipelines.lightweight@6.7/manual/2DLightProperties.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774955782883), and a lot more.

## 5. Search the Asset Store

Q&A (0)

**1.**In the Asset store search tab, type “sprite” to search for available Sprite assets. All assets with the tag of “Sprite” appear.

[Image: image]

**2.**Use the checkbox on the right of the store screen to view only the free assets.

[Image: image]

**3.**From the search results, select the sprite collection of your choice.

**4.**When searching for an asset for your project, it is critical to make sure that the assets will be compatible with your version of Unity. Select a product to view its Details page, where you will see all the information about the asset, including the Unity version compatibility.

## 6. Download and import assets

Q&A (0)

**1.**Select **Add to My Assets** to begin the process of downloading the asset package you have chosen. From here, you can select **Go to My Assets** to view all the assets you have acquired in the Asset Store, or you can select **Open in Unity** to begin the import process immediately.

**2.**Continue the process of downloading and importing the asset package into your project. As needed, [review the process in the Introduction to 3D tutorial](https://learn.unity.com/tutorial/get-3d-assets#5fa60493edbc2a001f01b8fa).

**3.**When the import process is complete, select one of the new Sprites and drag it into your Scene.
