## 1. Light Up Your Scene

In this challenge, you will practice illuminating a car using Unity’s Lighting Engine. By completing this challenge, you will have a basic understanding of lighting a Unity Scene.

In this Scene, you will add several lights to simulate different lighting scenarios for the car. To do so, you will:

1. Add and configure a Directional light
2. Add and configure a Spotlight to simulate a streetlight or showroom light
3. Fill in the shadows by adding and configuring a Point light

## 2. Add and Configure a Directional Light

Q&A (0)[Image: image][Image: image]

1. Add a**Directional Light**to the Scene by clicking (**Create > Light > Directional Light**).
2. Use the **Rotate tool** or the **Transform component** in the Directional Light’s Inspector to rotate the light.
3. In the Directional Light’s Inspector window, change the Shadow Type from **None** to **Hard Shadows.**
4. Before moving on to the next step, rotate the Directional Light to point directly upwards to simulate night. This will allow us to focus on the Spotlight and explore its function.

--------------------

**Tip — Shadows**

To add a level of realism, change Shadow Type on the Directional Light to Hard Shadows in the Light component in the Inspector. (Note: We are using Hard Shadows to exemplify the shadow’s properties. To learn more about shadows, click [here](https://docs.unity3d.com/Manual/ShadowOverview.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774952424002).)

## 3. Add and Configure a Spotlight to Simulate a Streetlight or Showroom Light

Q&A (0)[Image: image]

1. Add a Spotlight to the Scene (**Create > Light > Spotlight**).
2. Position the Spotlight so that it's directly above the car and pointing straight down. Use the light’sTransform component to adjust its position, rotation, and scale.
3. Adjust the Spotlight’s parameters so that it illuminates the car. Start with the **Intensity**, then adjust the **Spot Angle**.

## 4. Fill in the Shadows by Adding and Configuring a Point Light

Q&A (0)

*Fill in the shadows on the driver side by adding a Point Light.*

[Image: image]

**1.** Create a Point Light (**Create > Light > Point Light**).

**2.** Position the light so that it fills in the shadows on the driver side using the Move tool or the Point Light’s Transform component.

**3.** Adjust the Point Light’s parameters to properly light the side of the car. Start with **Intensity**, then explore other color options.
