## 1. About game jams

Q&A (0)

Game jams, hackathons, application jams, whatever you want to call them are an incredible outlet for your students and you to test your skills that you've been developing. These events, generally run over 3 consecutive days or a weekend put learners in a timed/scoped activity to create a Minimum Viable Product (MVP) that the other participants can then play and give feedback on. These help build collaboration, project management, research and other important industry skills.

Unity runs the Create with Code Game Jam, and you can check all of the resources for the jam [**here.**](https://learn.unity.com/project/create-with-code-game-jam)

Below you'll find some videos that were made to help support a game jam that you can use.
