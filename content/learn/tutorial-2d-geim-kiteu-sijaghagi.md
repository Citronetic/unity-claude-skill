**2.** 창 왼쪽의 **Learn** 탭을 선택합니다.

## 3. 중요: Unity 프로젝트를 저장할 수 없는 경우

Q&A (0)

**참고:** 현재 일부 사용자에게 Hub를 통해 다운로드한 Unity 프로젝트를 저장할 수 없는 오류가 발생하고 있습니다. 이 오류가 발생한 경우, 다음 해결 방법을 사용할 수 있습니다.

**1.** 상단 메뉴에서 **File**> **Close**로 이동합니다.

**2.**Keep Project? 대화창에서 **Keep**을 선택합니다.

[Image: image]

**3.**  컴퓨터 운영체제의 저장 창을 사용해 프로젝트를 저장합니다. 전용 프로젝트 폴더나 문서 폴더처럼 프로젝트에 쉽게 액세스할 수 있는 위치를 선택합니다.

**4.**  프로젝트를 저장한 후 Unity Hub를 다시 엽니다.

**5.** **Add**를 선택하고 프로젝트를 저장한 위치로 이동합니다. 그러면 해당 프로젝트가 Hub의 프로젝트 목록에 추가됩니다.

[Image: image]

**6.**  프로젝트 목록에서 해당 프로젝트를 클릭해 연 다음 튜토리얼을 계속 진행합니다.

이렇게 하면 프로젝트를 문제없이 저장할 수 있습니다.

## 4. Unity 에디터 인터페이스 살펴보기

Q&A (0)

이 프로젝트를 진행하며 Unity 에디터에서 사용하는 주요 요소는 코드 작성이 필요 없는 크리에이터 키트에서 사용했던 것과 같습니다.

[Image: image]

Unity 에디터에는 4개의 주요 섹션이 있습니다.

**1.  씬(Scene) 뷰**게임의 3D 공간에서 오브젝트를 선택하고 이동하여 현재 씬을 편집할 수 있습니다. 이 키트에서는 게임 레벨이 하나의 씬에 포함됩니다.

**2.  계층(Hierarchy) 창**
씬에 있는 모든 게임 오브젝트의 목록을 표시합니다. 게임 내의 모든 오브젝트를 게임 오브젝트라고 합니다. 이러한 게임 오브젝트는 부모-자식 계층 구조로 배치해 그룹화할 수 있습니다. 즉, 부모 오브젝트가 이동하면 모든 자식 오브젝트도 동시에 이동합니다.

**3.  인스펙터(Inspector) 창**
현재 선택한 오브젝트와 관련된 모든 설정을 보여줍니다. 과정을 진행하며 더 자세히 살펴보게 될 것입니다.

**4.  프로젝트(Project) 창**
프로젝트 에셋을 관리하는 곳입니다. 에셋이란 프로젝트에 사용되는 미디어 파일(예: 이미지, 3D 모델, 음향 파일)을 의미합니다. 프로젝트 창은 파일 탐색기와 같은 기능을 하며 컴퓨터에서 폴더를 탐색하고 생성하는 데 사용할 수 있습니다. 과정을 진행하며 특정 파일 경로에서 에셋을 찾아야 할 때 이 창을 사용합니다.

**팁:** 에디터 레이아웃이 위 이미지와 다른 경우 툴바 오른쪽 상단의 레이아웃 드롭다운 메뉴에서 **Default**를 선택합니다.

## 5. Unity 에디터 툴바 살펴보기

Q&A (0)

툴바에 포함된 다양한 버튼은 게임을 디자인하거나 테스트할 때 유용하게 사용할 수 있습니다.

[Image: image]

#### 플레이 버튼

**플레이**플레이 기능은 현재 계층 창에 로드된 씬을 테스트하는 데 사용되며 에디터에서 게임을 실시간으로 테스트해 볼 수 있습니다.

**일시 정지**일시 정지 기능은 게임 창에서 플레이 중인 게임을 일시 정지합니다. 놓치기 쉬운 시각적 문제나 게임플레이 문제를 확인하는 데 유용합니다.

**스텝**스텝 기능은 일시 정지된 씬을 프레임 단위로 진행하는 데 사용됩니다. 이는 게임 월드에서 변경되는 사항을 실시간으로 확인할 때 매우 유용합니다.

#### 오브젝트 조작

다양한 도구를 사용하여 씬 뷰에서 게임 오브젝트를 이동하고 조작합니다. 버튼을 클릭하거나 단축키를 이용하여 도구를 활성화할 수 있습니다.

[Image: image]

**핸드 툴**

[Image: image]

핸드 툴을 사용하면 창 안에서 씬 카메라를 이동할 수 있습니다. 마우스 중간 버튼을 클릭해도 핸드 툴을 사용할 수 있습니다.

**이동 툴**

[Image: image]

이 툴을 사용하면 아이템을 선택하거나 개별적으로 이동할 수 있습니다.

**회전 툴**

[Image: image]

이 툴을 사용하면 아이템을 선택하고 회전시킬 수 있습니다.

**스케일 툴**

[Image: image]

이름에서 알 수 있듯이 게임 오브젝트를 확대하고 축소하는 툴입니다.

**사각 트랜스폼 툴**

[Image: image]

사각 트랜스폼 툴은 다양한 기능을 제공합니다. 무엇보다도 이동, 확대/축소, 회전 기능이 하나의 툴에 결합되어 2D 및 UI에 특화된 기능을 제공합니다.

**회전, 이동, 스케일**

[Image: image]

이 툴 또한 다양한 기능을 제공합니다. 게임 오브젝트의 이동, 회전, 확대/축소에 사용하지만 3D에 보다 특화된 툴입니다.

#### 게임 오브젝트로 포커스 이동

선택한 오브젝트에 포커스를 맞출 수 있게 해 주는 단축키인 **F** 키 또한 기억해 두면 유용합니다.  씬에서 게임 오브젝트의 위치가 기억나지 않는 경우 계층 구조에서 게임 오브젝트를 선택합니다. 그런 다음 커서를 씬 뷰 위로 이동하고 **F**를 누르면 해당 게임 오브젝트가 중앙에 나타납니다.

[Image: image]

#### 마우스로 탐색

씬 뷰에서는 다음 작업도 가능합니다.

- 씬에 있는 게임 오브젝트를 클릭하여 선택할 수 있습니다.
- 마우스 중간 버튼을 클릭하고 드래그하면 핸드 툴을 사용하여 씬 뷰의 카메라가 이동합니다.

씬 뷰에서 게임 오브젝트를 이동하는 방법을 자세히 알아보려면 매뉴얼에서 [씬 뷰 내비게이션](https://docs.unity3d.com/Manual/SceneViewNavigation.html?ampDeviceId=92c91bc4-9bf1-4741-9062-ee22bfe0f504&ampSessionId=1774844981984&ampTimestamp=1774931684581) 항목을 참조하세요.

## 6. Unity에서 진행하는 작업의 주요 개념 살펴보기

Q&A (0)

게임 스크립트 편집에 대해 알아보기에 앞서, 코드 작성이 필요 없는 이 게임 키트에서 살펴봤던 주요 개념을 다시 확인해 보겠습니다.

#### 씬(Scene)

Unity에서는 플레이어와 상호작용할 수 있는 게임 영역이 일반적으로 1개 이상의 씬으로 구성되어 있습니다. 작은 게임에는 1개의 씬만 사용할 수도 있고, 큰 게임에는 수백 개를 사용할 수도 있습니다. 크리에이터 키트: 코딩의 기초에서 사용된 예제 게임은 몇 가지 다양한 씬을 사용하여 만들어졌으며, 이 튜토리얼에서는 게임을 플레이하고 커스터마이즈하는 데 사용하는 씬을 **예제 씬**이라고 합니다.

#### 게임 오브젝트 및 컴포넌트

Unity에서는 게임 월드 내 모든 오브젝트가 **게임 오브젝트**로 존재합니다. 게임 오브젝트에 알맞은 **컴포넌트**를 설정하면 다양한 기능을 부여할 수 있습니다. 새 게임 오브젝트는 트랜스폼 컴포넌트가 추가된 상태로 생성됩니다. 이 컴포넌트는 3D 또는 2D 게임스페이스에서 게임 오브젝트의 위치 프로퍼티를 제어합니다. 다른 컴포넌트는 모두 인스펙터에서 수동으로 추가해야 합니다.

#### 프리팹

프리팹은  게임에서 재사용할 게임 오브젝트를 구성하고 저장하는 데 매우 유용합니다. 프리팹은 특정 게임 오브젝트의 컴포넌트와 프로퍼티를 저장하고 씬 내에서 여러 인스턴스를 생성할 수 있도록 하는 템플릿 역할을 합니다.  하나의 씬 안에서 복사한 프리팹은 모두 서로 연결됩니다. 즉, 체력 물약 프리팹의 오브젝트 값을 변경하면 같은 씬에 복사한 프리팹도 값이 모두 동일하게 변경됩니다. 하지만 게임 오브젝트의 특정 인스턴스를 기본 프리팹 설정과 다르게 만들 수도 있습니다.
