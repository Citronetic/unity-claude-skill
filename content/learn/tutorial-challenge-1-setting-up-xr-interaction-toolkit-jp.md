## 1. XR Interaction ツールキットのインストール

Q&A (0)

1. スターターパッケージをダウンロードし、Starter シーンを開きます。

2. XR Interaction ツールキットをパッケージマネージャーのプレビューパッケージからダウンロードします。Packages フォルダーには、残りの機能に使用するスクリプトとプレハブが入っています。

[Image: image]ステップを完了としてマーク

## 2. Room-Scale XR Rig の追加

Q&A (0)

1. Room-Scale XR Rig を追加します

[Image: image]

2. XR Interaction Manager がシーンに追加されていることを確認します

3. XR Rig をじっくりとご覧ください。注：メインカメラにはTracked Pose Driver、コントローラには XR Controller、XR Ray、Line Renderer、そして XR Interactor が搭載されています。

ステップを完了としてマーク

## 3. XR Plugin Management パッケージのインストール

Q&A (0)

1. VR をセットアップするには、パッケージマネージャーから XR Management パッケージをインストールすることで、OpenVR Desktop パッケージを入れる必要がなくなります。

2. インストールが完了したら、Edit > Project Settings > XR Plugin Management の順に進み、**Install XR Plugin Management**をクリックします。

[Image: image]

3. Project Settings で、デバイスに適したプラグインをインストールします。例えば、Oculus ヘッドセットを使用している場合は、Oculus SDK をインストールします。

[Image: image]

4. 再生ボタンをクリックして、周囲を見回してみましょう。これで、シーンを見ることができるはずです。
