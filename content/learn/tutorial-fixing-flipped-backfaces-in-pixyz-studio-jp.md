## 1. PiXYZ Studio での反転したバックフェースの修正

Q&A (0)

*本チュートリアルは、Unity 2019 LTS と PiXYZ 2020.1.1.8 を使って検証しています。*

Unity では、反転している面（カメラの反対側を向いている面、バックフェースとも呼ばれる）は、通常、カリングされるか、表示から除去されます。カメラの視点から見て表面の後ろにあるものが、代わりに表示されます。ただし、フェースのマテリアルが両面の場合は例外です。PiXYZ Studio では、手動で、またはスクリプトや修復処理の一環として、バックフェースを反転させることができます。スクリプトや修復処理の一環として面の向きを変える場合は、ユーザーが制御できないため、ほとんどの場合、手動で調整する必要があります。

PiXYZ Studio ウィンドウの上部中央には、バックフェースの処理方法を設定するボタンがあります **(画像 01)**。これには 3つの設定があり、クリックするか、ドロップダウンの三角マークを使って切り替えることができます：

**BF COLOR：**バックフェースは、前面に配置された表面とは異なり、非常に見やすく、選択可能で、無地のホットピンクでレンダリングされます。この設定は、PiXYZ Studio で表面側を配置する際に推奨される設定です。

**BF CULLING：**バックフェースは、すべて表示*から除去されます*。

**2-SIDED：**バックフェースは、外観も挙動も視点と同じ側の面 (表面側) と区別がつきません。

[Image: image]

1 つのオカレンスですべてのバックフェースが必要になることもありますが、可能性は低いです。この場合、オカレンスをクリックして選択し、Mesh のドロップダウンから Invert Faces Orientation を選択します **(画像 02)**。ここでは、顔を反転させる方法を説明します。

[Image: image]

1. 反転させたい面やオカレンスをクリックします。どちらをクリックしてもオカレンス全体が選択されます。

2. Mesh のドロップダウンから Explode Connected Meshes を選択します**（画像 03）**。このオカレンスのコンポーネントが個別に選択できるようになりました。

[Image: image]

3. 複数のパーツを選択できるように Ctrl を押しながら、反転させたい面をクリックします **(画像 04)**。

[Image: image]

4. 間違った面を選択してしまった場合は、Ctrl を押しながらもう一度クリックすると、選択が解除されます。

5. Mesh ドロップダウンから Invert Meshes Orientation を選択します **(画像 05)**。

[Image: image]

6. Product Structure ペインでは、分割した元のパーツをクリックして選択します。

7. 簡単にするために、反転させた面の一つを右クリックして、コンテキストメニューから Find in tree を選択すると、Product Structure に強調表示されます **(画像 06)**。クリックして、その親を選択します。

[Image: image]

9. Product Structure ペイン内の分割されたパーツを選択した状態で、Scene のドロップダウンから Merge Parts を選択します **(画像 07)** 。

[Image: image]

バックフェースの反転はすでに高速ですが、ここで紹介するアクションにショートカットキーを割り当てることで、より高速に動作させることができます。キーボードショートカットを表示および編集するには、Windows のドロップダウンから Workspace > Keyboard Shortcuts と選択します **(画像 08)**。

[Image: image]

または、Mesh のドロップダウンメニューにある Smart Orient Algorithm を利用すると、一度にすべての面の向きを自動的に統一することができます。この機能は、自動車などの完全なモックアップモデルに使用することを想定しています。

[Image: image]
