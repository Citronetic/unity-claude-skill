**Create with Code - ティーチャートレーニング - セクション 2/3**

Create with Code ティーチャートレーニングのこのセクションでは、あなたのニーズと教室の条件に最も適した方法でコースを設定するために必要な時間を取ります。まず、一般的なコース構成をレビューし、可能な限り柔軟性を持たせるためのコンテキストを提示します。次に、自分のクラスの状況を、クラス独自の学習環境と制約を含めて検討します。最後に、時間的な制約からコースのどの部分を除外するか（もしあれば）を含め、あなたにとって最適なコース構成を選択します。
