## 2. 스무딩 그룹

Q&A (0)

**스무딩 그룹** 또는 **커스텀 버텍스 노멀**을 사용하여 가장자리의 각진 정도를 정의하고 모델의 룩을 바꿉니다. 스무딩 그룹은 아트 제작 시 의도적으로 폴리곤을 적게 사용할 때 셰이딩의 효과를 높이는 데 도움이 됩니다.

베이크 시 스무딩 그룹이 모델의 UV 섬(모델에서 일정 단위로 구성된 부분)과 노멀 맵 품질에 영향을 준다는 점에 주의하세요.

3D 모델에 스무딩을 구현할 때는 모델을 3D 소프트웨어에서 익스포트한 다음 Unity로 임포트해야 합니다.

오브젝트에 스무딩을 적용하면 어떤 결과가 나오는지 다음 이미지에서 확인할 수 있습니다.

## 3. 메시 토폴로지

Q&A (0)

메시 토폴로지를 사용할 때 유용한 팁은 다음과 같습니다.

- 3D 에셋을 만들 때는 토폴로지를 적절한 수준에서 간결하고 깔끔하게 유지합니다.
- 변형되거나 애니메이션화되는 캐릭터와 오브젝트에는 정리된 토폴로지를 사용합니다.
- 토폴로지를 너무 완벽하게 만들 필요는 없습니다. 텍스처와 머티리얼을 적용하면3D 모델의 와이어프레임이 플레이어나 최종 사용자에게는 보이지 않기 때문입니다.

다음 이미지는 간단한 지오메트리와 토폴로지를 사용하는 암벽 메시의 와이어프레임입니다. 머티리얼이 적용되니 암벽이 훨씬 보기 좋아졌습니다.

## 4. 셰이프 과장

Q&A (0)

셰이프 과장은 오브젝트의 특정 부분을 보통 상태보다 크게 만들어 시인성을 높입니다. 이 접근법이 적합한지는 어떤 게임을 만드는지에 따라 다릅니다.

모바일 기기는 화면이 작아서 셰이프가 매우 작으면 알아보기 어려울 수 있는데, 셰이프 과장으로 이를 해결할 수 있습니다. 예를 들어 캐릭터의 손을 크게 만들면 작은 화면에서도 쉽게 알아볼 수 있습니다.

과장된 손이 어떤 식으로 나타나는지 다음 이미지에서 확인할 수 있습니다. 손, 칼, 신체 비율이 모두 다양한 방식으로 강조됩니다. 폴리곤 수를 적게 사용하면서 시인성을 높이기 위해 다음과 같은 설정이 적용되었습니다.

## 5. 메시 결합

Q&A (0)

렌더링에 필요한 드로우 콜 횟수를 줄이기 위해 [**Mesh.CombineMeshes()**](https://docs.unity3d.com/ScriptReference/Mesh.CombineMeshes.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774954411501) 메서드를 사용하여 여러 메시를 하나로 결합할 수 있습니다. 모든 메시의 머티리얼이 동일하다면, 결합된 그룹의 메시마다 단일 하위 메시를 생성하도록 **mergeSubMeshes**인수를 **true**로 설정합니다.

여러 메시를 하나의 큰 메시로 결합했을 때의 장점은 다음과 같습니다.

- 더 효과적인 오클루더를 생성합니다.
- 타일 기반 에셋을 보다 큰 크기의 경계가 없는 견고한 에셋으로 변경합니다.

이 기법을 적용하는 방법은 다음과 같습니다.

1. 계층 구조에서 빈 게임 오브젝트를 만들고, 결합할 메시의 부모로 지정합니다.
2. Mesh.CombineMeshes()를 구현하는 스크립트를 부모 게임 오브젝트에 연결합니다.

씬 구성에 따라 이 메서드가 성능 최적화에 유용할 수 있습니다. 큰 메시가 작은 메시보다 시야에 더 오래 머무는 경향이 있으므로 실험을 통해 적정 크기로 만듭니다.

## 6. 모델 설정

Q&A (0)

- **애니메이션화되지 않는 FBX 메시 모델의 애니메이션 데이터를 임포트하지 않습니다.** 애니메이션 데이터가 없는 FBX 메시를 임포트할 때는 Import Settings의 Rig 탭에서 **Animation Type**을 **None**으로 설정합니다. 계층 구조에 메시를 배치하면 이 설정에 따라 Unity가 사용되지 않는 애니메이터 컴포넌트를 생성하지 않습니다.
- **메시 읽기/쓰기를 방지합니다.**런타임 시 모델이 수정되는 경우, Unity에서는 수정과 동시에 원본을 유지하도록 메모리에 메시 데이터의 사본을 보관합니다. 모델이 런타임 시 수정되지 않으면 Import Settings의 Model 탭에서 **Read/Write Enabled** 옵션을 비활성화하여 복사본이 생성되지 않도록 합니다.
- **정적/동적 배칭을 활용합니다.** 정적 배칭은 드로우 콜 횟수를 줄이는 일반적인 최적화 기법으로, 렌더링하는 동안 이동, 회전, 확대/축소되지 않는 버텍스가 많은 오브젝트에 적합합니다. 정적 배칭을 활성화하려면 타겟 모델의 메시 렌더러가 포함된 인스펙터에서 Static 체크박스를 선택합니다. 빌트인 동적 배칭은 동일한 머티리얼을 공유하며 숫자는 보다 적으나 비슷한 버텍스가 포함된 오브젝트에 사용합니다. 동적 배칭을 활용하려는 메시에 필요한 기준을 더 알아보려면 이 기술 문서를 참조하세요.
