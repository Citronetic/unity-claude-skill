## 2. ¿Qué es la documentación?

Q&A (0)

**La documentación**se refiere a cualquier instrucción, proceso o referencia por escrito. Utilizas la documentación cada vez que sigues las instrucciones de un manual de usuario para un nuevo dispositivo, buscas un método en el manual de la API (si eres programador) o buscas instrucciones sobre cómo llenar un formulario.

Para una aplicación como Unity, la documentación es la fuente oficial de información de todos los aspectos del producto.

#### Documentación comparada con tutoriales

Por lo general, la documentación se diferencia del contenido de aprendizaje, como este tutorial, en que la documentación es una referencia detallada de cada función, mientras que los tutoriales te guían por los procesos y los flujos de trabajo. Por ejemplo, compara lo siguiente:

- [La página del Manual de Unity en la ventana Hierarchy (Jerarquía) del Editor de Unity](https://docs.unity3d.com/Manual/Hierarchy.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774953053707). Esta documentación enumera y explica todos los aspectos y funciones de la ventana Hierarchy.
- [Un tutorial de Unity Learn que presenta la ventana Hierarchy](https://learn.unity.com/tutorial/work-with-gameobjects-in-a-3d-scene#5fa5cd60edbc2a0020bca0a7). Este tutorial te presenta la ventana Hierarchy pues te guía paso a paso por un proyecto de muestra de Unity.

La documentación y los tutoriales tienen algunas cosas en común. Ambos incluyen definiciones de términos y explicaciones de las características del producto. Ambos contienen instrucciones paso a paso, aunque los tutoriales suelen utilizar un proyecto de muestra, mientras que las instrucciones de documentación tienden a ser más genéricas.

Tanto el Manual de Unity como Unity Learn comparten un propósito común: ayudarte a aprender y usar Unity.

[Image: image]

#### Documentación para la resolución de problemas

La documentación es especialmente útil al solucionar problemas. Por lo general, incluye explicaciones de los mensajes de error y consejos para evitar o solucionar problemas. La documentación también está organizada por tema para que puedas encontrar toda la información de referencia sobre un tema en un solo lugar.

## 3. ¿Cómo comenzar a usar la documentación de Unity?

Q&A (0)

Echemos una mirada al Manual de Unity:

**1.** [Ve a la página de inicio de la documentación de Unity](https://docs.unity.com/). Es la puerta principal de la documentación de Unity. Al momento de escribir este artículo, esta página incluye enlaces a los temas de Primeros pasos, el Manual del Editor de Unity, la API de creación de scripts y mucho más. Esta página está sujeta a cambios. Aquí verás enlaces organizados por tema, industria y producto. Es un excelente punto de partida para todas tus necesidades de documentación.

**2.** Busca la sección titulada **Manual del Editor de Unity** y selecciona el botón **Más información** (destino: [el Manual de Unity](https://docs.unity3d.com/Manual/index.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774953053707)). Esta es tu referencia completa al Editor de Unity y al Unity Hub.

**3.** Explora la tabla de contenido en el menú de la izquierda. Hay mucho que saber sobre Unity y lo tienes todo aquí.

**4.** En la esquina superior izquierda, observa el número de versión de Unity para cualquier página. Este es un menú desplegable que te permite ver la misma página (si está disponible) para cualquier otra versión de Unity.

[Image: image]

**5.** Usa la tabla de contenidos para dirigirte a **Packages > Verified packages > ProBuilder**.

**6.** Selecciona el enlace debajo del título para abrir la documentación del paquete modular de ProBuilder en una nueva pestaña. Los paquetes se documentan de esta forma modular porque se actualizan de manera independiente del sistema de versiones del Editor de Unity.

**7.** Regresa a la pestaña del navegador anterior. En el menú superior, busca un enlace para la API de creación de scripts y selecciónalo (destino: [API de creación de scripts](https://docs.unity3d.com/ScriptReference/index.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774953053707)) para ver la página del portal de la API. La API de creación de scripts de Unity es extensa y puede resultar intimidante al principio. Contiene toda la información que podrías necesitar para programar en el motor de Unity.

**8.** En la barra de búsqueda en la parte superior derecha, escribe «MonoBehaviour**»**. Si has completado [la misión de programación en el trayecto Aspectos básicos de Unity](https://learn.unity.com/project/essentials-of-programming-in-unity)o si has programado con [¿Cómo crear con código?](https://learn.unity.com/mission/programming-basics), este término te resultará familiar.

**9.** Desplázate hacia abajo en esta página. Hay mucha información aquí. Si ya has programado, algunas partes te resultarán familiares, pero muchas pueden parecer nuevas. El punto es que todo lo que necesitas saber sobre este tema está aquí, mucho más de lo que podrías haber aprendido en cualquier tutorial.

Con esto concluye tu recorrido por el Manual de Unity. En este recorrido, has aprendido a hacer lo siguiente:

- Acceder a la [página de inicio para obtener la documentación de Unity](https://docs.unity.com/).
- Acceder al Manual del Editor de Unity.
- Navegar por la tabla de contenidos del Manual de Unity.
- Cambiar la versión de Unity de la página que estás viendo.
- Acceder a la documentación sobre los paquetes de Unity.
- Acceder a la documentación de la API de creación de scripts de Unity.

A medida que crezcas en tu aprendizaje de Unity, el Manual se convertirá en un recurso de confianza para el aprendizaje intermedio y avanzado.

## 4. ¿Cómo encontrar lo que necesitas?

Q&A (0)

El Manual de Unity es amplio y abarca una gran variedad de temas. Estos son algunos consejos y trucos para encontrar lo que necesitas de manera rápida y sencilla.

- **Afina tus términos de búsqueda:**Sé lo más específico posible al buscar en el Manual de Unity. Al buscar, encontrarás términos más específicos en los resultados de búsqueda. Busca más para encontrar exactamente lo que quieres.
- **Mantente atento a la API de creación de scripts:**Algunos resultados de búsqueda te llevarán a la API de creación de scripts. Revisa la parte superior de la ventana y observa si la API de creación de scripts o el Manual están resaltados. Si estás en el lugar incorrecto, solo selecciona el otro manual.
- **Examina los encabezados:**Para abarcar mucha información, algunas páginas pueden ser extensas. Asegúrate de examinar los encabezados y las tablas en busca de frases clave relevantes.
