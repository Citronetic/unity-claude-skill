## 2. 시작하기 전에

Q&A (0)

프로젝트가 아직 준비되지 않았다면 [여기](https://connect-prd-cdn.unity.com/20210111/c313396b-3519-48b0-af40-3b8d852354f2/ARMUnityMobileOptimization.zip?_ga=2.151481081.1300965009.1610309756-1588052204.1590585134)에서 샘플 데모가 포함된 프로젝트를 다운로드합니다. 팝업이 표시되면 **Lighting Demo - Non-baked** 또는**Lighting Demo - Baked**를 클릭합니다.

Project 뷰에서 샘플 씬을 열어도 됩니다(**Assets**>**4 Lighting**>**Scene**>**Lighting_Baked** 또는 **Assets**>**4 Lighting**>**Scene**>**Lighting_Unbaked**). 다운로드한 씬이 열리면 에디터에서 플레이 모드로 진입하거나 모바일 기기로 씬을 빌드하여 프로파일러에서 프로파일링합니다.

## 3. 살펴보기

Q&A (0)

이전 [튜토리얼](https://learn.unity.com/tutorial/lighting-for-static-objects-6081?uv=2019.4&courseId=5f6baa23edbc2a0020abb1c0&projectId=5f6ca1eaedbc2a652270d9d5#)에서 설명했듯이 Unity 엔진은 라이트맵 생성을 위한 세 가지 옵션(**인라이튼**, **프로그레시브 CPU 라이트매퍼**, **프로그레시브 GPU 라이트매퍼**)을 제공합니다. 인라이튼은 지원 중단 예정이며 프로그레시브 GPU 라이트매퍼는 프리뷰 버전이므로 이 프로젝트에서는 프로그레시브 CPU 라이트매퍼를 선택했습니다.

프로그레시브 CPU 라이트매퍼를 사용하여 베이크된 조명을 구현하면 조명 정보를 처리할 때 CPU 사이클을 절약할 수 있습니다. 그 결과 CPU 사용량이 줄고, 초당 프레임 수(FPS)가 크게 증가하는 것을 볼 수 있습니다. 두 씬의 FPS를 측정하면 **Statistics 창**에서 큰 차이를 확인할 수 있습니다.

모바일 기기에서는 그 차이가 더 확실하게 드러납니다. 선택한 스마트폰에 샘플 씬을 빌드하고 두 씬을 프로파일링하여 프로파일러의 **Global Illumination** 섹션에서 **Total CPU** 그래프를 확인합니다. 스마트폰의 사양에 따라 CPU 사용량이 크게 다를 수 있습니다.

[Image: image][Image: image]

(**참고:**여기서는 프로그레시브 CPU 라이트매퍼를 적용했지만 프로그레시브 GPU 라이트매퍼로도 실험하고 프로파일링해 보시기 바랍니다. 시스템의 GPU에 따라 성능은 달라질 수 있습니다.)
