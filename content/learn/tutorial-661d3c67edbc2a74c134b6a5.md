Did you notice that the **Hierarchy** window, which is on the left in Unity's default layout, was automatically populated with a list when you opened the scene?

The **Hierarchy** window is where you organize all the things in your game world. These things are called **GameObjects.**

- There's an important difference between the **Project** and **Hierarchy** windows:

- The **Hierarchy** displays all the GameObjects in the current scene.

The **Project** window displays all the assets available to your entire project, whether or not they are in the current scene.

#### Instructions

**1.** In the **Hierarchy** window, double-click on some of the GameObjects and notice what happens.

The object is framed in the **Scene** view at the center of the Unity interface.

**2.** In the **Hierarchy** window, locate the **Cubes** GameObject, then use the foldout (triangle) to expand it and see the GameObjects within.

GameObjects are typically organized in a hierarchical tree-like structure. In the **Hierarchy** window, a GameObject can have parents and children. **Parent** GameObjects contain other GameObjects, which are referred to as **child** GameObjects.

**3.** To return to a view that allows you to see the entire environment, double-click the **Ground** GameObject, which will frame the entire ground in view.

If you accidentally make an unwanted change, use **Ctrl+Z** (macOS: **Cmd+Z**) to undo.

In the center of the default Unity Editor layout is the **Scene** view. This is your interactive window into the world you are creating. You'll use the **Scene** view to manipulate objects and view them from various angles.

#### **Instructions**

**1.** With your cursor in **Scene** view, right-click and drag. You'll notice the cursor turns into an eyeball icon when you do this. This is the **View** tool.

It's like turning your head to look around in the real world.

**2.** Release the right-mouse button, then use the arrow keys to freely move around in the **Scene** view. The Up and Down arrow keys move you forward and backward. The Left and Right arrow keys pan the view sideways.

**3.** As a challenge, use a combination of the right-mouse button and the arrow keys to position yourself behind the red sphere, looking down the ramp.

**4.** If you ever get lost in **Scene** view, simply go back to the **Hierarchy** window and double-click one of the objects to frame and center it in **Scene** view.

It is time to create your first C# script!

**C#** (pronounced “see-sharp”) is a versatile programming language that is widely used for developing a broad range of applications, from web to mobile to game development, and particularly with Unity for game scripting.

Your first **script,**, which is just a document with code in it, will be named "PlayerController". In this script, you'll define how your player interacts within the game world.

#### **Instructions**

**1.**  In the Project window, navigate to **_Unity Essentials > Scripts.**. There should already be a folder inside the Scripts folder named “Provided Scripts” — ignore that folder for now.

**2.**  Inside the Scripts folder, right-click in some empty space and select **Create > C# Script.**.

**3.**  WIth the script’s name automatically highlighted, immediately rename this new script to "PlayerController" (with a capital 'P' and 'C'). It's important to get the name correct right now — renaming it later can cause problems.

**4.**  Press **Enter** to save the script name. You'll see the code of the new blank script in the Inspector window. Notice that the name of the file is included in the code. That's why it's important to spell the file name correctly.

**Note:** If you make a typo in your script name or have to rename it for any reason, it will be easier to just delete it and create a new one with the correct name.

In this step, you'll just explore the silent kitchen scene.

This scene is already set up with a script, attached to the Main Camera, that will work in Play mode. This script allows the user (you, for now) to easily explore the environment with the WASD keys and listen to the sounds in the scene from a first-person perspective.

By default, the Main Camera will have an **Audio Listener** component on it, which acts kind of like the player’s ears. That way, the camera acts as the player’s eyes and ears in the scene. When the Audio Listener component is far away from a sound, it should be quieter. When the Audio Listener is closer to a sound, it should be louder.

For now, though, there won’t be any audio — that’s your task!

#### **Instructions**

**1.**  In the Project window, in the **_Unity Essentials > Scenes** folder, locate and open the **3_Kitchen_Audio_Scene.**

**2.**  In Scene view, use Flythrough mode (Right-click + WASD) or the Frame-Orbit-Zoom technique to give yourself a good view of the interior of the kitchen.

**3.**  Enter Play mode, then use the WASD keys for moving forward, backward, and for turning left and right. To look up and down, use your mouse.

If you are you using your mouse to look up and down and the cursor moves off to the edge of your screen during Play mode, don’t worry – that’s expected.
