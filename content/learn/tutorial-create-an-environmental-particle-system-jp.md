[Image: 環境パーティクルシステムの作成]Summary

Particle System (パーティクルシステム) は、驚くほど汎用性の高いシステムです。パーティクルシステムのモジュールを少し変更するだけで、さまざまなエフェクトを作り出すことができます。このチュートリアルでは、まったく新しいパーティクルシステムを作成し、そのモジュールを設定して、シーンに雪や雨を降らせる方法を説明します。

このチュートリアルが終わるころには、次のことができるようになります：

- シーンに新しいParticle System (パーティクルシステム) をセットアップする。
- Main モジュールを変更することで、Particle System の主要なプロパティ（寿命、サイズ、最大パーティクル数など）を設定することができる。
- Shape モジュールを変更することで、パーティクルの位置と最初の向きを制御する。
- Emission モジュールを変更することで、パーティクルの発生速度やタイミングを制御する。
- Renderer モジュールを変更することで、個々のパーティクルの外観を制御する。

## 1. 概要

Q&A (0)

パーティクルシステムの最も一般的で重要な使用例の一つは、最も簡単に実現できるものの一つでもあります。それは、天候のエフェクトです。ほんの数回の編集で、晴れた青空から雷雨や吹雪のシーンに早変わりします。

[Image: image][Image: image]

これらのエフェクトは、ユーザーの目の前にある一つのソースから発せられるのではなく、ユーザーを完全に取り囲み、没入させるものです。

このチュートリアルでは、パーティクルシステムのコア機能のいくつかを使って、シーン内に天候効果を作成します。

## 2. 新しいパーティクルシステムの追加と配置

Q&A (0)

雨や雪などの天候効果を作成するには、まず Particle System オブジェクトを新規に作成し、空から地面に向かって下向きに配置する必要があります。

**1.**CreativeCore_VFX_ProjectFiles を Unity エディターで開きます（まだ開いていない場合）。

**2.**Project ウィンドウで、**Assets > CreativeCore_VFX > Scenes** の順に選択し、TutorialScene_VFX_Outdoor シーンを開いてください。

**3.**Hierarchy で、**右クリック > Effects > Particle System** と進みます。

[Image: image]

デフォルトでは、シーン内のどこかに大きな白いドットを放出するパーティクルシステムが作成されます。

**4.**Hierarchy で右クリック、新しいパーティクルシステム（**Particle System > Rename**）を作るものによって、FX_Snow または FX_Rain に名前を変更します。

FX とは、Effects の略語です。その他によく見かける略語として、SFX があり、これは Special Effects の略です。業界やプロジェクトのタイプによっては、これらの名称を他よりもよく目にすることがあるかもしれません。一般的に、オブジェクトの名前に、それが実際にはパーティクルエフェクトであることを明確にすることは良い習慣です。

雪や雨を降らせる場合は、上空に下向きにシステムを配置することをお勧めします。

**5.**  ゲームオブジェクトの Transform コンポーネントで、**Position** を **X=0, Y=10, Z=0**に設定して、炎の上の中央に配置、**Rotation** を **X=90, Y=0, Z=0**に設定して、パーティクルが上から下に放出されるように設定します。

[Image: image]

**6.**  **Play** を選択してアプリケーションを実行し、Particle System をプレビューします。すでに、画面全体に白い点が浮遊しているような、天候効果のような見た目になっているはずです。

[Image: image]

そのパーティクルの大きさや速度が適切でないのですが。それについては、次で説明します。

## 3. メインモジュールのプロパティ設定

Q&A (0)

パーティクルシステムはたくさんの異なるモジュールによって制御されており、それぞれがシステムの異なる側面を制御しています。最初に編集するのはメインモジュールで、サイズ、速度、寿命など最も重要なパーティクルプロパティが含まれています。

**1.**メインモジュールの名前（この場合はFX_Snow）を選択して展開されていることを確認します。

[Image: image]

メインモジュールは他のどのモジュールとも似ていないので、見落としやすいかもしれません：

- 他のモジュールより少し縦長にした、パーティクルテクスチャのアイコンのモジュールです。
- メインモジュールの名前は、そのモジュールがアタッチされているゲームオブジェクトの名前で表示（例：FX_Snow）されます。
- 必須項目であり、他のモジュールのようにチェックボックスで ON/OFF を切り替えることはできません。

**2.**パーティクルの大きさを変えるには、メインモジュールの **Start Size**プロパティを 0.1 に下げて、小さな雨粒や雪の結晶を作ります。

必要であれば、時間をかけてそのサイズを変更する機能があるため、単なる Size ではなく、Start Size と呼ばれています。下の図は、Start Size を 1.0 にした場合と 0.1 にした場合の違いを示しています。

[Image: image]

**3.**選択した天候効果をより正確に反映させるために、パーティクルの速度を変更します。雪の場合は **Start Speed** プロパティを 5 から 1 程度に減らし、雨の場合は 10 程度に増やします。

これでパーティクルは適切な速度で動いているように見えるはずです。ただし、速度を下げた場合は、シーン全体を動き回るには十分な速度でない可能性があります。

[Image: image]

Start Speed を上げると、あまりに速いので、地面を通過した後、必要以上に長く生き残ることになるのでしょう。

[Image: image]

この問題に対処するためには、パーティクルの寿命を変える必要があります：

**4.  Start Lifetime**プロパティを 5 秒から、パーティクルがカメラの視野内を移動するのにかかる時間まで増減します。パーティクルは地面まで到達する必要がありますが、それ以上には到達しません。

[Image: image]

Game ビューで **Play**を押してアプリケーションをプレビューすると、かなり大きな問題に気づきます。アプリケーションが始まると、パーティクルが生成されて空からゆっくりと落ちてくるのを辛抱強く待つ必要があります。ところが、アプリケーションの開始時に、すでに雪や雨が降っていたらどうでしょう？

**5.**メインモジュールで、Prewarm プロパティを有効にします。

[Image: image]

これで、シーンが始まると、パーティクルのフルサイクルが事前に入力されます。VFX アーティストとして、常にエフェクトのテストと再テストを行っている場合、この設定によって多くの時間を節約することもできます。

次に、メインモジュールから離れ、パーティクルが同じ方向に下降していくようにします。

## 4. Shape モジュールと Emission モジュールの設定

Q&A (0)

メインモジュールに続く最初の 2 つのモジュールは、どちらも新しい Particle System でデフォルトで有効になっている、**Emission** と**Shape**のモジュールです。

[Image: image]

これらのモジュールが連動して、パーティクルをどれだけ放出（**Emission**）するか、どのようなボリュームの形状 (**Shape**) からパーティクルを放出するかを制御します。

まず、パーティクルが発生する領域の形状を、平らな長方形の雲のような形状に変えてみましょう。

**1.** **Shape** モジュールを選択して展開し、Scene ビューに表示される円錐状の形状に注目して、**Shape**プロパティを**Cone** から**Box**に変更します。

[Image: image]

空に浮かぶ箱のように見えるはずですが、大きな雲や天候システムをシミュレーションするには、まだ小さすぎるようです。

[Image: image]

**注意：**形状の輪郭が表示されない場合は、 Scene ビューの右上にある **Gizmos** を有効にする必要があるかもしれません。

**2.** **Shape** の**Scale**プロパティを**X = 10、Y = 10、Z = 1** に変更し、ボックスのサイズを大きくします。

ボックスは、焚き火台の真上でカメラの視野をカバーできる大きさの正方形のボリュームの形状として表示されるはずです。

[Image: image]

パーティクルがよりまばらになり、軽い天候効果のように見えることに気がつくでしょう。これは、以前と同じ数のパーティクルが、より広い領域から生成されているためです。

そのため、このパーティクルシステムの放出量を増やす必要があるのです。

**3.** **Emission**モジュールを拡張し、**Rate over Time** プロパティを 10 から、生成しようとする天候エフェクトの強さに応じて、毎秒 150 ～ 1000 パーティクルの間の数値に増やします。

十分な放出量を確保すると、パーティクルの生成に奇妙な切れ目が入り始めることがあることに気づくはずです。

[Image: image]

画面上のパーティクルの数が、システムで許容される上限に達した場合に起こります。

**4.**  メインモジュールで、**Max Particles** プロパティを 1,000 から 10,000 に増やします。これで、パーティクル放出の一時停止が解消されるはずです。

[Image: image]

この時点で、**Emission Rate**と **Max Particles**の上限を 100 万個まで上げて、世界が見たこともないようなクレイジーな気象現象を起こしたくなりますよね。でも、その誘惑に負けないでください！VFX アーティストの仕事は、エフェクトを最適化することですが、パーティクルをやたらと増やすと、アプリのパフォーマンスが低下する可能性があります。

パーティクルはまだあまりいい感じではありません。雪片や雨粒のようにはとても見えませんね。

[Image: image]

パーティクルの見栄えを良くするために、リストの最後のモジュールである Renderer にアクセスする必要があります。

## 5. Renderer モジュールの設定

Q&A (0)

最後のモジュールは、デフォルトで有効になっている **Renderer** です。このモジュールは、テクスチャを含め、各パーティクルのレンダリング方法（見え方）を制御します。

現在、作成したパーティクルはデフォルトの ParticlesUnlit マテリアルを使用しており、デフォルトのパーティクルテクスチャが使用されています。

[Image: image]

見た目は問題ないのですが、新しいマテリアルを使えば、もっと雪の結晶や雨粒のようになることは間違いないでしょう。

**1.** **Renderer** モジュールを選択して展開し、**Material**プロパティの丸い選択アイコンを使用して、作業内容に応じて**SnowMaterial**または **RaindropMaterial**を選択します。

[Image: image]

これで、個々のパーティクルの外観が変化します。

[Image: image]

そのパーティクルマテリアルについて、もう少し詳しく見てみましょう。

**2.**Inspector で、Renderer モジュール内からマテリアルの名前を直接ダブルクリックします。

[Image: image]

これにより、Project ウィンドウでマテリアルが選択され、Inspector にはそのプロパティが表示されます。

マテリアルについて知っておくべきことはたくさんあります。幸いなことに、[マテリアルのチュートリアル](https://learn.unity.com/mission/creative-core-shaders-and-materials?contentId=619f9e6eedbc2a5554f0b472&missionId=619f9b6cedbc2a39aabd7b1e&tab=content)で、そのすべてを学ぶことができるので、ご安心ください。ただし、このパーティクルマテリアルには注目すべき点がいくつかあるので、自作する場合は参考にしていただきたいと思います。

[Image: image]

- Inspector の上部で、**Shader**が Particles/Unlit シェーダーに設定されています。このシェーダーは、ライトを反射する必要のないパーティクルに最適化されています。
- **Surface Type** プロパティは Transparent に設定されており、パーティクルにある程度の透明度を持たせることができます。これがないと、パーティクルは白い四角のように見えます。
- **Base Map** のテクスチャには、背景が透明な Snowflake や Raindrop のテクスチャが設定されています。Photoshop や Illustrator などで独自のパーティクルテクスチャを作成したい場合は、それを Base Map として使用することができます。

## 6. VFX をプレハブとして保存

Q&A (0)

天候のエフェクトがとても見栄えが良くなったので、それを**プレハブ** (**Prefab**) として保存してみましょう。VFX は非常にモジュール化された再利用可能なアセットである傾向が強いので、プレハブは特に有用です。次にシーンに吹雪を起こしたい時は、保存したプレハブを追加して雪を降らせましょう！その後、[プレハブバリアント](https://docs.unity3d.com/Manual/PrefabVariants.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774954182065)として、より重い天候や軽い天候効果を作成することもできます。

Particle System オブジェクトを Hierarchy から Project ウィンドウの Prefabs フォルダーへドラッグします。これにより、Hierarchy と Project ウィンドウに新しい青いアイコンが表示され、プレハブとして保存されたことが示されます。
