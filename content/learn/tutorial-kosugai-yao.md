## 1. コース概要

Q&A (0)

「教育関係者のための VR 作成」へようこそ！

今後数週間で、Unity で VR 体験を作成するために必要なこと、そして生徒が明日のクリエイターになるためのスキルと経験を身につける方法について詳しく説明します。このコースでは、教育関係者が業界をリードするインタラクティブデザインおよび開発ツールである Unity を使用して VR 開発をうまく教えるためのトレーニング、サポート、コミュニティ、リソースを提供します。

#### **学習到達目標**

このコースが終わるころには、以下の事が行えるはずです：

- 業界を超えた VR の可能性を認識し、これらのスキルを持つ学生の実際のキャリアの機会を特定する
- 独自のプロジェクトを作成することで、Unity での VR 開発の基礎知識を得ることができる
- Unity を教えるためのベストプラクティスやアプローチを特定する
- シラバス、カリキュラム、レッスンプランなどのリソースにアクセスし、授業、プログラム、カリキュラムに VR 開発を取り入れることができる

#### **コースの形式**

#### ウェビナー

- **プロフェッショナル育成のためのウェビナーシリーズ**
- Mark Suter 氏（Elida High School）、Luis Zanforlin 氏（MIT）、および特別ゲストが指導するこれらのセッションでは、VR 開発を教室で行うためのツール、ヒント、戦略などが紹介されます。
- **事前に収録されたオフィスアワーのシリーズ**
- このセッションでは、専門家による指導で、教育関係者のコースプロジェクトをサポートし、教室での VR の学習と指導に関する質問に答えます。

#### 自分のペースで進められる学習

- Unity の新しい Create with VR コースに含まれる**5 時間以上の自己学習とハンズオンプロジェクト**
- **注：**このコースには、[Create with VR](https://learn.unity.com/course/create-with-vr/?tab=educator) のフルコースで提供される***個人プロジェクトのラボは含まれていません***。教育関係者が 30 時間以内にコースを完了できるように、これらのチュートリアルを除外しています。

詳しくは、コース [FAQ](https://create.unity3d.com/create-with-vr-for-educators-faq?ampDeviceId=b1d4c960-c18d-4868-99d7-4a16921fb9dd&ampSessionId=1774948551783&ampTimestamp=1775035250929) をご覧ください。

## 2. 教育関係者向けリソースへのアクセス

Q&A (0)

Unity Learn は、何百ものプロジェクト、チュートリアル、コースを集めた無料のライブラリで、コースのカリキュラムを充実させるために使用できます。Unity Learn の各リソースには、Unity プロジェクトを作成するための無料のアセットとステップバイステップの手順が含まれています。

Unity Learn のリソースの多くには、教育関係者が生徒の学習を評価するために使用するクイズ、チェレンジ問題、個人プロジェクトのガイダンスが含まれています。Create with VR や [**Educator Hub**](https://learn.unity.com/educators) にあるその他のリソースには、Unity の教育計画を簡単に立てるためのさまざまな教師用マテリアルが含まれています。

*これらのリソースは、メインコースページの**For Educators タブ**でご覧いただけます。*

## 3. Unity Educator プラン

Q&A (0)

[Unity Educator プラン](https://unity.com/products/unity-educator)は、Unity を授業で教える認定教育機関の中等教育後および幼稚園児から高校生までの教育関係者を対象としており、プロが学生をサポートするために使用しているものと同じリアルタイム 3D 開発ツールに**無料**でアクセスすることが可能です。

このプランに含まれるのは、Unity Pro、クラウドベースのコラボレーション、クラウドビルド、無料の Unity アセットなどです。

## 4. Unity Teach コミュニティから学ぶ

Q&A (0)

Unity を教えることの素晴らしい点の 1 つは、車輪の再発明をする必要がないことです。もし、Unity の教え方についてヘルプやガイダンスが必要な場合は、[**Facebook の Unity Teach Community に参加**](https://www.facebook.com/groups/unityteachcommunity/)してみてください。

Unity Teach Community は、あらゆる教育レベル、さまざまな分野で Unity を教える教育関係者のためのグローバルな専門学習コミュニティです。このコミュニティでは、ライブのウェビナー、教育・学習リソースの共有、ベストプラクティスに関する有益なディスカッションを開催しています。
