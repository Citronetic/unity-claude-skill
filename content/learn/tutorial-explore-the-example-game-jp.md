## 2. ゲームテンプレートの設定

Q&A (0)

以下の手順で、サンプルゲームを Unity プロジェクトにインストールします：

**1.**  メインメニューで **Window > Content Manager** と開きます。

**2.**  **Unity MARS Platformer Template**を選択します。

**3.**  **Install**を選択します。

**4.**  Import Unity Package のダイアログウィンドウが表示されたら、すべてのアセットが含まれていることを確認し、**Import**を選択します。

**5.**  メインメニューの**Window > MARS > Choose Template** の順に選択します。

**6.**  **Game - Simple** テンプレートを選択します。ゲームシーンが Scene ビューにロードされます。

テンプレートを開くと、Scene ビューに小さなロボットキャラクターと、水平面上に格子状に配置された 9 個の青いクリスタルが表示されるはずです。また、Simulation View や Device View のウィンドウにも、これらのデジタルオブジェクトが表示されます。

## 3. サンプルゲームの主な特徴は？

Q&A (0)

Unity Mars 向けのシンプルなサンプルゲームでは、プレイヤーはロボットキャラクターを制御し、様々なサーフェスからクリスタルを収集することができます。

サンプルゲームは、Unity Mars の以下のキーコンセプトを示すために作成されました：

- AR 体験でデジタルオブジェクトを複製して設定する方法：たとえば、ゲーム内で収集可能なオブジェクトの位置を変更する場合などです。
- デジタルオブジェクトを使用して、トラッキングされた平面上にサーフェスを作成し、そのサーフェスを使用する動的なキャラクターを設定する方法です。例えば、デジタルキャラクターがアプリユーザーの部屋の物理的なテーブルの上を移動できるようにします。
- プロキシを **Proxy Groups**(**プロキシグループ**) に整理して、より複雑な AR 体験をよりコントロールしやすくする方法です。

このチュートリアルでは、基本的なことから始め、最初の 2 つのコンセプトを探ります。次のチュートリアルでは、Proxy Groups を使ってゲームを自分でカスタマイズし、Unity Mars の追加コンセプトについて学びます。

## 4. デジタルオブジェクトの複製

Q&A (0)

作成した AR アプリは、デジタルオブジェクトのプレハブの単一のインスタンスを、アプリが検出した特定の Proxy（または Proxy Group）に関連付けるように指示することができます。ただし、プレハブの複数のインスタンスと現実世界で一致する多くのオブジェクトを関連付けたい場合は、Replicator を使用するのが最も効率的です。

**Replicator**を使用すると、設定したマッチング条件が満たされるたびにプロキシを複製することができます。例えば、平面条件付きのプロキシを設定することで、マッチングした際に AR アプリのデジタル環境の一部が上部に表示されるようにすることができます。このプロキシを Replicator に入れると、条件に合った他のすべての現実世界のオブジェクトにプロキシが複製されます。

ゲーム内のクリスタル収集オブジェクトのプロキシは、Replicator で制御されます。以下の手順で、クリスタル用の Replicator を設定します：

**1.**  MARS Panel の Content Hierarchy で、折りたたみを選択し、**Place crystals on all reasonable sized surfaces** を展開します。

**2.**  Content Hierarchy で、**Horizontal Surface** ゲームオブジェクトを選択します。

**3.**  Inspector で、Alignment Condition MARS コンポーネントを見つけ、展開します。アライメント (Alignment) とは、プロキシが現実世界のオブジェクトとどのように一致するかを制御するために使用できる条件の 1 つです。

**4.**  **Alignment**プロパティを **Nothing** に設定します。Simulation View からクリスタルが消えます。

**5.**  **Alignment** プロパティを **Vertical** に設定します。Simulation View では、クリスタルはすべての垂直面に表示されます。

## 5. 現実世界のオブジェクトにサーフェスを作成する

Q&A (0)

デジタルオブジェクトが物理的な世界と相互作用できるようにしたい場合、Mesh Collider (メッシュコライダー) を使用する必要があります。例えば、サンプルゲームのロボットキャラクターがテーブルの上を移動できるようにするには、キャラクターの移動に適した Proxy 条件に合致するすべてのサーフェスにメッシュコライダーを設定する必要があります。Unity Mars では、**Build Surface Action** Mars のコンポーネントを使用してこれを行うことができます。

以下の手順で、サンプルゲームで Build Surface Action の動作を確認します：

**1.**  MARS Panel Content Hierarchy で、**Put colliders on all walkable surfaces**を選択します。

**2.**  **Put colliders on all walkable surfaces**ゲームオブジェクトを展開し、複製された Proxy 子ゲームオブジェクトを確認します。

**3.** **Surface that can fit character (Clone)**子ゲームオブジェクトを 1 つ選択します。

**4.**  Inspector で、Plane Size Condition MARS コンポーネントを探して展開します。このコンポーネントを使用して minimum size (最小サイズ) を設定することで、Proxy はそのサイズを満たすか超えるオブジェクトとしかマッチングしないようにすることができます。つまり、ロボットキャラクターが着地するための十分な広さのベースが常に確保されていることになります。

**5.**  Build Surface Action MARS コンポーネントを検索して展開します。これは、Mesh Collider または Mesh Filter コンポーネントと一緒に使用し、一致したサーフェスからメッシュを作成します。

**6.** Mesh Collider コンポーネントを探して確認します。

**7.**  Mesh Collider と一緒に Build Surface Action を使用して、この Proxy 条件に一致するすべてのサーフェスに Mesh Collider を更新して設定します。

**注：**このプロセスについてより詳しいガイダンスが必要な場合は、Build Surface Action コンポーネントの「？」アイコンを選択するか、[コンポーネントのドキュメントを今すぐ確認](https://docs.unity3d.com/Packages/com.unity.mars@1.5/manual/ReferenceGuideActions.html#build-surface-action-buildsurfaceaction?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774955003491)しましょう。

## 6. キャラクターの動きの仕組み

Q&A (0)

サンプルゲーム Unit-E のロボットキャラクターは、サーフェス上を転がったり、異なるサーフェス間をジャンプしたり、スポーンされたクリスタルを集めたりすることができます。

さて、ここまででキャラクターが実世界のサーフェス上を移動するためのプロキシ条件を説明しましたが、次にロボットの動作そのものを確認するために、以下の手順を行います：

**1.** MARS Panel Content Hierarchy で、**Unit-E**ゲームオブジェクトのプレハブを選択します。このキャラクターは、Build Surface Actions で生成されたコライダーを使用して現実世界を移動します。

**2.** Inspector で、Direct AR Character Controller (Script) コンポーネントを探し、確認します。

[Image: image]

キャラクターの加速、減速、速度を調整するために使用できるさまざまなプロパティに注目してください。

**ヒント：**Unit_E の動きをより速く、加速度を小さくして、現在のプレイヤー体験と比較してみてください。
