## 4. Use the Painting tool to raise and lower the terrain

Q&A (0)

- Start with larger features and add smaller details to create an organic looking terrain

[Image: image]

- Select the Main Camera GameObject and position it where the scene will be viewed to keep the end view in mind

[Image: image]

- Create a concave terrain to limit the players view.

[Image: image]

- Switch textures often to keep an organic appearance

[Image: image]

- Use the hotkeys to quickly change size, rotation, and strength.

- S key + Mouse to modify brush size
- A key + Mouse to modify brush strength
- D key + Mouse to modify brush rotation
