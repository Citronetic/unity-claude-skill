このチュートリアルでは、コンポーネントがどのようにしてスプライトに機能を追加するかを確認します。ここで実際に動作するところを見るコンポーネント（RigidBody 2D コンポーネント）を使用すると、スプライトは空間に浮かずに物理オブジェクトのように動作します。このチュートリアルでは、次のことを行います。

- Main Camera の位置を調整して、「Game」ビューにアクションを表示する。
- RigidBody 2D コンポーネントを適用して、2D ゲームオブジェクトに物理プロパティを追加する。
- Unity で 2D 物理演算を試す。

## 1. 概要

Q&A (0)

**コンポーネント**はゲームオブジェクトに動作や機能を追加します。ゲームオブジェクトには、「Transform」コンポーネントや、新しいスプライトを作成するとすぐに参照できる「Sprite Renderer」コンポーネントなどのデフォルトのコンポーネントがあります。このチュートリアルでは、もう 1 つのコンポーネントである RigidBody 2D コンポーネントを追加します。このコンポーネントは、スプライトに物理的なプロパティを与え、重力や他のスプライトと相互作用できるようにします。Main Camera を配置して、スプライトが 2D で重力にどう反応するかを確認します。

## 3. Main Camera を配置する

Q&A (0)

すべての新しいシーンには、「Scene」ビューのカメラアイコンで示される**カメラ**があります。このカメラは、「Hierarchy」では「Main Camera」と呼ばれ、**「Game」ビュー**に表示されるシーンをキャプチャしてプレイヤーに表示します。

**1.** 「Hierarchy」ウィンドウで「Main Camera」を選択します。

**2.** Circle が落下して見えるように「Main Camera」を移動します。トランスフォームツールを使用して、他のスプライトと同じように 2D 空間で Main Camera を移動および回転できます。

[Image: image]

**注：**「Scene」ビューでは、ウィンドウの上部にある「**2D**」ボタンを選択して、2D ビューと 3D ビューを切り替えることができます。

## 4. スプライトに質量を与える

Q&A (0)

**1.** 「Hierarchy」ウィンドウで「Circle」を選択します。

[Image: image]

**2.** 「Inspector」ウィンドウで「**Add Component**」ボタンを選択します。

[Image: image]

**3.** 検索バーを使用して「**Rigidbody 2D**」コンポーネントを探し、選択します。「**Rigidbody**」と「**Rigidbody 2D***」の 2 つのオプションがあることに注意してください。*通常の（3D）コンポーネントではなく、「**Rigidbody 2D**」コンポーネントを選択してください。

[Image: image]

**4.** これらのプロパティの効果を確認するには、再生ボタンを押してゲームを開始すると、「Game」ビューが表示されます。

ゲームを停止するまでスプライトが落下し続けます。

**5.** 画面の上部にある再生ボタンをもう一度選択してゲームを再び停止します。

## 5. コライダーを追加する

Q&A (0)

別のオブジェクトにぶつかるオブジェクトは無限に落ちるオブジェクトよりも楽しいので、物理空間でオブジェクトに形状を与える**コライダー**について話しましょう。このコースの 3D プロジェクトでは、作成したプリミティブゲームオブジェクトにはコライダーがすでに組み込まれていました。画像から作成したスプライトの場合は、コライダーを自分で追加する必要があります。

RigidBody 2D コンポーネントでもスプライトに物理プロパティが付与されますが、違いは何でしょうか？RigidBody のプロパティでは、ゲームオブジェクトが重力や空気密度と相互作用する方法を制御します。たとえば、Circle スプライト上の RigidBody プロパティはそれを落下させますが、別のゲームオブジェクトにぶつかると、その中を通過します。Collider コンポーネントは、オブジェクトが相互に作用する方法を決定するプロパティを追加します。Collider コンポーネントを Circle に追加し、その下に地面を表すスプライトを追加すると、Circle は地面に達したときに下向きの軌道を停止します。

**1.** 「Hierarchy」パネル内で右クリックし、「**2D Object**」 > 「**Sprite Shape**」を選択して新しいスプライトを作成します。

**2.** 新しいスプライトシェイプを選択し、「Ground」という名前に変更して、「Scale」プロパティの「Y」を 0.1 に変更します

[Image: image]

**3.** RigidBody 2D コンポーネントを Ground スプライトに追加します。

**4.** ゲームを実行します。Circle と Ground の両方が落下します。Ground が正しく機能するように、Ground スプライトの RigidBody 2D コンポーネントに移動し、「Constraints」を展開して、X、Y、Z 軸の「Freeze Position」チェックボックスを選択します。これらのオプションは、ゲームの実行時に落下せずその場所に留まる必要があることをスプライトに伝えます。

**5.** ゲームを再度実行します。Circle は Ground まで落下しますが、それを突き抜けて落ち続けることがわかります。2 つのオブジェクトに物理的な境界がないため、Circle が Ground を通過するからです。Collider コンポーネントがそれを修正します。

**6.** Circle スプライトを選択し、「Inspector」ウィンドウで「**Add Component**」ボタンを選択します。「**Circle Collider 2D**」を追加し、デフォルト設定のままにします。

**7.** Ground スプライトについても同じプロセスに従い、「**Box Collider 2D**」コンポーネントを追加します。

**8.** ゲームを実行します。Circle は Ground に落ちて止まります。

## 6. スプライトの落下動作を試す

Q&A (0)

この演習のバリエーションを試してみましょう。Circle スプライトと Main Camera を動かして、望む結果を得てください。

その他にも以下のようなことをお試しいただけます：

- 高さの異なる丸をさらに追加します。
- 小さい画像をインポートして、さまざまな形状の他のスプライトを追加します。
- 異なる場所にオブジェクトを落とします。

ゲームの実行中でも選択したスプライトのプロパティを変更できますが、ゲームが停止するとすべての値がゲーム開始前の値に戻ってしまうことに注意してください。これは実行中に異なるパラメーターをテストするのに便利ですが、変更を永続的にしたい場合は、ゲームが停止している間に変更を行う必要があります。
