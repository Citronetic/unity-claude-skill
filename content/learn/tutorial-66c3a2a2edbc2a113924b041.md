## 3. Open the Unity Hub and launch the project

Q&A (0)

If you haven’t already opened the **Unity Essentials in-Editor Pathway** project, you can launch the project directly using the Unity Hub.

[Image: image]

**1.  Launch Unity Hub:**

- Open the Unity Hub application.

**2.  Select New project:**

- In the Hub, select the **New project**button.

**3.  Choose Unity version 6.0 or later:**

- At the top of the **New** **project** window, ensure **Unity 6.0** (or later) is selected.

**4.  Select the Learning templates tab:**

- Select the **Learning** tab from the left-most panel to access Unity’s learning templates.

**5.  Select the Essentials Pathway project:**

- Find and select **Essentials Pathway**.

- This template includes all the assets you need to start learning.
- Enter a name for the project and choose a suitable location on your computer to save it.
- Select the **Create project** button and wait for the project to open.

- This will take a few minutes.

The Unity Editor will open with a dialog, welcoming you to the pathway.
