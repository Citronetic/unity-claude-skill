## 1. Make the Buttons’ Images blue, and all Text red by “Applying” and “Reverting changes

Q&A (0)

- To make the Buttons’ Images blue, right click on “Source Image,” which should be bolded.

- To make the Text Red, right click on the Color parameter in the red Text’s Inspector, and click “Apply”
- To make the blue Text red, right click on the color parameter and select “revert”
- To make the Red Image blue, right click on the Source Image in the Inspector and select “Revert.”

Mark step as complete

## 2. Add another GameOver UI prefab to the scene, and unpack it completely from the prefab

Q&A (0)

- Add another GameOver UI.

- Position it above the first.
- In the Hierarchy, right click on the prefab and select “Unpack Prefab Completely.”
- Adjust the prefab so the “Game Over” text is in the middle of the menu. Be sure to scale the text up so the messaging is clear.
- Reduce the size of the Replay button, and position it at the bottom of the screen.

Q&A (0)
