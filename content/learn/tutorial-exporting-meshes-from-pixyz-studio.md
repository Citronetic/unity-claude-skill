## 1. Exporting Meshes from PiXYZ Studio

Q&A (0)

*This tutorial has been verified using Unity 2019 LTS and PiXYZ 2020.1.1.8*

Exporting Meshes from PiXYZ Studio is a straightforward and easy process. With your model’s triangle-count size properly reduced and optimized for real-time use — such as Unity or Virtual or Augmented Reality — it can be exported via one of many supported formats.

There are two primary ways to export a model from PiXYZ Studio: either from File, the Menu Bar, **(Figure 01)**, or the Export button from the Toolbar. **(Figure 02)**

[Image: image][Image: image]

Clicking Export will open the PiXYZ Export window. Here you will be able to choose the export format, the export location, and the file name. **(Figure 03)**

[Image: image]

The supported export formats are: fbx, 3dxml, obj, gltf, glb, usdz, usda, usdc, prc, and pdf. If you leave Save as Type as All PiXYZ files, it will save the model as an .fbx file.

Once you’ve selected the export location, name, and format, click the Save button and PiXYZ will export the model.
