이제 새로운 기술을 테스트할 시간입니다. 이 과제에서는 스프라이트를 사용하여 파친코 스타일의 인터랙션을 구현합니다. 원이나 다른 오브젝트를 '핀'(다른 스프라이트) 그리드로 떨어뜨려 도달 위치를 확인합니다.

이 미션의 요구 사항을 충족하려면 이 튜토리얼에서 2D 프로젝트를 갤러리에 제출해야 합니다. 다른 사람과 공유하거나 비공개로 설정해도 됩니다.

## 1. 개요

Q&A (0)

이 과제에서는 스프라이트를 사용하여 나만의 씬을 만듭니다. 이 과제에서 수행할 내용은 다음과 같습니다.

- 새로운 2D 씬을 생성합니다.
- 새로운 스프라이트를 생성합니다.
- 씬 뷰의 2D 또는 3D 공간에서 이동합니다.
- 스프라이트를 이동, 회전, 확대/축소합니다.
- 메인 카메라를 이동 및 회전합니다.
- 스프라이트에 Rigidbody 2D 컴포넌트를 추가합니다.
- 스프라이트에 Collider 컴포넌트를 추가합니다.
- 게임 뷰에서 게임 플레이 테스트를 진행합니다.

단계를 완료로 표시

## 2. 씬 구성

Q&A (0)

이 과제에서는 다음과 유사하게 간단한 파친코 스타일 게임을 제작합니다.

[Image: image]

몇 가지 지침이 아래에 나와 있지만 창의력을 발휘해야 하는 부분은 여러분에게 달려 있습니다.

**1.**이전 튜토리얼에서 설치한 스프라이트또는 프로젝트에 있는 스프라이트를 사용합니다.

**2.**각 스프라이트에 Rigidbody 2D 및 Collider 컴포넌트를 사용하여 물리 프로퍼티를 부여합니다.

**3.**인스펙터 창에서 Order in Layer 프로퍼티를 사용하여 모자, 지면과 같은 오브젝트를 앞으로 옮깁니다. 이러한 오브젝트의 Order in Layer 프로퍼티를 1로 설정하면 각 오브젝트가 앞으로 이동하고 공을 그 뒤에 떨어뜨릴 수 있습니다.

[Image: image]

**4.  힌트:** 스프라이트를 제자리에 고정하려면 Rigidbody 2D 컴포넌트의 **Constraints**섹션을 사용합니다.

[Image: image]

**5.**적합한 시야를 찾아 메인 카메라의 위치를 지정합니다.

**6.**씬을 실행하여 테스트하고, 필요한 경우 공이 통과할 때까지 파친코를 조정합니다.

**7.**다른 셰이프의 낙하 스프라이트를 더 추가해 봅니다. 다른 셰이프의 2D 콜라이더를 테스트합니다.

**8.**학습한 다른 기술을 적용하여 나만의 씬을 만듭니다.
