## 1. 개요

Q&A (0)

Arm & Unity: 모바일 애플리케이션용 3D 아트 최적화 과정에 오신 것을 환영합니다.

스마트폰은 주머니에 들어가는 슈퍼 컴퓨터라고들 합니다. 수많은 크리에이터가 모인 유니티에서는 즉시 활용할 수 있는 유용한 툴과 몰입도 높은 경험을 개발하려 노력하고 있습니다. 스마트폰은 3D 게임과 같은 복잡한 애플리케이션을 실행할 수 있을 정도로 뛰어난 하드웨어를 갖추고 있지만, 한계가 있는 것은 사실입니다.

이 과정에서는 여러 유형의 3D 에셋 제작과 관련된 다양한 베스트 프랙티스와 모바일 개발 관련 프로파일링 및 최적화 워크플로에 대한 개괄적인 내용을 학습합니다. 이 과정에서 학습한 내용을 활용하면 애플리케이션의 속도와 효율성을 높이고, 타겟 잠재 고객에 보다 뛰어난 경험을 제공할 수 있습니다.

## 3. 샘플 데모 사용 방법

Q&A (0)

이 과정에서는 섹션마다 중요한 최적화 방식을 소개하는 5가지의 샘플 데모가 제공됩니다. 해당 데모는 Unity LTS 2019(Unity 2019.4.10f1)에서 테스트했습니다. 프로젝트는 [여기](https://connect-prd-cdn.unity.com/20210111/c313396b-3519-48b0-af40-3b8d852354f2/ARMUnityMobileOptimization.zip?_ga=2.247292868.1300965009.1610309756-1588052204.1590585134)에서 다운로드할 수 있습니다.

샘플 프로젝트를 열면 각 샘플 데모에 빠르게 액세스할 수 있는 README 메시지가 표시됩니다. Unity 에디터도 데모에 맞게 커스터마이즈되어 있으며, 빌트인 **프로파일러**및 **프레임 디버거** 뷰가 이미 에디터에 배치되어 간편히 액세스할 수 있습니다.

README 지침(**Tools**>**Show Read Me**)이나 각 프로파일링 뷰(**Window**>**Analysis**)는 Unity 에디터의 메뉴 바에서 찾아 액세스할 수 있습니다.

**중요 참고 사항:** 샘플 데모가 포함된 Unity 프로젝트를 다운로드한 후에는 SRP 배처를 꺼야 합니다. 이 기능은 유니버설 렌더 파이프라인을 지원하는 프로젝트에서 기본적으로 켜져 있으며, 이 과정에서 추가로 설명할 예정입니다.

**Assets**>**Content**>**Settings**에서 *UniversalRenderPipelineAsset*을 클릭하여 인스펙터에서 해당 프로퍼티를 강조 표시합니다. **SRP Batcher**토글 항목은 **Advanced**섹션에 있습니다.
