## 2. Android デバイスの接続

Q&A (0)

デバイスとコンピューターの USB 接続を有効にします。

1. **注意：**以下の手順は、お使いの Android デバイスの種類によって異なります。
2. Android デバイスをパソコンの USB ポートに接続します。

1. **注意：**パソコンが携帯電話を認識しない場合は、必要なデバイスドライバーを確認してください。また、携帯電話の画面を下にスワイプして、「USBでこのデバイスを充電中」というオプションがあるかどうかを確認することもできます。このオプションが表示されている場合は、それをタップします (**画像 1**)

[Image: image]

1. File Transfer オプションを選択します (**画像 2**)
2. **注意：**携帯電話に接続できない場合は、以下のガイドをご覧ください。

1. [Windows 10 doesn’t recognise Android phone [FULL GUIDE]](https://windowsreport.com/windows-10-doesnt-recognize-android/#:~:text=Press%20Windows%20Key%20%2B%20X%20and,and%20choose%20Update%20Driver%20Software.&text=From%20the%20list%20choose%20MTP,Android%20device%20should%20be%20recognised.)
2. [How to Fix Windows 10 Doesn’t Recognize Android Device Problem](https://www.androidrecovery.com/blog/fix-windows10-not-recognize-android.html#:~:text=Load%20Android%20as%20MTP%20on,USB%20connection%20as%20MTP%20mode.&text=To%20fix%20this%20error%2C%20you,choose%20Media%20device%20(MTP).)
3. [Fix: Android phone not recognized on Windows 10](https://mobileinternist.com/windows-10-android-phone-not-recognized)

## 3. USB デバッグの有効化

Q&A (0)

お使いのデバイスで USB デバッグを有効にします。

1. これらの手順は、使用している Android デバイスの種類によって異なる場合があります。ただし、一般的には、以下の手順で USB デバッグを有効にすることができます：

a. 携帯電話の Settings にアクセスする

b. About Phone をタップする

c. Build Number を 7 回タップする

d. Setting のメインページに戻る

e. System をタップする

f. Developer Options をタップする

g. USB デバッグの有効化

## 4. Unity Project Build の保存

Q&A (0)

Unity プロジェクトを保存して、デバイスにエクスポートします。

1. Unity エディターに戻る

2. **File** > **Build Settings**とクリックする

3. Refresh ボタンをクリックする

4. Run Device の隣にあるドロップダウンメニューをクリックして、Android デバイスを選択する (**画像 3**)

[Image: image]

5.  Build and Run ボタンをクリックします (**画像 4**)

[Image: image]

6. apk ファイルを保存するかどうかのプロンプトが表示されます。このファイルは、デフォルトの場所に保存し、任意の名前を入力することができます。例えば、「HelloARWorld」などです。Save をクリックします (**画像 5**)

[Image: image]

7.  **注意：**セキュリティ上の理由でポップウィンドウが表示される場合は、Allow access ボタンをクリックしてください (**画像 6**)

[Image: image]

8. エラーが表示されなければ、お使いのデバイスで Hello AR World アプリケーションが実行されます。お使いのデバイスでは、アプリケーションによる写真撮影や動画撮影を許可するよう求められることがあります。**Allow** をタップします (**画像 7**)
