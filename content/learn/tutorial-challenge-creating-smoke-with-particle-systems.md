## 1. Create a Smoke Effect

Q&A (0)

**1.** Create a new Particle System in the scene in an open demo region

**2.**Enable and modify the general particle settings:

[Image: image]

**a.** Increase the **Duration**to **10**

**b.** Set the **Start Speed**to around **2**

**c.**Reduce the **Start Size**to **3**

**d.**Set the **Starting Color**to a **smoky grey**

**3.** Enable and modify the **Emission**

[Image: image]

**a.** Set the **Rate over Time**to around **20**

**4.** Enable and modify the Shape

[Image: image]

**a.** Set the **Shape**to **Cone**

**5.** Modify the **Renderer**

[Image: image][Image: image]

**a.** Set the **Material**to **SmokeLight**

**b.**In the SmokeLight Material select “**Apply** **to Systems**” to enable the custom vertex streams.

**6.** Enable and modify the **Texture Sheet Animation**

[Image: image]

**a.** Set the **Mode**to **Grid**and **Tiles**to **5**by **5**

**7.** Enable and modify the **Noise**

[Image: image]

**a.** Reduce the **Strength** to around **0.1**
