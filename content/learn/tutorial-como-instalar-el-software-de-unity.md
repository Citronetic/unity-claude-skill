**Descripción general:**

Si aún no tienes la versión recomendada de Unity instalada en tu computadora, lo primero que debes hacer antes de comenzar el curso es instalarla. Para ello tendrás que crear una cuenta de Unity, si aún no tienes una. Cuando instales el software, instalarás el Unity Hub, que te permite gestionar tus instalaciones y proyectos, el propio motor de Unity, y Visual Studio, el entorno de desarrollo integrado (o IDE) que utilizarás para programar en C#.

**Resultado del proyecto:**

El Unity Hub, el Editor de Unity y Visual Studio se instalarán en tu computadora.

## 2. ¿Cómo descargar e instalar el Unity Hub?

Q&A (0)

Para poder descargar, instalar y gestionar de forma eficaz las versiones de Unity en nuestra computadora, utilizaremos algo llamado Unity Hub.

1. En una nueva pestaña, busca en Google «Descargar Unity Hub» o ve a [https://unity3d.com/get-unity/download](https://unity3d.com/get-unity/download?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774953735699) y haz clic en **Download Unity Hub (Descargar Unity Hub).**
2. En tu carpeta de descargas, **haz clic doble** en el archivo **Unity Hub Setup (Configuración) del Unity Hub** para comenzar con la instalación.
3. Acepta los Términos de servicio de Unity y sigue las instrucciones para instalar Unity Hub.
4. **Abre** Unity Hub por primera vez y haz clic en las pestañas del lado izquierdo para explorarlo.

## 3. ¿Cómo instalar una nueva versión de Unity?

Q&A (0)

Ahora que Unity Hub está instalado, debemos instalar una nueva versión de Unity y nuestro editor de código, Visual Studio.

**1.**  En la pestaña **Installs (Instalaciones)**, haz clic en **Add (Añadir)** para agregar una nueva versión de Unity.

**2.**Selecciona **2020.3.X LTS** (también puedes seleccionar **2019.4.X LTS**o **2018.4.X LTS** si quieres utilizar una versión anterior) y haz clic en **Next** (Siguiente). LTS significa soporte a largo plazo, y son versiones estables de Unity que tendrán soporte durante 2 años.

[Image: image]

**3.**En la pantalla **Add modules (Agregar módulos)**, selecciona **Visual Studio** (para Mac o PC).  Este es el software que usarás para editar código. Si ya tienes Visual Studio instalado, no aparecerá como una opción.

[Image: image]

**4.**Acepta los términos y condiciones necesarios y comienza la instalación

## 4. ¿Cómo iniciar sesión o crear una nueva cuenta de Unity?

Q&A (0)

Para acceder a muchos servicios importantes de Unity, incluida la Asset Store, tenemos que iniciar sesión con una cuenta de Unity.

1. En el menú **Account (Cuenta)** en Unity Hub, haz clic para **Sign in (Iniciar sesión).**
2. Si ya tienes una cuenta, **inicia sesión**, de lo contrario, puedes registrarte rápidamente con **Google** o **Facebook** o puedes crear **una nueva** cuenta de Unity.
