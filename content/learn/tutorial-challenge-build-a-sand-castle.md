## 1. Get Ready

Q&A (0)

Start by doing one of the following:

- Load a Hover Racer project from a previous lesson in this course that has been migrated to Unity 2018 LTS

OR
- Download, unzip, and open the project **Hover Racer 2018 LTS** using the link above.

Mark step as complete

## 2. Extend the Sand Terrain

Q&A (0)

1. In the Scene view, navigate to an edge of the existing sand terrain.
2. In the Hierarchy window, select Environment > SandFloor_Alt. The Terrain Editor module will appear in the Inspector.
3. Select the paintbrush tool.
4. In the drop-down immediately below the toolbar, select "Create Neighbor Terrains" from the dropdown, and extend the existing sand terrain. Tip: You have to click exactly on one of the wireframe edges that appear.
5. Rename the new objects that appear in the Project and Hierarchy windows.

Mark step as complete

## 3. Build Your Sand Castle

Q&A (0)

Click the Paintbrush tool. Use the **Raise or Lower Terrain** and **Set Height** options along with the brushes of your choice to build your sand castle.

Tip: Remember to use the SHIFT key to lower height when using the **Raise or Lower Terrain** option.

Mark step as complete

## 4. Make it a Stone Castle

Q&A (0)

Next, use the paintbrush to paint the castle with a rock or stone texture.

1. Click the Paint Terrain button in the Terrain Inspector.
2. In the pop-up window, search for “stone” and “rock” to find some suitable textures.
3. With the new Terrain Layer selected, paint rock or stone onto your sand castle.
4. Experiment with tiling size and other settings to get a pleasing effect.

Mark step as complete
