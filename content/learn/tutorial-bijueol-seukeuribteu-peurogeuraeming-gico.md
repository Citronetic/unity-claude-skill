## 2. 해결할 문제: 각기 다른 렌더링 속도

Q&A (0)

하드 코딩된 값과 변수를 사용하여 큐브가 프레임마다 몇 도 회전하도록 설정했습니다. 하지만 컴퓨터마다 디스플레이의 새로고침 속도가 다르므로, 더 빠른 디스플레이에서는 프레임당 3도 회전이 매우 빠른 반면 느린 디스플레이에서는 느리게 진행됩니다.

모든 디스플레이의 큐브가 똑같이 나타나게 하려면 어떻게 해야 할까요? 비주얼 스크립트에서 이 문제를 해결해 보겠습니다.

프레임당 각도로 고정 회전 속도를 설정하는 대신, 초당 각도 속도를 계산할 것입니다. 그러면 그래프에서 해당 값이 Transform:Rotate 유닛에서 사용할 프레임당 각도로 전환됩니다. 다른 Unity 개발자가 인스펙터에서 속도를 제어할 수 있도록 오브젝트 변수를 사용할 것입니다.

수행해야 할 계산:

[초당 원하는 각도] * [프레임당 컴퓨터 표시 속도(초)] = [프레임당 각도]

예를 들어, 개발자가 인스펙터에 원하는 회전 속도를 초당 45도로 입력한다고 가정해 보겠습니다. 각 프레임이 0.02초 안에 렌더링되면 큐브는 프레임당 45 * 0.02 = 0.9도 회전해야 합니다.

## 3. 새 그래프 추가

Q&A (0)

새 그래프를 시작하겠습니다. 이 방법은 이전에 사용한 방법과 약간 다릅니다.

**1.**프로젝트 창에서, 앞서 만든 VisualScripts 폴더로 이동합니다.

**2.**오른쪽 클릭하고 **Create**> **Visual Scripting** > **Script Graph**를 선택합니다. 그러면 폴더에 새 그래프가 추가됩니다.

**3.**새 그래프의 이름을 “RotateSpeed”로 지정합니다.

**4.**이전과 동일한 단계를 사용하여 큐브에 새 Script Machine 컴포넌트를 추가합니다.

**5.**프로젝트 창의 새 스크립트 에셋을 **None(Script Graph Asset)**이 표시되는 필드로 드래그합니다. 그러면 스크립트의 이름이 표시됩니다.

**6.**이 컴포넌트에서 **Edit Graph**를 클릭하여 비주얼 스크립트를 엽니다. 스크립트가 비어 있을 것입니다(Start 및 Update 미포함).

**7.**Rotation 비주얼 스크립트가 포함된 다른 Script Machine 컴포넌트 옆의 박스를 비활성화하여 해당 스크립트가 실행되지 않도록 합니다.

## 6. Multiply 유닛 추가

Multiply 유닛의 오브젝트 유형 표시기가 초록색으로 표시되어 이 유닛에 다양한 오브젝트 유형을 적용할 수 있음을 알 수 있습니다. 정수와 플로트를 곱해 보겠습니다.

## 8. 플로 브랜칭

Q&A (0)

조건문 'if'는 프로그래밍에서 일반적으로 쓰이는 강력한 구조입니다. 이 구조에서는 부울(참/거짓) 값을 테스트하여 참이면 하나의 플로를 따르고 거짓이면 다른 플로를 따르는데, 이렇게 비주얼 스크립트의 플로를 **브랜칭**합니다.

If 유닛은 키보드 입력을 감지하는 Get Key 유닛과 함께 사용하여 최종 사용자가 큐브를 제어하는 기능을 구현할 수 있습니다. 사용자가 프레임 중에 스페이스바를 선택하면 큐브가 회전하며, 스페이스바를 눌렀다가 놓는 것으로 회전의 시작과 중지를 효과적으로 제어하게 됩니다.

**1.**Update 이벤트 유닛과 Transform:Rotate 유닛 간의 연결을 끊습니다. 커넥터의 시작점을 오른쪽 클릭해서 연결을 끊을 수 있습니다(그 사이에 새 유닛이 들어감).

**2.**'Input: Get Key(Key)'라는 제목의 유닛을 추가합니다(퍼지 파인더에서 'get key' 검색).

**3.**Get Key 유닛은 드롭다운이 매우 깁니다. **Space**를 선택합니다(상단 근처).

**4.**그래프에 If 유닛을 추가합니다(퍼지 파인더에서 'if' 검색).

**5.**Get Key 유닛은 부울 값을 출력하는데, 지정된 키를 누른 상태에는 True, 그렇지 않으면 False입니다. 그래프는 이 값에 따라 브랜칭됩니다. Get Key의 부울 값을 If에 연결하세요(분홍색 표시기).

**6.**Update에서 Get Key로, Get Key에서 If로 그래프의 플로를 연결합니다.

**7.**If 유닛에는 두 개의 출력부가 있는데 하나는 True이고 다른 하나는 False입니다. Get Key가 True를 보낼 때 큐브가 회전하도록 만들 것이므로, True 플로를 Transform:Rotate 유닛에 연결합니다.

**8.**Get Key가 False를 보내면 그래프는 아무 작업도 수행하지 않으므로 False의 플로 화살표는 연결하지 않은 상태로 둡니다.

## 9. Vector3로 위치 변경

Q&A (0)

Vector3는 세 가지 부동 소수점 숫자(X, Y, Z)로 구성된 구조입니다. 3D 공간에서 Vector3는 일반적으로 게임 오브젝트 또는 공간 내 다른 지점의 위치를 지정하거나 변경하는 데 사용됩니다.

Vector3 구조와 Vector3 조작에 유용한 몇 가지 유닛을 사용하여 큐브의 위치를 변경해 보겠습니다. W 키(WASD 키보드 입력에서 '위' 키)를 누르고 있으면 큐브가 위로 이동하는 동작을 구현하겠습니다.

**1.**기존 그래프에서 Get Key와 If 유닛을 복제하여 작업을 시작합니다. 이들을 선택한 다음 오른쪽 클릭하고 **Duplicate Selection**을 선택합니다.

**2.**새로운 Get Key 유닛의 **Key**를 W로 선택합니다.

**3.**원래 If 유닛의 False 출력부에 있는 플로를 새 Get Key(W)의 플로 입력부로 연결합니다. 사용자가 스페이스를 누르지 않고 있는 경우, W를 누르고 있는지 확인하기 위한 플로가 진행됩니다.

[Image: image]

**4.**ChangePos라는 이름의 새 그래프 변수를 만들고 **Type**을 **Vector3**로 지정합니다. **Values**는 0, 0, 0으로 유지합니다. ChangePos는 현재 위치에서 큐브가 이동하는 거리를 나타내는 Vector3를 포함합니다.

**5.**ChangePos를 계산해 보겠습니다. Unity는 몇 가지 유용하고 간단한 Vector3 유닛을 제공합니다. 방향 및 기타 작업을 나타내는 간단한 Vector3 값이 있는데, 그중 하나는 **Vector 3: Get Up**입니다. 이 유닛을 추가하고 Graph Inspector에서 설명을 확인해 보세요. 참고로 Vector3에서의 값은 X, Y, Z이고 Y가 위/아래입니다.

**6.**Get Up Vector3에서 Y 값은 1이지만, 프레임당 1 Unity 유닛(미터)는 큐브를 옮기기에 매우 빠른 속도가 될 것입니다. 이 값에 0.01을 곱해 보겠습니다. **Float Literal** 유닛을 만들고 인라인 값을 0.01로 지정합니다.

**7.**Multiply 유닛에는 여러 오버로드가 있으며 그중 일부는 Vector3용입니다. 하지만 여기서는 하나의 부동 소수점 숫자에 Vector3의 세 값을 곱하기만 하면 되는데, 이 경우 **Multiply (Math/Generic)**를 사용하면 충분합니다. Multiply 유닛을 추가하여 Get Up에 0.01을 곱하도록 연결하세요.

[Image: image]

**8.**그래프 변수 ChangePos의 값을 Multiply의 출력으로 설정하는 Set Variable 유닛을 추가합니다.

**9.**If 유닛의 True 출력부에서 Set Variable 유닛으로 플로 화살표를 연결합니다.

**10.**Transform: Translate(Translation, Relative To) 유닛을 추가합니다. 이 유닛은 **Translation**이라고 하는 양만큼 Self(큐브)를 변환합니다. ChangePos의 출력 값을 Translation에 연결하고, **Relative To** 설정을 Self로 유지합니다.

**11.**Set Variable에서 Transform:Translate로 플로를 연결합니다.

## 10. Switch

Q&A (0)

큐브를 한 방향으로만 옮기는 것은 별로 유용하지 않으므로 S 키를 추가하여 아래로 옮기겠습니다. 방금 추가한 유닛을 복제하고, Get Key 유닛에서 W를 S로 바꾼 다음 Vector 3: Get Up을 Vector 3: Get Down으로 교체하는 정도는 간단할 것입니다. 하지만 나중에 왼쪽 및 오른쪽 움직임까지 추가한다고 상상해 보세요. 나중에 이를 과제로 드릴 수도 있습니다. 그러면 그래프가 커지고 다루기 힘들어집니다.

Switch 유닛은 3개 이상의 선택지가 있는 경우 길게 연속되는 If 유닛을 대체할 수 있는 강력한 브랜칭 메서드입니다. 이 그래프를 깔끔하게 유지하기 위해 Switch 유닛을 사용해 보겠습니다.

**1.**Space를 확인하는 Input Get Key 유닛을 삭제합니다. 그 자리에 **Input: Get Input String**을 추가합니다. 이 유닛은 눌린 키가 있는지 확인하고 해당 키 입력을 문자열로 출력합니다.

**2.**첫 번째 If 유닛을 삭제하고 그 자리에 **Switch On String**을 추가합니다. 이 유닛은 해당 문자열을 입력하고 그에 따라 그래프의 플로를 브랜칭합니다.

**3.**Input: Get Input String 유닛에는 입력부가 없습니다. Graph Inspector를 살펴보면 Update 유닛 없이 프레임마다 키보드 입력을 반환합니다. Update에서 Switch로 직접 이어지는 플로 화살표를 연결하고 Get Input String의 값 커넥터를 Switch의 문자열 입력에 연결합니다.

**4.**Graph Inspector에서 Switch On String 유닛을 다음과 같이 구성합니다.

- **Ignore Case**를 활성화합니다.
- **Options**에서 **+** 아이콘을 선택합니다.
- 공백을 하나 입력합니다. 그러면 그래프의 유닛에 공백이 추가됩니다.
- **+** 아이콘을 두 번 더 선택하여 W 및 S에 대한 옵션을 추가합니다.

**5.**Switch 유닛에서 공백 문자열의 출력부를 Transform: Rotate 유닛에 연결합니다.

**6.**마찬가지로, W 문자열의 출력부를 ChangePos를 업데이트하는 Set Variable 유닛에 연결합니다.

**7.**W 키에 대해 Float, Multiply, Set Variable 유닛을 복제하고 S 키에 대해 이들 유닛의 새로운 세트를 추가합니다.

- W 키에서는 Vector 3: Get Up을 사용한 곳에 **Vector 3: Get Down** 유닛을 추가합니다.
- 새로운 Set Variable 유닛의 플로 화살표를 Transform: Translate에 연결합니다.

**8.**Transform: Translate 유닛의 **Translation** 입력부에는 Set Variable 유닛 모두를 다중 입력으로 만들 수는 없습니다. 대신 Get Variable: ChangePos 유닛을 추가하고 이 유닛을 **Translation**에 대한 입력으로 만듭니다.

**9.** 더 이상 사용되지 않는 Input: Get Key(W)와 해당 If 유닛을 삭제합니다.
