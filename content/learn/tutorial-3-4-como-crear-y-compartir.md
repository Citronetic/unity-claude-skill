## 1. ¿Cómo escribir el nombre de la aplicación y el número de versión?

Q&A (0)

En primer lugar, revisa que no se utilicen los marcadores de posición predeterminados para el nombre de la aplicación, el nombre del desarrollador o la empresa y la vista en miniatura.

**1.  Accede al panel Player Settings (Ajustes del reproductor):**

- Haz clic en **Edit** > **Project Settings**,
- En el lado izquierdo, selecciona el panel **Player**.

**2.  Cambia la información predeterminada de la aplicación:**

- Cambia la información de las propiedades **Company Name (Nombre de la empresa), Product Name (Nombre del producto)** y **Version** **o Número de versión**, para que reflejen el estado actual de tu aplicación.

**3.  Si deseas editar la imagen de bienvenida que aparece cuando se inicia la aplicación:**

- Expande la sección **Splash Image (Imagen de bienvenida)**y edita la configuración.
- Debes tener al menos una licencia Pro para deshabilitar la imagen de bienvenida.

[Image: image]

Ahora, tu aplicación debe aparecer en tu dispositivo con el nombre correcto y se debe cargar con la imagen de bienvenida que deseas.

**Recursos relacionados:**

- [Prácticas recomendadas para los nombres](https://developer.oculus.com/distribute/publish-content-bp/)
- [Prácticas recomendadas para los íconos](https://developer.oculus.com/distribute/asset-guidelines/)

## 2. ¿Cómo confirmar la configuración de publicación recomendada?

Q&A (0)

Además de optimizar el rendimiento de tu aplicación, hay otras recomendaciones específicas para cada plataforma que te ayudarán a que tu aplicación se pueda crear de la mejor manera y tenga el mejor rendimiento posible.

Debido a que las recomendaciones son específicas para cada plataforma y cambian constantemente, la mejor opción para encontrar información precisa y actualizada es buscar en línea.

**1.  Busca orientación sobre las configuraciones recomendadas para la publicación de VR:**

- Explora los enlaces incluidos en la sección «Recursos relacionados» para encontrar algunas recomendaciones específicas.
- Busca en Google «Configuración recomendada de Unity para [dispositivo]» o «Recommended Unity settings for [dispositivo]» (para ver resultados en inglés).

**2.  Configura el panel Player Settings:**

- Haz clic en Edit > Project Settings, luego haz clic en **Player** en el panel a la izquierda.
- Desplaza la pantalla hacia abajo hasta llegar a la sección **Other Settings (Otras configuraciones)**.

**3.  Elige la configuración de calidad:**

- Haz clic en **Quality (Calidad)** en el panel izquierdo de Project Settings (Configuración del proyecto).

**4.  Elige la configuración de XR (Realidad extendida):**

- Haz clic en **XR Plug-in Management (Administración de complementos de XR)**en el panel izquierdo de Project Settings.

**5.  Elige la configuración de procesado:**

- Busca y selecciona el Asset (Recurso) **UniversalRenderPipelineAsset**en la ventana Project (Proyecto).

**6.  Confirma la configuración de sombras:**

- Para cualquier **luz mixta o en tiempo real**, asegúrate de utilizar las sombras adecuadas.

**7.  Para confirmar la configuración de creación:**

- Haz clic en File > Build Settings.

[Image: image]

Ahora, tu aplicación debe tener todas las configuraciones recomendadas para publicarse en la plataforma que elegiste como objetivo.

**Recursos relacionados**:

- [Ajustes de configuración](https://developer.oculus.com/documentation/unity/unity-conf-settings/)
- [Blog: Configuración de Unity para VR móvil](https://developer.oculus.com/blog/tech-note-unity-settings-for-mobile-vr/?locale=en_US)
- [Procesado en estéreo en VR o AR](https://blogs.unity3d.com/2017/11/21/how-to-maximize-ar-and-vr-performance-with-advanced-stereo-rendering/?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774949578207)

## 3. ¿Cómo investigar las opciones para compartir o publicar tu aplicación?

Q&A (0)

Hasta este punto, solo has usado Unity para crear y ejecutar tu aplicación. Averigua lo que necesitarías para distribuir tu aplicación fuera de Unity.

**1.  Explora los requisitos para enviar tu aplicación a una tienda oficial:**

- Utiliza los enlaces que aparecen abajo para obtener más información sobre el proceso.
- Busca en Google «Cómo enviar una aplicación a [tienda]» (p. ej., Steam, Oculus Store, etc.) o «Submit app to [tienda]» (para ver resultados en inglés).

**2.  Explora otras plataformas alternativas donde puedes distribuir tu aplicación:**

- Explora los requisitos para enviar tu aplicación a algunos sitios web, como [SideQuest](https://sidequestvr.com/listing-guide) o [Itch.io](https://itch.io/games/tag-virtual-reality).

Ahora debes tener una idea de las diferentes plataformas disponibles para distribuir tu aplicación y entender lo que se puede necesitar para que tu aplicación se apruebe en una de esas plataformas.

**Recursos relacionados:**

- [¿Cómo enviar tu aplicación a la tienda de Oculus?](https://developer.oculus.com/distribute/)
- [El ciclo de vida de una aplicación de Oculus.](https://developer.oculus.com/distribute/publish-app-review/)
- [Documentación para desarrolladores de Oculus.](https://developer.oculus.com/documentation/unity/)
- [Recomendaciones VRC de Oculus.](https://developer.oculus.com/distribute/publish-quest-req/)

## 5. Actividades de extensión

Q&A (0)

Si deseas desarrollar aún más tus habilidades, explorar nuevos conceptos y mejorar tu proyecto, echa un vistazo a algunas de las actividades de extensión opcionales que aparecen abajo.

Estas actividades tienen etiquetas de [Fácil], [Medio], [Difícil] o [Experto], así como una etiqueta que indica que una actividad [Requiere programación] si es necesario escribir algo de código.

**1.  Investiga el proceso de publicación [Fácil]**

Investiga los requisitos para enviar una aplicación a la plataforma de tu preferencia:

- Esto puede incluir un mercado de aplicaciones oficial, como la [tienda de Oculus](https://www.oculus.com/experiences) o [Steam](https://store.steampowered.com/).
- También puedes enviar tu aplicación a una plataforma no oficial, como [SideQuest](https://sidequestvr.com/) o [Itch.io](https://itch.io/).

**2.  Crea arte para tu aplicación [Medio]**

Toma capturas de pantalla fabulosas y crea un ícono, una imagen principal u otros materiales para mostrar tu aplicación:

- Puedes utilizar la herramienta [Unity Recorder (Grabadora de Unity)](https://docs.unity3d.com/Packages/com.unity.recorder@2.0/manual/index.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774949578207) para capturar imágenes de alta calidad de tu aplicación.
- Sigue las normas de la plataforma de aplicaciones relevante sobre cómo hacer íconos o imágenes de la mejor calidad.

- Ejemplo: [Blog de Oculus sobre cómo preparar la aplicación para el envío (en inglés)](https://developer.oculus.com/blog/how-to-prep-your-app-for-submission/?locale=en_US)
- Ejemplo: [Requisitos de Sidequest sobre el tamaño de las imágenes](https://sidequestvr.atlassian.net/wiki/spaces/SIDEQUEST/pages/196610/How+To+Submit+an+App+to+SideQuest) para anuncios e íconos
