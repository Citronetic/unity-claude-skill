## 1. 概要

Q&A (0)

**ゲームジャム**とは、さまざまな個人が一からビデオゲームを制作するのを競うコンテストです。ゲームジャムは、一般的に時間に制限が設けられています（週末など）。個人向けに組織されているものもあれば、チームとして参加する形式のものもあります。目標がゲームを制作することであれば、ゲームジャムに（対面式またはバーチャルで）参加するのも 1 つの手です。

## 3. ゲームジャムを探す

Q&A (0)

自分の関心に合ったゲームジャムを探すのに役立つリソースをいくつか紹介します。

- **Unity** は [Unity Play プラットフォーム](https://play.unity.com/discover/all-showcases)上でショーケースをホストしており、多くの場合に賞金や賞品が出るほか、Will Wright や Universal のようなクリエイターからさまざまな特典がもらえます。
- [**itch.io**](https://itch.io/jams) は常時何十ものゲームジャムをホストしています。参加はすべてオンラインです。インタラクティブな Jam Calendar では、何百ものゲームジャムを一目で確認できます。
- [**Indie Game Jams**](http://www.indiegamejams.com/) には、世界各地、あるいはオンラインの両方で開催されるゲームジャムがまとめられており、更新も頻繁に行われます。
- [**Game Jams サブレディット**](https://www.reddit.com/r/gamejams/)は、Indie Game Jams ほど定期的には更新されませんが、ゲームジャムを見つけるのに便利なソースの 1 つです。
- [**Ludum Dare**](https://ldjam.com/) は、長年にわたって根強い人気を誇る、オンラインで開催されるゲームジャム兼コミュニティです。「競技」（手厚いサポートを受けられます）は 3 か月ごとに開催され、72 時間にわたって行われます。コミュニティがテーマのアイデアを出し、毎回投票によって新しいテーマが選ばれます。
- [**Global Game Jam**](https://globalgamejam.org/) は、世界最大のゲームジャムイベントです。毎年 1 月に世界各地（とオンライン）で開催され、参加者は何千人にものぼります。

## 4. ゲームジャムに参加する準備を整える

Q&A (0)

少し時間を取って、[ゲームジャムに向けて準備するにあたっての Unity のアドバイス](https://learn.unity.com/tutorial/preparing-for-a-game-jam)や、[いくつかの重要なヒント](https://learn.unity.com/tutorial/game-jam-do-s-and-don-ts)に目を通してみてはいかがでしょうか。

また、Unity ではよくこのパスウェイで触れてきた [Microgame を使用したゲームジャム](https://play.unity.com/discover)をバーチャルで開催しています。ぜひ参加をご検討ください！過去のゲームジャムで実際に使用された [Unity x レゴ® ライブ学習シリーズの録画をご覧ください](https://learn.unity.com/project/unity-x-lego-r-live-learning-series)。

ゲームジャムを含めた今後のライブイベントは、[Unity Learn のライブカレンダー](https://learn.unity.com/live-calendar)で確認できます。
