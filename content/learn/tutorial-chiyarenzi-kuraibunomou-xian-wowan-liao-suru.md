## 1. 概要

Q&A (0)

このチャレンジでは、クライブの次の難問をスクリプティングします。新しいシーンの 3 つの部屋で、クライブが解くべき独自のパズルを作るタスクです。カスタムレベルエディターを使って、シーンに障害物、制御、インベントリアイテム、動かせるオブジェクトを追加します。

それから、プロジェクトを公開し、ギャラリーに掲載して、「Clive the Cat」でビジュアルスクリプティングを学んでいる他の開発者たちと共有することをお勧めします。

## 2. チャレンジシーンのプレビュー

Q&A (0)

実際に作業するシーンをプレビューするには：

**1. Assets > VisualScriptingTutorial > Tutorial > Scenes > ChallengeScene**の順にシーンを開きます。

[Image: image]

**2.**部屋やドア、始点と終点を示す緑と赤の網掛けのセルに注目してください。このレイアウトをそのまま使用することもできますが、以下で説明するカスタムの Level エディターツールを使って、壁やドアを変更したり、プレイエリアの大きさを変えたりすることもできます。クライブはどのような道を通って、自分のエサにたどり着くべきなのか？

**3.**Project ウィンドウで、**Assets > VisualScriptingTutorial > CompleteGame > Prefabs > Objects** の順に進み、そのサブフォルダーに移動します。まだ使用しないで、パズルに加えることができるオブジェクトを確認してください。あなたはどんなオブジェクトをパズルに加えたいですか？

**4.**このシーンを再生してみてください。クライブは壁で止まっていますが、ドアをジャンプして通り抜けられることがわかります。ドアを通れないようにするスクリプトはありません。追加する他のオブジェクトにはデフォルトのビジュアルスクリプトがあるかもしれませんが、これは動いているオブジェクトの侵入を防ぐためだけのものです。クライブのためにどんなチャレンジを作りたいですか？

これらのことを念頭に置いて、クライブの課題に対するアイデアをブレインストーミングしてみましょう。このプロジェクトのビジュアルスクリプトの中で、あなたが楽しんで作ったもの、あるいはもっと良くしたいと思ったものを考えてみてください。それぞれのドアを通過するために、クライブは何をしなければならないのでしょうか？例えば、2 つのドアがある壁には何ができるだろう？クライブの行く手を阻む障害物をどこに置くか。そして、クライブはその障害物を押しのけることができるのか、それとも回避する道を探さなければならないのでしょうか。

SampleScene と TutorialScene を見て、アイデアを考えてみましょう。さらにいくつかのアイデアがあります：

- ボタンを押すことができるアイテムだけでなく、動かせるオブジェクトを障害物として使用する
- クライブにもっと多くのアイテムを（キノコ、キュウリ）与えて、彼のインベントリに集めたり、食べたりできるようにする
- クライブがインベントリにアイテムを持っているか、他のボタンを押したか、レバーを切り替えた場合にのみアイテムを押せるようにする
- クライブがインベントリに別のアイテムを持っていたり、別のボタンを押したり、レバーを切り替えたりした場合にのみアイテムを回収できるようする
- 最初のシーンで登場したキツネを追加する。クライブが動くたびにキツネも左右に動く

- Wants to Enter セル：

- ドアが開いていても何もしない
- ドアが閉まっている場合：

- クライブがキュウリを持っている場合、TrapDoor を開き、動きをキャンセルする

## 4. ソリューションを得るためのリサーチ方法

Q&A (0)

ここで取り上げていないスクリプトロジックのアイデアがある場合はどうすればよいでしょうか？ここでは、自分で調べてみる方法をご紹介します：

- Fuzzy Finder を使って、知っているユニットのオーバーロードや、まだ試していないユニットの名前を探ってみましょう。
- [Unity Scripting API](https://docs.unity3d.com/2021.1/Documentation/ScriptReference/index.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774952760340) のドキュメントを参照してください。そこに記載されている関数やメソッドは、ユニットとしても利用できます。例えば、「Transform」で検索すると、ゲームオブジェクトの Transform コンポーネントを構成する他のユニットに関するドキュメントが表示されます。
- その他の機能については、[Unity Visual Scripting](https://docs.unity3d.com/Packages/com.unity.visualscripting@1.5/manual/index.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774952760340) のドキュメントを参照してください。

**Bolt**というキーワードで質問をオンライン検索してみてください。Bolt が独立した製品として存続している間、コミュニティではよくある質問に対する答えが議論されました。

## 5.  Level エディター

Q&A (0)

シーンにオブジェクトを追加したり、部屋やドアの配置を変えたりするには、本プロジェクトで提供されているカスタムの Level エディターを使用します：

**1.**Unity エディターのメインメニューで、**Tutorial > Tools > Level Editor**の順に選択します。

**2.**ドッキングされていない LevelEditor ウィンドウが表示されます。

**3. Ground** ボタンと **Wall**ボタンを使用して、地下室の地面や部屋の間の壁を作ったり消したりします。

**4. Spawn Point** と **End Point**ボタンを使って、パズルの開始点と終了点を移動します。

**5. Cell Object**のセクションでは、各セクションを開くと、セルに配置できるオブジェクトや、セルオブジェクトの **Erase** ボタンが表示されます。

**6.**Edge Object セクションには、同様のボタンと、ドア用の **Erase**ボタンがあります。

**7.**Level エディターを終了し、Unity エディターに戻ります。

**8.**詳細は、**Assets > VisualScriptingTutorial > CompleteGame > Documentation > DocumentationAndNotes** の順に進み、Level エディターのドキュメントをご覧ください。

**注意：**あなたは、「自己責任で」ゲームに独自のアセットを追加することができます。ドキュメントファイルには、任意のゲームオブジェクトを Cell オブジェクトまたは Edge オブジェクトにする方法が記載されています。

ステップを完了としてマーク

## 6. Cell オブジェクトと Moving オブジェクト

Q&A (0)

PushableBox (Crate)、PushableStatue (Statue)、Fox などの動くオブジェクトは、Prefabs (**Assets > VisualScriptingTutorial > CompleteGame > Prefabs > Objects**の順に選択) を使って追加する必要があります。このプレハブには、本ゲームのために C# で作成された **Moving Object コンポーネント**があります。

セル内の他のオブジェクトは、**Cell Object コンポーネント**を持っています。

Cell オブジェクトを Moving オブジェクト（クライブが押せるオブジェクト）に変換するには、Cell Object コンポーネントを削除し、 Moving Object コンポーネントを追加します。

Moving Object を Cell Object（クライブが押せないオブジェクト）に変換するには、Moving Object コンポーネントを削除し、Cell Object コンポーネントを追加します。
