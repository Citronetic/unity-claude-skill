## 2. Be prepared! Get Unity & Unity Hub

Q&A (0)

First things first: We always recommend using a computer mouse when using Unity. Ok, onto the next!

- If you already have both Unity and the Unity Hub, go to the next step.
- If you've **never** installed the Unity, get it by following the["New Users" path here](https://store.unity.com/download-nuo). This will automatically install the Unity Hub and the right version of Unity for the game jam. When asked to choose a microgame template, select the "Karting" one. Launch Unity with your Karting game. For a step-by-step *how-to*,[follow this video](https://www.youtube.com/watch?v=rE03nC4K_Eg&list=PLX2vGYjWbI0Q1e0IIGsYro3SiE0chtRtc&index=3&t=3s). Have some fun familiarizing yourself with Unity by following the In-Editor-Tutorials that appear in the editor. That's it! Just open this project in Unity (accessible from the Unity Hub) at the Jam on May 3 and follow along to learn cool tips and tricks to customize your game so you can learn Unity in a fun way with expert guidance. You can now skip step 3 and go to step 4!
- If you already have Unity, but you don't have the Unity companion app called the Unity Hub, get it by clicking the["Download Unity Hub" button here](https://unity3d.com/get-unity/download?ampDeviceId=b1d4c960-c18d-4868-99d7-4a16921fb9dd&ampSessionId=1774948551783&ampTimestamp=1775035148060). Once it's installed, go to the next step.

## 3. Be prepared! Get the new-and-improved Karting Microgame.

Q&A (0)

We released an all-new version of the Karting Microgame that runs on 2019.x, so if you already had the Karting Microgame for 2018.4 you’ll need to get the latest version:

**How to get the latest Karting Microgame:**

1. Open the Unity Hub application. IMPORTANT! If you see a lower banner prompting you to install the latest version of the Hub, do so by clicking “Restart now”. (You need the latest version of Hub 2.3.0+)

2. Click the “Learn” tab

3. Click the "Karting Microgame" > Download Project > Open Project.

IMPORTANT! If the project has already been downloaded from the hub (it would say "√ DOWNLOADED") which means you’ll need to download the new version of the Karting Microgame from the Unity Asset Store. If yours doesn’t indicate that, continue on.

4. The Hub will prompt you to install the required version of Unity if you don’t already have it. If that's your case, install it. If prompted with the opportunity to “Add modules to your install” be sure to tick √ the WebGL Build Support module.

5. Open your Karting Microgame in Unity.

6. That’s it! You'll see some In-Editor Tutorials automatically appear. (If they don’t click “Tutorials > Show Tutorials” in the top navbar.) If you're new to Unity or need a refresher, go ahead and follow them. Otherwise, just open this project in Unity at the Jam on May 3 and follow along to learn cool tips and tricks, ask questions, and have a chance to win a Unity Gear Store gift card! (Scroll down to Step 4.)
