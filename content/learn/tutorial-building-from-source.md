## 1. Clone the Source Code

Q&A (0)

There are (fortunately) multiple ways to clone the Unity source code and get it locally on your machine. Previously, source only lived within Mercurial version control but recent efforts have pushed all major branches and trunk to Git.

### Git

- Familiar Git workflow.
- Git repository can be found on our [internal Github instance](https://github.cds.internal.unity3d.com/unity/unity?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774951950289).

### Mercurial

- Instructions are available [on Confluence](https://confluence.unity3d.com/display/DEV/Development+Setup?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774951950289).
