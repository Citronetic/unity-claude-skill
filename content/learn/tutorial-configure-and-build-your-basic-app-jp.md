## 2. Rule の新規作成

Q&A (0)

Hierarchy ウィンドウの MARS メニューオプションを使用して、すでにプロキシ (Proxy) を作成しましたね。ただし、プロキシの作成と設定には、よりガイド的な方法があり、特に、Unity Mars: the Rules
 ワークフローに慣れていないクリエイターにとって有用です。

**Rule**(**ルール**) のワークフローは、AR コンテンツの設定をガイドするように設計されています。Rule のワークフロー以外でも AR オブジェクトを作成できますが、一般的にガイドなしでこのアプローチを取るには、Unity Mars の概念とオブジェクトについてより深い理解が必要です。

以下の手順で、Rule を新規に作成します：

**1.**  Hierarchy で、既存の **Horizontal Plane** ゲームオブジェクトとその子**Sphere** を削除します。これらはテストシーンで使用しましたが、これから基本アプリ用に新しいプロキシ (Proxy) を作成します。

**2.**  メインメニューから **Window > MARS > Proxy Rule Set**の順に選択し、Proxy Rule Set ウィンドウを表示します。

**3.**  **Add Rule** を選択します。デフォルトでは、MARS は「On Every Horizontal Surface (Proxy)」と表示され、コンテンツが含まれないルールを作成します。平面プロキシのビジュアライザーが Simulation ビューに表示され、Scene ビューでマッチングするサーフェスすべてに汎用のプロキシギズモが表示されるはずです。

**4.** 作成した新しい Rule の右側にカーソルを合わせます。表示されたら **Add** (**+**) を選択し、**Spawn Object**を選択します。

**5.**  マッチングするサーフェス上にスポーンするオブジェクトを選択します。オブジェクトを選択すると、Rule の下にインデントされた列で表示されます。このチュートリアルでは、リンゴを選択しました。

**6.**  Simulation View で、右クリック + WASD キーを使ってシーンをナビゲートします。椅子、ソファ、コーヒーテーブルやサイドテーブルなど、あらゆる水平面に、選んだオブジェクトが配置されていることに気づくはずです。

[Image: image]

**7.**  Proxy Rule Set ウィンドウで、ドロップダウンを使って、Rule の頻度を **Every**から **One** に変更します。

[Image: image]

これにより、MARS は Rule にマッチする 1 つだけを検索し、スポーンするようになり、Simulation View に反映されることが確認できます。このサンプルの Simulation View では、リンゴは窓際のサイドテーブルという 1 つの平面にのみ表示されています。

[Image: image]

Rule のワークフローについて詳しく知りたい場合は、[Rule に関する Unity Mars のドキュメントを参照](https://docs.unity3d.com/Packages/com.unity.mars@1.5/manual/index.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774953949124)してください。

## 3. Unity Mars コンポーネントとは？

Q&A (0)

Rules を設定することだけがプロキシを設定する方法ではありません。Unity Mars の特定のコンポーネントを使用して、デジタルコンテンツと現実世界とのマッチングを定義、制限、制御することもできます。

Unity Mars のコンポーネントは 3 種類あります：

- **Unity Mars Condition：**Condition コンポーネントは、Proxy が実世界のオブジェクトと一致するために満たす必要のある要件を定義するために使用できます。
- **Unity Mars Action：**Action コンポーネントを使って、Proxy の条件が一致したとき、あるいは条件の Mars データが変化したときに起こる反応を定義することができます。
- **Unity Mars Force：**Force コンポーネントを使用すると、Proxy ゲームオブジェクトを最終的な位置に引っ張ったり、押したり、保持したりする柔軟なバネのような力を表現することができます。あるゲームオブジェクトに作用する力を組み合わせて、他のオブジェクトの配置に影響を与えることができます。

このチュートリアルでは、基本アプリに設定した Proxy に、Unity Mars Condition コンポーネントを追加します。

#### Unity Mars Condition コンポーネント

**Condition** (**条件**) とは、現実世界のオブジェクトのサイズや色など、1 つのプロパティを定義するコンポーネントの一種です。

各条件には、特性と、その特性の値型の単一のインスタンスが指定した値とどれだけ一致するかを評価するメソッドが含まれています。条件は、Unity Mars がプロキシにマッチングして配置されるために、環境内で満たされる必要がある制約だと考えてください。

通常、実世界のオブジェクトの複雑な定義を構築するために、プロキシに複数の条件を付加する必要があります。より一般的な条件から始めて、より具体的なレベルにまで落とし込んでいく必要があります。例えば、まず平面条件を追加し、その条件に合うサイズと向きを定義します。

## 4. プロキシに条件を追加する

Q&A (0)

以下の手順で Unity Mars Condition を追加し、選択したオブジェクトがスポーンする水平面の大きさを指定します：

**1.** Proxy Rule Set ウィンドウ（**Window > Mars > Proxy Rule Set**の順に選択）で、Rule を選択します。Rule が Inspector に表示されます。

**2.**  Inspector で Proxy (Script) コンポーネントの下に移動し、**Add MARS Component... > Condition > Plane Size**の順に選択します。

この条件により、Unity Mars が指定したサイズのサーフェスを見つけた時のみ、プロキシが表示されるようになります。

**3.**  Proxy (Script Inspector) コンポーネント内の Mars コンポーネントリストの最後にある**Plane Size Condition**を見つけます。デフォルトで表示されていない場合は、折りたたみの矢印を選択し、Mars コンポーネントのプロパティを展開します。

[Image: image]

**4.** **Minimum Size**の**X** と**Y**の値を **0.3** に設定します。これにより選択したモデルが水平面に収まることが保証されます。

**注：**このアプリでは最大サイズの制限は必要ないので、**Maximum Size**プロパティは有効にしないでください。

## 5. Simulation View でアプリを確認する

Q&A (0)

実際のデバイスでコンテンツをテストする前に、Simulation View を使ってイテレートし、プロキシが期待通りの動作をすることをチェックすることができます。

以下の手順に従って、ビルドする前にアプリを確認してください：

**1.**Unity エディターのカスタムレイアウトで、Scene ビューの下に配置されている Simulation View に移動します。再びこのビューを開く必要がある場合は、メインメニュー（**Window > MARS > Simulation View**の順に選択）から開くことができます。

**2.**  Simulation View ウィンドウを右に拡張して、より多くのコンテンツをウィンドウに表示することができます（役に立つ場合）。この場合、Device View ウィンドウの幅が狭くなります。

**3.**  選択したモデルが、窓の横のテーブルに表示され、この場所だけにあることを確認します。

**重要：**Proxy Rule Set の設定が異なる場合、その設定は Simulation View ウィンドウに表示されるコンテンツに反映されます。

Simulation View を使ったテストについて詳しく知りたい場合は、[Unity Mars のドキュメント](https://docs.unity3d.com/Packages/com.unity.mars@1.5/manual/index.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774953949124)を確認します。
