첫 게임 오브젝트 생성에서 커스텀 스크립트 작성에 이르기까지, Unity에서 게임을 생성하는 데 필요한 모든 단계를 살펴보았습니다.

이제 게임 제작이 완료되었으며 **빌드**를 거쳐 디지털 스토어에 업로드할 수 있는 스탠드얼론 애플리케이션을 생성해야 합니다. 빌드 후에는 사용자가 Unity 에디터를 사용하거나 에셋을 다운로드하지 않고도 게임을 실행할 수 있게 됩니다.

## 1. 기본 플레이어 설정

Q&A (0)

사용자에게 게임을 배포하기 위해 에디터에서 생성하는 애플리케이션을 **플레이어**라고 합니다. 플레이어를 생성하기에 앞서 플레이어 설정을 변경해 보겠습니다.

**1.**상단 메뉴 바에서  **Edit > Project Settings**로 이동하고 **Player**를 선택합니다. 여기에서 게임에 관한 정보를 일부 설정할 수 있습니다.

[Image: image]

**2.  Company Name**은 빌드된 게임과 관련된 파일이 저장될 폴더를 생성하는 데 사용합니다. 원하는 경우 Company Name을 변경할 수 있지만, 빌드 설정에 필수적 요소는 아닙니다.

**3.  Product Name**은 게임의 이름을 말합니다.  게임 이름을 '**John Lemon’s Haunted Jaunt**'로 변경합니다. 일반 플레이어 설정에 대한 자세한 내용은 기술 자료를 참고하시기 바랍니다.

**4.**다음 섹션 상단의 아래쪽 화살표 버튼은 이 섹션의 모든 설정이 **PC, Mac 및 Linux 스탠드얼론 플랫폼**용임을 의미합니다. Unity 설치 시 다른 플랫폼에 대한 지원을 설치한 경우에는 툴바에 여러 버튼이 표시됩니다.

[Image: image]

각 섹션을 클릭하면 섹션이 펼쳐지며 각각의 설정이 표시됩니다. 여기에서는 간단한 내용만 다룰 예정이며 [스탠드얼론 플랫폼용 플레이어 설정](https://docs.unity3d.com/Manual/class-PlayerSettingsStandalone.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774951685296) 기술 자료에서 전체 설정에 대한 설명을 확인할 수 있습니다.

## 2. 해상도 및 화면 표시 설정

Q&A (0)

플레이어에게 게임을 표시하는 방식을 조정해 보겠습니다.

**1.  Resolution and Presentation** 섹션을 클릭하여 엽니다.

[Image: image]

**2.  Resolution**에서는 게임이 시작되는 기본 모드를 지정합니다. **Run In Background** 설정은 창/애플리케이션이 상위에 표시되지 않을 때 게임 실행을 지속할지 여부를 지정합니다. 예를 들어 이 옵션을 비활성화할 경우, 사용자가 게임을 하는 도중 웹 브라우저를 열어 검색하게 되면 게임이 일시 중지됩니다.

**3.  Standalone Player Options** 하위 섹션에서 **Display Resolution Dialog**를 Enabled로 설정했는지 확인합니다. Display Resolution Dialog는 사용자가 게임을 실행했을 때 해상도를 선택할 수 있도록 창을 표시합니다.

[Image: image]

**4.**Splash Images 섹션에서 다이얼로그 상단에 표시될 이미지(**Application Config Dialog Banner)** 또는 게임 시작 시 나타나는 로고(**Logos**)를 변경할 수 있습니다.

이제 설정이 끝났으며 빌드 준비가 완료되었습니다.

## 3. 게임 빌드

Q&A (0)

플레이어 설정을 완료했으니 이제 게임을 빌드할 차례입니다. 게임 빌드에는 스크립트, 이미지 및 음향 등 모든 에셋이 포함되며 배포에 최적화된 형식으로 패키징됩니다.

Unity에서 애플리케이션을 빌드하는 방법은 다음과 같습니다.

**1.**상단 메뉴에서 **File > Build Settings**를 선택합니다.

[Image: image]

**2.**상단의 **Scenes In Build** 섹션은 게임에 포함할 모든 씬을 나열합니다. 기능을 테스트하거나 디버그하기 위해서만 사용하는 씬이 있을 수 있기 때문에 Unity에서 최종 제품에 포함될 씬을 지정해야 합니다.

MainScene이 아직 열려 있는 경우 **Add Open Scenes**를 클릭하여 목록에 추가합니다. 또한 씬을 프로젝트 창에서  Build Settings 창

의 Scenes In Build 섹션으로 드래그 앤 드롭할 수도 있습니다.**3.**왼쪽 하단의 **Platform** 섹션에서 게임 실행에 사용할 플랫폼을 선택할 수 있습니다. 기본적으로 에디터는 에디터가 설치된 기기의 플랫폼만 지원합니다.

추가 플랫폼을 설치하는 방법은 다음과 같습니다.

- Unity Hub를 엽니다.
- **설치**
- 해당 Unity 버전의 옆에 있는 **...**를 클릭합니다.
- **컴포넌트 추가**를 클릭하고 설치할 플랫폼을 선택합니다.

**4.**오른쪽 하단에 현재 선택된 플랫폼에 관한 설정이 있습니다. 이 설정은 주로 디버깅 또는 특정 빌드를 위한 설정이므로 지금은 무시해도 괜찮습니다.

**5.**우선은 에디터가 설치된 플랫폼을 기준으로 빌드를 실행합니다. **Build**를 클릭하여 빌드를 트리거합니다.

**6.**Unity에서 파일 탐색기가 열리고 빌드된 게임을 저장할 폴더를 선택하라는 메시지가 나타납니다. 파일 탐색기는 에셋, 프로젝트 설정 및 라이브러리 폴더를 포함하는 프로젝트 폴더를 표시합니다.

새 폴더의 이름을**Build**로 지정하고 해당 폴더를 선택합니다.

## 4. Unity 빌드의 결과물

Q&A (0)

이제 Unity에서 게임을 빌드하고 있습니다. 게임을 빌드하는 중에는 Unity 에디터를 사용할 수 없습니다. 현재 Unity에서는 다음과 같은 작업을 수행 중이기 때문입니다.

- 모든 에셋을 압축하고 패킹합니다.
- 사용하지 않는 에셋을 식별하고 무시합니다.
- 최적화된 양식으로 스크립트를 컴파일합니다.

빌드가 완료되면 Unity에서 프로젝트가 빌드된 폴더가 열립니다. 이 폴더에서 플랫폼용으로 빌드된 실행 파일(windows용 .exe, mac OSX용 .app 등)을 찾을 수 있습니다.

실행 파일을 클릭하여 게임을 실행해 보세요.
