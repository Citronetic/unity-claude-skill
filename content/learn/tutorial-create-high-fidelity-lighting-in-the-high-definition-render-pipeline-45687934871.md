[Image: Project Files: Create High Fidelity Lighting in the High Definition Render Pipeline]Summary

The Create High Fidelity Lighting in the High Definition Render Pipeline workshop is an in-depth exploration of best practices for setting up HDRP lighting in a Scene to create realistic, high-fidelity visuals. It covers lighting configuration, lighting for different scenarios, light types and properties, and how Material properties affect lighting in a Scene. This workshop is taught in 2019.4 LTS using the High Definition Render Pipeline.
