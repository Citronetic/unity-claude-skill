## 2. 進捗を確認する

Q&A (0)

このパスウェイでは、次のことを学習しました。

- Unity エディターの必須のツールとウィンドウを使用する方法
- Unity Hub でプロジェクトと Unity のバージョンを管理する方法
- 3D 空間内でのナビゲート方法（決してたやすいことではありません！）
- 3D プロジェクトを開始する方法
- Unity プロジェクトのスクリプティングを開始する方法
- Unity でオーディオを操作する方法
- 2D プロジェクトを開始する方法

自分が達成したことを評価しましょう！このパスウェイを正式に修了すると、[Unity Essentials パスウェイのバッジ](https://www.credly.com/org/unity/badge/unity-essentials-pathway)がもらえます。このバッジはソーシャルメディアや自分のウェブサイトに掲載できます。  ミッションやパスウェイをさらに修了すると、Learn プラットフォーム上で追加のバッジや経験値（XP）が集まり、実績にマークが付きます。
