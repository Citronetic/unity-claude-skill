## 1. 概要

Q&A (0)

UI デザインの核となるのはテキストです。ユーザーへの情報伝達の主要な手段です。うまくデザインできれば、テキストは驚くほど便利で明快なものになります。

クリーンで一貫した UI の例として、[Airbnb.com](https://www.airbnb.com/) を見てみましょう。

テキストは、デザインが悪いと、醜くなったり、圧迫感を与えたりします。

ごちゃごちゃして分かりにくい UI の例として、[Craigslist.com](https://www.craigslist.com/) を見てみましょう。

このチュートリアルでは、シーンにタイトルを追加して、見栄えをよくする方法を説明します。

## 2. タイトルテキストを追加し、中央へ配置する

Q&A (0)

プロジェクトの最初の UI 要素であるタイトルを追加してみましょう。

**1.** Hierarchy で、右クリックして、**UI > Text - TextMeshPro** の順に選択します。TextMeshPro Importer ウィンドウがポップアップしたら、**Import TMP Essentials** を選択します。TextMeshPro (TMP) は、堅牢で使いやすいテキスト編集ツールで、異なる画面でも明確に表示されるように最適化されています。

これで Game ビュー画面に New Text の文字がかなり小さなフォントで表示されるはずです。まったく同じ位置に文字が表示されなかったり、大きさが違っていても大丈夫です。

[Image: image]

**2.**Hierarchy で**Text**オブジェクトを選択した状態で、**Rect Transform**コンポーネントの**Pos X**と**Pos Y**プロパティを探します。Rect Transform コンポーネントは、2D の矩形の位置とスケールを制御します。

**3.  Pos X**を 0、**Pos Y**を 0 に設定すると、テキストが画面の中央に表示されます。
テキストが他のオブジェクトの上に乗っていて見にくい場合は、**Pos X**と**Pos Y** を調整して修正します。

[Image: image]

**4.** Hierarchy で、**Text** (**TMP**) ゲームオブジェクトを「Title text」にリネームしてください。

また、テキストオブジェクトを作成した瞬間に、いくつかの新しいゲームオブジェクトが自動的に Hierarchy へ追加されていることに気がつくでしょう。

UI 要素の親オブジェクトとして必要な**Canvas** オブジェクトと、ボタンやトグルの選択などの UI インタラクションを管理する **EventSystem** オブジェクトがあります。

[Image: image]

**Canvas** と **EventSystem**については、次回のチュートリアルで詳しく説明します。とりあえず、タイトルの見栄えを少し良くしてみましょう！

## 3. タイトルテキストのカスタマイズ

Q&A (0)

**1.** Text オブジェクトを選択したまま、**TextMeshPro - Text** (**UI**) コンポーネントを探します。このコンポーネントは、テキストの見栄えをカスタマイズするために使用します。

**2.  Text Input**フィールドに、プロジェクトの新しいタイトルを入力します。タイトルは何でもかまいません。新規テキストよりずっと長い場合は、複数行に折り返される可能性があります。次にそれを修正します。

[Image: image]

**3**.  **Wrapping** プロパティを**Disabled** に変更すると、タイトルが 1 行に収まるようになります。

[Image: image]

**4.**テキストの外観や位置をカスタマイズできます。

- TextMeshPro コンポーネントでは、**Font Asset**、**Font Style**、**Font Size**、**Vertex Color**、**Spacing** などのプロパティを使用して、タイトルの見栄えをカスタマイズすることができます。
- Rect Transform コンポーネントの **Pos X**と **Pos Y**プロパティを使用して、画面上でタイトルを移動させますが、かなり中央に近い位置に保つようにしてください。
- タイトルの特定の位置で改行したい場合は、**Text Input**フィールドで手動で追加することができます。

これで、タイトルが美しく見えるはずです。

## 4. アクセシビリティを確保したテキストの作成

Q&A (0)

#### テキストアクセシビリティとは？

タイトルにこだわりすぎる前に、基本的な**アクセシビリティ**の要件を満たしているかどうかを確認しましょう。

アクセシビリティとは、さまざまな身体能力を持つ人々がアプリケーションをうまく使いこなすことができるかということです。テキストの場合、それは主に視覚的なアクセシビリティに関連します。

ここでは、具体的にいくつかのポイントをご紹介します：

- **テキストのサイズ：**テキストは快適に読める大きさでなければなりません。
- **テキストとのコントラスト：**テキストは背景から十分に目立つようにします。
- **テキストに使用されるフォント/書体：**テキストのフォントは読みやすいものでなければなりません。
- **テキストコンテンツ：**テキストは、スクリーンリーダーで読めるように書かれた身近な言葉を使うこと

#### アクセシビリティの評価

以下のタイトルの例を見てください：

[Image: image]

このタイトルのどこがアクセシビリティの要件を満たさないかを特定してみてください。

#### 作品のチェック

上のサンプル例では、タイトルが小さすぎ、コントラストが不十分（特に火の部分）、読みにくいフォントが使われており、Best のスペルも S ではなくドルマークになっています。

これは明らかに極端な例ですが、わずかな変更でも、誰かがアプリケーションをうまく使えるかどうかの分かれ目になることがあります。

テキストのアクセシビリティの詳細については、[**テキストのサイズ**](https://accessibility.digital.gov/visual-design/typography/)、[**書体/フォント**](https://webaim.org/techniques/fonts/)、[**コントラスト**](https://webaim.org/articles/contrast/)、[**コンテンツ**](https://www.w3.org/WAI/tips/writing/)に関する追加情報をご覧ください。

## 5. 新しいフォントのダウンロードとインポート

Q&A (0)

TextMeshPro コンポーネント内に、**Font Asset**プロパティがあるのがわかると思います。オブジェクトピッカーを使用すると、私たちが用意したいくつかのフォントから選択することができます。

TMP で新しいフォントを使用するには、TMP の **Font Asset Creator ツール**を使用する必要があります。これにより、TMP がテキストを表示するために使用する「Font Atlas (フォントアトラス)」と呼ばれるものが生成されます。

[Image: image]

**1.**あなたのプロジェクトで合法的に使用できる、気に入ったオープンソースのフォントをオンラインでブラウズしてください。[**Google フォント**](https://fonts.google.com/)は、このための素晴らしいリソースです。

**2.** 好きなフォントを .otf または .ttf ファイルとしてダウンロードし、プロジェクトにインポートします。

**3.**Unity のメインメニューから、**Window > TextMeshPro > Font Asset Creator**の順に選択します。

**4.**Font Asset Creator ウィンドウで、フォントを**Source Font File**として指定し、**Generate Font Atlas**を選択し、**Save**を選択します。

これで、タイトルに新しいフォントが使えるようになったはずです！

[Image: image]

TMP 用フォントの作成については、こちらの [**Font Aasset Creation**](https://learn.unity.com/tutorial/textmesh-pro-font-asset-creation) チュートリアルを参照してください。
