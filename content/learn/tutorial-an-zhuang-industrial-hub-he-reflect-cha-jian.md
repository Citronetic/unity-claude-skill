## 1. 准备开始

Q&A (0)

Industrial Hub 是 Unity Hub 的特殊版本，其中包括用于其他数字内容创建工具（例如 Revit）的 Reflect 集成插件。除了此新增特性外，其在功能上与标准 Unity Hub 并无任何不同，可按相同的方式使用。如果需要，标准 Hub 和 Industrial Hub 可以在同一台机器上使用；但是，它们必须安装在不同的文件目录中。本教程将指导您如何安装 Industrial Hub 以及将 Reflect 插件集成到 Autodesk Revit 中。

- 在 Reflect 文件夹中找到并运行 Unity Hub 可执行文件。
- 如果在已安装标准 Hub 的机器上安装 Industrial Hub，请选择 Program Files/Applications 以外的目录来进行安装。
- 如果出现消息提示 New Plugins Are Available，请单击 Restart Now。这样可以确保您拥有最新的 Reflect 插件。（**图 01**）。

## 2. 安装 Reflect 插件

Q&A (0)

- 在 Industrial Hub 中，单击 Installs 选项卡，然后选择 Companion Applications。在此处会列出与 Reflect 兼容的所有程序。
- 单击 Find my Companion Apps 按钮即可开始扫描系统中的兼容软件（**图 02**）。

[Image: image]

- 从列表中选择所需的软件，然后单击软件卡片右上方显示为三个竖向点的图标。对于本教程，我们将安装 Revit 集成（**图 03**）。

[Image: image]

- 选择 Install Plugin。随后将为该软件安装 Reflect 插件。
