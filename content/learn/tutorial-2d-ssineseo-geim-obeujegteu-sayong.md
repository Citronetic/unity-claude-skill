이 튜토리얼에서 배울 내용은 다음과 같습니다.

- 새 스프라이트를 생성합니다.
- Sprite Renderer 컴포넌트를 사용하여 스프라이트 이미지를 변경합니다.
- Unity 에디터의 계층 창과 씬 뷰 창에서 2D 오브젝트를 선택합니다.
- 인스펙터 창에서 Transform 컴포넌트를 사용하여 숫자 값으로 2D 오브젝트를 이동, 회전 및 확대/축소합니다.
- Unity 변환 툴을 사용하여 씬 뷰에서 2D 오브젝트를 이동, 회전 및 확대/축소합니다.
- 인스펙터에 표시되는 프로퍼티와 씬에서 게임 오브젝트가 표시되는 방식 사이의 관계를 파악합니다.
- 사각 트랜스폼 툴을 사용하여 씬에서 스프라이트를 조작합니다.
- 스프라이트의 틴트 컬러를 변경합니다.

## 1. 개요

Q&A (0)

3D 프로젝트와 마찬가지로 2D 프로젝트는 제작 중인 경험의 모든 요소가 담긴 **씬**으로 구성됩니다. 2D 씬의 게임 오브젝트를 **스프라이트**라고 합니다. 스프라이트는 일반적으로 임포트한 이미지이며, 해당 이미지를 인터랙티브 2D 게임 오브젝트로 사용할 수 있게 하는 특정 프로퍼티를 가집니다.

2D 프로젝트는 3D 공간을 측면에서 본 것으로, 최종 사용자는 플랫 2D 뷰를 보게 되지만 실제 작업 공간은 여전히 3D입니다. 이러한 접근 방식을 사용하면 더 유연하게 작업할 수 있으며, Microsoft의 [Ori and the Will of the Wisps](https://www.orithegame.com/) 게임과 같은 스타일의 하이브리드 프로젝트를 만들 수 있습니다.

[Image: image]

이 튜토리얼에서는 스프라이트를 생성하고 계층 창과 인스펙터 창에서 스프라이트를 검사합니다. 또한 Unity 변환 툴을 사용하여 스프라이트를 조작하고 인스펙터가 변경 사항을 어떻게 반영하는지 살펴봅니다.

## 3. 첫 스프라이트 생성

Q&A (0)

**1.** 계층 창에서 오른쪽 클릭하고 **2D Object > Sprite**를 선택하여 플레이스홀더 역할을 할 빈 스프라이트를 생성합니다.  이때 씬 뷰에서는 스프라이트를 볼 수 없지만, 스프라이트에 이미지를 할당하면 스프라이트를 볼 수 있습니다.

[Image: image]

**2.**계층 구조에서 생성한 스프라이트를 선택하고 인스펙터에서 스프라이트의 이름을 Circle로 변경합니다.

[Image: image]

계층 구조에서 변경된 이름을 확인할 수 있습니다.

[Image: image]

**3.**인스펙터에서 **Sprite Renderer** 컴포넌트를 찾습니다. **Sprite** 프로퍼티에서 원 아이콘을 클릭하여 Assets 패널을 엽니다.

[Image: image]

**4.**Assets 패널에서 **Knob**이미지를 선택합니다. 이제 스프라이트에 Knob 이미지가 포함됩니다.

[Image: image][Image: image]

**5.**Transform 컴포넌트에는 선택한 스프라이트의 Position, Rotation, Scale 값이 포함됩니다. 인스펙터에서 이 값을 변경하고 씬에서 변경 사항을 확인할 수 있습니다. 또는 씬에서 스프라이트를 조작하면 해당 값이 그에 따라 변경됩니다. Circle 스프라이트를 선택하고 Scale 값을 10, 10, 1로 변경합니다. 씬 뷰에서 스프라이트가 변경되는지 확인합니다.

[Image: image]

**참고:** Unity는 **Y-up 좌표계**를 사용하며, 이는 2D와 3D 모두에 적용됩니다. 플레이어의 시점에서 Y 방향은 위를, Z 방향은 앞뒤를 나타냅니다. 따라서 Z 방향의 Scale 값을 변경해도 플레이어에게는 표시되지 않습니다. Z의 Position 값을 변경하면 다른 애플리케이션의 Z 순서와 같이 스프라이트가 다른 스프라이트의 앞 또는 뒤에 배치됩니다.

**6.**툴바의 이동 툴을 선택(단축키: W)하고 마우스를 사용하여 스프라이트를 씬의 새 위치로 옮깁니다.

[Image: image]

새 위치가 Transform 컴포넌트의 Position 프로퍼티에 어떻게 반영되는지 확인해 보세요. 결과는 다르게 표시될 수 있습니다.

[Image: image]

**7.  사각 트랜스폼** 툴을 사용하면 스프라이트의 모양과 위치를 빠르고 쉽게 변경할 수 있습니다. 스프라이트를 선택한 다음 툴바에서 사각 트랜스폼 툴을 선택(단축키: T)하면 코너에 그립 포인트가 있는 직사각형 테두리가 표시됩니다.

[Image: image]

오브젝트의 아무 지점이나 마우스로 드래그하여 씬에서 스프라이트를 옮깁니다. 모서리에 있는 그립을 드래그하면 X 또는 Y 차원에서 스프라이트의 스케일을 조정할 수 있습니다.
