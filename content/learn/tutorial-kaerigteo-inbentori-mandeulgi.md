[Image: 캐릭터 인벤토리 만들기]Summary

플레이어 인벤토리는 일반적인 게임 메카닉으로, 도구, 무기, 능력, 체력 등 플레이어가 플레이 중에 얻거나 잃을 수 있는 아이템을 포함합니다. 이 튜토리얼에서는 비주얼 스크립팅을 사용하여 클라이브의 인벤토리를 만들어 보겠습니다. 이번 예제에서 클라이브는 문을 여는 열쇠가 필요합니다.

이 튜토리얼에서 배울 내용은 다음과 같습니다.

- 비주얼 스크립트에서 List 오브젝트 유형을 사용하여 플레이어 인벤토리를 만듭니다.
- 비주얼 스크립트에 대한 Scene 변수를 만듭니다.
- 비주얼 스크립트를 통해 씬에서 게임 오브젝트를 제거합니다.
- 원하는 결과가 주어지면 적절한 비주얼 스크립트를 코딩합니다.

## 1. 개요

Q&A (0)

계속해서 새로운 작업으로 게임플레이 로직을 매핑해 볼 텐데요, 이제 클라이브는 문을 열기 위해 열쇠를 가지고 이동할 것입니다. 이번에는 비주얼 스크립팅 변수를 사용하여 클라이브에게 소유한 아이템의 인벤토리를 제공한 다음, 클라이브가 문을 열려고 할 때 인벤토리를 검색하여 클라이브가 열쇠를 가지고 있는지 확인하게 됩니다.

이 기법을 사용해 게임 캐릭터의 도구나 무기 장착, 체력 회복이나 피해, 점수 획득 등을 구현할 수 있습니다.

## 2. 열쇠 얻기

Q&A (0)

클라이브에게 과제를 주겠습니다. 문을 열려면 클라이브에게 열쇠가 있어야 합니다.

이 레벨의 첫 번째 방에 반짝이는 황금 열쇠가 있습니다. 클라이브가 이 열쇠를 주워 문의 잠금을 해제하도록 하겠습니다. 클라이브가 열쇠를 소지하고 있지 않으면 문은 열리지 않습니다.

다음은 이 비주얼 스크립트를 작성하는 데 필요한 정보입니다.

- 계층 구조에서 **ObjectRoot > Key** 오브젝트에 새 Script Machine과 비주얼 스크립트를 추가합니다. 이 스크립트에 'KeyScript'라고 이름을 붙입니다.
- 오브젝트를 갖고 있는 클라이브의 동작을 시뮬레이션하려면, 모든 게임 오브젝트의 스크립트가 이 정보에 쉽게 액세스할 수 있도록 Scene 변수를 사용하여 클라이브에게 아이템 인벤토리를 제공합니다(**힌트:** 이 인벤토리를 사용하면 나중에 클라이브가 다른 아이템을 줍게 할 수 있습니다).
- 나중에 클라이브의 인벤토리에 더 많은 아이템을 추가해야 할 수 있으므로, Scene 변수에 대해 다른 오브젝트 유형인 **List**를 사용할 것입니다. 이 유형을 사용하면 하나의 변수에 원하는 만큼 많은 값을 포함할 수 있습니다. 이 리스트는 **List of Strings**이며 클라이브가 수집하는 아이템의 이름을 저장합니다. Scene 변수를 Inventory라고 하고 열쇠 이름을 CatKey로 지정하겠습니다.
- 리스트에 아이템을 추가하려면 **Add List Item** 유닛을 사용하세요.
- 열쇠가 있는 셀에 클라이브가 들어가면, 열쇠는 인벤토리에 추가된 후 사라집니다. 열쇠를 사라지게 하려면 **Component: Destroy (Obj)** 유닛을 사용하세요. 이 유닛은 기본적으로 속해 있는 컴포넌트(여기서는 Script Machine)를 파괴하는데, 이 경우에는 적절한 결과가 아니죠. 대신 **This** 유닛을 추가하여 게임 오브젝트(열쇠)를 파괴하도록 지정하세요.

위의 모든 정보를 고려해서 이 열쇠를 직접 스크립팅할 수 있을까요? 직접 도전해 보세요. 필요에 따라 다음 단계의 이미지를 참고하여 작업 현황을 확인할 수 있습니다. 작업을 반드시 저장하세요(**Ctrl + S/Cmd + S**).

플레이 모드를 실행하여 비주얼 스크립트를 테스트합니다. 클라이브가 열쇠가 있는 셀에 들어가기 전에 계층 구조에서 **Scene Variables** 오브젝트를 열고 Inventory 변수를 확인합니다. 클라이브가 셀에 들어가면 'CatKey'라는 문자열 하나로 이루어진 리스트가 Inventory 변수에 포함됩니다. 이제 키가 사라지고, 만들어 둔 Scene 변수에 'CatKey' 문자열이 나타나야 합니다.

## 3. 열쇠 얻기(지침)

Q&A (0)

다음은 열쇠의 스크립트를 작성하는 단계별 지침입니다.

1. **ObjectRoot**> **Key**를 선택합니다.
2. Key 게임 오브젝트에 Script Machine을 추가하고 비주얼 스크립트의 이름을 KeyScript로 지정합니다. 체계적인 구성을 유지하려면 VisualScripts 폴더에 저장하세요.
3. 이 스크립트는 열쇠가 있는 셀에 클라이브가 들어갈 때 실행되므로, Enter Cell 이벤트로 플로를 시작합니다.
4. 오브젝트 유형이 **List of String**인 **Inventory**라는 Scene 변수를 만듭니다(**팁:** Type 메뉴에서 'list of string'을 검색하는 것이 가장 쉬움). Value는 지정하지 않습니다.
5. KeyName이라는 Object 변수를 만들고, Type은 String으로, Value는 'CatKey'로 지정합니다. 이는 나중에 문을 열 때 찾게 될 문자열입니다.
6. **Add List Item** 유닛을 추가하고 Enter Cell 이벤트에서 플로를 연결합니다.
7. 리스트와 열쇠 이름에 대한 Get Variable 유닛을 추가하고, Add Item List의 입력부에 연결합니다.
8. 클라이브가 열쇠를 얻은 뒤 열쇠가 사라지도록 **Component: Destroy (Obj)** 유닛을 추가합니다.
9. 열쇠 게임 오브젝트를 나타내기 위해 **This** 유닛을 추가하고 Component: Destroy의 입력부에 연결합니다.
10. 작업을 저장합니다(**Ctrl + S/Cmd + S**).

## 4. 열쇠를 사용하여 문 열기

Q&A (0)

이제 문을 열어 보겠습니다. 'CatKey'가 인벤토리에 있는지 확인하는 새로운 조건을 추가하면 됩니다. 인벤토리에 있는 경우, IsOpen을 True로 변경하고 문 열기 애니메이션과 효과를 플레이합니다.

인벤토리 리스트에서 'CatKey'를 검색하려면 **List Interface: Contains**를 사용합니다. 그러면 클라이브의 열쇠 소지 여부를 나타내는 Boolean이 반환됩니다.

기존 플로에서 리스트를 확인해야 하는 위치는 어디일까요? IsOpen이 False라면 클라이브가 열쇠를 가지고 있는지 여부에 관계없이 클라이브의 이동이 취소되어야 하므로, Cancel Movement 이후여야 합니다. 하지만 열쇠가 없으면 IsOpen을 True로 설정할 수 없죠. 따라서 IsOpen을 True로 설정하는 Set Variable 유닛보다 앞에 있어야 합니다. 따라서 Cancel Movement와 Set Variable 사이에 If 유닛을 추가합니다.

**그룹 제안:** 몇 개의 문을 더 스크립팅할 것입니다. 나중에 이 비주얼 스크립트를 더 읽기 쉽게 만들기 위해 그룹을 활용해서 무엇을 할 수 있을까요?

이 스크립트를 작성해 보세요. 필요에 따라 다음 단계의 이미지를 참고하여 작업 현황을 확인할 수 있습니다. 작업을 반드시 저장하세요(**Ctrl + S/Cmd + S**).

플레이 모드를 실행하여 비주얼 스크립트를 테스트합니다. 클라이브가 열쇠 없이 문에 접근하게 한 다음, 열쇠를 얻고 다시 시도하도록 하세요. 클라이브는 잠시 멈췄다가 문이 열린 후 다음 방으로 갈 수 있을 것입니다.

## 5. 열쇠를 사용하여 문 열기(지침)

Q&A (0)

다음은 클라이브가 열쇠를 가지고 있는 경우에만 열릴 첫 번째 문의 스크립트를 작성하는 단계별 지침입니다.

**1. ObjectRoot**> **FirstDoor**의 비주얼 스크립트로 돌아갑니다.

**2.**KeyName이라는 Object 변수를 만들고, Type은 String으로, Value는 'CatKey'로 지정합니다. 이 값을 사용하여 리스트를 검색하게 됩니다.

**3. List Interface: Contains** 유닛을 추가하여 플로에서 Cancel Movement와 Set Variable 사이에 배치합니다.

**4.**List Interface: Contains 유닛에 대한 입력으로 Get Variable 유닛을 사용하여 Inventory 변수와 KeyName 변수를 가져옵니다.

**5.**List Interface: Contains 유닛은 부울 값을 출력합니다. If 유닛을 사용하여 이 Boolean을 확인하고 이 값이 True인 경우에만 플로를 계속합니다.

**6.**제안: 이 스크립트의 가독성을 높이기 위해 그룹을 몇 개 추가해 보세요.

**7.** 작업을 저장합니다(**Ctrl + S/Cmd + S**).
