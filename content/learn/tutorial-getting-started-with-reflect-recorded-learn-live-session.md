[Image: Getting Started with Reflect - Recorded Learn Live Session]Summary

Watch the recording of the Learn Live virtual session where you will experience Unity’s newest product offering for the AEC industry: Reflect. You'll learn how to install and integrate Reflect into Autodesk Revit, and how the viewer can be used on different platforms. After watching this session, you will be able to:

- Describe the differences between the standard and Industrial Hub
- Install the Reflect Plugin for Revit
- Identify what platform types the Reflect viewer is available on today
- Navigate in the Reflect viewer
- Use the Live Link feature to see changes in Revit appear in Reflect in real time
- Use Reflect in VR and AR
- Import Revit assets into the Unity Editor
- Identify the different features of the Reflect Prefab to make custom viewers
- Identify the render pipelines that Reflect will support
