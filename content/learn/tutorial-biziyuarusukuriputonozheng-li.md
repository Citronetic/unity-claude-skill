## 1. 概要

Q&A (0)

「Clive the Cat's Visual Crypting」ゲームの最初のレベルをプレイすると、アニメーションや視覚効果でドアが開閉するのが見えました。このシーケンスは多くのドアに適用され、部屋ごとに異なるロジックで行われます。あるドアはクライヴがボタンを押すと開き、他のドアはクライヴが鍵を持っていないと開かない、などです。

クライヴの冒険をプログラムする準備をして、これらのエフェクトを何度もスクリプティングするのを避けるために、ドアを開閉するビジュアルスクリプトに追加できる**スーパーユニット**を作成します。スーパーユニットは、ビジュアルスクリプトを他のビジュアルスクリプトに入れ子にして再利用することができます。時間と労力の節約になります。

このチュートリアルでは、ユニットを整理したり、自分のメモやコメントを追加したりするのに使えるグループも紹介します。

これらのツールを使えば、ビジュアルスクリプトを整頓して効率的に保つことができるでしょう。

## 2. はじめる前に

Q&A (0)

これらのチュートリアルでは、**TutorialScene**（Project ウィンドウで：**Assets > VisualScriptingTutorial > Tutorial > Scenes > TutorialScene**の順に移動）というタイトルのシーンで作業を行います。

## 3. ビジュアルスクリプトの検証とテスト

Q&A (0)

ビジュアルスクリプトのサンプルである DoorAnimation を開きました。ここでは、このフローに含まれる他の 4 つのユニット（詳しくは、Graph ウィンドウで各ユニットを選択し、Graph Inspector を参照してください）について説明します：

- **Component：Get Component in Children**（最初のコンポーネント、左から順に）は、ゲームオブジェクト「Self」とその子の中から Animator コンポーネントを探します。ここでは、「Self」は FirstDoor です。FirstDoor には Animator コンポーネントがあり、このユニットはそれを検出して出力します。
- **Animator：Set Bool** は、「Opened」というパラメーターを True または False（チェックボックス）の値で、その Animator に送信します。Animator は、このパラメーターが True に変わるとオープニングアニメーションを再生し、False に変わるとクロージングアニメーションを再生するように設定されています。
- **Component：Get Component in Children**（2つ目）は、Self（FirstDoor）やその子にある Visual Effect コンポーネントを検索します。ここでは、FirstDoor の子である VFX_GateMovingSmoke に Visual Effect コンポーネントがあります。
- **Visual Effect：Play** はその視覚効果を再生します。

このチュートリアルでは、それぞれのユニットが何をするのかを大まかに知っていることが重要で、アニメーションやビジュアルエフェクトがどのように動作するかは重要ではありません。

このビジュアルスクリプトをテストするには：

**1.**Start ユニットを追加し、フローの始まりに接続します。このスクリプトが何をするのかを確認するために、一時的に使用します。

**2.**Animator で：Set Bool ユニットで Value を有効 (True に設定）にして、ドアが開くようにします。

**3.**Hierarchy で、**ObjectRoot > FirstDoor**と選択します。

**4.**FirstDoor にすでにアタッチされている****Script Machine に加えて、もう 1つ Script Machine コンポーネントを追加します（Inspector で**Add Component**を選択し、Add Component メニューから **Script Machine**を選択します）。

**5.**DoorAnimation スクリプトを Project ウィンドウから **Graph**プロパティにドラッグして、この新しい Script Machine に追加します。

**6. Script Machine** の隣にあるチェックボックスを使って、両方の Script Machine が有効になっていることを確認します。

[Image: image]

**7.**Play モードに入り、FirstDoor を観察します。FirstDoor とは、クライブがこのレベルを開始する最初の部屋にある鉄製のドアのことです。ゲーム開始時、他のドアはすべて閉じられていますが、FirstDoor は少しのほこり（視覚効果）を伴って開かれます。

## 4. ビジュアルスクリプトでユニットをグループ化

Q&A (0)

グループを使ってこのビジュアルスクリプトを整理してみましょう。**グループ**とは、ビジュアルスクリプトを整理して読みやすくするために、定義してコメントで説明できるユニットのセットのことです。 これは、スクリプトの構造やパフォーマンスを変えるものではありません。あなたやビジュアルスクリプトを読む人がよりよく理解できるように、参考のために用意されています。C# のようなコード化されたプログラミング言語のコメント行に相当するものです。

この Graph にグループを追加するには：

**1.** Ctrl キー (Windows) または Cmd キー (macOS) を押しながら、マウスの主ボタンをドラッグして、最初の **Component: Get Component in Children** と **Animator: Set Bool**ユニットを囲む長方形を作り、ドアのアニメーションを再生します。

**2.** ボックス自体または Graph Inspector の「Group」という文字をダブルクリックして、グループのタイトルを編集し、「Animation」などの意味のある名前を付けます。

**3.** このグループについてメモを取るには、Graph Inspector でコメント（例：「開閉アニメーションを再生します」）を追加します。

**4.** お好みで Graph Inspector のカラーピッカーを使って、このグループに特徴的な色をつけてみましょう。

**5.** 以上の手順を 2つ目の **Component: Get Component in Children** と **Visual Effect: Play** ユニットで繰り返し、ビジュアルエフェクトを再生します。

## 5. スーパーユニットの作成

Q&A (0)

**スーパーユニット**とは、カスタムユニットとして使用できるネストされたスクリプトのことです。スーパーユニットは、同じ流れのユニットを何度も使用する必要がある場合に便利です。このフローをスーパーユニットに変換して、他のいくつかのビジュアルスクリプトでドアの開閉を行う際に使用できるようにします。（スーパーユニットの汎用性を示すために、後で何度か強化することもあります）。

#### 整理整頓

**1.**プロジェクトを整理するために、このスクリプトを「working (作業中)」のフォルダーに移動しましょう。Project ウィンドウまたはファイルエクスプローラーで、DoorAnimation ビジュアルスクリプトを 1 つ上のレベルの VisualScripts フォルダーに移動します。

**2.**ファイル名を変更しましょう。というのも、このファイルは、作業が終わるまでに、ドアのアニメーション以上のことをするからです。Project ウィンドウでファイルを右クリックして **Rename** を選択し、**AnimAndFX**に名前を変更します。

#### 入力と出力の追加

他のユニットと同様に、スーパーユニットにも入力と出力があります。これらは**Input**と**Output** ユニットで指定します。これらをスーパーユニットに追加してみましょう：

**1.**この Graph から Start ユニットを削除します (Play モード開始時に実行するのではなく、他のビジュアルスクリプトからこのビジュアルスクリプトを実行することになります)。

**2.** Fuzzy Finder で **Nesting**カテゴリーを選択し、**Input**を選択すると、Graph の先頭に Input ユニットが追加されます。このユニットでは、スーパーユニットのフローの始まりを指定したり、元のビジュアルスクリプトからスーパーユニットに渡す値を定義することができます。

**3.** Input ユニットを選択した状態で、 Graph Inspector に移動し、**Trigger Inputs**セクションを見つけます。ここでは、このスーパーユニットへの流れを定義します。+ を選択してTrigger Input を追加し、Key フィールドに Input と入力して Enter キーを押します。

**4.** Input ユニットのフローコネクターを Animation グループの Get Component in Children ユニットに接続します。

**5.** Graph Inspector の **Data Inputs** セクションに進み、元のスクリプトからこのスーパーユニットに渡す値を定義します。今回の例では、ドアが開くか閉じるかを指定します。+ を選択して Data Input を追加し、**Key** フィールドに**AnimationValue** と入力して Enter キーを押します。**Type** として **Boolean**を選択します。

**6.** Input ユニットには、**Animation Value** と書かれた出力があります。この出力を Animator: Set Bool ユニットの入力に接続します。

**7.** Fuzzy Finder で **Nesting** カテゴリーを選択し、**Output**を選択すると、Graph の最後に Output ユニットを追加することができます。このユニットでは、スーパーユニットのフローの末端を指定したり、スーパーユニットから元のビジュアルスクリプトに渡すことができる値を定義することができます。

**8.** Graph Inspector で、Output の**キー**を使用して **Trigger Output**を追加し、Enter キーを押します。

**9.** この Output ユニットには、**Data Outputs**を追加しないでください。この場合、スクリプトは元のスクリプトに新しい値を返しません。ただし、このスーパーユニットが新しい値を計算している場合は、それを返すために Data Output を追加することを覚えておいてください。

**10.** Input フローと Output フローを、それぞれグラフ (Graph) の始点と終点に接続します。最終的には下の画像のようなグラフになるはずです。

**11.** 作業を保存します (Ctrl+S / Cmd+S)。
