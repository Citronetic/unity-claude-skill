## 4. ¿Cómo crear objetos simples en 3D?

Q&A (0)

Los **primitivos**son GameObjects de formas básicas en 3D, como cubos y esferas, que puedes agregar a una Escena para crear objetos simples y marcadores para recursos que luego importarás. Usarás cubos y esferas primitivos en todo este proyecto. Consulta [Objetos primitivos y marcadores (en inglés)](https://docs.unity3d.com/Manual/PrimitiveObjects.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774953042576) para obtener más información sobre otros primitivos disponibles.

**1.**Para crear un cubo primitivo en la Escena, haz clic derecho en una sección vacía en Hierarchy y selecciona **3D Object >** **Cube***.*

[Image: image]

El GameObject llamado Cube (Cubo) ahora aparece en Hierarchy y aparece un cubo en la vista de Escena.

## 5. ¿Cómo practicar tus habilidades con el Editor de Unity?

Q&A (0)

Este es un ejercicio para practicar y probar tu habilidad para realizar tareas importantes de rutina en el Editor de Unity. Realiza este ejercicio para poner en práctica tus habilidades. Si necesitas una guía práctica, consulta [**Explorar el Editor de Unity (en inglés)**](https://learn.unity.com/tutorial/explore-the-unity-editor-1#6124ecdcedbc2a54df07500f).

**Nota:** Hemos agregado color a las imágenes a continuación para que se puedan ver mejor. Si necesitas mejorar el contraste entre GameObjects y el suelo en el Editor de Unity, puedes [cambiar el color de fondo (en inglés)](https://learn.unity.com/tutorial/project-setup-processes#61310680edbc2a061b6dddc9).

**1.**  En la ventana Hierarchy, selecciona Cube (Cubo).

**2.**  Usa Focus (Foco) para centrarte en tu cubo y luego aléjalo un poco.

[Image: image]

**3.**  Usa la herramienta Move (Mover) para mover el cubo horizontalmente (sobre el eje X o Z) y hacer lugar para agregar otro cubo en la misma ubicación.

**4.**  Sigue el proceso anterior para agregar otro cubo.

**5.** Cada cubo tiene una unidad (un metro) de ancho. Mueve los cubos para que estén a cuatro o cinco unidades separados.

**6.**  Cambia la visualización para que puedas ver los dos cubos.

[Image: image]

**7.** Usa la herramienta Scale (Ajustar tamaño) para cambiar las dimensiones de un cubo, de modo que sea rectangular en vez de cuadrado.

**8.** Usa la herramienta Rotate (Girar) para girar el otro cubo y que se vea como un rombo.

[Image: image]

**9.** Usa Pan (Vista panorámica), Zoom o Flythrough (Sobrevuelo) para mover tu punto de visualización entre el cubo rectangular y el cubo de rombo.

**10.**  Usa Orbit (Girar alrededor) para girar la visualización alrededor del objeto, de modo que puedas ver solo el cubo rectangular al mirar de un lado y solo el cubo de rombo al mirarlo de otro lado. Desde este punto de visualización, no podrás ver los dos al mismo tiempo.

En este ejercicio, usaste las herramientas Move, Scale y Rotate, así como Pan, Zoom, Flythrough y Orbit, y fuiste a una ubicación específica en el espacio en 3D. Cuando puedas realizar estas operaciones con facilidad, estarás listo para continuar.

¿Qué más te gustaría hacer en el Editor? Como práctica adicional, estas son otras maniobras que puedes probar:

- Obtén una visualización aérea (desde arriba) o inferior (desde abajo) de los cubos.
- Agrega más primitivos y organízalos para crear un muñeco de nieve, una casa, un automóvil u otro prototipo.
- Alinea varios primitivos en una pista de obstáculos y luego usa la herramienta Flythrough para girar alrededor de ellos.
