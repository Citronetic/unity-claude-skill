비주얼 스크립팅 작업 영역을 설정하고 나면 이제 '유닛'이라고 하는 비주얼 스크립팅의 요소를 알아보고, 유닛을 로직 플로에 추가하고 정렬하는 방법을 배울 수 있습니다. 이 튜토리얼에서 배울 내용은 다음과 같습니다.

- 비주얼 스크립팅에서 '유닛'의 의미

- 유닛 부분 식별: 제목과 아이콘, 데이터 유형 표시기, 플로 화살표, 입력부, 출력부

- 흐리게 표시된 유닛의 의미 설명
- Graph 창의 Dim 기능 토글
- 플로 화살표와 커넥터로 유닛 연결
- 유닛에서 인라인 값 변경

## 2. Start 및 Update

Q&A (0)

Script Machine 컴포넌트에서 **New** 버튼을 사용하였으므로 Start 이벤트와 Update 이벤트가 그래프에 이미 포함된 상태입니다. C#을 사용하여 새 스크립트 컴포넌트를 만들면 Start 메서드와 Update 메서드가 동일한 방식으로 포함됩니다.

[Image: image]

그래프의 각 직사각형 노드를 **유닛**이라고 합니다. 유닛은 특정 결과를 발생시키는 명령 또는 이벤트로, 노드라고 불리기도 합니다.

이번 튜토리얼에서 다룰 대상은 Update 이벤트로, Update는 플레이 모드에서 발생하는 모든 프레임(화면 업데이트)마다 트리거(실행)됩니다. 사용자의 그래프는 큐브를 프레임마다 특정 각도로 회전시킵니다.

Start 이벤트는 플레이 모드가 시작될 때 트리거되는데, 이 튜토리얼의 비주얼 스크립트에서는 사용하지 않는 이벤트입니다. Start 유닛을 선택한 후 Delete 키를 눌러 Start 유닛을 삭제합니다.

## 3. 퍼지 파인더 표시

Q&A (0)

유닛을 그래프에 추가하려면 Graph 창 배경을 오른쪽 클릭합니다. 그러면 **퍼지 파인더**라고도 하는 **Unit** 컨텍스트 메뉴가 나타납니다.

[Image: image]

**퍼지 파인더**는 모든 유형의 유닛을 포함하는 멀티 레벨 메뉴로, 모든 Unity 스크립팅 API가 포함되어 있습니다. 퍼지 파인더를 사용하면 모든 유닛을 이름으로 검색하거나 카테고리에 따라 선택할 수 있습니다.

## 4. 필요한 유닛 찾기

Q&A (0)

필요한 유닛을 쉽게 찾으려면 Unity API에 대해 어느 정도 익숙해져야 하며, 이를 위해서는 반복해서 사용해 봐야 합니다. 이번 작업에 필요한 유닛은 'Transform: Rotate'입니다.

퍼지 파인더의 검색창에 'rotate'를 입력합니다.

[Image: image]

몇 가지 다양한 'Transform:Rotate' 유닛을 선택할 수 있는데, 이러한 유닛들을 **오버로드**라고 합니다. 같은 유닛의 각 오버로드는 동일한 작업을 수행하지만 각각 다른 입력 파라미터 세트가 필요합니다. 이번 연습에서는 **Transform: Rotate(X Angle, Y Angle, Z Angle)**를 선택합니다. 이 유닛은 게임 오브젝트의 Transform 컴포넌트에 대한 회전 설정을 제어합니다.

## 5. 유닛 살펴보기

Q&A (0)

새 유닛을 자세히 살펴보겠습니다. 살펴볼 유닛을 선택합니다.

[Image: image]

- 이 유닛에는 회색 제목이 있는데, 회색 제목은 명령어를 나타냅니다. 그래프에서 몇 가지 다른 색상으로 유닛을 식별할 수 있습니다.
- 빨간색, 파란색, 초록색으로 구성된 회전 기호는 여러 유닛 표시기 중 하나로, 그래프를 해석하는 데 도움이 됩니다.
- **Self**는 이 유닛이 머신을 통해 이 그래프에 연결된 게임 오브젝트를 제어함을 의미합니다.
- **플로 화살표**는 유닛과 유닛 사이의 플로 순서를 나타냅니다. 잠시 후에 그래프의 실행 순서를 나타내기 위해 플로 화살표를 연결해 보겠습니다.
- 유닛의 왼쪽에 있는 원은 **입력부**이고, 다른 유닛들의 오른쪽에 있는 원은 **출력부**입니다. 이러한 원은 유닛 사이에서 값과 오브젝트를 전달하는 데 사용됩니다.

X Angle, Y Angle, Z Angle 옆에 있는 기호는 각 입력부에 대한 **오브젝트 유형 표시기**입니다. 이 경우 파란색 점은 부동 소수점 숫자를 나타냅니다. 오브젝트 유형은 이 프로젝트 후반부에서 다루겠습니다.

## 7. 유닛 설정

Q&A (0)

작동 중인 플로에 아직 연결되지 않은 유닛은 선택하지 않으면 흐리게 표시됩니다. **Dim** 버튼을 켜거나 꺼서 이 기능을 제어할 수 있습니다.

[Image: image]

Update 유닛의 오른쪽에 있는 플로 화살표를 Rotate 유닛의 왼쪽에 있는 플로 화살표로 드래그하여 Transform:Rotate 유닛을 이 그래프의 플로에 연결합니다. 입력부 위에 옅은 파란색 사각형이 나타나는데, 해당 사각형의 아무 곳에나 화살표를 놓으면 됩니다.

커넥터의 시작점(왼쪽) 끝을 오른쪽 클릭해서 플로 화살표를 삭제할 수 있습니다.

[Image: image]

이제 완전한 비주얼 스크립트를 위한 유닛이 준비되었습니다. 이 유닛은 이벤트로 시작하고, 이벤트가 발생할 때 수행할 명령어로 끝납니다.

**플레이** 버튼을 선택하여 비주얼 스크립트를 실행해 보세요.

Graph 창에서 커넥터를 따라 움직이는 구슬이 플로를 나타냅니다. 하지만 Transform:Rotate 유닛의 0 값을 변경하여 얼마나 회전해야 하는지 설정하지 않았으므로, 씬 뷰에서는 아무 일도 일어나지 않습니다.

## 8. 그래프에서 인라인 값 변경

Q&A (0)

큐브를 회전시키는 방법 중 하나는 유닛 자체의 입력 필드인 **인라인 값**을 변경하는 것입니다.

**1.**플레이 모드를 종료합니다.

**2.**Transform:Rotate 유닛에서 **X Angle**이라는 레이블이 지정된 인라인 값을 **1**로 변경합니다.

**3.**플레이 모드를 다시 시작합니다. 큐브가 X차원 기준으로 프레임당 1도씩 회전합니다.

**4.**플레이 모드에서 **X Angle** 값을 **3**으로 변경한 다음 원하는 결과를 얻을 때까지 **Y Angle**과 **Z Angle** 값도 변경합니다.

**5.**세 가지 값을 모두 변경한 후 플레이 모드를 종료하고, 해당 값이 유닛에서 유지되는 것을 확인합니다.

씬을 저장합니다(Ctrl/Cmd + S키). 씬 파일과 씬에서 사용된 그래프의 .asset 파일을 각각 저장하게 됩니다.

C# 스크립트였다면 원하는 큐브 회전을 만드는 값을 찾을 때까지 스크립트의 플레이, 중지, 편집을 반복해야 했을 것입니다. C# 스크립팅에서는 실행되는 동안 코드를 편집할 수 없지만, 비주얼 스크립팅에서는 가능합니다.

C# 스크립팅 경험이 있다면 코드에서 직접 값을 지정할 경우 해당 값이 하드 코딩된다는 점을 알고 있을 것입니다. 여기에서는 Transform:Rotate 유닛의 하드 코딩된 값을 변경했습니다.
