존 레몬의 공포 체험을 개발하는 다음 단계로 게임의 종료 지점을 생성해 보겠습니다. 이 단계를 통해 플레이어를 위한 완전한 경험을 만들고 코드 작성에 대한 자신감을 쌓을 수 있습니다.

이 튜토리얼을 완료하면 레벨이 완성되며, 이후에는 플레이어에 맞서는 적을 추가할 예정입니다.

## 1. UI 설정

Q&A (0)

벌써 많은 작업을 통해 게임의 캐릭터, 환경 및 카메라를 설정했습니다. 이제 JohnLemon이 집을 탈출했을 때 게임이 끝나도록 엔딩을 생성해야 합니다. 엔딩을 제작하고 나면 적을 게임에 배치하고 최종 개선 사항을 추가할 예정입니다.

제작에 들어가기 전 이번 튜토리얼에서는 어떤 기능을 추가할지 먼저 생각해 보겠습니다.

JohnLemon이 출구에 도달했을 때 게임이 페이드아웃하고 종료되어야 합니다. 그러나 Unity 에디터에서 게임이 종료되는 것과 최종적으로 빌드된 게임 버전에서 종료되는 것은 다릅니다.

먼저 게임이 페이드아웃되도록 만들어야 합니다. 게임을 페이드아웃하려면 Unity의**UI(사용자 인터페이스) 시스템**을 사용합니다.

**3.**씬 창에서 상단 바의 2D 버튼을 클릭하여 2D 모드를 활성화합니다. 이를 통해 새 게임 오브젝트를 제대로 볼 수 있습니다.

## 2. 캔버스 설정

Q&A (0)

**1.**계층 구조에서 Canvas의 이름을 **FaderCanvas**로 변경합니다.

**2.**인스펙터에서 FaderCanvas에 연결된 컴포넌트를 확인합니다.

[Image: image]

FaderCanvas의 Transform 컴포넌트가 이전의 Transform 컴포넌트와 다른 것을 확인할 수 있습니다. UI 시스템의 게임 오브젝트에는 위치에 대해 더 많은 제어가 필요하므로 **Rect Transform**컴포넌트를 설정해야 합니다. UI 계층 구조 루트에 있는 캔버스의 경우 Rect Transform 설정은 읽기 전용입니다.

**3.**Canvas 컴포넌트는 해당 캔버스에 속하는 UI 요소가 렌더링되는 방식을 관리합니다. 이 렌더링은 기본적으로 **Render Mode** 설정에 따라 관리됩니다.

Render Mode에서 제공되는 세 가지 모드는 다음과 같습니다.

- Screen Space - Overlay: 캔버스가 화면을 채우고 캔버스의 모든 UI 요소가 모든 항목 위에 렌더링되는 모드
- Screen Space - Camera: 캔버스가 화면을 채우지만, 특정 카메라로 렌더링되고 카메라의 거리에 영향을 받는 모드
- World Space: 씬에 UI가 있으며 다른 오브젝트의 앞이나 뒤에 렌더링되는 모드(예: 3D 월드에서 캐릭터 위에 표시되는 이름 태그)

화면 전반에 걸쳐 이미지를 늘리고 해당 이미지가 모든 항목 위에 렌더링되도록 해야 합니다.  즉, 여기서는 기본 렌더 모드인 **Screen Space - Overlay** 모드가 적합합니다.

**4.**FaderCanvas 게임 오브젝트에서 확인할 다음 컴포넌트는 **Canvas Scaler** 컴포넌트입니다.  Canvas Scaler 컴포넌트를 이용하면 다양한 크기의 화면에서 UI 요소의 상대적인 크기를 조정할 수 있습니다. 지금은 이미지가 화면 전체를 채우고 있으므로 상대적인 크기는 신경 쓰지 않아도 됩니다.

Canvas Scaler 컴포넌트 오른쪽 상단에 있는 설정(톱니바퀴) 아이콘을 클릭하여 컨텍스트 메뉴를 엽니다. **Remove Component**를 선택합니다.

[Image: image]

**5.**FaderCanvas 게임 오브젝트의 마지막 컴포넌트는 **Graphic Raycaster** 컴포넌트입니다.  이는 클릭과 같은 UI 이벤트를 감지합니다.  어떤 UI 요소가 클릭되었는지를 파악하며 해당 요소에 이벤트를 보내 적합한 컴포넌트가 반응할 수 있도록 합니다. 이 게임 내에서 플레이어는 UI와 상호 작용하지 않기 때문에 이 컴포넌트가 필요하지 않습니다.

Graphic Raycaster 컴포넌트 오른쪽 상단에 있는 설정 아이콘을 클릭하여 컨텍스트 메뉴를 엽니다. **Remove Component**를 선택합니다.

## 4. Rect Transform 컴포넌트 자세히 알아보기

Q&A (0)

Rect Transform 컴포넌트에 대해 좀 더 자세히 알아보겠습니다.

3D 게임 오브젝트의 위치는 게임 오브젝트의 피벗에 있는 단일 포인트로 표시됩니다.  Transform 컴포넌트에서 이 피벗 포인트의 위치는 게임 오브젝트의 부모와 관련이 있습니다. 사각 트랜스폼도 이와 유사하게 작동하지만, UI 요소는 영역을 표현하기 때문에 일부 다른 점이 있습니다. 사각 트랜스폼의 위치가 게임 오브젝트 부모의 단일 피벗 포인트와 관련이 있는 반면, UI 요소는 **부모의 영역**과 관련이 있습니다.  이 부모의 영역은 **사각 트랜스폼의 앵커**로 표시됩니다.

씬 창에서 꽃처럼 생긴 기즈모를 보셨을 것입니다.

[Image: image]

이는 실제로 여러 포인트가 함께 모인 것으로,  각각의 포인트가 바로 앵커입니다.  총 부모 영역의 비율에 맞춰 4개의 앵커 포인트로 직사각형이 생성됩니다.

[Image: image]

이미지는 FaderCanvas의 자식으로, 화면 전체를 채웁니다.  즉, 이미지의 위치는 화면 전체 영역과 관련이 있습니다.

UI 요소의 위치는 픽셀 단위로 측정됩니다. 모든 화면에 동일한 수의 픽셀이 사용되지 않으므로 매우 중요한 부분입니다.  바로 이 부분에서 앵커 시스템이 활약하게 됩니다. 앵커는 화면의 한 지점을 기준으로 삼으며, 사각 트랜스폼은 해당 기준점에서 UI 요소가 얼마나 떨어져 있는지(오프셋) 픽셀 단위로 나타냅니다.

[Image: image]

만약 앵커가 분산되어 있으면 사각 트랜스폼이 앵커 영역의 각 면에서 픽셀 오프셋을 표시합니다.

[Image: image]

그럼 이를 게임에 어떻게 적용해야 할까요?  우선 전체 화면이 페이드되어야 합니다.  즉, 이미지가 화면 모양이나 크기와 관계없이 화면 전체를 덮을 수 있어야 합니다. 전체 화면을 페이드하기 위해서는 앵커 영역이 화면 전체인지, 해당 영역에서 오프셋이 없는지를 확인해야 합니다.

## 5. Rect Transform 컴포넌트 설정

Q&A (0)

Rect Transform 컴포넌트를 설정하는 방법은 다음과 같습니다.

**1.**계층 창에서 **Image** 게임 오브젝트를 선택합니다.

**2.**인스펙터에서 **Rect Transform** 컴포넌트를 찾습니다. **Anchors** 설정을 펼칩니다.

**3.  x 및 y의 최솟값을 0**으로 설정하고, **x 및 y의 최댓값을 1**로 설정합니다.

[Image: image]

앵커는 앵커의 부모와 연관되기 때문에 0은 화면의 맨 왼쪽 또는 맨 아래, 1은 화면의 맨 오른쪽 또는 맨 위를 의미합니다.

앵커를 설정하였으니 변경된 이미지의 위치를 확인해 봅니다. 이제 위치가 Left, Top, Pos Z, Right 및 Bottom으로 명시되어 있습니다.  Pos Z(중요하지 않음)를 제외하고 Left, Top, Right 및 Bottom은 앵커 영역에서 게임 오브젝트까지의 거리를 픽셀 단위로 나타냅니다. 음수 값은 요소가 앵커 영역 밖에 있음을 나타내고,  0 값은 앵커 영역에서 오프셋이 없음을 의미합니다.

위에 나온 예시를 보면 이미지의 왼쪽은 앵커 영역의 왼쪽으로부터 394픽셀, 이미지의 오른쪽은 앵커 영역의 오른쪽으로부터 942픽셀, 이미지의 위쪽은 앵커 영역의 위쪽에서부터 487픽셀, 이미지의 아래쪽은 앵커 영역의 아래쪽으로부터 145픽셀 들어와 있음을 의미합니다.

**4.**이미지의 앵커 영역이 전체 화면이므로 오프셋은 필요하지 않습니다. 이미지의 Rect Transform에서 **Left**, **Top**, **Right** 및 **Bottom** 프로퍼티를 **0**으로 설정합니다.

[Image: image]

**6.**이제 이미지가 화면을 모두 덮습니다.

[Image: image]

이제 이미지 크기 설정이 완료되었으며 컬러를 변경해야 합니다.

**7.**인스펙터에서 **Image** 컴포넌트를 찾습니다.

[Image: image]

첫 번째 프로퍼티는 Source Image 프로퍼티입니다.  Source Image 프로퍼티에서 특정 그림을 표시할 수 있으며,   특정 그림이 없이 공백인 경우에는 단색의 직사각형이 표시됩니다.  직사각형의 컬러는 **Color** 프로퍼티에서 설정할 수 있습니다.

**8.**컬러 피커 창을 엽니다. RGB 채널을 **0**으로 설정하고 A는 최댓값으로 남겨둡니다(범위가 0~1인 경우 1, 0~255인 경우 255). 이렇게 하면 컬러가 검정색으로 설정됩니다.

A는 컬러를 구성하는 네 번째 채널인 **Alpha** 채널입니다.  컬러의 Alpha는 투명한 정도를 나타내며,  Alpha 값이 낮을수록 게임 오브젝트가 더 투명해집니다. 이미지의 알파 값 조정은 페이드인 및 페이드아웃을 만들기 위한 핵심 요소입니다.

**9.**에디터의 다른 곳을 클릭하여 피커 창을 닫습니다.

이제 화면이 완전히 검정색으로 바뀌었습니다.

if 문의 코드는 알파 값이 1이 될 때까지만 실행되므로, 다음 줄을 추가하여 게임을 종료시키면 됩니다.

```csharp
Application.Quit();
```

**8.**먼저 알아 두어야 할 점이 있습니다. 이 메서드는 실제로 게임을 종료하지만, 완전히 빌드된 애플리케이션에만 작동합니다. 현재 이 게임은 에디터에서 실행하는 프로젝트이기 때문에 이 메서드가 작동하지 않습니다. 따라서 마지막 튜토리얼에서 게임을 빌드한 후 이 코드가 작동하는지 확인할 수 있습니다.  그때까지는 이전과 동일하게 플레이 모드를 종료해야 합니다.

**9.**현재 스크립트 상태로는 이미지의 페이드가 끝남과 동시에 게임이 종료됩니다. 그러나 이미지가 페이드인하고, 플레이어가 잠시 이미지를 확인한 다음 게임이 종료된다면 훨씬 더 나을 것입니다.

이를 구현하려면 마지막 if 문에 시간을 좀 더 추가하면 됩니다. 변수를 사용하면 언제든 이미지가 보이는 시간을 원하는 대로 변경할 수 있습니다.

fadeDuration 변수 선언(클래스의 상단 부근) 아래에 시간 변수 선언을 하나 추가합니다.

```csharp
public float displayImageDuration = 1f;
```

**10.**이제 다음과 같이 변경하여 if 문의 fadeDuration에 시간을 추가하기만 하면 됩니다.

```csharp
if(m_Timer > fadeDuration + displayImageDuration)
        {
            Application.Quit();
        }
```

이제 코딩이 끝났습니다. 완료된 스크립트는 다음과 같습니다.

```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class GameEnding : MonoBehaviour
{
    public float fadeDuration = 1f;
    public float displayImageDuration = 1f;
    public GameObject player;
    public CanvasGroup exitBackgroundImageCanvasGroup;

    bool m_IsPlayerAtExit;
    float m_Timer;

    void OnTriggerEnter (Collider other)
    {
        if (other.gameObject == player)
        {
            m_IsPlayerAtExit = true;
        }
    }

    void Update ()
    {
        if(m_IsPlayerAtExit)
        {
            EndLevel ();
        }
    }

    void EndLevel ()
    {
        m_Timer += Time.deltaTime;

        exitBackgroundImageCanvasGroup.alpha = m_Timer / fadeDuration;

        if(m_Timer > fadeDuration + displayImageDuration)
        {
            Application.Quit ();
        }
    }
}
```
