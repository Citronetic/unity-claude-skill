**Create with Code - Teacher Training - Section 3 of 3**

In this final section of the Create with Code Teacher Training, you will review the most important steps that need to be completed before the course can be rolled out with your students. This includes setting up the computer lab so that it's ready to go when students walk in, making sure you leave enough time to complete the necessary training before the course start date, and, if relevant, purchasing any certification exam licenses so your students can validate their skills.
