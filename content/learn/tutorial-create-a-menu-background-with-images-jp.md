シンプルな背景やアイコンから、より複雑なヘッドアップディスプレイやダッシュボードまで、UI 設計において画像は非常に重要です。このチュートリアルでは、 Settings (*設定)*メニュー背景とボタンにカスタム画像を追加し、それらが異なる方向に引き伸ばされても見栄えが良くなることを確認します。

このチュートリアルが終わるころには、次のことができるようになります：

- 画像要素を追加する。
- UI スプライトの適用と設定。
- Image コンポーネントにマテリアルを適用し、設定する。

## 1. 概要

Q&A (0)

これまでのチュートリアルでは、テキストとボタンの要素を扱いました。UI 設計におけるもう一つの主要な要素は**画像 (Image)**です。画像は、背景、アイコン、バッジなどに使用することができます。

このチュートリアルでは、設定画面の新しい背景画像を追加し、デフォルトのボタン画像をカスタムのものに置き換え、9-slicing と呼ばれる技術を使って、画像が適切に拡大縮小されるように設定する方法について説明します。

## 2. 基本設定の背景の追加

Q&A (0)

Settings (*設定*) メニューの要素は、単純な矩形の上に配置されます。この矩形を作成するために、Image オブジェクトを追加する必要があります。

**1.**まず、**Title Text**と**Settings Button**ゲームオブジェクトを無効にして、Canvas をクリアします。こうすることで、何もない白紙の状態から作業を始めることができます。

[Image: image]

**2.**  Hierarchy で、**右クリック**して、**UI > Image** と進み「Settings Menu」という名前に変更します。**画像** (**Image**) は、プロジェクトにインポートした任意の画像を表示することが可能な、非常にシンプルな UI 要素です。デフォルトでは、シーンの中央に白い四角形が追加されます。

[Image: image]

**3.**  Scene ビューで、**Rect** ツールを使って、 Settings (*設定*) メニューに適したものになるように画像の位置とサイズを変更します。

[Image: image]

**4.**  Image コンポーネントで、カラーピッカーを使って背景 (background) の色変更を選択します。Color ウィンドウから、Alpha プロパティ (**A**) を使って、背景を半透明にすることもできます。

[Image: image]ステップを完了としてマーク

## 3. 「Settings」タイトルの追加

Q&A (0)

**1.**Hierarchy で、**Settings Menu**ゲームオブジェクトを右クリックし、**UI > Text - TextMeshPro**と選択します。

[Image: image]

デフォルトでは、背景がその親オブジェクトであるため、これは New Text オブジェクトを背景オブジェクトの中心に固定します。

**2.**  **Text (TMP)**ゲームオブジェクトの名前を「Settings Text」に変更し、TextMeshPro - Text (UI) コンポーネントのプロパティを編集して、テキストがうまく表示されるようにします。

[Image: image]

これで、Settings (*設定*) メニューはかなり見栄えが良くなったはずです。 最後に、Title に戻るためのカスタム **Exit**ボタンが残されています。

## 4. シンプルな終了ボタンの作成

Q&A (0)

設定画面に移動するための設定ボタンがありますね。今度は、タイトル画面に戻るための終了ボタンが必要です。このボタンを作成しながら、Image コンポーネントを使って UI 要素の設計をカスタマイズする方法について、さらに詳しく見ていきます。

**1.** Hierarchy で、**Settings Menu** ゲームオブジェクトを右クリックし、**UI > Button - TextMeshPro** と選択します。これで新しい Button の子オブジェクトが作成されるので、「Exit Button」という名前に変更することができます。

[Image: image]

デフォルトでは、ボタンには Button という文字が表示され、デフォルトのフォントが使用されます。

**2.**Exit Button オブジェクトを展開し、子オブジェクトである Text オブジェクトを選択します。テキストを、あなたの好きなフォントで「X」と表示されるように変更します。「X」は、閉じる、または終了を意味する記号です。

[Image: image]

もちろん、終了ボタンはまだ理想的な形や位置にあるわけではありません。

**3.**Scene ビューの Rect ツールか Rect Transform コンポーネントのプロパティを使用して、終了ボタンを UI 背景の右上隅に完全な正方形で配置することができます。

[Image: image]

この終了ボタンはどこに配置してもかまいませんが、ユーザーはこの種のボタンを右上隅か左上隅に表示することに慣れており、直感的に操作できることが UI 設計の目標の一つであることを心に留めておいてください。

## 5. 9 スライス画像の選択

Q&A (0)

通常、画像を横方向や縦方向に拡大縮小すると、画像は歪んでしまいます。

例えば、このリスの画像をご覧ください。

[Image: image]

次に、水平方向や垂直方向に拡大したときに、かわいそうなリスがどのように歪んで見えるかに注目してください。

[Image: image][Image: image]

ただし、終了ボタンの画像をリサイズして、長方形から正方形に変えても、画像がつぶれたり歪んだりすることはありませんでした。どうしてでしょうか？

**1.**ボタンを選択した状態で、Inspector の下部にある Image Preview ウィンドウを探します。画像を表示するには、ウィンドウを拡大する必要があります。

[Image: image]

画像プレビューでは、3×3 のグリッドで 9 つのセクションに分けられていることに注目してください。 これは**9-slicing (9 スライス)**と呼ばれる手法で、長方形の画像を引き伸ばすことなくスケールすることができます。

これは、角は伸ばさず、それ以外の面を必要な分だけスケーリングすることで実現されます。

以下は、ボタンの例と、このテクニックを使った場合と使わない場合の水平方向のスケールの見え方の例です：

[Image: image]

9-slicing については、[**マニュアル**](https://docs.unity3d.com/Manual/9SliceSprites.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774954116647)に詳しく書かれています。

これは Unity が提供するデフォルトの 9 スライスボタン画像ですが、もちろんこれを、あるいは他の UI 画像コンポーネントを、カスタムの 9 スライス画像に置き換えることができます。

**2.**Image コンポーネントで、オブジェクトピッカーボタンを使って、私たちが用意した他の UI ボタン画像をいくつか見てみましょう。Settings (*設定*) メニューに最適と思われるものを選んでください。

## 6. UI のカスタマイズを続ける

Q&A (0)

UI に画像を追加したり、入れ替えたりする方法をご存知ですよね。これらのスキルを応用して、UI 要素をさらに見栄えのよいものにしましょう。設定ボタンにデフォルトの画像ではなく、カスタム画像を使用させたり、背景の周りにボーダーを追加して、より目立たせることも可能でしょう。

[Image: image]

UI 要素にさらに詳細を加える場合、Canvas の**Draw Order** を理解することが重要です。オブジェクトは、Hierarchy にリストされた順に画面に描画されます。つまり、Hierarchy の下位にあるオブジェクトは、上位にあるオブジェクトの上に描画されることになります。

Hierarchy でオブジェクトの順序が正しくないと、下図のようにオブジェクトが重なってしまうことがあります。

[Image: image]

これを解決するには、その終了ボタンを Hierarchy の背景となるボーダーの下に配置すればよいのです。
