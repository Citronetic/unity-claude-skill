대규모 프로젝트는 항상 처음부터 체계적으로 구성하는 것이 좋습니다. 이 튜토리얼에서는 불필요한 반복 작업을 줄이면서 비주얼 스크립트를 체계적으로 구성하고 읽기 쉽게 유지하는 방법을 알아봅니다.

이 튜토리얼에서 배울 내용은 다음과 같습니다.

- 비주얼 스크립트에서 유닛을 그룹화합니다.
- 그룹을 사용하여 비주얼 스크립트에 제목과 코멘트를 추가합니다.
- 다른 비주얼 스크립트에서 호출할 수 있는 슈퍼 유닛을 만들고 편집합니다.
- Graph Inspector에서 슈퍼 유닛에 대한 입력과 출력을 지정합니다.

## 1. 개요

Q&A (0)

고양이 클라이브와 비밀의 지하실 게임의 첫 번째 레벨을 플레이하면서, 문이 애니메이션이나 시각 효과와 함께 열리고 닫히는 것을 보았습니다. 이 시퀀스는 많은 문에 적용되는데, 각 방마다 다른 로직을 활용합니다. 어떤 문은 클라이브가 버튼을 눌러야 열리고, 또 다른 문은 클라이브가 열쇠를 가지고 있어야 열리는 식입니다.

클라이브의 모험을 프로그래밍할 준비를 하고 애니메이션이나 시각 효과를 반복해서 스크립팅할 필요가 없도록, 문을 열거나 닫는 모든 비주얼 스크립트에 추가할 수 있는 **슈퍼 유닛**을 만들어 보겠습니다. 슈퍼 유닛을 사용하면 비주얼 스크립트를 다른 비주얼 스크립트에 중첩하여 재사용함으로써 시간과 노력을 줄일 수 있습니다.

이 튜토리얼에서는 유닛을 구성하고 자신만의 메모와 코멘트를 추가하는 데 사용할 수 있는 '그룹'도 소개합니다.

이러한 툴을 사용하면 비주얼 스크립트를 깔끔하고 효율적으로 관리할 수 있습니다.

## 2. 시작하기 전에

Q&A (0)

이 튜토리얼에서는 **TutorialScene**이라는 씬에서 작업합니다. 프로젝트(Project) 창에서 **Assets > VisualScriptingTutorial > Tutorial > Scenes > TutorialScene**을 선택하면 됩니다.

또한 비주얼 스크립트가 포함된 다음 폴더를 사용합니다.

- 작업 스크립트: **VisualScripts**(프로젝트 창: **Assets > VisualScriptingTutorial > Tutorial > VisualScripts**)
- 샘플 및 예제: VisualScripts 아래의 **Samples**하위 폴더

프로젝트 창의 Samples 하위 폴더에서 **DoorAnimation**파일을 찾아 더블 클릭해서 엽니다.

이 스크립트에는 게임 오브젝트의 Animator 컴포넌트를 제어하는 유닛이 포함되어 있습니다. Animator 컴포넌트와 Animator 창에 익숙하다면, Animator 창을 열고 Door Animator 컨트롤러를 확인하면 아래 단계에서 이어지는 내용에 대한 맥락을 파악할 수 있습니다.

## 3. 비주얼 스크립트 분석 및 테스트

Q&A (0)

학습을 시작할 샘플 비주얼 스크립트인 DoorAnimation을 열었습니다. 이 플로의 네 가지 유닛에 대한 아래 설명을 읽어 보세요. 자세한 내용은 Graph 창에서 각 유닛을 선택하고 Graph Inspector를 참조하세요.

- **Component: Get Component in Children**(왼쪽에서 첫 번째)은 게임 오브젝트 'Self'와 그 자식에서 Animator 컴포넌트를 검색합니다. 여기에서 'Self'는 FirstDoor로, 이 유닛이 찾아서 출력하게 될 Animator 컴포넌트가 있습니다.
- **Animator: Set Bool**은 Value가 True 또는 False(체크박스 선택)인 'Opened' 파라미터를 Animator로 보냅니다. Animator는 파라미터가 True로 변경되면 열기 애니메이션을 재생하고, False로 변경되면 닫기 애니메이션을 재생하도록 설정되어 있습니다.
- **Component: Get Component in Children**(두 번째)은 Self(FirstDoor) 또는 그 자식에서 Visual Effect 컴포넌트를 검색합니다. 이 경우 FirstDoor의 자식인 VFX_GateMovingSmoke에 Visual Effect 컴포넌트가 있습니다.
- **Visual Effect: Play**는 시각 효과를 플레이합니다.

이 튜토리얼에서는 애니메이션이나 시각 효과가 작동하는 방식보다 이러한 각 유닛의 기능을 전반적으로 이해하는 것이 중요합니다.

이 비주얼 스크립트를 테스트하는 방법은 다음과 같습니다.

**1.**Start 유닛을 추가하고 플로의 시작 부분에 연결합니다. 이 스크립트가 어떤 일을 하는지 보기 위해 임시로 이 유닛을 사용할 것입니다.

**2.**문이 열리도록 Animator: Set Bool 유닛에서 값을 활성화(True로 설정)합니다.

**3.**계층 구조(Hierarchy)에서 **ObjectRoot > FirstDoor**를 선택합니다.

**4.**FirstDoor에 이미 연결된 Script Machine 외에 다른 Script Machine 컴포넌트를 추가합니다. 인스펙터(Inspector)에서 **Add Component**를 선택하고 Add Component 메뉴에서 **Script Machine**을 선택하면 됩니다.

**5.**DoorAnimation 스크립트를 프로젝트 창에서 **Graph** 프로퍼티로 드래그하여 새로운 Script Machine에 추가합니다.

**6. Script Machine** 옆의 체크박스를 선택하여 두 Script Machine을 모두 활성화합니다.

[Image: image]

**7.**플레이 모드를 실행하여 클라이브가 이 레벨을 시작하는 첫 번째 방의 철문인 FirstDoor를 살펴봅니다. 게임이 시작되면 다른 문은 모두 닫혀 있으며, 먼지가 약간 흩날리는 시각 효과와 함께 FirstDoor가 열립니다.

## 4. 비주얼 스크립트에서 유닛 그룹화

Q&A (0)

그룹을 사용하여 비주얼 스크립트를 구성해 보겠습니다. **그룹**은 비주얼 스크립트를 체계적으로 구성하고 읽기 쉽게 유지하기 위해 코멘트로 정의하고 설명할 수 있는 단순한 유닛의 집합입니다. 그룹은 스크립트의 구조나 성능을 변경하지 않으며, 작성자 본인을 포함하여 사람들이 비주얼 스크립트를 더 잘 이해할 수 있도록 하기 위한 레퍼런스로 사용됩니다. 또한 그룹은 C#과 같은 코딩된 프로그래밍 언어의 주석과 동일한 역할을 합니다.

그래프에 그룹을 추가하는 방법은 다음과 같습니다.

**1.** Ctrl(Windows) 또는 Cmd(macOS) 키를 누른 상태에서 클릭하고 드래그하여 첫 번째 **Component: Get Component in Children**과 **Animator: Set Bool** 유닛을 포함하는 직사각형을 만듭니다. 이 둘은 문 애니메이션을 플레이합니다. 음영 처리된 상자가 유닛 주위에 나타납니다.

**2.** 상자 자체 또는 Graph Inspector에서 'Group'이라는 단어를 더블 클릭하고 그룹 제목을 편집하여 'Animation'과 같이 식별 가능한 이름을 지정합니다.

**3.** 그룹에 대한 메모를 작성하려면 Graph Inspector에 코멘트를 추가합니다(예: '열기/닫기 애니메이션 플레이').

**4.** 필요한 경우 Graph Inspector의 컬러 피커를 사용하여 그룹에 고유 컬러를 지정합니다.

**5.** 두 번째 **Component: Get Component in Children**과 **Visual Effect: Play** 유닛에 대해 위 단계를 되풀이합니다. 이 둘은 시각 효과를 플레이합니다.

비주얼 스크립트는 아래 이미지처럼 표시되어야 합니다.

[Image: image]

비주얼 스크립트의 어디서나 그룹을 사용하면 작업자 본인뿐만 아니라 다른 사람들에게 유닛 그룹이 수행하는 작업, 특정 방식으로 스크립트를 작성하는 이유, 나중에 개선할 수 있는 사항 등을 알릴 수 있습니다. 이 튜토리얼을 진행하며 그룹의 활용법을 몇 가지 안내할 예정이며, 일부 샘플 비주얼 스크립트에도 그룹이 사용된 것을 확인할 수 있을 것입니다.

## 5. 슈퍼 유닛 만들기

Q&A (0)

**슈퍼 유닛**은 커스텀 유닛으로 사용할 수 있는 중첩된 스크립트입니다. 슈퍼 유닛은 유닛의 동일한 플로를 여러 번 반복해서 사용해야 할 때 유용합니다. 이 플로를 슈퍼 유닛으로 전환하면 문을 열거나 닫으려 할 때 다른 비주얼 스크립트에도 여러 번 활용할 수 있습니다. 플로를 몇 차례 수정하면서 슈퍼 유닛의 다양한 활용성을 확인해 보겠습니다.

#### 체계적 구성 유지

**1.**프로젝트를 체계적으로 관리하기 위해 이 스크립트를 작업 중인 폴더로 옮기겠습니다. 프로젝트 창이나 파일 탐색기에서 DoorAnimation 비주얼 스크립트를 한 단계 위의 VisualScripts 폴더로 옮깁니다.

**2.**파일 이름을 변경합니다. 작업이 완료될 때쯤에는 문 애니메이션화뿐만 아니라 다른 작업도 수행할 것이기 때문입니다. 프로젝트 창에서 파일을 오른쪽 클릭하고 **Rename**을 선택한 다음 이름을 **AnimAndFX**로 변경합니다.

#### 입력과 출력 추가

다른 유닛과 마찬가지로 슈퍼 유닛에도 **입력**과 **출력**이 있습니다. 입력은 Input 유닛으로, 출력은 Output 유닛으로 지정됩니다. 입력과 출력을 슈퍼 유닛에 추가하겠습니다.

**1.**그래프에서 Start 유닛을 삭제합니다. 플레이 모드가 시작될 때 실행하는 대신, 다른 비주얼 스크립트에서 이 비주얼 스크립트를 실행할 것입니다.

**2.** 퍼지 파인더에서 **Nesting** 카테고리를 선택한 다음 **Input**을 선택하여 그래프 시작 부분에 Input 유닛을 추가합니다. 이 유닛을 사용하면 슈퍼 유닛 플로의 시작점을 지정하고, 원래 비주얼 스크립트에서 슈퍼 유닛으로 전달할 값을 정의할 수 있습니다.

**3.** Input 유닛을 선택한 상태에서 Graph Inspector로 이동하여 **Trigger Inputs** 섹션을 찾습니다. 여기에서 이 슈퍼 유닛으로 들어오는 플로를 정의하게 됩니다. Trigger Input에서 +를 선택해 항목을 추가한 다음, **Key** 필드에 Input을 입력하고 Enter 키를 누릅니다.

**4.** Input 유닛의 플로 커넥터를 Animation 그룹의 Get Component in Children 유닛에 연결합니다.

**5.** Graph Inspector에서 **Data Inputs** 섹션을 이어서 살펴봅니다. 여기에서는 원래 스크립트에서 이 슈퍼 유닛으로 전달할 값을 정의할 수 있습니다. 이 경우에는 문이 열릴지 혹은 닫힐지를 지정하려 합니다. Data Input에서 +를 선택해 항목을 추가한 다음, **Key** 필드에 **AnimationValue**를 입력하고 Enter 키를 누릅니다. **Type**으로는 **Boolean**을 선택합니다.

**6.** 이제 Input 유닛에 **Animation Value** 레이블이 지정된 출력이 생성됩니다. 이 출력부를 Animator: Set Bool 유닛의 입력부에 연결합니다.

**7.** 퍼지 파인더에서 **Nesting** 카테고리를 선택한 다음 **Output**을 선택하여 그래프 끝 부분에 Output 유닛을 추가합니다. 이 유닛을 사용하면 슈퍼 유닛 플로의 끝을 지정하고, 슈퍼 유닛에서 원래 비주얼 스크립트로 전달할 값을 정의할 수 있습니다.

**8.** Graph Inspector에서 **Trigger Output**을 추가한 다음, **Key**에 Output을 입력하고 Enter 키를 누릅니다.

**9.** 이 Output 유닛에서 **Data Output**은 추가하지 않습니다. 이 경우 스크립트는 원래 스크립트에 새 값을 반환하지 않습니다. 그러나 이 슈퍼 유닛이 새 값을 계산하는 경우 Data Output을 추가하여 값을 반환해야 한다는 점을 기억하세요.

**10.** Input과 Output의 플로를 그래프의 시작점과 끝점에 각각 연결합니다. 최종 그래프는 아래 이미지와 같아야 합니다.

**11.** 작업을 저장합니다(Ctrl+S / Cmd+S).

슈퍼 유닛 그래프는 아래 이미지와 같아야 합니다.
