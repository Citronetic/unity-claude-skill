[Image: 3.  Choosing a Framework]Summary

It’s fun building everything from scratch, but making (and finishing) a game is a LOT of work. You need to save as much time and energy as possible, so utilizing a “framework” asset will help you not reinvent the wheel constantly. In this lesson, I list several excellent framework assets that can get your project off the ground quickly; that way you can focus on making a great game.
