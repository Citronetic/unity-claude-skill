## 1. 제공된 에셋을 다운로드하여 새 Unity 프로젝트로 임포트

Q&A (0)

- 페이지 상단으로 이동하여 ModTheCubeChallengeAssets.zip을 다운로드합니다.
- **폴더의 압축을 해제합니다.**압축된 파일에 있는 .Unitypackage는 포함된 폴더의 압축을 해제하지 않으면 임포트되지 않습니다.
- 에디터의 최신 LTS 버전을 사용하여 새 Unity 프로젝트를 생성합니다.
- ModTheCube.unitypackage를 새 프로젝트로 임포트합니다.

단계를 완료로 표시

## 2. 기본 스크립트 기능 살펴보기

Q&A (0)

- 임포트된 .untypackage에는 C# 스크립트, 머티리얼, 씬의 세 가지 항목이 있습니다. 씬을 열고 플레이를 눌러 스크립트의 기본 동작을 살펴봅니다.
- 씬을 플레이하면 큐브를 변경하는 여러 프로퍼티를 확인할 수 있습니다. 이러한 모든 변경 사항은 cube.cs 스크립트에 하드코딩되며, 큐브는 씬이 플레이될 때마다 동일한 방식으로 수정됩니다.

단계를 완료로 표시

## 3. cube.cs 스크립트 수정

Q&A (0)

- 큐브의 동작이 **2가지 이상**변경되도록 cube.cs 스크립트를 수정합니다. 변경해 볼 만한 내용은 다음과 같습니다.

- 큐브의 위치를 변경합니다(트랜스폼).
- 큐브의 스케일을 변경합니다.
- 큐브의 회전 각도를 변경합니다.
- 큐브의 회전 속도를 변경합니다.
- 큐브의 머티리얼 색상을 변경합니다.
- 큐브의 머티리얼 불투명도를 변경합니다.

- 어느 정도 자신감이 생겼다면 다음 작업도 시도해 보세요.

- 씬이 플레이될 때마다 무작위로 변경되도록 위의 변경 사항을 수정합니다.
- 큐브에 기능을 추가합니다. 예를 들어 시간 경과에 따라 큐브 색상을 변경하려면 어떻게 해야 할까요?

Q&A (0)

**1.**큐브가 잘 보이도록 카메라 구도를 조정합니다.

**2.**[프로젝트의 WebGL 빌드를 생성합니다.](https://learn.unity.com/tutorial/create-and-publish-webgl-builds)
