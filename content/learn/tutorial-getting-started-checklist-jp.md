[Image: チェックリストの概要]Summary

**Create with Code - ティーチャートレーニング - セクション 3/3**

この Create with Code ティーチャートレーニングの最終セクションでは、コースを生徒に提供する前に完了する必要がある最も重要なステップを確認します。このセクションには、生徒が入室したときにすぐに使えるようにコンピューターラボをセットアップすること、コース開始日までに必要なトレーニングを完了するための十分な時間を確保すること、また、必要であれば生徒が自分のスキルを確認できるように認定試験のライセンスを購入することなどが含まれます。
