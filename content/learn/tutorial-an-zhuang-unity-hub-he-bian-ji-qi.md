## 2. 在开始前

Q&A (0)

在你开始这个项目之前，请检查你的电脑是否符合使用 Unity 的要求。Unity 可以安装在 Windows 和 macOS 上。对 Linux 的支持处于预览阶段，这表示你可以使用它，但可能会遇到一些问题。要使 Unity 运行良好，有一些[最低系统要求](https://docs.unity3d.com/Manual/system-requirements.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774950825792)。

Unity 目前不能安装在平板电脑或 Chrome OS 上。

## 3. 下载安装向导

Q&A (0)

**1.** 前往 **[Unity 下载页面](https://store.unity.com/download-nuo)。**

**2.**选择适合你的选项：新用户或老用户。

[Image: image]

- **新用户**：选择上图所示的**从这里开始**按钮下载带有新用户安装向导的 Unity。这个向导会引导从未使用过 Unity 的用户顺利完成安装。接下来选择**同意并下载**来下载安装文件，然后继续。
- **老用户**：选择上图所示的**点击此处**按钮直接下载 Unity Hub。如果你已有Unity ID，请选择这个选项。接下来同意服务条款，并选择**下载 Unity Hub**来下载安装文件。

Mark step as complete

## 4. 安装和启用 Unity Hub

Q&A (0)

**1.** 找到下载好的 UnityHubSetup.exe 文件。

**2.**  启动 **UnityHubSetup** 安装程序。

**3.** 按照平台说明安装 Unity Hub。

**4.** 打开 Unity Hub 应用程序。

**5.**选择安装位置，然后点击**安装**开始安装 Unity 编辑器。

[Image: image]

接下来，按照 Unity Hub 上的说明继续。

**注意：**如果你使用过 Unity，需要解决特定安装问题，[请查看文档中关于安装 Unity 的部分](https://docs.unity3d.com/Manual/GettingStartedInstallingUnity.html?ampDeviceId=53ad3448-c94c-4a0d-abf9-666d0f82aae1&ampSessionId=1774863089977&ampTimestamp=1774950825792)。
