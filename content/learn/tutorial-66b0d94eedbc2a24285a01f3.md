In this tutorial, you’ll learn how to set up and scale user acquisition campaigns. User acquisition campaigns allow your game to be found by your target users in today’s incredibly crowded marketplace. Throughout this video series, you’ll learn how to get started with paid user acquisition campaigns and why you should use them, how to run campaigns on an ad network, and best practices for ad creatives and optimization techniques.
