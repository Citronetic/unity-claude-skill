[Image: 뷰어에서 프로젝트에 액세스하기]Summary

Unity Reflect 뷰어를 사용하면 프로젝트를 제작한 CAD/BIM 애플리케이션 외부에서 BIM 모델에 액세스 및 검토할 수 있습니다. Unity에서 무료로 이용 가능한 이 뷰어는 단독 설치 프로그램이며 클라이언트와 동료가 Unity Reflect 라이선스 없이도 프로젝트에 액세스하도록 지원합니다. 사용자에게 할당된 프로젝트는 Unity 계정을 통해 뷰어에서 액세스할 수 있습니다.

이 튜토리얼에서는 Reflect 뷰어를 열고 사용자 계정으로 로그인하여 사용 가능한 프로젝트를 살펴볼 것입니다.

## 1. 소개

Q&A (0)

Reflect 뷰어를 사용하면 Revit 같은 CAD 애플리케이션의 BIM 데이터에 액세스할 수 있습니다. BIM 애플리케이션에서 익스포트한 모델을 Reflect 뷰어의 데스크톱 버전 또는 iOS 모바일 애플리케이션에서 볼 수 있습니다. BIM 디자이너는 이를 통해 다음 작업을 할 수 있습니다.

- 고가의 소프트웨어나 기술적 지식 없이도 BIM 모델을 클라이언트와 공유
- 가상 현실 및 증강 현실 경험을 즉각 활성화
- 비교적 낮은 사양의 하드웨어 및 모바일 기기에서 모델에 포함된 광범위한 BIM 정보에 실시간 액세스

이 튜토리얼에는 다음이 필요합니다.

- Reflect 뷰어 설치 - iOS 또는 데스크톱 앱
- Unity 계정
- 사용할 Unity 계정에 할당된 Reflect 프로젝트

## 2. Reflect 뷰어에서 프로젝트에 액세스하기

Q&A (0)

**1.** Reflect 뷰어를 엽니다(**그림** **01**).

[Image: image]

**2.** 계정에 로그인하기 위해 **Please sign in**(**그림 02**)을 클릭합니다. 그러면 Unity 웹 기반 로그인 페이지가 표시됩니다. 기기에서 이미 Unity 계정에 로그인했다면 Unity Reflect가 해당 계정을 사용하여 할당된 프로젝트를 열 것입니다.

[Image: image]

**3.** Unity 계정으로 로그인합니다.

**4.**Reflect 뷰어가 해당 Unity 계정과 공유된 모든 프로젝트를 표시합니다(**그림** **03**). 참고: Reflect 뷰어가 아무런 오류 경고 없이 닫히는 경우 올바른 계정으로 로그인하지 않은 것입니다. 아래의 "Reflect 뷰어가 예기치 않게 닫히는 경우"를 참조하시기 바랍니다.

[Image: image]

**5.** **새로 고침** 아이콘(**그림 04**)을 클릭하여 화면을 새로 고침합니다. 이 기능은 뷰어를 연 상태에서 새 프로젝트를 계정에 공유할 경우 유용합니다.

## 3. Reflect 뷰어 프로젝트 인터페이스

Q&A (0)

Reflect 뷰어 프로젝트 인터페이스는 프로젝트에 액세스하고 관리하는 옵션을 제공합니다. 각 프로젝트의 오른쪽에 **삭제**(휴지통 아이콘), **다운로드**(구름 아이콘), **Open**(그림 05) 버튼이 있습니다.

[Image: image]

**1.** **삭제**를 누르면 로컬 프로젝트 파일을 삭제할 수 있습니다(**그림 06**). 프로젝트가 열려 있으면 대부분의 데이터는 로컬 서버로부터 스트리밍됩니다. 이를 통해 애플리케이션을 사양이 낮은 하드웨어에서 실행할 수 있습니다. 그러나 일부 파일은 반드시 로컬 디바이스로 복사해야 하므로 일부 공간을 차지할 것입니다. 삭제 버튼으로 이런 파일들을 삭제할 수 있습니다.

[Image: image]

**2.** **다운로드**를 선택하면 중앙 Reflect 서버에서 로컬 기기로 필요한 파일을 다운로드하는 프로세스가 시작됩니다(**그림 07**). 이 파일들은 **Open**버튼이 선택되었을 경우 자동으로 다운로드됩니다.

[Image: image]

**3.** **Open** 버튼을 선택하면 Reflect 뷰어 내의 관련 프로젝트가 열립니다(**그림 08**). 또한 다운로드 옵션으로 필요한 파일을 로컬 Reflect 서버에서 다운로드하지 않은 경우 이 때 다운로드가 시작됩니다.

[Image: image]단계를 완료로 표시

## 4. Reflect 뷰어가 예기치 않게 닫히는 경우

Q&A (0)

로그인하거나 기기에서 열 때 Reflect 뷰어가 예기치 않게 닫힐 수 있습니다. 이는 사용 중인 기기가 현재 로그인한 Unity 계정의 정보를 저장했기 때문입니다.

예를 들어 개인 계정으로 로그인했지만 모든 Reflect 프로젝트가 업무 계정에 할당된 경우 Unity가 개인 계정에 할당된 프로젝트를 찾지 못하여 닫힐 수 있습니다.

이 경우 Unity 계정 페이지로 이동하여 로그아웃을 해야 합니다(**그림 09**).

[Image: image]

로그아웃한 다음 Reflect 뷰어로 돌아가 **Please sign in** 버튼을 클릭합니다(**그림** **10**).

[Image: image]

이제 프로젝트가 표시될 것입니다(**그림** **11**).
