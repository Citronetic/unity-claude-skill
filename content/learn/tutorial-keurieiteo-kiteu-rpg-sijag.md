## 1. 개요

Q&A (0)

RPG 크리에이터 키트에 오신 것을 환영합니다. 용감한 모험가를 꿈꾸고 NPC 퀘스트를 완료하여 인벤토리에 아이템을 채우고 싶다면 이 키트가 마음에 드실 겁니다.

이 단계별 학습 프로젝트에서 진행할 내용은 다음과 같습니다.

- Unity 에디터 인터페이스를 탐색합니다.
- 플레이어가 탐험할 월드를 제작합니다.
- 월드와 상호 작용할 캐릭터를 배치합니다.
- 캐릭터용 커스텀 대화를 작성합니다.
- 플레이어가 완료하여 보상을 받을 수 있는 퀘스트를 디자인합니다.

이 크리에이터 키트는 코딩이 필요하지 않으므로, Unity 에디터를 배우며 나만의 아이디어와 관심사에 따라 게임을 커스터마이징하는 데 집중할 수 있습니다.  이 학습 프로젝트를 완료하면 자신이 커스터마이즈한 RPG 게임을 친구들과 공유할 수 있습니다. 그 외에 다양한 2D 게임 콘텐츠를 살펴볼 수도 있습니다.

## 2. 시작하기 전에

Q&A (0)

#### Unity를 처음 사용하시나요?

이 학습 과정은 여러분이 Unity 에디터에 익숙하다는 가정하에 진행됩니다. Unity를 처음 사용한다면 [Unity 필수 과정 학습 길잡이](https://learn.unity.com/pathway/unity-essentials)를 통해 기초를 다지고 Unity 에디터에서 제작을 시작할 수 있습니다.

#### Unity Hub 업데이트

Unity 프로젝트 설정을 시작하기 전에 Unity Hub를 최신 릴리스로 업데이트하는 것이 좋습니다. 이전 버전의 Hub를 사용할 경우 제공된 지침과 실제 경험하는 내용에 차이가 있을 수 있습니다.

#### Unity 에디터 기초 확인

Unity 에디터의 기초를 다시 확인하고 싶을 때는 언제든지 [**Unity 에디터 둘러보기**](https://learn.unity.com/tutorial/explore-the-unity-editor-1)를 살펴보세요.

#### Unity 프로젝트 설정

Unity 프로젝트를 설정하는 방법은 다음과 같습니다.

**1.**  **Unity Hub**를 엽니다.

**2. 주요 템플릿(2D 또는 3D)을 사용해**  [Unity 프로젝트를 생성](https://learn.unity.com/tutorial/project-setup-processes#60f6aedeedbc2a7e96802196)합니다.  임포트하는 패키지가 기본 템플릿 설정을 오버라이드할 것이므로 어떤 주요 템플릿을 선택해도 좋습니다.

**3.**  Unity 에셋 스토어의 [**Creator Kit: RPG**에셋](https://assetstore.unity.com/packages/templates/tutorials/creator-kit-rpg-149309)으로 이동합니다.

**4.** [에셋을 다운로드하고 Unity 프로젝트로 임포트합니다.](https://learn.unity.com/tutorial/project-setup-processes#60ed7a86edbc2a002520b6f4)

단계를 완료로 표시

## 3. 디스플레이 설정

Q&A (0)

게임을 테스트해 보기 전에 게임이 올바른 종횡비로 표시되도록 디스플레이 설정을 조정해야 합니다.

다음과 같이 종횡비를 변경합니다.

**1.**  씬(Scene) 뷰에서 **Game** 탭을 선택합니다.

[Image: image]

**2.**  **Aspect Ratio** 드롭다운 메뉴를 클릭합니다.

[Image: image]

**3.**  **1920x1080**이 기본 옵션으로 제공되는 경우 이를 선택합니다. 그렇지 않으면 드롭다운 메뉴 하단의 **+** 버튼을 클릭하여 이를 커스텀 옵션으로 추가합니다.

[Image: image]

**4.** **Ctrl + S**(Windows) 또는 **Cmd + S**(macOS)를 눌러 변경 사항을 저장합니다.

## 4. 게임 테스트

Q&A (0)

이제 데모 레벨을 플레이할 준비가 되었습니다. 먼저 예제 게임이 포함된 씬을 엽니다.

**1.**프로젝트(Project) 창에서 *Assets/Creator Kit - RPG/Scenes*로 이동합니다.

**2.  SampleScene** 씬 아이콘을 더블 클릭합니다.

[Image: image]

**3.**씬이 열리면 게임을 테스트할 수 있습니다. 툴바에서 **플레이** 버튼을 클릭하여 시작합니다.

[Image: image]

이 게임에서는 다음을 수행할 수 있습니다.

- 키보드의 **화살표 키**를 눌러 이동합니다.
- 걸어가서 아이템을 수집합니다.
- 다른 캐릭터에게 걸어가서 상호 작용합니다.
- **화살표 키**를 사용하여 대화 옵션을 전환합니다.
- **스페이스 바**를 사용하여 단일 대화문을 닫고 응답 선택지를 선택합니다.

NPC를 찾아 퀘스트를 수행할 수 있는지 확인해 보세요.

[Image: image]

게임을 모두 살펴보았으면 다시 **플레이** 버튼을 클릭하여 플레이 모드를 종료합니다.
