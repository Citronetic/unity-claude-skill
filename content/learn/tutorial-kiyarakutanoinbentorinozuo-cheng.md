[Image: キャラクターのインベントリの作成]Summary

一般的なゲームの仕組みとして、プレイヤーのインベントリがあります。インベントリとは、プレイヤーがプレイ中に得たり失ったりするツール、武器、パワー、体力、その他のアイテムのことです。このチュートリアルでは、ビジュアルスクリプティングを使ってクライブのインベントリを作成します。今回の例では、クライブはドアを開けるために鍵が必要です。

このチュートリアルを終える頃には、以下のことができるようになっています：

- ビジュアルスクリプトで List オブジェクトタイプを使用してプレイヤーのインベントリを作成
- ビジュアルスクリプトのシーン変数を作成
- ビジュアルスクリプトで、シーンからゲームオブジェクトを削除する
- 望む結果が得られたら、適切なビジュアルスクリプトをコーディングする

## 1. 概要

Q&A (0)

引き続き、新しいタスクでゲームプレイのロジックをマッピングしていきます。クライブは、ドアを開けるために鍵を「運ぶ」ことになります。ビジュアルスクリプトの変数を使って、クライブに所持アイテムのインベントリを与え、クライブがドアを開けようとしたときにそのインベントリを検索して、鍵を持っているかどうかを確認します。

この技術を使って、自分のゲームのキャラクターにツールや武器を持たせたり、体力やダメージを与えたり、得点を稼いだりすることができるようになります。

## 2. 鍵の取得

Q&A (0)

クライヴに課題を与えましょう。ドアを開けるための鍵を持ってもらうように要求します。

このレベルの最初の部屋には、ゴールドに輝く鍵があります。クライブにこの鍵を拾わせて、ドアを「ロック解除」しましょう。クライブが「持って」いないとドアは開きません。

このビジュアルスクリプトを書くために必要な情報は以下の通りです：

- Hierarchy の中のオブジェクト (**ObjectRoot > Key** と選択) に新しい Script Machine とビジュアルスクリプトを追加します。名前は KeyScript としましょう。
- クライブがオブジェクトを所有しているというアクションをシミュレートするために、Scene 変数を使ってアイテムのインベントリを与え、どのゲームオブジェクトのスクリプトでもこの情報に簡単にアクセスできるようにします (**ヒント：**このインベントリがあれば、クライブは後からでも他のアイテムを手に入れることができるでしょう。)
- 後でクライブのインベントリにもっとアイテムを追加したくなるかもしれないので、Scene 変数には別のオブジェクトタイプを使います。これは、1つの変数に必要な数の値を格納できる**List**です。このリストは **List of Strings** となり、クライブが集めたアイテムの名前が格納されます。Scene 変数の名前を Inventory とし、鍵の名前を CatKey としましょう。
- リストにアイテムを追加するには、**Add List Item**ユニットを使います。
- クライブが鍵のある小部屋に入ると、Key (鍵) はクライブのインベントリに追加され、その後消えます。鍵を消滅させるには、**Component: Destroy (Obj)**ユニット  を使います。このユニットは、デフォルトでは、自分が入っているコンポーネント（Script Machine）を破壊しますが、それはあなたが望んでいることではありません。代わりに **This**ユニットを追加して、ゲームオブジェクト (Key) を破壊することを指定します。

以上の情報を踏まえて、あなたはこの鍵を自分でスクリプトを作成できるでしょうか？あえて自分で挑戦してみましょう。必要に応じて、次のステップの画像を使って自分の作業を確認してください。必ず作業内容を保存（**Ctrl + S / Cmd + S**）してください。

Play モードに入り、ビジュアルスクリプトをテストします。クライブに鍵を使用して小部屋に入れる前に、Hierarchy 内の **Scene Variables** オブジェクトを開き、Inventory 変数を確認します。クライブが小部屋に入った後、小部屋には「CatKey」という 1つの文字列のリストが含まれます。鍵が消えて、作成した Scene 変数に「CatKey」という文字列が現れるはずです。

成功したら、次のステップに完了マークをつけます。困ったときは、次のステップの手順と画面イメージに従ってください。

## 3. 鍵の取得（手順）

Q&A (0)

ここでは、鍵をスクリプティングするためのステップバイステップの手順を説明します：

1. **ObjectRoot**> **Key**と選択します。
2. Key ゲームオブジェクトに Script Machine を追加し、そのビジュアルスクリプトを KeyScript と名付けます。整理するために、必ず VisualScripts フォルダーに保存してください。
3. このスクリプトは、Key がいる小部屋にクライブが入ったときに実行されるので、イベント Enter Cell を使ってフローを開始します。
4. オブジェクトタイプを **List of String** (**ヒント：**Type メニューで「list of string」と検索するのが一番簡単です。) とし、**Inventory**という名前の Scene 変数を作成します。Value は指定しないでください。
5. Type が String、Value が「CatKey」の KeyName という名前の Object 変数を作成します。これは、後でドアを開けるために探す文字列になります。
6. **Add List Item** ユニットを追加します。Enter Cell イベントからフローを接続します。
7. List と key name の Get Variable ユニットを追加し、これらを Add List Item の入力として接続します。
8. クライブが「手に取った」時点で鍵を消滅させるには、**Component: Destroy (Obj)** ユニットを追加します。
9. Key ゲームオブジェクトを表す **This**ユニットを追加し、これを Component: Destroy への入力とします。
10. 作業内容を保存 **(Ctrl + S / Cmd + S**) します。

## 4. 鍵でドアを開ける

Q&A (0)

では、ドアを開けてみましょう。インベントリに「CatKey」があるかどうかをチェックする新しい条件を追加し、あれば IsOpen を True に変更し、ドアを開けるアニメーションとエフェクトを再生すればよいのです。

インベントリリストで「CatKey」を検索するには、**List Interface: Contains** を使用します。クライブが鍵を持っているかどうかを示す Boolean が返されます。

既存のフローのどこでリストをチェックすべきでしょうか？IsOpen が False の場合、鍵を持っていてもいなくても、クライブの動きはキャンセルする必要があります - そのため、Cancel Movement の後でなければなりません。しかし、彼がキーを持っていない限り、IsOpen を True に設定することはできません。したがって、IsOpen を True に設定する Set Variable ユニットの前でなければなりません。そこで、Cancel Movement と Set Variable の間に If ユニットを追加します。

**グループ提案：**さらにいくつかのドアをスクリプト化することになります。グループを使って、このビジュアルスクリプトを後でより読みやすくするにはどうしたらいいでしょうか？

このスクリプトを書きます。必要に応じて、次のステップの画像を使って、必ず自分の作業内容を保存 (**Ctrl + S / Cmd + S**) してください。

Play モードに入り、ビジュアルスクリプトをテストします。クライブに鍵を持たせずにドアに近づかせてから、鍵を持たせて再挑戦させます。すると、一時停止してドアが開き、次の部屋に行けるようになります！

成功したら、次のステップに完了マークをつけます。困ったときは、次のステップの手順と画面イメージに従ってください。

## 5. 鍵でドアを開けます（手順）

Q&A (0)

ここでは、クライブが鍵を持っている場合のみ、最初のドアが開くようにスクリプトを作成する手順を説明します：

**1. ObjectRoot > FirstDoor**でビジュアルスクリプトに戻ります。

**2.**KeyName という名前の Object 変数を、Type が String、値が「CatKey」で作成します。この値を使ってリストを検索することになります。

**3 List Interface: Contains** ユニットを追加し、Cancel Movement と Set Variable の間のフローに挿入します。

**4.**List Interface: Contains ユニットへの入力として、Get Variable ユニットを使って、Inventory 変数と KeyName 変数を取得します。

**5.**List Interface: Contains ユニットは Boolean を出力します。If ユニットを使ってこの Boolean をチェックし、この値が True の場合のみフローを続行します。

**6.**提案：このスクリプトを読めるようにするために、いくつかのグループを追加してみましょう。

**7.** 作業内容を保存（**Ctrl + S / Cmd + S**）します。
