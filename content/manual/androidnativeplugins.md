# Native plug-ins for Android

Unity supports [native plug-ins](plug-ins-native.html)A platform-specific native code library that is created outside of Unity for use in Unity. Allows you can access features like OS calls and third-party code libraries that would otherwise not be available to Unity. [More info](./plug-ins.html)
See in [Glossary](Glossary.html#Nativeplug-in) for Android applications so you can integrate middleware libraries or existing C/C++ code into your Unity application.
