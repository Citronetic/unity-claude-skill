# Overriding prefab instance data

Use overrides to create variations of [prefab instances](CreatingPrefabs.html#create-an-instance-of-a-prefab), while still linking those instances to the same **prefab**An asset type that allows you to store a GameObject complete with components and properties. The prefab acts as a template from which you can create new object instances in the scene. [More info](Prefabs.html)
