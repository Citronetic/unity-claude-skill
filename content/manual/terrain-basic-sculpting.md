# Primary sculpting tools

Primary tools for sculpting height are available in both the built-in **Terrain**The landscape in your scene. A Terrain GameObject adds a large flat plane to your scene and you can use the Terrain’s Inspector window to create a detailed landscape. [More info](terrain-UsingTerrains.html)
See in [Glossary](Glossary.html#Terrain) system and the Terrain Tools package. The tools are:

| Tool | Description |
| --- | --- |
| Set the height of an area or tile | Set a single height for a whole tile or parts of it. |
| Sculpt the terrain with a brush | Sculpt areas of the terrain. |
| Paint holes in the terrains | Paint holes in the terrain to allow characters and objects to enter caves or other underground structures. |
| Smooth the terrain’s height | Smooth sharp formations and transitions between areas of the terrain. |
| Stamp a shape onto the terrain | Use a stamp or meshThe main graphics primitive of Unity. Meshes make up a large part of your 3D worlds. Unity supports triangulated or Quadrangulated polygon meshes. Nurbs, Nurms, Subdiv surfaces must be converted to polygons. More infoSee in Glossary to add or remove height as a set shape. |
