# Configuring lightmapping

Resources for choosing between baked and realtime lightmapping, and changing how lightmapping works.

| Page | Description |
| --- | --- |
| Configure lightmapping with a Lighting Settings Asset | Create a set of lightmapping settings and assign them to a sceneA Scene contains the environments and menus of your game. Think of each unique Scene file as a unique level. In each Scene, you place your environments, obstacles, and decorations, essentially designing and building your game in pieces. More infoSee in Glossary. |
| Change the fade distance of lights with fall-off | Change the rate at which light fades in lightmapsA pre-rendered texture that contains the effects of light sources on static objects in the scene. Lightmaps are overlaid on top of scene geometry to create the effect of lighting. More infoSee in Glossary using a script. |
| Store light direction with Directional Mode | Improve lighting by generating an extra lightmap texture that stores light direction and amount. |
