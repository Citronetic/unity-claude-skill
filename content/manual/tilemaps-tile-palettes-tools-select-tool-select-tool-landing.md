# The Select tool

Use the **Select** tool to select tiles on the **tilemap**A GameObject that allows you to quickly create 2D levels using tiles and a grid overlay. [More info](../../../../tilemaps/work-with-tilemaps/tilemap-reference.html)
See in [Glossary](../../../../Glossary.html#Tilemap), and use that selection with other **Tile Palette** editor tools such as the [Move tool](../move-tiles-with-move-tool.html) to move selected tiles.
