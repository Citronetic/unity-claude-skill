# GPU Resident Drawer

To speed up rendering, enable the GPU Resident Drawer so Unity automatically uses the `BatchRendererGroup` API to reduce the number of draw calls.

| Page | Description |
| --- | --- |
| Enable the GPU Resident Drawer | Automatically use the BatchRendererGroup API to use instancing and reduce the number of draw calls. |
| Make a GameObject compatible with the GPU Resident Drawer | Include or exclude a GameObjectThe fundamental object in Unity scenes, which can represent characters, props, scenery, cameras, waypoints, and more. A GameObject’s functionality is defined by the Components attached to it. More infoSee in Glossary from the GPU Resident Drawer. |
