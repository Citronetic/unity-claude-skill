# Package inspection

Inspect the contents of any package in your project.

You can view information about the package in a dedicated ****Inspector**A Unity window that displays information about the currently selected GameObject, asset or project settings, allowing you to inspect and edit the values. [More info](UsingTheInspector.html)
See in [Glossary](Glossary.html#Inspector)** window and access the package’s manifest file.
