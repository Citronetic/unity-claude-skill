# Mixed Reality multiplayer tabletop template

Unity’s Mixed Reality multiplayer tabletop template serves as a starting point for mixed reality development leveraging XR Interaction Toolkit, Netcode for GameObjects, Unity Cloud Gaming Services, and AR Foundation. This template provides samples and examples, best practices, and more for you to use in your own projects.

The template configures project settings, pre-installs the necessary packages, and includes various samples that demonstrate how to set up a project that's ready for a variety of multiplayer Mixed Reality (MR) use cases. The template provides three tabletop games (sandbox, slingshot, and chess) that demonstrate Mixed Reality multiplayer functionality.

You can use this template in mixed, augmented, and virtual reality modes. You can learn more about the types of extended reality (XR) experiences in the Unity [XR](https://docs.unity3d.com/Manual/XR.html) user manual.
