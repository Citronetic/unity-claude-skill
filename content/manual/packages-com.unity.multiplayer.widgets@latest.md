# Multiplayer widgets

##### Important

The Multiplayer Widgets package is deprecated. Use [Unity Building Blocks](https://docs.unity3d.com/Documentation/Manual/building-blocks.html) instead to quickly add functionality to your Unity project.

Use the multiplayer widgets package to test the behavior of the Unity [Multiplayer services](https://docs.unity.com/ugs/en-us/manual/mps-sdk/manual?ampDeviceId=6d7aef6b-aa4a-4844-ba5a-2f3cf5238729&ampSessionId=1774862229751&ampTimestamp=1774948693657) without the need to write any code.
