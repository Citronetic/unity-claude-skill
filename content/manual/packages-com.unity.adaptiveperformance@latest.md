# Adaptive Performance

     The latest documentation for Adaptive Performance is available in [the Unity Manual](https://docs.unity3d.com/6000.3/Documentation/Manual/adaptive-performance/adaptive-performance.html). This package now contains only samples and visual scripting nodes.

Adaptive Performance is a tool you can use to automatically adjust application quality based on real-time thermal and power state, ensuring consistent performance and preventing thermal throttling.

| Topic | Description |
| --- | --- |
| What's new | Learn about the latest package features and improvements. |
| Installation | Install the Adaptive Performance package. |
| Samples | Explore practical demonstrations of Adaptive Performance features with the provided samples. |
| Visual scripting | Use visual scripting graphs to control device performance and thermal state without writing C# code. |
