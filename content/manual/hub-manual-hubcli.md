# Unity Hub

The Unity Hub is a standalone application that you can use to navigate, download, and manage your Unity projects and installations.Read time 1 minuteLast updated 10 days ago

---

TipFor information on how to create a game in Unity, refer to the documentation on the [Unity User Manual](https://docs.unity3d.com/Manual/first-time-user.html?ampDeviceId=39b84bea-fe15-432a-8dc4-5265dd477fef&ampSessionId=1774852400735&ampTimestamp=1774939324686) website, or the tutorials on [Unity Learn](https://learn.unity.com/). After you [download and install the Hub](/en-us/hub/install-hub), you can also access tutorials in the **Learn** tab.
Use the Hub to:

- Manage, download, and install modules and versions of the Unity Editor.

- Create and manage your Unity projects.

- Explore templates, sample projects, and learning material.

- Manage your profile, settings, and Unity licenses.

- Send feedback and get help from Unity.
