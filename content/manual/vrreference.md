# XR API reference

Understand the common APIs for **XR**An umbrella term encompassing Virtual Reality (VR), Augmented Reality (AR) and Mixed Reality (MR) applications. Devices supporting these forms of interactive applications can be referred to as XR devices. [More info](XR.html)
See in [Glossary](Glossary.html#XR) development that Unity provides.

Unity provides APIs for XR development under the `XR` namespace. Refer to the following table to understand the XR APIs:

| Topic | Description |
| --- | --- |
| XR.XRSettings | APIs for Global XR related settings. |
| XR.XRDevice | APIs related to XR devices. |
| XR.InputTracking | APIs for accessing XR input devices. |
