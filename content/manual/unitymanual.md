# Unity 6.2 User Manual

[Unity 6.2](https://unity.com/download?ampDeviceId=fffb83ff-ec04-401c-8bb9-ed5ebd99cd33&ampSessionId=1774849551466&ampTimestamp=1774938846931) is the latest release of the next generation of the Unity Engine. It combines the latest technologies and tools to deliver high-quality, high-performance experiences for all supported platforms.

For more information about new features, and how to upgrade your existing projects to this version, refer to the following topics:

- [New in Unity](WhatsNew.html)

- [Upgrade Unity](UpgradeGuides.html)
