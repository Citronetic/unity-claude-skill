# Search performance and debugging

These search providers help you debug your project and improve its performance.

| Provider | Description |
| --- | --- |
| Search performance trackers | Search Performance Trackers. |
| Search Profiler Markers | Search ProfilerA window that helps you to optimize your game. It shows how much time is spent in the various areas of your game. For example, it can report the percentage of time spent rendering, animating, or in your game logic. More infoSee in Glossary Markers. |
| Search Logs | Search the Editor log. |
