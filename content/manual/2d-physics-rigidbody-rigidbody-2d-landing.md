# Rigidbody 2D

Rigidbodies enable physics-based behavior, such as reactions to gravity, mass, drag, and momentum. A **Rigidbody**A component that allows a GameObject to be affected by simulated gravity and other forces. [More info](../../class-Rigidbody.html)
See in [Glossary](../../Glossary.html#Rigidbody) 2D is a 2D component you can use to enable an object to act under the control of physics.
