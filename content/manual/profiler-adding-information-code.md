# Adding profiling information to your code

You can add **profiler**A window that helps you to optimize your game. It shows how much time is spent in the various areas of your game. For example, it can report the percentage of time spent rendering, animating, or in your game logic. [More info](Profiler.html)
See in [Glossary](Glossary.html#Profiler) markers and counters to your code to further understand specific performance data related to your application, and visualize that data in custom Profiler modules.
