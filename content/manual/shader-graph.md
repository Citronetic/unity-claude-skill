# Creating shaders with Shader Graph

Shader Graph is a tool that enables you to build shaders visually. Instead of writing code, you create and connect nodes in a graph framework. **Shader**A program that runs on the GPU. [More info](Shaders.html)
See in [Glossary](Glossary.html#Shader) Graph gives instant feedback that reflects your changes, and it’s simple enough for users who are new to shader creation.
