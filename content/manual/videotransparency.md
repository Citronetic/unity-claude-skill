# Video transparency support

Unity’s [Video Clip](class-VideoClip.html) and [Video Player](class-VideoPlayer.html) components support alpha values in video files, also known as [transparency](StandardShaderMaterialParameterAlbedoColor.html).

This information covers the different types of transparent videos and how to set them up for use in Unity.
