# Unity for first-time users

If you’re new to Unity, this section provides resources you need to get started. It includes step-by-step guidance on creating your first project, choosing between 2D and 3D development, and understanding key concepts in the Unity Editor. You’ll also find best practice guides that help you build skills: from the basics to more advanced topics. Use the links below to begin your journey with Unity.

| Topic | Description |
| --- | --- |
| Create your first project | If you’ve never used the Unity Editor before, create your first project with Unity’s getting started resources. |
| 2D and 3D projects | Review the different types of 2D and 3D games to help you choose the one you want to create. |
| Getting started with AI | Explore Unity’s AI-powered tools for content generation, coding assistance, and runtime inference. Learn how Unity AI can help you prototype, create assets, and integrate machine learning models into your projects. |
| Key concepts | Use this reference to key Unity Editor concepts as you work on your first few projects. |
