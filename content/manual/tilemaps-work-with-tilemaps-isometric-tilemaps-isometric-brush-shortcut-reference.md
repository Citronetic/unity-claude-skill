# Isometric brush shortcut Reference

There are some keyboard shortcuts that are specific to when you work with tile palette brushes on an **Isometric Z as Y **Tilemap**A GameObject that allows you to quickly create 2D levels using tiles and a grid overlay. [More info](../../../tilemaps/work-with-tilemaps/tilemap-reference.html)
See in [Glossary](../../../Glossary.html#Tilemap)**.

With the Tile brush selected, use the following shortcut keys to quickly switch to different Z positions.

| Shortcut key | Command |
| --- | --- |
| - | Increase Z position by 1. |
| = | Decrease Z position by 1. |
