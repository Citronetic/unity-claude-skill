# Keyboard shortcuts

Use the **Shortcuts** window to view and manage keyboard shortcuts in the Unity Editor. You can assign shortcuts to commands, remove or reset shortcuts, manage conflicts, and save your shortcuts to multiple profiles. You can also assign shortcuts to custom tools, **scripts**A piece of code that allows you to create your own Components, trigger game events, modify Component properties over time and respond to user input in any way you like. [More info](creating-scripts.html)
