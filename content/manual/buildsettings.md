# Create a build from the Editor

Unity can build your application for different platforms with unique build configurations using **build profiles**A set of customizable configuration settings to use when creating a build for your target platform. [More info](build-profiles.html)
See in [Glossary](Glossary.html#Buildprofile) in the Unity Editor.
