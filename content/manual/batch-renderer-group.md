# BatchRendererGroup API in URP

BatchRendererGroup (BRG) is an API for high-performance custom rendering in projects that use a [Scriptable Render Pipeline](scriptable-render-pipeline-introduction.html) (SRP) and the [SRP Batcher](SRPBatcher.html).
