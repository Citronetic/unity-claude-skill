# Microsoft GDK Tools package

The Microsoft GDK Tools package provides tools and workflow support for the development of Unity projects using the Microsoft Game Development Kit (GDK). Use this package to configure GDK Settings and Microsoft Game Configuration files in the Unity Editor. The GDK settings and game configuration files are stored as assets, allowing for easier management.

Although the Microsoft GDK Tools package can be used as a standalone package, it’s recommended to use it in conjunction with the [Microsoft GDK API package](https://docs.unity3d.com/Packages/com.unity.microsoft.gdk@latest). The Microsoft GDK API package provides convenient C# access to the native GDK API and allows for the use of Xbox services, such as Achievements and Leaderboards.

The Microsoft GDK Tools package is provided by Unity and co-developed in partnership with the Microsoft Corporation.

##### Note

The Microsoft GDK Tools package is supported only on Unity Editor for Windows.
