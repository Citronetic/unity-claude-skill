# Game Controller support

Unity supports a standardized **Game Controller**A device to control objects and characters in a game.
See in [Glossary](Glossary.html#gamecontroller) Input API provided by Apple as part of the standard Unity Input API. You can use the [Input class](../ScriptReference/Input.html) to enable the Game Controller capability in your application, so you can support users who use a a physical or virtual controller to interact with your application.
