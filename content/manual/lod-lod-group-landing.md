# LOD Group

LOD Group is a flexible Unity **LOD**The *Level Of Detail* (LOD) technique is an optimization that reduces the number of triangles that Unity has to render for a GameObject when its distance from the Camera increases. [More info](../LevelOfDetail.html)
See in [Glossary](../Glossary.html#LOD) solution. It provides more optimization options than the [Mesh LOD](mesh-lod-landing.html) feature, but has a larger memory footprint and computational overhead.
