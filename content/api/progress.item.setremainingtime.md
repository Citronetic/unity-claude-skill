## Declaration

public void SetRemainingTime(long seconds);






### Parameters



| Parameter | Description |
| --- | --- |
| seconds | The progress indicator's remaining time, in seconds. |





### Description



Sets the progress indicator's remaining time, in seconds.





When you call this function, the system sets the progress indicator's remaining time. It stops automatically computing the estimated remaining time. To use automatic computation again, call the function [Progress.Item.ClearRemainingTime](Progress.Item.ClearRemainingTime.html).
