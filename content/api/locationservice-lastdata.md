                    public [LocationInfo](LocationInfo.html) lastData;






### Description



The last geographical location that the device registered.





Before you access this property, call [Start()](LocationService.Start.html) in [Input.location](Input-location.html) to start the location service.

**Note**: On WebGL, this value is 0 or null if the browser has no implementation for it.
