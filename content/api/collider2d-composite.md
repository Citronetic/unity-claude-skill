                    public [CompositeCollider2D](CompositeCollider2D.html) composite;






### Description



Get the [CompositeCollider2D](CompositeCollider2D.html) that is available to be attached to the collider.





Gets any [CompositeCollider2D](CompositeCollider2D.html) that this [Collider2D](Collider2D.html) would use if the Collider geometry is being composited using [Collider2D.compositeOperation](Collider2D-compositeOperation.html) or returns null if no [CompositeCollider2D](CompositeCollider2D.html) were available.

Additional resources: [CompositeOperation](Collider2D.CompositeOperation.html) and [CompositeCollider2D](CompositeCollider2D.html).
