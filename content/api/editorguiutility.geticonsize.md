public static [Vector2](Vector2.html) GetIconSize();






### Description



Get the size that has been set using [SetIconSize](EditorGUIUtility.SetIconSize.html).





The default size is [Vector2.zero](Vector2-zero.html) where the size is determined by the available space.

Additional resources: [SetIconSize](EditorGUIUtility.SetIconSize.html).
