                    public static int columnTotalTime;






### Description



The CPU time in milliseconds that Unity spends in a sample, including the time from child samples.





**Note:** If [inverted mode](Profiling.HierarchyFrameDataView.ViewModes.InvertHierarchy.html) is active, for non-root items, this value represents the part of their parent's `columnTotalTime` that their sample stacks contain.
