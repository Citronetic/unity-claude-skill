### Description



Display UI for editing material's render queue setting.





The Render Queue UI allows you to set [Material.renderQueue](Material-renderQueue.html) to one of the common values (e.g. Geometry or Transparent), as well as allowing you to specify a custom render queue value.

Additional resources: [Material.renderQueue](Material-renderQueue.html), [Shader.renderQueue](Shader-renderQueue.html), [RenderQueue](Rendering.RenderQueue.html) enum.
