## Declaration

public [ParticleSystem.PlaybackState](ParticleSystem.PlaybackState.html) GetPlaybackState();






### Returns



**PlaybackState**
        The current internal state of the Particle System.





### Description



Returns all the data that relates to the current internal state of the Particle System.





If you want to restore the Particle System to its current state in the future, store the PlaybackState this function returns along with [ParticleSystem.GetParticles](ParticleSystem.GetParticles.html) and [ParticleSystem.GetTrails](ParticleSystem.GetTrails.html).

Additional resources: [PlaybackState](ParticleSystem.PlaybackState.html), [SetPlaybackState](ParticleSystem.SetPlaybackState.html), [GetTrails](ParticleSystem.GetTrails.html).
