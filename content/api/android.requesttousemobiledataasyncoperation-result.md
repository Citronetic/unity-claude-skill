### Description



Indicates whether the end user allowed the application to use mobile data to download Android asset packs.





Until the operation is complete and [RequestToUseMobileDataAsyncOperation.isDone](Android.RequestToUseMobileDataAsyncOperation-isDone.html) returns true, this returns null.
Read-only.
