                    public bool isPathStale;






### Description



Is the current path stale. (Read Only)





When true, the path may no longer be valid or optimal.
This flag will be set if: there are any changes to the [areaMask](AI.NavMeshAgent-areaMask.html), if any OffMeshLink is enabled or disabled, or if the costs for the NavMeshAreas have been changed.
