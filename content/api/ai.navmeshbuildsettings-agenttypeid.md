### Description



The agent type ID the NavMesh will be baked for.





Each [NavMeshAgent](AI.NavMeshAgent.html) or [NavMeshQueryFilter](AI.NavMeshQueryFilter.html) can only use a NavMesh which is built for its agent type; it is the ID that is matched.
