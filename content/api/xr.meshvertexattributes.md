### Description



A set of vertex attributes.





This enum is used by [XRMeshSubsystem.GenerateMeshAsync](XR.XRMeshSubsystem.GenerateMeshAsync.html) to request particular vertex attributes, or by [MeshGenerationResult](XR.MeshGenerationResult.html) to indicate which vertex attributes were written to the [Mesh](Mesh.html).





### Properties



| Property | Description |
| --- | --- |
| None | No vertex attributes |
| Normals | Vertex normals |
| Tangents | Vertex tangents |
| UVs | Vertex UVs |
| Colors | Vertex normals |
