## Declaration

public void RefreshAllTiles();






### Description



Refreshes all [Tile](Tilemaps.Tile.html)s in the [Tilemap](Tilemaps.Tilemap.html). The Tilemap will retrieve the rendering data, animation data and other data for all tiles and update all relevant components.





Refer to [Scriptable Tiles](../Manual/Tilemap-ScriptableTiles-TileBase.html) and [Tilemap](../Manual/class-Tilemap.html) for more information.
