                    public bool HasBrushAttributes;






### Description



True if the Terrain Tool has brush attributes, false otherwise.





Returns a boolean indicating whether the Terrain Tool should display an overlay containing sliders for brush attributes such as brush size and strength, used primarily for paint tools.
