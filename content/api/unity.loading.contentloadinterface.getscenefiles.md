## Declaration

public static ContentSceneFile[] GetSceneFiles([Unity.Content.ContentNamespace](Unity.Content.ContentNamespace.html) nameSpace);






### Parameters



| Parameter | Description |
| --- | --- |
| nameSpace | The ContentNamespace used to filter the results. |





### Returns



**ContentSceneFile[]**
        Returns an array of all the [ContentSceneFile](Unity.Loading.ContentSceneFile.html)s belonging to the [ContentNamespace](Unity.Content.ContentNamespace.html).





### Description



An array of all the [ContentSceneFile](Unity.Loading.ContentSceneFile.html)s associated with the [ContentNamespace](Unity.Content.ContentNamespace.html).





The results will include all [ContentFile](Unity.Loading.ContentFile.html)s regardless of their [ContentSceneFile.Status](Unity.Loading.ContentSceneFile.Status.html).
