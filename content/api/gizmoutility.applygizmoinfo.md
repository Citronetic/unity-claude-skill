## Declaration

public static void ApplyGizmoInfo([GizmoInfo](GizmoInfo.html) info,
bool addToRecentlyChanged);






### Parameters



| Parameter | Description |
| --- | --- |
| info | The GizmoInfo to apply. |
| addToRecentlyChanged | Set true to append this component to the "Recently Changed" list in the Annotation Window. |





### Description



Apply [GizmoInfo.gizmoEnabled](GizmoInfo-gizmoEnabled.html) and [GizmoInfo.iconEnabled](GizmoInfo-iconEnabled.html) for a [GizmoInfo](GizmoInfo.html) object.





This is equivalent to calling [SetGizmoEnabled](GizmoUtility.SetGizmoEnabled.html) and [SetIconEnabled](GizmoUtility.SetIconEnabled.html).
