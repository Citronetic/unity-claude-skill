                    public uint uintValue;






### Description



Value of an integer property as an unsigned int.





Contains a valid value when [propertyType](SerializedProperty-propertyType.html) is [SerializedPropertyType.Integer](SerializedPropertyType.Integer.html).
                Suitable for unsigned types of 32 bits or smaller (uint, ushort and byte).

                Additional resources: [ulongValue](SerializedProperty-ulongValue.html), [intValue](SerializedProperty-intValue.html), [numericType](SerializedProperty-numericType.html), [propertyType](SerializedProperty-propertyType.html), [SerializedPropertyType.Integer](SerializedPropertyType.Integer.html).
