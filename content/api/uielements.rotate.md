### Description



Provides rotation information for visual elements that rotates around the [TransformOrigin](UIElements.TransformOrigin.html). Positive values represent clockwise rotation.





### Properties



| Property | Description |
| --- | --- |
| angle | The angle applied by the rotation. Positive values represent clockwise rotation and negative values represent counterclockwise rotation. |





### Constructors



| Constructor | Description |
| --- | --- |
| Rotate | Create a Rotate struct that corresponds to a rotation around the specified axis by the provided Angle. |





### Static Methods



| Method | Description |
| --- | --- |
| None | Return a value of Rotate that applies no rotation |
