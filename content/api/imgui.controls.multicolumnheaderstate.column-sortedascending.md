                    public bool sortedAscending;






### Description



Value that controls if this column is sorted ascending or descending.





Note this state is stored for each column and should only be used if the column is currently the active sorted column which is controlled by [MultiColumnHeader.sortedColumnIndex](IMGUI.Controls.MultiColumnHeader-sortedColumnIndex.html).
