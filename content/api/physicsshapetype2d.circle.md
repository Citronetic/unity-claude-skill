### Description



Use a circle shape to interpret the [PhysicsShape2D](PhysicsShape2D.html) geometry.





A circle geometry type is comprised of a single vertex in the [PhysicsShape2D](PhysicsShape2D.html) and a [PhysicsShape2D.radius](PhysicsShape2D-radius.html). The single vertex represents the center of the circle with the radius defining the radius of the circle.
