                    public ulong Timestamp;






### Description



The timestamp associated with this transform.





A larger value indicates a more recent time. This timestamp can be compared with [MeshGenerationResult.Timestamp](XR.MeshGenerationResult.Timestamp.html) to determine whether the generation result (which is asynchronous) contains a newer transform.

                    Additional resources: [XRMeshSubsystem.GetUpdatedMeshTransforms](XR.XRMeshSubsystem.GetUpdatedMeshTransforms.html)
