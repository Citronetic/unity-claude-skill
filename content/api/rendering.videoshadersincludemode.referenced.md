### Description



Include video shaders in builds when referenced by scenes.





If a [VideoPlayer](Video.VideoPlayer.html) or [VideoClip](Video.VideoClip.html) is in a scene, video shaders are included in the build.

**Note:** Class references are not inspected during the build. If you create a [VideoPlayer](Video.VideoPlayer.html) through scripting and you are not using a [VideoClip](Video.VideoClip.html), use the [VideoShadersIncludeMode.Always](Rendering.VideoShadersIncludeMode.Always.html) mode.
