public static int GetParentId(int id);






### Parameters



| Parameter | Description |

| id | The progress indicator's unique ID. |





### Returns



**int**
        The unique ID of the progress indicator's parent. If the progress indicator is not a child of any other progress indicators, returns -1.





### Description



Gets the unique ID of the progress indicator's parent, if any.
