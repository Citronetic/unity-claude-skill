                    public bool forceChildVisibility;






### Description



Controls the visibility of the child hidden fields.





A boolean value that controls the visibility of the child hidden fields. True means that any hidden fields are displayed. False means that any hidden fields are not displayed. Set to false by default.
                Additional resources: [HideInInspector](HideInInspector.html), [SerializedProperty.NextVisible](SerializedProperty.NextVisible.html)
