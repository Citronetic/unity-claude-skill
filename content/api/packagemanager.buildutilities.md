### Description



Utility class that allows packages to register build callbacks with the Unity Package Manager.





`BuildUtilities` is a static class so you don't need to obtain an instance of it before calling its methods.

                Additional resources: [IShouldIncludeInBuildCallback](PackageManager.IShouldIncludeInBuildCallback.html).





### Static Methods



| Method | Description |
| --- | --- |
| RegisterShouldIncludeInBuildCallback | Registers a callback object for a package. |
