## Declaration

public static void RemoveAllNavMeshData();






### Description



Removes all NavMesh surfaces and links from the game.





Unloads all surfaces and links that have been loaded from the Scene or added with [AddNavMeshData](AI.NavMesh.AddNavMeshData.html) or [AddLink](AI.NavMesh.AddLink.html) and frees all the internal resources associated with the NavMesh.

Additional resources: [RemoveNavMeshData](AI.NavMesh.RemoveNavMeshData.html), [RemoveLink](AI.NavMesh.RemoveLink.html).
