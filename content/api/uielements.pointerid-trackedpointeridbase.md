                    public static int trackedPointerIdBase;






### Description



The base ID for tracked device pointers.
 See for example InputSystem's [XRController](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.12/api/UnityEngine.InputSystem.XR.XRController.html).





The pointer ID for a tracked device event is a number between trackedPointerIdBase and trackedPointerIdBase + trackedPointerCount - 1.
