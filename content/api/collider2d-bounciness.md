### Description



The bounciness used by the [Collider2D](Collider2D.html).





A [Collider2D](Collider2D.html) can be assigned a [PhysicsMaterial2D](PhysicsMaterial2D.html) either directly via to the [Collider2D.sharedMaterial](Collider2D-sharedMaterial.html), indirectly via the attached [Rigidbody2D.sharedMaterial](Rigidbody2D-sharedMaterial.html), the global default or if no [PhysicsMaterial2D](PhysicsMaterial2D.html) is assigned then a default value is used.

Additional resources: [PhysicsMaterial2D](PhysicsMaterial2D.html), [PhysicsMaterial2D.bounciness](PhysicsMaterial2D-bounciness.html)
