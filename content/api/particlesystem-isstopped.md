                    public bool isStopped;






### Description



Determines whether the Particle System is in the stopped state.





This property is true after a call to [ParticleSystem.Stop](ParticleSystem.Stop.html) stops the system, if a non-looping system finishes playing and all its particles die, or if the system has not yet played.

[ParticleSystem.IsAlive](ParticleSystem.IsAlive.html) is also false when the system is in the stopped state.
