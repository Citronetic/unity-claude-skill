## Declaration

public void SetStartPosition([Vector2](Vector2.html) position);






### Parameters



| Parameter | Description |
| --- | --- |
| position | The position to use. |





### Description



A helper method that simultaneously sets both the [Rigidbody2D.SlideMovement.startPosition](Rigidbody2D.SlideMovement-startPosition.html) to the specified /position but also sets [Rigidbody2D.SlideMovement.useStartPosition](Rigidbody2D.SlideMovement-useStartPosition.html) to true.





Additional resources: [Rigidbody2D.SlideMovement.useStartPosition](Rigidbody2D.SlideMovement-useStartPosition.html) and [Rigidbody2D.SlideMovement.startPosition](Rigidbody2D.SlideMovement-startPosition.html).
