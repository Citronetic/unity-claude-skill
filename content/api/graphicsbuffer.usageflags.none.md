### Description



Sets the update mode flags to None. This is the default update mode.





In this mode, the buffer can be written to at any time using [GraphicsBuffer.SetData](GraphicsBuffer.SetData.html) and equivalent functions. The GPU can also copy to and write to the buffer.

Additional resources: [GraphicsBuffer](GraphicsBuffer.html), [GraphicsBuffer.SetData](GraphicsBuffer.SetData.html).
