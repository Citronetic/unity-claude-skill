### Description



Default color space conversion based on project settings.





This value picks [sRGB](RenderTextureReadWrite-sRGB.html) (when Linear color space is used) or [Linear](RenderTextureReadWrite.Linear.html)
(when gamma color space is used) based on [PlayerSettings.colorSpace](PlayerSettings-colorSpace.html).

See [RenderTextureReadWrite](RenderTextureReadWrite.html) overview page for more details.
