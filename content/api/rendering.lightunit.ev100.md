### Description



A value that represents a combination of a camera's shutter speed and f-number.





It is essentially a measurement of exposure such that all combinations of shutter speed and f-number that yield the same level of exposure have the same EV. Lights can use EV100, which is EV with a 100 International Standards Organisation (ISO) film.

Compatible light types: [LightType.Point](LightType.Point.html), [LightType.Spot](LightType.Spot.html), [LightType.Pyramid](LightType.Pyramid.html), [LightType.Rectangle](LightType.Rectangle.html), [LightType.Disc](LightType.Disc.html), [LightType.Tube](LightType.Tube.html).

Additional resources: [Light.lightUnit](Light-lightUnit.html), [light component](../Manual/class-Light.html).
