                    public CapsuleCollider[] capsuleColliders;






### Description



An array of CapsuleColliders which this Cloth instance should collide with.





Any capsule colliders specified in [Cloth.capsuleColliders](Cloth-capsuleColliders.html) will collide with the cloth vertices. A maximum of 32 capsules are supported.
