                    public float AverageThroughputMBPerSecond;






### Description



The mean rate of request throughput, in Mbps, for read request metrics included in the summary calculation.





This is similar to [bandwidth](Unity.IO.LowLevel.Unsafe.AsyncReadManagerSummaryMetrics-bandwidth.html), but takes into account the waiting time as well as reading time.
