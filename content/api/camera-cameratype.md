                    public [CameraType](CameraType.html) cameraType;






### Description



Identifies what kind of camera this is, using the [CameraType](CameraType.html) enum.





Regular cameras in your scene have a value of [CameraType.Game](CameraType.Game.html), both at runtime and in the Unity Editor. Cameras that render different parts of the Unity Editor have other values; for example, cameras that render the Scene view have a value of [CameraType.SceneView](CameraType.SceneView.html).

This is useful in the Scriptable Render Pipeline, where you can define different rendering behavior for Unity Editor cameras as well as cameras in your scene.
