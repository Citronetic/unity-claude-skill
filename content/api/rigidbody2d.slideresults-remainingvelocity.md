                    public [Vector2](Vector2.html) remainingVelocity;






### Description



Returns the remaining velocity that couldn't be used when performing a [Rigidbody2D.Slide](Rigidbody2D.Slide.html).





There are a few reasons why all the specified velocity may not be used:



          - An error occured due to an invalid argument provided.

          - The [Rigidbody2D.SlideMovement.maxIterations](Rigidbody2D.SlideMovement-maxIterations.html) was reached so movement was stopped.





Additional resources: [Rigidbody2D.Slide](Rigidbody2D.Slide.html) and [SlideMovement](Rigidbody2D.SlideMovement.html).
