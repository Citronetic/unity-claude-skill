                    public static float fixedUnscaledDeltaTime;






### Description



The interval in seconds of timeScale-independent ("real") time at which physics and other fixed frame rate updates (like MonoBehaviour's [MonoBehaviour.FixedUpdate](MonoBehaviour.FixedUpdate.html)) are performed.(Read Only).





Unlike [Time.fixedDeltaTime](Time-fixedDeltaTime.html) this value is in real time rather than scaled game-time and therefore not affected by [Time.timeScale](Time-timeScale.html).
