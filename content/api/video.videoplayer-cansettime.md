### Description



Whether you can change the current time using the [VideoPlayer.time](Video.VideoPlayer-time.html) or [VideoPlayer.frame](Video.VideoPlayer-frame.html) properties. (Read Only)





Seeking is not supported in all contexts. For example, seeking in a HTTP live stream.

This value is only valid after the movie has been prepared. See [VideoPlayer.Prepare](Video.VideoPlayer.Prepare.html).
