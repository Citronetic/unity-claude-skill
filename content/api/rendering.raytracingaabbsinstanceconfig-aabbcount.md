                    public int aabbCount;






### Description



The number of AABBs Unity uses when you build the acceleration structure for this ray tracing instance.





Set the value to `-1` to add all the AABBs from [RayTracingAABBsInstanceConfig.aabbBuffer](Rendering.RayTracingAABBsInstanceConfig-aabbBuffer.html) to the acceleration structure.
