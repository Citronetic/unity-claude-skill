### Description



Indicates that [TextureMipmapLimitSettings](TextureMipmapLimitSettings.html) overrides the global texture mipmap limit by the [TextureMipmapLimitSettings.limitBias](TextureMipmapLimitSettings-limitBias.html) value, instead of offsetting it.
