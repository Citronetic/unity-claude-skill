## Declaration

public delegate void LayerCallback([SortingLayer](SortingLayer.html) layer);






### Description



Calls the methods in its invocation list when a sorting layer is added or removed.





`LayerCallback` is used by [SortingLayer.onLayerAdded](SortingLayer-onLayerAdded.html) and [SortingLayer.onLayerRemoved](SortingLayer-onLayerRemoved.html).
