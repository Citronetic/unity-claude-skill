### Description



Import materials from file.





When set to false ModelImporter will use default material (Default-Diffuse.mat) instead of imported materials,
otherwise it will find existing or create new materials based on [materialName](ModelImporter-materialName.html) and [materialSearch](ModelImporter-materialSearch.html) options.

Additional resources: [materialName](ModelImporter-materialName.html), [materialSearch](ModelImporter-materialSearch.html) options.
