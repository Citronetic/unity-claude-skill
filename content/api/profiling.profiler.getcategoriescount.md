## Declaration

public static uint GetCategoriesCount();






### Returns



**uint**
        Returns number of [ProfilerCategory](Unity.Profiling.ProfilerCategory.html) registered in Profiler.





### Description



Returns number of [ProfilerCategory](Unity.Profiling.ProfilerCategory.html) registered in Profiler.





Returns a total number of [ProfilerCategory](Unity.Profiling.ProfilerCategory.html) registered in the Profiler. Can be used together with [Profiler.GetAllCategories](Profiling.Profiler.GetAllCategories.html) to pre-allocate a container to the required size.
