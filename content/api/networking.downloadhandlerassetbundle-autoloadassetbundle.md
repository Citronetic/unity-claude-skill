                    public bool autoLoadAssetBundle;






### Description



If true, the AssetBundle will be loaded as part of the [UnityWebRequest](Networking.UnityWebRequest.html) process. If false, the [AssetBundle](AssetBundle.html) will be loaded on demand when accessing the [DownloadHandlerAssetBundle.assetBundle](Networking.DownloadHandlerAssetBundle-assetBundle.html) property.





Default: false.
