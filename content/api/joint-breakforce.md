                    public float breakForce;






### Description



The force that needs to be applied for this joint to break.





The force might come from collisions with other objects, forces applied with [Rigidbody.AddTorque](Rigidbody.AddTorque.html) or from other joints.
The break force can be set to [Mathf.Infinity](Mathf.Infinity.html) to render the joint unbreakable.
Additional resources: [Joint.OnJointBreak](Joint.OnJointBreak.html).
