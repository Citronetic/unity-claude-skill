## Declaration

public static bool Start();






### Returns



**bool**
        True if the engine was switched into output recording mode. False if it is already recording.





### Description



Enters audio recording mode. After this Unity will output silence until [AudioRenderer.Stop](AudioRenderer.Stop.html) is called.
