### Description



Built-in shader types used by [GraphicsSettings](Rendering.GraphicsSettings.html).





Additional resources: [GraphicsSettings.SetShaderMode](Rendering.GraphicsSettings.SetShaderMode.html), [BuiltinShaderMode](Rendering.BuiltinShaderMode.html), [Graphics Settings](../Manual/class-GraphicsSettings.html).





### Properties



| Property | Description |
| --- | --- |
| DeferredShading | Shader used for deferred shading calculations. |
| DeferredReflections | Shader used for deferred reflection probes. |
| ScreenSpaceShadows | Shader used for screen-space cascaded shadows. |
| DepthNormals | Shader used for depth and normals texture when enabled on a Camera. |
| MotionVectors | Shader used for Motion Vectors when enabled on a Camera. |
| LightHalo | Default shader used for light halos. |
| LensFlare | Default shader used for lens flares. |
