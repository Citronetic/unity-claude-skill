### Description



Indicates that the application does not have permission to download asset packs under the current device circumstances.





One possible cause of this is that the application is running in the background.
Additional resources: [AndroidAssetPacks.DownloadAssetPackAsync](Android.AndroidAssetPacks.DownloadAssetPackAsync.html), [AndroidAssetPacks.GetAssetPackStateAsync](Android.AndroidAssetPacks.GetAssetPackStateAsync.html).
