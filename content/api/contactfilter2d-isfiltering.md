                    public bool isFiltering;






### Description



Given the current state of the contact filter, determine whether it would filter anything.





This property checks the following properties and returns true, indicating filtering is enabled; [useTriggers](ContactFilter2D-useTriggers.html), [useLayerMask](ContactFilter2D-useLayerMask.html), [useDepth](ContactFilter2D-useDepth.html) and [useNormalAngle](ContactFilter2D-useNormalAngle.html).
