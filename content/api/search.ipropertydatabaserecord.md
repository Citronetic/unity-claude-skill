### Description



Interface of a record that is stored in the [PropertyDatabase](Search.PropertyDatabase.html).





A record is the actual block of data that is stored in the [PropertyDatabase](Search.PropertyDatabase.html). A record is composed of a key, which describes what is stored and is used to sort the records for faster retrieval, and the value.





### Properties



| Property | Description |
| --- | --- |
| key | The key of the record. |
| validRecord | Boolean indicating if the record is valid. |
| value | The value of the record. |
