                    public float variantScale;






### Description



Value used to downscale the master's texture.





While packing a variant [SpriteAtlas](U2D.SpriteAtlas.html), the master Atlas' packed Texture will be duplicated and scaled according to this value. The resulting new Texture will be the packed Texture of this Atlas.
