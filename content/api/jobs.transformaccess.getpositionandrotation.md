## Declaration

public void GetPositionAndRotation(out [Vector3](Vector3.html) position,
out [Quaternion](Quaternion.html) rotation);






### Description



Gets the position and rotation of the transform in world space.





When getting both the position and rotation of a transform, calling this method is more efficient than querying to position and rotation
individually.
