                    public [PhysicsMaterialCombine2D](PhysicsMaterialCombine2D.html) frictionCombine;






### Description



Determines how the effective friction is calculated when two [Collider2D](Collider2D.html) come into contact.





Default to [PhysicsMaterialCombine2D.Mean](PhysicsMaterialCombine2D.Mean.html) which allows either [Collider2D](Collider2D.html) to reduce friction to zero. For example, anything slides on ice.
