### Description



When this flag is set, Unity performs occlusion culling as part of the culling operation.





Default value: set if the [Camera](Camera.html) from which you obtained the CullingParameters object has [Camera.useOcclusionCulling](Camera-useOcclusionCulling.html) set to `true`. Otherwise, unset.

Additional resources: [Camera.useOcclusionCulling](Camera-useOcclusionCulling.html), [Occlusion culling](../Manual/OcclusionCulling.html), [ScriptableCullingParameters.cullingOptions](Rendering.ScriptableCullingParameters-cullingOptions.html), [ScriptableRenderContext.Cull](Rendering.ScriptableRenderContext.Cull.html), [CullingResults](Rendering.CullingResults.html).
