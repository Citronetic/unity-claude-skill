                    public string[] downloadedAssetPacks;






### Description



Gets the names of Android asset packs downloaded by this operation.





This property returns the names of asset packs that the device downloaded and made available to the app based on the download request that this async operation represents. To get the path to the directory that contains the assets, call [AndroidAssetPacks.GetAssetPackPath](Android.AndroidAssetPacks.GetAssetPackPath.html).
Read-only.
