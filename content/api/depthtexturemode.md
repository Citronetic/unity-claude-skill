### Description



Depth texture generation mode for [Camera](Camera.html).





The flags can be combined, so you can set a Camera to generate any combination of: Depth, Depth+Normals, and MotionVector textures if needed.

Additional resources: [Using camera's depth textures](../Manual/SL-CameraDepthTexture.html), [Camera.depthTextureMode](Camera-depthTextureMode.html).





### Properties



| Property | Description |
| --- | --- |
| None | Do not generate depth texture (Default). |
| Depth | Generate a depth texture. |
| DepthNormals | Generate a depth + normals texture. |
| MotionVectors | Specifies whether motion vectors should be rendered (if possible). |
