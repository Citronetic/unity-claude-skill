## Declaration

public bool AddScriptableObject([ScriptableObject](ScriptableObject.html) obj);






### Parameters



| Parameter | Description |
| --- | --- |
| obj | The ScriptableObject reference to add. |





### Returns



**bool**
        Returns true if the reference is added. Returns false if the sprite is already referencing the [ScriptableObject](ScriptableObject.html) .





### Description



Adds a [ScriptableObject](ScriptableObject.html) reference to the sprite.





Refer to [Sprite.GetScriptableObjects](Sprite.GetScriptableObjects.html) for sample usage.
