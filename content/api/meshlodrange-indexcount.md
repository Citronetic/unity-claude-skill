                    public uint indexCount;






### Description



This property, together with [indexStart](MeshLodRange-indexStart.html), determines which part of the whole index buffer is used by
a particular Mesh LOD.

This should be a positive number or zero.

Additional resources: [indexStart](MeshLodRange-indexStart.html), [Mesh.SetLod](Mesh.SetLod.html), [Mesh.SetLods](Mesh.SetLods.html).
