## Declaration

public void ClearInstances();






### Description



Removes all ray tracing instances from the RayTracingAccelerationStructure.





Note that in order to reflect this action on the GPU, building the acceleration structure has to be triggered by calling [RayTracingAccelerationStructure.Build](Rendering.RayTracingAccelerationStructure.Build.html) or [CommandBuffer.BuildRayTracingAccelerationStructure](Rendering.CommandBuffer.BuildRayTracingAccelerationStructure.html).

Additional resources: [RayTracingAccelerationStructure.AddInstance](Rendering.RayTracingAccelerationStructure.AddInstance.html).
