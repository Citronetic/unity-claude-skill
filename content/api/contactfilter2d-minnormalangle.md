                    public float minNormalAngle;






### Description



Sets the contact filter to filter the results to only include contacts with collision normal angles that are greater than this angle.





This is only used if [useNormalAngle](ContactFilter2D-useNormalAngle.html) is true.  If the `minNormalAngle` is set to -[Mathf.Infinity](Mathf.Infinity.html) or [Mathf.Infinity](Mathf.Infinity.html) then the lowest possible angle is used.

Additional resources: [ContactPoint2D.normal](ContactPoint2D-normal.html).
