## Declaration

public void RemoveCommandBuffers([Rendering.CameraEvent](Rendering.CameraEvent.html) evt);






### Parameters



| Parameter | Description |
| --- | --- |
| evt | When to execute the command buffer during rendering. |





### Description



Remove command buffers from execution at a specified place.





This function removes all command buffers set on the specified camera event.
This API is only available with the Built-in renderer.

Additional resources: [CommandBuffer](Rendering.CommandBuffer.html), [RemoveCommandBuffer](Camera.RemoveCommandBuffer.html), [RemoveAllCommandBuffers](Camera.RemoveAllCommandBuffers.html).
