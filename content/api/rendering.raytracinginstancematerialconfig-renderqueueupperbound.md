                    public int renderQueueUpperBound;






### Description



The upper limit of a render queue interval.





Together with the [RayTracingInstanceMaterialConfig.renderQueueLowerBound](Rendering.RayTracingInstanceMaterialConfig-renderQueueLowerBound.html) value, this value is used to determine the Material type.

Additional resources: [RayTracingAccelerationStructure.CullInstances](Rendering.RayTracingAccelerationStructure.CullInstances.html).
