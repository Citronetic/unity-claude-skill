### Description



Vertical resolution that the display is rendering at.





Rendering resolution can be different from a platform's original display resolution (see [Display.systemHeight](Display-systemHeight.html)).

Additional resources: [renderingWidth](Display-renderingWidth.html), [SetRenderingResolution](Display.SetRenderingResolution.html).
