                    public static bool supportsPerDrawCall;






### Description



Returns true if variable fragment shading rates per draw call are supported by the current graphics card for variable rate shading.

                Note that this feature is not currently supported in Unity.
Additional resources: [SystemInfo.supportsVariableRateShading](SystemInfo-supportsVariableRateShading.html).
