                    public int cullingMask;






### Description



This is used to render parts of the Scene selectively.





For example if a [GameObject](GameObject.html)'s `layer` is set to 2, and the second bit of the camera's `cullingMask` is set to zero, the GameObject will be invisible to the camera. See [Layers](../Manual/Layers.html) for more information.

Additional resources: [camera component](../Manual/class-Camera.html).
