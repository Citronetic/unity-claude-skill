                    public bool autoFlush;






### Description



Boolean indicating if the [PropertyDatabase](Search.PropertyDatabase.html) will update the backing file automatically or not.





When set to true, the [PropertyDatabase](Search.PropertyDatabase.html) will update the backing file automatically when there are no more changes applied on the [PropertyDatabase](Search.PropertyDatabase.html). By default, the delay between changes to trigger an automatic update is 5 seconds.
