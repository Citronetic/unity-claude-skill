### Description



ETC2 texture decompression fallback override on Android devices that don't support ETC2.





Allows to choose which texture format to decompress the texture to on Android devices that have no ETC2 texture format support. Additional resources: AndroidETC2Fallback, [AndroidETC2FallbackOverride](AndroidETC2FallbackOverride.html).
