                    public static ulong currentTextureMemory;






### Description



The amount of memory that all Textures in the scene use.





Provides a snapshot of the amount of memory used while the mipmap streaming and budget are applied. The amount of memory used trends toward [Texture.targetTextureMemory](Texture-targetTextureMemory.html) as the Texture mipmaps are loaded or unloaded.
Additional resources: [Texture.targetTextureMemory](Texture-targetTextureMemory.html).
