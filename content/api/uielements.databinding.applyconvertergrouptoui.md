## Declaration

public void ApplyConverterGroupToUI([UIElements.ConverterGroup](UIElements.ConverterGroup.html) group);






### Parameters



| Parameter | Description |
| --- | --- |
| group | The converter group. |





### Description



Applies a [ConverterGroup](UIElements.ConverterGroup.html) to this binding that will be used when converting data between a
 data source to a UI control.





Converter groups can be queried using [ConverterGroups.TryGetConverterGroup](UIElements.ConverterGroups.TryGetConverterGroup.html).
