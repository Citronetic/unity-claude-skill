## Declaration

public void SetEditorPreviewTile([Vector3Int](Vector3Int.html) position,
[Tilemaps.TileBase](Tilemaps.TileBase.html) tile);






### Parameters



| Parameter | Description |
| --- | --- |
| position | Position of the editor preview Tile on the Tilemap. |
| tile | The editor preview Tile to be placed the cell. |





### Description



Sets an editor preview [Tile](Tilemaps.Tile.html) given the XYZ coordinates of a cell in the [Tilemap](Tilemaps.Tilemap.html).





The editor preview Tile is used for previewing possible additions to the [Tilemap](../Manual/class-Tilemap.html).
