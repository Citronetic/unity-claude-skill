### Description



Extension methods for the [Material](Material.html) asset type in the editor.





### Static Methods



| Method | Description |
| --- | --- |
| PerformBumpMapCheck | Iterates over all the Material properties with the MaterialProperty.PropFlags.Normal flag and checks that the textures referenced by these properties are imported as TextureImporterType.NormalMap. |
