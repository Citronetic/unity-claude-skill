## Declaration

public bool PlayOnGamepad(int slot);






### Parameters



| Parameter | Description |
| --- | --- |
| slot | Slot number of the gamepad (0-3). |





### Returns



**bool**
        Returns TRUE if enabling audio output through this users controller was successful.





### Description



Enable the audio source to play through a specific gamepad.





Set your current [BuildTarget](BuildTarget.html) to **PS4** or **PS5** to avoid a build error in the Windows Editor.
