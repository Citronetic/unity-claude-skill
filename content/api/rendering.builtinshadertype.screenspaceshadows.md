### Description



Shader used for screen-space cascaded shadows.





Cascaded shadow maps for directional lights on PC/console platforms compute a
screenspace shadow mask using this shader.

Additional resources: [GraphicsSettings.SetShaderMode](Rendering.GraphicsSettings.SetShaderMode.html), [BuiltinShaderMode](Rendering.BuiltinShaderMode.html), [Graphics Settings](../Manual/class-GraphicsSettings.html), [Shadow Cascades](../Manual/shadow-cascades.html).
