                    public bool disposeUploadHandlerOnDispose;






### Description



If true, any [UploadHandler](Networking.UploadHandler.html) attached to this [UnityWebRequest](Networking.UnityWebRequest.html) will have [UploadHandler.Dispose](Networking.UploadHandler.Dispose.html) called automatically when [UnityWebRequest.Dispose](Networking.UnityWebRequest.Dispose.html) is called.





Default: true.

If no [UploadHandler](Networking.UploadHandler.html) is attached to this [UnityWebRequest](Networking.UnityWebRequest.html), this property has no effect.
