                    public bool alphaIsTransparency;






### Description



Indicates whether this texture was imported with [TextureImporter.alphaIsTransparency](TextureImporter-alphaIsTransparency.html) enabled. This setting is available only in the Editor scripts. Note that changing this setting will have no effect; it must be enabled in [TextureImporter](TextureImporter.html) instead.
