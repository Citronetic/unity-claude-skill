                    public static string windowsDevicePortalAddress;






### Description



Specifies the Windows DevicePortal connection address of the device to deploy and launch the UWP app on when using Build and Run.





The WDP connection address typically can be found next to the DevicePortal options under the "Developer" settings of the target Windows device.
Please refer to the [Microsoft DevicePortal documentation](https://docs.microsoft.com/en-us/windows/uwp/debug-test-perf/device-portal) for more details.
