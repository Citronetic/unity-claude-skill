### Description



Options for controlling how memory is cleared.





You can either clear memory on allocation or leave it uninitialized. [NativeArrayOptions.ClearMemory](Unity.Collections.NativeArrayOptions.ClearMemory.html) is the default.





### Properties



| Property | Description |
| --- | --- |
| UninitializedMemory | Leaves NativeArray<T0> memory uninitialized. |
| ClearMemory | Clears NativeArray<T0> memory on allocation. |
