### Description



Three channel (RGB) texture format, 8-bits unsigned integer per channel.





Note that there are almost no GPUs that support this format natively, so at texture load time it is converted into an [RGBA32](TextureFormat.RGBA32.html) format. RGB24 is thus only useful for some game build size savings.

Additional resources: [Texture2D](Texture2D.html), [texture assets](../Manual/Textures.html).
