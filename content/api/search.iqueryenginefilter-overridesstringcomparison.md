                    public bool overridesStringComparison;






### Description



Indicates if the filter overrides the global string comparison options.





This flag is set to true when there is a string comparison option for the filter which overrides the global string comparison options. See [AddFilter](Search.QueryEngine_1.AddFilter.html).
