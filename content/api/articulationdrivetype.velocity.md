### Description



Drives in this mode have a very high damping and track the [ArticulationDrive.targetVelocity](ArticulationDrive-targetVelocity.html) almost kinematically.





The damping value that's used in this mode is not serialized, so switching back to a different [ArticulationDriveType](ArticulationDriveType.html) will use the serialized values.
