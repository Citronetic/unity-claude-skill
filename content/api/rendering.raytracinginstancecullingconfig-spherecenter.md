                    public [Vector3](Vector3.html) sphereCenter;






### Description



The center of the sphere used for culling ray tracing instances associated with the Renderers in a Scene.





To enable sphere culling, use [RayTracingInstanceCullingFlags.EnableSphereCulling](Rendering.RayTracingInstanceCullingFlags.EnableSphereCulling.html) flag in [RayTracingInstanceCullingConfig.flags](Rendering.RayTracingInstanceCullingConfig-flags.html).

Additional resources: [RayTracingAccelerationStructure.CullInstances](Rendering.RayTracingAccelerationStructure.CullInstances.html).
