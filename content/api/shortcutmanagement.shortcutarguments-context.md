                    public object context;






### Description



Instance of the context in which the shortcut was triggered.





If the triggered shortcut was registered with a context of type [EditorWindow](EditorWindow.html) then `context` will be the instance of the [EditorWindow](EditorWindow.html) in which the shortcut was triggered.
