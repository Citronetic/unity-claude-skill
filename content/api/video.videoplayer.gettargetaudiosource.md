## Declaration

public [AudioSource](AudioSource.html) GetTargetAudioSource(ushort trackIndex);






### Parameters



| Parameter | Description |
| --- | --- |
| trackIndex | Index of the audio track for which the AudioSource is wanted. |





### Returns



**AudioSource**
        The source associated with the audio track.





### Description



Gets the [AudioSource](AudioSource.html) that will receive audio samples for the specified track if [VideoPlayer.audioOutputMode](Video.VideoPlayer-audioOutputMode.html) is set to [VideoAudioOutputMode.AudioSource](Video.VideoAudioOutputMode.AudioSource.html).
