## Declaration

public static void SetDuration(U playable,
double value);






### Parameters



| Parameter | Description |
| --- | --- |
| playable | The Playable used by this operation. |
| value | The new duration in seconds, must be a positive value. |





### Description



Changes the duration of the [Playable](Playables.Playable.html).





Use this templated extension method on any type that inherits from [IPlayable](Playables.IPlayable.html).
