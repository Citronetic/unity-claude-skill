### Description



Structure to hold scene data extracted from a SketchUp file.





When importing a SketchUp file, Unity retrieves all the scenes in the SketchUp file.

This can be extracted later from [SketchUpImporter](SketchUpImporter.html) with [SketchUpImporter.GetScenes](SketchUpImporter.GetScenes.html).





### Properties



| Property | Description |
| --- | --- |
| camera | The camera data of the SketchUp scene. |
| name | The name of the SketchUp scene. |
