                    public [Texture](Texture.html) motionVectors;






### Description



The motion vectors requested by the [DLSSContext](NVIDIA.DLSSContext.html). Depending on the [DLSSFeatureFlags](NVIDIA.DLSSFeatureFlags.html) specified in [DLSSContext.initData](NVIDIA.DLSSContext-initData.html), this buffer can be a smaller scale or the full output resolution. This texture is mandatory and you must set it to a non-null value.
