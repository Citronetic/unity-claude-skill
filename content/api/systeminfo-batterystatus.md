### Description



Returns the current status of the device's battery (Read Only).





See the [BatteryStatus](BatteryStatus.html) enumeration for possible values.

The battery status includes information about whether the device is plugged in to a power source and whether the battery is charging. If battery status is not available on your target platform, this property returns [BatteryStatus.Unknown](BatteryStatus.Unknown.html).

Additional resources: [batteryLevel](SystemInfo-batteryLevel.html).
