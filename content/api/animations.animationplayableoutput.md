### Description



A [IPlayableOutput](Playables.IPlayableOutput.html) implementation that connects the [PlayableGraph](Playables.PlayableGraph.html) to an [Animator](Animator.html) in the Scene.





**NOTE:** You can use [PlayableOutputExtensions](Playables.PlayableOutputExtensions.html) methods on AnimationPlayableOutput objects.





### Public Methods



| Method | Description |
| --- | --- |
| GetTarget | Returns the Animator that plays the animation graph. |
| SetTarget | Sets the Animator that plays the animation graph. |





### Static Methods



| Method | Description |
| --- | --- |
| Create | Creates an AnimationPlayableOutput in the PlayableGraph. |
