### Description



Defines a set of changes that happens in order to update a search asset index.





See [SearchMonitor](Search.SearchMonitor.html) for how this structure is used.





### Properties



| Property | Description |
| --- | --- |
| all | Enumerate all changes. |
| empty | Indicates if the changeset is empty. |
| removed | Enumerate all asset that were removed. |
| updated | Enumerates all assets that were updated. |





### Constructors



| Constructor | Description |
| --- | --- |
| AssetIndexChangeSet | Create a search asset index changeset. |
