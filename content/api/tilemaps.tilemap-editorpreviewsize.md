### Description



The size of the [Tilemap](Tilemaps.Tilemap.html) in cells inclusive of editor preview Tiles.





This is used when rendering the [Tilemap](Tilemaps.Tilemap.html) in Editor mode, taking both placed Tiles and editor preview Tiles for preview placement into account.
