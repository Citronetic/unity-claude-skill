### Description



Enumeration specifying the current pause state of the Editor.

Additional resources: [PlayModeStateChange](PlayModeStateChange.html), [EditorApplication.pauseStateChanged](EditorApplication-pauseStateChanged.html), [EditorApplication.isPaused](EditorApplication-isPaused.html).





### Properties



| Property | Description |
| --- | --- |
| Paused | Occurs as soon as the Editor is paused, which may occur during either edit mode or play mode. |
| Unpaused | Occurs as soon as the Editor is unpaused, which may occur during either edit mode or play mode. |
