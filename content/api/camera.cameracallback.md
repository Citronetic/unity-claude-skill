## Declaration

public delegate void CameraCallback([Camera](Camera.html) cam);






### Description



Delegate type for camera callbacks.





Use this with [Camera.onPreCull](Camera-onPreCull.html), [Camera.onPreRender](Camera-onPreRender.html) or [Camera.onPostRender](Camera-onPostRender.html) to get callbacks when any camera does rendering.

Camera that invokes the callback will be passed as the argument.

Additional resources: [onPreCull](Camera-onPreCull.html), [onPreRender](Camera-onPreRender.html), [onPostRender](Camera-onPostRender.html).
