### Description



The [GameObject](GameObject.html) root of the animated hierarchy. (Read Only)





The root is set by the constructor (See: [ctor](Animations.GameObjectRecorder-ctor.html)).

You can bind a property from the root, or any of its children. To bind a property, use one of the following methods: [BindComponent](Animations.GameObjectRecorder.BindComponent.html), [BindComponentsOfType](Animations.GameObjectRecorder.BindComponentsOfType.html), [BindAll](Animations.GameObjectRecorder.BindAll.html), or [Bind](Animations.GameObjectRecorder.Bind.html).
