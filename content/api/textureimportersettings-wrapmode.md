                    public [TextureWrapMode](TextureWrapMode.html) wrapMode;






### Description



Texture coordinate wrapping mode.





Using `wrapMode` sets the same wrapping mode on all axes. Different per-axis wrap modes can be set using [wrapModeU](TextureImporterSettings-wrapModeU.html), [wrapModeV](TextureImporterSettings-wrapModeV.html), [wrapModeW](TextureImporterSettings-wrapModeW.html).
Querying the value returns the U axis wrap mode (same as [wrapModeU](TextureImporterSettings-wrapModeU.html) getter).

Additional resources: [Texture.wrapMode](Texture-wrapMode.html), [texture assets](../Manual/class-TextureImporter.html).
