### Description



[AnimationStream](Animations.AnimationStream.html) will be initialized with the default values from the [Animator](Animator.html).





Before it is modified during [IAnimationJob.ProcessAnimation](Animations.IAnimationJob.ProcessAnimation.html) or [IAnimationJob.ProcessRootMotion](Animations.IAnimationJob.ProcessRootMotion.html), the [AnimationStream](Animations.AnimationStream.html) contains the default values of the associated [Animator](Animator.html).

This is the default behaviour for an [AnimationPlayableOutput](Animations.AnimationPlayableOutput.html).

Additional resources: [AnimationPlayableOutputExtensions.SetAnimationStreamSource](Experimental.Animations.AnimationPlayableOutputExtensions.SetAnimationStreamSource.html).
