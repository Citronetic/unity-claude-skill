                    public static int maxNumberOfQueries;






### Description



The maximum number of queries that the [PhysicsDebugWindow](PhysicsDebugWindow.html) will visualize at one given time.





[PhysicsDebugWindow](PhysicsDebugWindow.html) takes the [PhysicsVisualizationSettings](PhysicsVisualizationSettings.html) filtering settings into account before appending a query to the visualization list and therefore will prevent filtered out queries from increasing the total number of queries.
