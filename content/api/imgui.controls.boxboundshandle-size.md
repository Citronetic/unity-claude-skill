                    public [Vector3](Vector3.html) size;






### Description



Returns or specifies the size of the bounding box.





Negative values along any axis of the specified [Vector3](Vector3.html) are automatically converted into a positive value. Disabled axes are automatically converted to `0`.

Additional resources: [PrimitiveBoundsHandle.axes](IMGUI.Controls.PrimitiveBoundsHandle-axes.html).
