### Description



A [IPlayable](Playables.IPlayable.html) implementation that contains a [PlayableBehaviour](Playables.PlayableBehaviour.html) for the [PlayableGraph](Playables.PlayableGraph.html). [PlayableBehaviour](Playables.PlayableBehaviour.html) can be used to write custom Playable that implement their own PrepareFrame callback.





A branch of a [PlayableGraph](Playables.PlayableGraph.html) must be connected to an output to be evaluated.





NOTE: You can use [PlayableExtensions](Playables.PlayableExtensions.html) methods with ScriptPlayable objects.
