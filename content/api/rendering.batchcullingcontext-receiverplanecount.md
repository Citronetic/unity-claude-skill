                    public int receiverPlaneCount;






### Description



The number of receiver planes.





The number of receiver planes in the [BatchCullingContext.cullingPlanes](Rendering.BatchCullingContext-cullingPlanes.html) array. Receiver planes are only present when culling Lights, otherwise the number is zero. You can use receiver planes to reject shadow casters that are not visible in the receiver view.
