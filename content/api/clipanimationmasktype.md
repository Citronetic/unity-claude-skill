### Description



AnimationClip mask options for [ModelImporterClipAnimation](ModelImporterClipAnimation.html).





Mask can be used to specify which transforms animation should be imported when generating the clip.
Additional resources: [ModelImporterClipAnimation.maskType](ModelImporterClipAnimation-maskType.html).





### Properties



| Property | Description |
| --- | --- |
| CreateFromThisModel | A mask containing all the transform in the file will be created internally. |
| CopyFromOther | Use a mask from your project to specify which transforms animation should be imported. |
| None | No Mask. All the animation will be imported. |
