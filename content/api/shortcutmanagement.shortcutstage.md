### Description



Represents the stage at which a shortcut action was invoked.





This is used for clutch shortcuts (see [ClutchShortcutAttribute](ShortcutManagement.ClutchShortcutAttribute.html)) to determine if the shortcut action was invoked due to pressing the binding ([Begin](ShortcutManagement.ShortcutStage.Begin.html)) or releasing the binding ([End](ShortcutManagement.ShortcutStage.End.html)).





### Properties



| Property | Description |
| --- | --- |
| Begin | Represents that a shortcut action has begun. |
| End | Represents that a shortcut action has ended. |
