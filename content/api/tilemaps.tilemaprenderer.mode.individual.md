### Description



Sends each [Sprite](Sprite.html) from the [Tilemap](Tilemaps.Tilemap.html) to be rendered individually.





Use this mode if each [Sprite](Sprite.html) on the [Tilemap](Tilemaps.Tilemap.html) needs to interact with other Renderers, for example due to sorting.
