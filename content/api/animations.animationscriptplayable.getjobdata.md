## Declaration

public T GetJobData();






### Returns



**T**
        Returns the [IAnimationJob](Animations.IAnimationJob.html) data contained in the playable.





### Description



Gets the job data contained in the playable.





The generic type must be the same as the one used for the creation of the playable, otherwise an `ArgumentException` is raised.

Additional resources: the example in [AnimationScriptPlayable.Create](Animations.AnimationScriptPlayable.Create.html).
