### Description



An array of all the object being inspected.





For editors that support multi-object editing, you can use the targets property in [OnInspectorGUI](Editor.OnInspectorGUI.html). However, it is better to use the [serializedObject](Editor-serializedObject.html), as described on the page about the [Editor](Editor.html) class.
