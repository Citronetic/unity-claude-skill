                    public [PhysicsMaterialCombine2D](PhysicsMaterialCombine2D.html) bounceCombine;






### Description



Determines how the effective bounciness is calculated when two [Collider2D](Collider2D.html) come into contact.





Defaults to [PhysicsMaterialCombine2D.Maximum](PhysicsMaterialCombine2D.Maximum.html) which allows either [Collider2D](Collider2D.html) to maximize bounciness. For example, a very bouncy ball always remains very bouncy.
