                    public float yMin;






### Description



The minimum Y coordinate of the rectangle.





This value is the same as [y](Rect-y.html), but setting it will resize the rectangle, changing [y](Rect-y.html) and [height](Rect-height.html) to preserve [yMax](Rect-yMax.html).
