                    public bool usedByEffector;






### Description



Whether the collider is used by an attached effector or not.





When checked, the [Collider2D](Collider2D.html) continues to work as a collision or trigger area however it will also be used by any [Effector2D](Effector2D.html) on the same GameObject.
