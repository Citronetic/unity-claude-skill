## Declaration

public [UIElements.VisualElement](UIElements.VisualElement.html) CreatePanelContent();






### Returns



**VisualElement**
        Returns the contents of this [Overlay](Overlays.Overlay.html).





### Description



CreatePanelContent is invoked by the OverlayCanvas when this [Overlay](Overlays.Overlay.html) is shown.





IMGUIOverlay implements this function. The only method IMGUIOverlay must implement is the [IMGUIOverlay.OnGUI](Overlays.IMGUIOverlay.OnGUI.html) method.
