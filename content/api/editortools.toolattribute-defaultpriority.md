### Description



The default value for [ToolAttribute.toolPriority](EditorTools.ToolAttribute-toolPriority.html) and [ToolAttribute.variantPriority](EditorTools.ToolAttribute-variantPriority.html). Specify a priority lower than this value to display a tool before the default entries, or specify a higher value to display it after the default entries.
