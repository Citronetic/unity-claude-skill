                    public int pathCount;






### Description



The number of paths in the Collider.





A *path* is a cyclic sequence of line segments between points that define the outline of a polygon. Since the polygon can have holes and discontinuous parts, its shape is not necessarily defined by a single path.

Additional resources: [GetPath](CompositeCollider2D.GetPath.html).
