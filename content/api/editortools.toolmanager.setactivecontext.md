### Parameters



| Parameter | Description |
| --- | --- |
| context | The EditorToolContext type to be set as the active tool. |





### Description



Sets the active [EditorToolContext](EditorTools.EditorToolContext.html).





To restore the manipulation tools to their default behavior, pass [GameObjectToolContext](EditorTools.GameObjectToolContext.html) or null to the [context](EditorTools.ToolManager-context.html) argument.
