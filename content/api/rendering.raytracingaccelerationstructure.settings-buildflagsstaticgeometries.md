### Description



The [flags](Rendering.RayTracingAccelerationStructureBuildFlags.html) Unity uses when it builds acceleration structures associated with static geometries.





To customize the flags per ray tracing instance, use [Renderer](Renderer.html) settings or the parameters in the [RayTracingAccelerationStructure.AddInstance](Rendering.RayTracingAccelerationStructure.AddInstance.html) method.
