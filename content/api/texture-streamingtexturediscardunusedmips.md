                    public static bool streamingTextureDiscardUnusedMips;






### Description



This property forces the streaming Texture system to discard all unused mipmaps instead of caching them until the Texture [memory budget](../Manual/TextureStreaming#memory-budget.html) is exceeded. This is useful when you profile or write tests to keep a predictable set of Textures in memory.
