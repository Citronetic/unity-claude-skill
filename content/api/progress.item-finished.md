                    public bool finished;






### Description



Returns true if the progress indicator is finished, but not removed.





A progress indicator is considered finished when its status is either [Succeeded](Progress.Status.Succeeded.html) or [Failed](Progress.Status.Failed.html).

Additional resources: [Progress.GetStatus](Progress.GetStatus.html), [Status](Progress.Status.html).
