                    public static int IgnoreRaycastLayer;






### Description



Layer mask constant for the default layer that ignores raycasts.





The value of the mask is the bitwise complement of the [DefaultRaycastLayers](Physics2D.DefaultRaycastLayers.html) mask.

Additional resources: [Raycast](Physics2D.Raycast.html), [DefaultRaycastLayers](Physics2D.DefaultRaycastLayers.html), [AllLayers](Physics2D.AllLayers.html).
