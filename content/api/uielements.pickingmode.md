### Description



Describes the picking behavior. See [VisualElement.pickingMode](UIElements.VisualElement-pickingMode.html).





### Properties



| Property | Description |
| --- | --- |
| Position | Picking enabled. Performs picking based on the position rectangle. |
| Ignore | Prevents this element from being the target of pointer events or
 from being returned by IPanel.Pick and IPanel.PickAll. |
