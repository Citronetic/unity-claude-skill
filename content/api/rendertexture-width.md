                    public int width;






### Description



The width of the render texture in pixels.





Note that unlike [Texture.width](Texture-width.html) property, this is both read and write -
setting a value changes size.

Additional resources:: [height](RenderTexture-height.html), [format](RenderTexture-graphicsFormat.html), [depth](RenderTexture-depth.html).
