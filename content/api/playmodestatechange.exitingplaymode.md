### Description



Occurs when exiting play mode, before the Editor is in edit mode.





In this condition, [EditorApplication.isPlaying](EditorApplication-isPlaying.html) is `true` and [EditorApplication.isPlayingOrWillChangePlaymode](EditorApplication-isPlayingOrWillChangePlaymode.html) is `false`.
