### Description



Shadow resolution options for a [Light](Light.html).





Additional resources: [Light.shadowResolution](Light-shadowResolution.html), [QualitySettings.shadowResolution](QualitySettings-shadowResolution.html), [Shadow map size calculation](../Manual/ShadowPerformance.html).





### Properties



| Property | Description |
| --- | --- |
| FromQualitySettings | Use resolution from QualitySettings (default). |
| Low | Low shadow map resolution. |
| Medium | Medium shadow map resolution. |
| High | High shadow map resolution. |
| VeryHigh | Very high shadow map resolution. |
