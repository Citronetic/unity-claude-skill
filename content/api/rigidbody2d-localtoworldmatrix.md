                    public [Matrix4x4](Matrix4x4.html) localToWorldMatrix;






### Description



The transformation matrix used to transform the Rigidbody2D to world space.





The transformation matrix is calculated as the combination of the [Rigidbody2D.position](Rigidbody2D-position.html) and the [Rigidbody2D.rotation](Rigidbody2D-rotation.html).

Additional resources: [Collider2D.localToWorldMatrix](Collider2D-localToWorldMatrix.html) and [Matrix4x4](Matrix4x4.html).
