                    public float angularOffset;






### Description



The current angular offset between the [Rigidbody2D](Rigidbody2D.html) that the joint connects.





The joint will attempt to maintain this angular offset between the connected [Rigidbody2D](Rigidbody2D.html) using a maximum torque specified by [maxTorque](RelativeJoint2D-maxTorque.html).

Additional resources: [maxTorque](RelativeJoint2D-maxTorque.html), [maxForce](RelativeJoint2D-maxForce.html).
