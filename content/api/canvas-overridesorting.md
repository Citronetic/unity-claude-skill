                    public bool overrideSorting;






### Description



Allows for nested canvases to override the [Canvas.sortingOrder](Canvas-sortingOrder.html) from parent canvases.





If set, nested canvases can ignore the parent draw order, and either draw on top of or below the parent draw order.
