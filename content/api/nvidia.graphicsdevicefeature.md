### Description



Lists every feature ID the [GraphicsDevice](NVIDIA.GraphicsDevice.html) API supports. For now, this only includes **Deep Learning Super Sampling** (DLSS). To check if the device supports a feature, call [GraphicsDevice.IsFeatureAvailable](NVIDIA.GraphicsDevice.IsFeatureAvailable.html).





### Properties



| Property | Description |
| --- | --- |
| DLSS | Represents the Deep Learning Super Sampling (DLSS) feature. |
