## Declaration

public static void MoveSceneAfter([SceneManagement.Scene](SceneManagement.Scene.html) src,
[SceneManagement.Scene](SceneManagement.Scene.html) dst);






### Parameters



| Parameter | Description |
| --- | --- |
| src | The Scene to move. |
| dst | The Scene which should come directly before the source Scene in the hierarchy. |





### Description



Allows you to reorder the Scenes currently open in the Hierarchy window. Moves the source Scene so it comes after the destination Scene.
