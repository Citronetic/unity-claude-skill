## Declaration

public static void SetCameraAnimateMaterialsTime([Camera](Camera.html) camera,
float time);






### Description



Sets the global time for this camera to use when rendering.





If [EditorUtility.SetCameraAnimateMaterials](EditorUtility.SetCameraAnimateMaterials.html) is true for the given [Camera](Camera.html), this is the value that will be used for the time passed through to any used shaders.

Additional resources: [EditorUtility.SetCameraAnimateMaterials](EditorUtility.SetCameraAnimateMaterials.html).
