### Description



Provide a information to order and categorize at category level.





Categories will be sorted using first the Order property, and if equals, using then the Name.

See also [IRenderPipelineGraphicsSettings](Rendering.IRenderPipelineGraphicsSettings.html) for usage example.

See also [ElementInfoAttribute](Categorization.ElementInfoAttribute.html).





### Properties



| Property | Description |
| --- | --- |
| Name | The name to use for this category. |
| Order | The position this category should use. |
