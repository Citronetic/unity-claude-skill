## Declaration

public void ClearAllTiles();






### Description



Clears all [Tile](Tilemaps.Tile.html)s that are placed in the [Tilemap](Tilemaps.Tilemap.html).





This will also resize the [Tilemap](Tilemaps.Tilemap.html) to its default values.

In the Editor, this will also clear all editor preview [Tile](Tilemaps.Tile.html)s.
