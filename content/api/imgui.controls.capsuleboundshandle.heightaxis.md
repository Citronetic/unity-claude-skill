An enumeration for specifying which axis on a [CapsuleBoundsHandle](IMGUI.Controls.CapsuleBoundsHandle.html) object maps to the [CapsuleBoundsHandle.height](IMGUI.Controls.CapsuleBoundsHandle-height.html) parameter.





Additional resources: [CapsuleBoundsHandle.heightAxis](IMGUI.Controls.CapsuleBoundsHandle-heightAxis.html).
