### Description



Source of the video content for a VideoPlayer.





A VideoPlayer can contain valid references to both a [VideoClip](Video.VideoClip.html) and a URL at the same time. This enum expresses which of the two should be used for playback.





### Properties



| Property | Description |
| --- | --- |
| VideoClip | Use the current clip as the video content source. |
| Url | Use the current URL as the video content source. |
