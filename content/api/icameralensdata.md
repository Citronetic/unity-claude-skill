### Description



Implements this interface on a [Viewpoint<T0>](Viewpoint_1.html) to define a camera frustum when a Viewpoint is enabled in the Cameras Overlay.





These fields can be modified in the Scene view:



          - Field of View

          - Orthographic mode

          - Orthographic size
