                    public bool useSideFriction;






### Description



Should friction be used on the platform sides?





When false, a contact on the side uses no friction.  When true, any existing friction is used.  This is useful to stop friction slowing a [Collider2D](Collider2D.html) when in contact with a vertical surface when a force is being applied to keep the [Collider2D](Collider2D.html) in contact with the surface.  The "sides" are defined as the edges perpendicular to the "top" surface(s) in local-space.
