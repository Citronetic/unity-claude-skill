## Declaration

public Rotate([UIElements.Angle](UIElements.Angle.html) angle,
[Vector3](Vector3.html) axis);






### Description



Create a Rotate struct that corresponds to a rotation around the specified axis by the provided [Angle](UIElements.Angle.html).





3D rotations are only expected to work on world space panels and will cause masking issues on overlay panels.
