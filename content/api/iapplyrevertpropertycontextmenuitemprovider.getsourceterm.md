## Declaration

public string GetSourceTerm();






### Returns



**string**
        A string containing the name of the source term.





### Description



Returns the name of the source term to be used in the apply/revert menu item.





The source term is shown in the apply and revert menu item texts to describe the target of the operation. For example, in the case of the revert menu item,
                the text would be defined as "Revert {SourceTerm} override".
