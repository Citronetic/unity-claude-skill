                    public [Vector3](Vector3.html) boxThickness;






### Description



Thickness of the box to emit particles from.





When using edge and shell modes, this controls how far from the perimeter that Unity can generate particles.
Additional resources: [ParticleSystem.ShapeModule.shapeType](ParticleSystem.ShapeModule-shapeType.html).
