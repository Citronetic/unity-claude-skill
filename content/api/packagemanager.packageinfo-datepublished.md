                    public Nullable<DateTime> datePublished;






### Description



The date and time at which the package was published.





This property only has a valid value for packages that have been downloaded from the cloud (i.e. those packages whose [PackageInfo.source](PackageManager.PackageInfo-source.html) is [PackageSource.Registry](PackageManager.PackageSource.Registry.html)). For packages from [other sources](PackageManager.PackageSource.html), the value is null.
