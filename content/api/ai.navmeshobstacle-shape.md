### Description



The shape of the obstacle.





Set or get the shape of the [NavMeshObstacle](AI.NavMeshObstacle.html).





A newly created [NavMeshObstacle](AI.NavMeshObstacle.html) has a shape of the [NavMeshObstacleShape.Box](AI.NavMeshObstacleShape.Box.html) shape.
          The obstacle shapes are listed in [NavMeshObstacleShape](AI.NavMeshObstacleShape.html).





**Note:** When the shape is changed the [center](AI.NavMeshObstacle-center.html) is set back to zero.
