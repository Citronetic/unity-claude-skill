                    public bool useStartPosition;






### Description



Whether the specified [Rigidbody2D.SlideMovement.startPosition](Rigidbody2D.SlideMovement-startPosition.html) should be used or not.





When false, the [Rigidbody2D.SlideMovement.startPosition](Rigidbody2D.SlideMovement-startPosition.html) will not be used but instead the current [Rigidbody2D.position](Rigidbody2D-position.html) will be used.

When true, the specified [Rigidbody2D.SlideMovement.startPosition](Rigidbody2D.SlideMovement-startPosition.html) will be used.

Additional resources: [Rigidbody2D.SlideMovement.startPosition](Rigidbody2D.SlideMovement-startPosition.html), [Rigidbody2D.Slide](Rigidbody2D.Slide.html) and [SlideResults](Rigidbody2D.SlideResults.html).
