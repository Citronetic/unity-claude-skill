### Description



Constants that specify the shading rate combiner stage.





The various sources of shading rate are resolved using multiple combiners. This enum represent which stage a specific combiner is applied.

Additional resources: [CommandBuffer.SetShadingRateCombiner](Rendering.CommandBuffer.SetShadingRateCombiner.html), [ShadingRateCombiner](Rendering.ShadingRateCombiner.html), [ShadingRateInfo.supportsPerImageTile](Rendering.ShadingRateInfo-supportsPerImageTile.html).
