                    public [Vector3](Vector3.html) deltaPosition;






### Description



Gets the difference between the pointer's position during the previous pointer event and its position during the
 current pointer event.





This value is based on [IPointerEvent.position](UIElements.IPointerEvent-position.html) and is expressed in panel world coordinates.
