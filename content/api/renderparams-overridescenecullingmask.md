                    public bool overrideSceneCullingMask;






### Description



Uses the [RenderParams.sceneCullingMask](RenderParams-sceneCullingMask.html) property to specify a custom [SceneCullingMasks](SceneManagement.SceneCullingMasks.html). This property is only available in the Editor, you can still access it in a Player but it'll be ignored.
