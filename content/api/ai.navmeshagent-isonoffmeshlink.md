                    public bool isOnOffMeshLink;






### Description



Is the agent currently positioned on an OffMeshLink? (Read Only)





This property is useful when [autoTraverseOffMeshLink](AI.NavMeshAgent-autoTraverseOffMeshLink.html) is false and custom movement is needed when crossing the link.

Additional resources: [autoTraverseOffMeshLink](AI.NavMeshAgent-autoTraverseOffMeshLink.html), [CompleteOffMeshLink](AI.NavMeshAgent.CompleteOffMeshLink.html).
