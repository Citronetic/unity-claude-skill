                    public bool useDynamicScaleExplicit;






### Description



When this flag is set to true, render texture is set to be used by the [Dynamic Resolution system](../Manual/DynamicResolution.html). Scale is applied with an explicit call to [ApplyDynamicScale](RenderTexture.ApplyDynamicScale.html)
