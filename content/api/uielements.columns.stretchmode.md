### Description



Indicates how the size of a stretchable column in this collection should get automatically adjusted as other columns or its containing view get resized.
 The default value is StretchMode.Grow.





### Properties



| Property | Description |
| --- | --- |
| Grow | The size of stretchable columns is automatically and proportionally adjusted only as its container gets resized.
 Unlike StretchMode.GrowAndFill, the size is not adjusted to fill any available space within its container when other columns are resized. |
| GrowAndFill | The size of stretchable columns is automatically adjusted to fill the available space within its container when this container or other columns get resized |
