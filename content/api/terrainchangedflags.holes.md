### Description



Indicates a change to the Terrain holes data.





This flag is set when there are changes to the Terrain holes data, for example, after calls to [TerrainData.SetHoles](TerrainData.SetHoles.html). Note that calls to [TerrainData.SetHolesDelayLOD](TerrainData.SetHolesDelayLOD.html) don't set this flag, even though those calls update the Terrain holes data. See [DelayedHolesUpdate](TerrainChangedFlags.DelayedHolesUpdate.html).
