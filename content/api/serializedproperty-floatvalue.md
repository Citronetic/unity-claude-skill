### Description



Value of a float property.





Contains a valid value when [propertyType](SerializedProperty-propertyType.html) is [SerializedPropertyType.Float](SerializedPropertyType.Float.html).
          For accessing float properties. If you are accessing double precision properties use [doubleValue](SerializedProperty-doubleValue.html) instead.


          Additional resources: [doubleValue](SerializedProperty-doubleValue.html), [propertyType](SerializedProperty-propertyType.html), [SerializedPropertyType.Float](SerializedPropertyType.Float.html), [SerializedPropertyNumericType.Float](SerializedPropertyNumericType.Float.html).
