## Declaration

public static void SetIconSize([Vector2](Vector2.html) size);






### Description



Set icons rendered as part of [GUIContent](GUIContent.html) to be rendered at a specific size.





Set the size to [Vector2.zero](Vector2-zero.html) to use the default behaviour where the size is determined by the available space.

Additional resources: [GetIconSize](EditorGUIUtility.GetIconSize.html).
