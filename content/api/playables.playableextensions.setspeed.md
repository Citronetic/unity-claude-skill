## Declaration

public static void SetSpeed(U playable,
double value);






### Parameters



| Parameter | Description |
| --- | --- |
| playable | The Playable used by this operation. |
| value | The new speed. |





### Description



Changes the speed multiplier that is applied to the the current [Playable](Playables.Playable.html).





This affects the speed at which the local time is incremented when the [Playable](Playables.Playable.html) is playing.





Use this templated extension method on any type that inherits from [IPlayable](Playables.IPlayable.html).
