                    public bool visible;






### Description



Indicates whether or not this element should be rendered.





The value of this property reflects the value of [IResolvedStyle.visibility](UIElements.IResolvedStyle-visibility.html) for this element.
 The value is true for [Visibility.Visible](UIElements.Visibility.Visible.html) and false for [Visibility.Hidden](UIElements.Visibility.Hidden.html).
 Writing to this property writes to [IStyle.visibility](UIElements.IStyle-visibility.html).

 Invisible elements are ignored by pointer events and by [IPanel.Pick](UIElements.IPanel.Pick.html).


Additional resources: [VisualElement.resolvedStyle](UIElements.VisualElement-resolvedStyle.html), [VisualElement.style](UIElements.VisualElement-style.html)
