                    public static float defaultMaxAngularSpeed;






### Description



Default maximum angular speed of the dynamic Rigidbody, in radians (default 50).





Controls the maximum angualr speed of the dynamic Rigidbody, measured in radians. The angular speed limit can also be modified with [Rigidbody.maxAngularVelocity](Rigidbody-maxAngularVelocity.html) on a per rigid body basis.
