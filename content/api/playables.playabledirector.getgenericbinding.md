## Declaration

public Object GetGenericBinding([Object](Object.html) key);






### Parameters



| Parameter | Description |
| --- | --- |
| key | The object that acts as a key. |





### Description



Returns a binding to a reference object.





In Timeline this is the track to bind an object  to. This typically corresponds to the [PlayableBinding.sourceObject](Playables.PlayableBinding-sourceObject.html) in the PlayableAsset.
