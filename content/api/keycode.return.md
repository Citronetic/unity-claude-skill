### Description



Return key.





The key used to accept a line of text. osMac calls this `Return`.  A PC calls this `Enter`.  There is no `KeyCode.Enter`. On a PC use [Return](KeyCode.Return.html). Some laptops have no name on the `Return` or `Enter` key.
