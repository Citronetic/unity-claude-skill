                    public [AnimationClip](AnimationClip.html) animationClip;






### Description



The animation clip selected in the Animation window.





Change this value to select another animation clip. To select an animation clip, it must either exist in the active state machine of the [Animator](Animator.html), or be listed in the [Animation](Animation.html) component.
