                    public bool generateLinks;






### Description



Enables the links generation for this object.





When build sources are obtained using [NavMeshBuilder.CollectSources](AI.NavMeshBuilder.CollectSources.html), this value can be affected by using [NavMeshBuildMarkup](AI.NavMeshBuildMarkup.html). If this value is `true` and links parameters are valid in [NavMeshBuildSettings](AI.NavMeshBuildSettings.html) this source will be considered during links generation.
