                    public bool autoIntegrate;






### Description



True if the scene should be automatically integrated after the load completes. If this is set to false, the user must call [ContentSceneFile.IntegrateAtEndOfFrame](Unity.Loading.ContentSceneFile.IntegrateAtEndOfFrame.html) when they are ready to integrate.
