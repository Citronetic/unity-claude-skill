                    public bool multiplyColliderForceByParticleSize;






### Description



Specifies whether the physics system considers particle sizes when it applies forces to Colliders.





If enabled, the force applied to a collider is proportional to the area (2D) or volume (3D) of the particle hitting the collider.
Additional resources: [ParticleSystem.CollisionModule.colliderForce](ParticleSystem.CollisionModule-colliderForce.html), [ParticleSystem.collision](ParticleSystem-collision.html).
