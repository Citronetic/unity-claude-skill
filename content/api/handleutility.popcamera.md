## Declaration

public static void PopCamera([Camera](Camera.html) camera);






### Description



Retrieve all camera settings.





A call to PopCamera will retrieve the most recently stored Camera settings added to a "stack" structure by [PushCamera](HandleUtility.PushCamera.html). This allows for easy saving and restoration of temporary camera changes.
