                    public string viewDataKey;






### Description



Used for view data persistence, such as tree expanded states, scroll position, or zoom level.





This key is used to save and load the view data from the view data store. If you don't set this key, the persistence is disabled for the associated [VisualElement](UIElements.VisualElement.html).
 For more information, refer to [View data persistence in the Unity Manual](../Manual/UIE-ViewData.html).
