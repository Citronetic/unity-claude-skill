### Description



Use this interface to have a class provide its own list of Animation Clips to the Animation Window.  The class must inherit from [MonoBehaviour](MonoBehaviour.html).





This interface requires an [Animator](Animator.html) or [Animation](Animation.html) component to preview Animation Clips in the Scene.  Additional resources: [AnimationUtility.GetAnimationClips](AnimationUtility.GetAnimationClips.html).





### Public Methods



| Method | Description |
| --- | --- |
| GetAnimationClips | Returns a list of Animation Clips. |
