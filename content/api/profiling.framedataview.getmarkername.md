## Declaration

public string GetMarkerName(int markerId);






### Parameters



| Parameter | Description |
| --- | --- |
| markerId | Marker identifier. |





### Returns



**string**
        Returns marker name. Returns *null* if identifier is unknown.





### Description



Gets Profiler marker name for the specific marker identifier.





The Profiler uses unique identifier for each marker created during profiling session. Marker can generate many samples which [HierarchyFrameDataView](Profiling.HierarchyFrameDataView.html) and [RawFrameDataView](Profiling.RawFrameDataView.html) provide access for.

All samples generated by the same marker have the same integer marker identifier and the same name.

Marker identifiers are persistent for the entire profiling session.

**Throws:**

*System.ArgumentException* if *markerId* is invalid.

Additional resources: [GetMarkerId](Profiling.FrameDataView.GetMarkerId.html).
