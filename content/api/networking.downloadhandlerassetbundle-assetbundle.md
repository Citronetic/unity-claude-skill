                    public [AssetBundle](AssetBundle.html) assetBundle;






### Description



Returns the downloaded [AssetBundle](AssetBundle.html), or `null`. (Read Only)





This property returns the asset bundle which has been downloaded (or is downloading, in the case of streamed asset bundles).

If there is an error decoding the asset bundle’s assets, the system will log the error and this property will return `null`.
