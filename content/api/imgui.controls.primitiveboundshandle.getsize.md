## Declaration

protected [Vector3](Vector3.html) GetSize();






### Returns



**Vector3**
        The current size of the bounding volume for this instance.





### Description



Gets the current size of the bounding volume for this instance.





All axes of the returned [Vector3](Vector3.html) will always have positive values. Any disabled axes will have a value of `0`.

Additional resources: [axes](IMGUI.Controls.PrimitiveBoundsHandle-axes.html).
