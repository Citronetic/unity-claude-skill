                    public bool useAdjacentEndPoint;






### Description



Set this to true to use the [adjacentEndPoint](EdgeCollider2D-adjacentEndPoint.html) to form the collision normal that is used to calculate the collision response when a collision occurs at the Edge Collider's end point. Set this to false to not use the [adjacentEndPoint](EdgeCollider2D-adjacentEndPoint.html), and the collision normal becomes the direction of motion of the collision.





Additional resources: [adjacentEndPoint](EdgeCollider2D-adjacentEndPoint.html).
