                    public static string scrollViewWithFooterUssClassName;






### Description



The USS class name for scroll view when add/remove footer is enabled.





Unity adds this USS class  scroll view of [BaseListView](UIElements.BaseListView.html)when showAddRemoveFooter is set to `true`.
 Any styling applied to this class affects every list located beside, or below the stylesheet in the visual tree.
