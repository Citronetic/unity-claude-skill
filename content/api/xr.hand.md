### Description



A tracked hand on the device at an [XRNode](XR.XRNode.html) in the XR input subsystem.





The Hand type represents a body element hierarchy corresponding to a human hand. It is comprised of [Bone](XR.Bone.html) type elements.





### Public Methods



| Method | Description |
| --- | --- |
| TryGetFingerBones | Gets a list of the finger bones for a finger on this hand. |
| TryGetRootBone | Gets the root bone for this hand. |
