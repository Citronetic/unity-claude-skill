### Description



The rotation associated with the generated mesh relative to the session origin.





This value will be [Quaternion.identity](Quaternion-identity.html) unless the [MeshGenerationOptions.ConsumeTransform](XR.MeshGenerationOptions.ConsumeTransform.html) flag was provided to [XRMeshSubsystem.GenerateMeshAsync](XR.XRMeshSubsystem.GenerateMeshAsync.html).
