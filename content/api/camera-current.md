                    public static [Camera](Camera.html) current;






### Description



The camera we are currently rendering with, for low-level render control only (Read Only).





Most of the time you will want to use [Camera.main](Camera-main.html) instead.
Use this function only when implementing one of the following events:
[MonoBehaviour.OnRenderImage](MonoBehaviour.OnRenderImage.html), [MonoBehaviour.OnPreRender](MonoBehaviour.OnPreRender.html), [MonoBehaviour.OnPostRender](MonoBehaviour.OnPostRender.html).
