### Description



The mesh generation was canceled.





This can happen if the [XRMeshSubsystem](XR.XRMeshSubsystem.html) is stopped or destroyed while meshes are being generated.
                    No data is written to the [Mesh](Mesh.html) or [[MeshCollider] provided during the call to [XRMeshSubsystem.GenerateMeshAsync](XR.XRMeshSubsystem.GenerateMeshAsync.html).

                    Additional resources: [XRMeshSubsystem.GenerateMeshAsync](XR.XRMeshSubsystem.GenerateMeshAsync.html), [MeshGenerationResult](XR.MeshGenerationResult.html)
