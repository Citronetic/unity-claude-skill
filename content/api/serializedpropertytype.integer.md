### Description



Represents an integer property, for example int, byte, short, uint and long.





The specific type of integer is exposed by [SerializedProperty.numericType](SerializedProperty-numericType.html).
                    Additional resources: [SerializedProperty](SerializedProperty.html), [SerializedProperty.intValue](SerializedProperty-intValue.html), [SerializedProperty.uintValue](SerializedProperty-uintValue.html), [SerializedProperty.longValue](SerializedProperty-longValue.html), [SerializedProperty.ulongValue](SerializedProperty-ulongValue.html),.
