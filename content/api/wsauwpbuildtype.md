### Description



Determines the output build type when building to Universal Windows Platform.





This setting can be changed in the build window when the target platform is set to Universal Windows Platform. You can also use [EditorUserBuildSettings.wsaUWPBuildType](EditorUserBuildSettings-wsaUWPBuildType.html) property to change this setting programmatically.
