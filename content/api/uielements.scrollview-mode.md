                    public [UIElements.ScrollViewMode](UIElements.ScrollViewMode.html) mode;






### Description



Controls how the ScrollView allows the user to scroll the contents.
 [ScrollViewMode](UIElements.ScrollViewMode.html)





The default is [ScrollViewMode.Vertical](UIElements.ScrollViewMode.Vertical.html).
 Writing to this property modifies the class list of the ScrollView according to the specified value of
 [ScrollViewMode](UIElements.ScrollViewMode.html). When the value changes, the class list matching the old value is removed and
 the class list matching the new value is added.
