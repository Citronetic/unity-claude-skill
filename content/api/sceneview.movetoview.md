## Declaration

public void MoveToView([Transform](Transform.html) target);






### Parameters



| Parameter | Description |
| --- | --- |
| target | A transform to place at the scene pivot. |





### Description



Transforms all selected object to the scene [pivot](SceneView-pivot.html).





If no argument is passed, each selected object is moved to the [pivot](SceneView-pivot.html) point, keeping their relative spacing.
