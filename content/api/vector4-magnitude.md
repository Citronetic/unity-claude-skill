                    public float magnitude;






### Description



Returns the length of this vector (Read Only).





The length of the vector is square root of `(x*x+y*y+z*z+w*w)`.

If you only need to compare magnitudes of some vectors, you can compare squared magnitudes of them
using [sqrMagnitude](Vector4-sqrMagnitude.html) (computing squared magnitudes is faster).

Additional resources: [sqrMagnitude](Vector4-sqrMagnitude.html).
