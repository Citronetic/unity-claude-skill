                    public static Nullable<Color> splashScreenBackgroundColor;






### Description



The **Override** background color for the Unity splash screen.





In the Editor, Unity displays this under **Splash Image** in [UWP Player Settings](../Manual/class-PlayerSettingsWSA.html) as the **Override background color** setting.
This value overrides the Unity Splash Screen background color with an alternative color, specifically for Windows Holographic.
