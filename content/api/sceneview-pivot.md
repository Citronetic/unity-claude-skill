### Description



The central point that the camera orbits within the Scene view.





Use with [size](SceneView-size.html), [rotation](SceneView-rotation.html), and [CameraSettings.fieldOfView](SceneView.CameraSettings-fieldOfView.html) to calculate camera transformation. To create a smooth animation, use the camera [LookAt](SceneView.LookAt.html).
