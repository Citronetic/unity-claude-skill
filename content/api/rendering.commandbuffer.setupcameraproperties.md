## Declaration

public void SetupCameraProperties([Camera](Camera.html) camera);






### Parameters



| Parameter | Description |
| --- | --- |
| camera | Camera to setup shader variables for. |





### Description



Schedules the setup of Camera specific global Shader variables.





This function sets up view, projection and clipping planes global shader variables. This command is essentially the same to [ScriptableRenderContext.SetupCameraProperties](Rendering.ScriptableRenderContext.SetupCameraProperties.html).
