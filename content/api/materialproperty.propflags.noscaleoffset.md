### Description



Do not show UV scale/offset fields next to a texture.





This is only relevant to texture shader properties. When this flag is set, the default material Inspector
will not display UV scale/offset controls for a texture. This corresponds to the "[NoScaleOffset]" attribute in front
of a property in the shader code.
