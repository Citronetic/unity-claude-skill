                    public double doubleValue;






### Description



Value of a float property as a double.





Contains a valid value when [propertyType](SerializedProperty-propertyType.html) is [SerializedPropertyType.Float](SerializedPropertyType.Float.html).
          For accessing float and double properties. When assigning a float to [doubleValue](SerializedProperty-doubleValue.html), the value is clamped to the range of a float.


          Additional resources: [floatValue](SerializedProperty-floatValue.html), [propertyType](SerializedProperty-propertyType.html), [SerializedPropertyType.Float](SerializedPropertyType.Float.html), [SerializedPropertyNumericType.Double](SerializedPropertyNumericType.Double.html).
