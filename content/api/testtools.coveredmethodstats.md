### Description



Describes the summary of the code coverage for the specified method used by [Coverage](TestTools.Coverage.html). For an example of typical usage, see [Coverage.GetStatsFor](TestTools.Coverage.GetStatsFor.html).





### Properties



| Property | Description |
| --- | --- |
| method | The covered method. |
| totalSequencePoints | The total number of sequence points in the method. |
| uncoveredSequencePoints | The total number of uncovered sequence points in the method. |
