                    public uint indexStart;






### Description



The first index from [indexBuffer](Rendering.RayTracingGeometryInstanceConfig-indexBuffer.html) that defines this ray tracing geometry instance.





This value must be a multiple of 3 and together with [indexCount](Rendering.RayTracingGeometryInstanceConfig-indexCount.html) it must define a valid range into [indexBuffer](Rendering.RayTracingGeometryInstanceConfig-indexBuffer.html).
