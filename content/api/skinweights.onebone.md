### Description



One bone affects each vertex. When used to access [Mesh.GetBoneWeightBuffer](Mesh.GetBoneWeightBuffer.html) the Bone Weight buffer will contain only indices to the bones, as the weight will be set to 1.





Additional resources: [QualitySettings.skinWeights](QualitySettings-skinWeights.html).
