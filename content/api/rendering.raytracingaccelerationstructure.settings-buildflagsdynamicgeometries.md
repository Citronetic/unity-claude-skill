### Description



The [flags](Rendering.RayTracingAccelerationStructureBuildFlags.html) Unity uses when it builds acceleration structures associated with dynamic geometries.





The flags can be customized per ray tracing instance from Renderer settings or when using [RayTracingAccelerationStructure.AddInstance](Rendering.RayTracingAccelerationStructure.AddInstance.html) methods.
