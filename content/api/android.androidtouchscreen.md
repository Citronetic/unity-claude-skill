### Description



Options to indicate whether the device supports touchscreen.





Additional resources: [AndroidConfiguration.touchScreen](Android.AndroidConfiguration-touchScreen.html)





### Properties



| Property | Description |
| --- | --- |
| Undefined | Mirrors the Android property value TOUCHSCREEN_UNDEFINED. |
| NoTouch | Mirrors the Android property value TOUCHSCREEN_NOTOUCH. |
| Finger | Mirrors the Android property value TOUCHSCREEN_FINGER. |
