                    public [ParticleSystem.MinMaxCurve](ParticleSystem.MinMaxCurve.html) meshSpawnSpeed;






### Description



In animated modes, this determines how quickly the particle emission position moves across the Mesh.





The value is specified in terms of the number of complete passes over the Mesh. A value of 2 would mean that the particle emission position traversed the Mesh twice per second.
Additional resources: [ParticleSystem.ShapeModule.meshSpawnMode](ParticleSystem.ShapeModule-meshSpawnMode.html), [ParticleSystemShapeMultiModeValue](ParticleSystemShapeMultiModeValue.html), [ParticleSystem.ShapeModule.shapeType](ParticleSystem.ShapeModule-shapeType.html).
