### Description



Color space for player settings.





This enum is used to indicate color space used in project ([PlayerSettings.colorSpace](PlayerSettings-colorSpace.html)) and sprite atlases ([AtlasSettings.colorSpace](Sprites.AtlasSettings-colorSpace.html)).

Additional resources: [Linear and Gamma rendering](../Manual/LinearLighting.html), [RenderTextureReadWrite](RenderTextureReadWrite.html).





### Properties



| Property | Description |
| --- | --- |
| Uninitialized | Uninitialized color space. |
| Gamma | Gamma color space. |
| Linear | Linear color space. |
