### Description



When set, this will sync the start time of this Tile Animation with other Tile Animations that are the same.





This will not affect Tile Animations that are changed using [Tilemap.SetAnimationTime](Tilemaps.Tilemap.SetAnimationTime.html) or [Tilemap.SetAnimationFrame](Tilemaps.Tilemap.SetAnimationFrame.html).
