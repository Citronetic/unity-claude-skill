## Declaration

public IEnumerable<IPropertyDatabaseRecord> EnumerateAll();






### Returns



**IEnumerable<IPropertyDatabaseRecord>**
        An enumeration of all the records.





### Description



Enumerates all records stored in the [PropertyDatabase](Search.PropertyDatabase.html)





This function returns a sorted set of all the records store in the property database, volatile or not, sorted by their keys.
