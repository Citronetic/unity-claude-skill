                    public bool useOutsideDepth;






### Description



Sets the contact filter to filter within the [minDepth](ContactFilter2D-minDepth.html) and [maxDepth](ContactFilter2D-maxDepth.html) range, or outside that range.





[useOutsideDepth](ContactFilter2D-useOutsideDepth.html) uses the range between [minDepth](ContactFilter2D-minDepth.html) and [maxDepth](ContactFilter2D-maxDepth.html) to filter depth.
Set `useOutsideDepth` to true to only return object depth outside that range.
Set `useOutsideDepth` to false to only return object depth within that range. It is false by default.

Additional resources: [minDepth](ContactFilter2D-minDepth.html), [maxDepth](ContactFilter2D-maxDepth.html) & [useDepth](ContactFilter2D-useDepth.html).
