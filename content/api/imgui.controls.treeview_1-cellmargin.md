                    protected float cellMargin;






### Description



When using a MultiColumnHeader this value adjusts the cell rects provided for all columns except the tree foldout column.





This value is used for all cell margins except the column with the tree view foldouts since that column uses [baseIndent](IMGUI.Controls.TreeView_1-baseIndent.html) and assumes full width for rename overlay placement.
