                    public float angle;






### Description



The world angle (in degrees) along which the suspension will move.





This provides 2D constrained motion similar to a SliderJoint2D.  This is typically how suspension works in the real world.
        Additional resources: [Rigidbody2D](Rigidbody2D.html).
