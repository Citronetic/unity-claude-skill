                    public int volumeDepth;






### Description



Volume extent of a 3D render texture or number of slices of array texture.





For volumetric render textures (see [dimension](RenderTexture-dimension.html)), this variable determines the volume extent.

For array render texture (see [dimension](RenderTexture-dimension.html)), this variable determines the number of slices.

Additional resources: [dimension](RenderTexture-dimension.html).
