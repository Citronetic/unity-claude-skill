### Parameters



| Parameter | Description |
| --- | --- |
| duration | The total time in seconds that the logo will be shown. Note minimum time is 2 seconds. |
| logo | The logo Sprite to display. |





### Returns



**SplashScreenLogo**
        The new logo.
