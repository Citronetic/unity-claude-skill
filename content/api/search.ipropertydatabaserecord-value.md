                    public [Search.IPropertyDatabaseRecordValue](Search.IPropertyDatabaseRecordValue.html) value;






### Description



The value of the record.





If the data is serializable (see [PropertyDatabase.IsPersistedType](Search.PropertyDatabase.IsPersistedType.html)), the record value contains the serialized data and the record can be stored on disk, otherwise it contains the C# object and the record is kept in memory.
