## Declaration

public void OnPlayableDestroy([Playables.Playable](Playables.Playable.html) playable);






### Parameters



| Parameter | Description |
| --- | --- |
| playable | The Playable that owns the current PlayableBehaviour. |





### Description



This function is called when the [Playable](Playables.Playable.html) that owns the PlayableBehaviour is destroyed.





The playable can be destroyed with [PlayableExtensions.Destroy](Playables.PlayableExtensions.Destroy.html).
