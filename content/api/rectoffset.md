### Description



Offsets for rectangles, borders, etc.





Used all over the place by [GUIStyle](GUIStyle.html).





### Properties



| Property | Description |
| --- | --- |
| bottom | Bottom edge size. |
| horizontal | Shortcut for left + right. (Read Only) |
| left | Left edge size. |
| right | Right edge size. |
| top | Top edge size. |
| vertical | Shortcut for top + bottom. (Read Only) |





### Constructors



| Constructor | Description |
| --- | --- |
| RectOffset | Creates a new rectangle with offsets. |





### Public Methods



| Method | Description |
| --- | --- |
| Add | Add the border offsets to a rect. |
| Remove | Remove the border offsets from a rect. |
| ToString | Returns a formatted string for this RectOffset. |
