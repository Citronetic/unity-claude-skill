                    public static float fixedUnscaledTime;






### Description



The timeScale-independent time at the beginning of the last [MonoBehaviour.FixedUpdate](MonoBehaviour.FixedUpdate.html) phase (Read Only). This is the time in seconds since the start of the game.





This value is updated in fixed increments equal to [Time.fixedUnscaledDeltaTime](Time-fixedUnscaledDeltaTime.html).

                Unlike [Time.fixedTime](Time-fixedTime.html) this value is not affected by [Time.timeScale](Time-timeScale.html).
