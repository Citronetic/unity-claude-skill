### Description



Indicates that the device has downloaded the Android asset pack and the asset pack is available to the application.





You can call AndroidAssetPacks.GetAssetPackPath to get the full path to this asset pack.
Additional resources: [AndroidAssetPacks.GetAssetPackPath](Android.AndroidAssetPacks.GetAssetPackPath.html), [AndroidAssetPacks.DownloadAssetPackAsync](Android.AndroidAssetPacks.DownloadAssetPackAsync.html), [AndroidAssetPacks.GetAssetPackStateAsync](Android.AndroidAssetPacks.GetAssetPackStateAsync.html).
