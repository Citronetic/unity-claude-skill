### Description



Mouse was moved (Editor views only).





The mouse was moved without any buttons being held down. Use [Event.mousePosition](Event-mousePosition.html) and [Event.delta](Event-delta.html) to determine mouse motion.

Note that this event is only sent in the Editor for [EditorWindow](EditorWindow.html) windows which have [EditorWindow.wantsMouseMove](EditorWindow-wantsMouseMove.html)
set to true. Mouse move events are never sent in the games.
