## Declaration

public void ClearRandomWriteTargets();






### Description



Unset random write targets for [Shader Model 4.5](../Manual/SL-ShaderCompileTargets.html) level pixel shaders.





This function unsets any "random write" targets that were previously set with [SetRandomWriteTarget](Rendering.CommandBuffer.SetRandomWriteTarget.html).
