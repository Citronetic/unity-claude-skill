                    public bool componentsNotMatchedBecomesOverride;






### Description



If a Component is not matched up then it can become an added Component on the new Prefab instance. This property is only used when used together with [ObjectMatchMode.ByHierarchy](ObjectMatchMode.ByHierarchy.html).





If this property is false then the Component will be deleted if it doesn't match a Component on the PrefabAsset.
Additional resources: [gameObjectsNotMatchedBecomesOverride](ConvertToPrefabInstanceSettings-gameObjectsNotMatchedBecomesOverride.html), [recordPropertyOverridesOfMatches](ConvertToPrefabInstanceSettings-recordPropertyOverridesOfMatches.html).
