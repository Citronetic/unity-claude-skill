### Parameters



| Parameter | Description |
| --- | --- |

### Returns

### Description



Returns the System.Type of the [ObjectIdentifier](Build.Content.ObjectIdentifier.html) and the referenced [SerializeReference](SerializeReference.html) class types specified by `objectID`.





Internal use only. See note on [ContentBuildInterface](Build.Content.ContentBuildInterface.html).
