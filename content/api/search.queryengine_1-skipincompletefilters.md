                    public bool skipIncompleteFilters;






### Description



Boolean. Indicates if incomplete filters should be skipped.
If true, filters are skipped. If false and [validateFilters](Search.QueryEngine_1-validateFilters.html) is true, incomplete filters will generate errors when parsed.





See [QueryValidationOptions.skipIncompleteFilters](Search.QueryValidationOptions-skipIncompleteFilters.html) for a complete example.
