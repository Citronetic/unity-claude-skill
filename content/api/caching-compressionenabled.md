                    public static bool compressionEnabled;






### Description



Controls compression of cache data. Enabled by default.





If cache compression is enabled, then all data will be stored in a compressed form using fast LZ4 algorithm.
This property affects only further downloads. It doesn't compress or decompress existing content in the cache.

Default value is "true".

Additional resources: [UnityWebRequestAssetBundle.GetAssetBundle](Networking.UnityWebRequestAssetBundle.GetAssetBundle.html).
