### Description



GraphicsBuffer can be used as a vertex buffer.





DirectX 11 does not allow `Vertex` buffers to also be [Structured](GraphicsBuffer.Target.Structured.html). For compute shader mesh data access with DirectX 11 compatibility, it is best to use [Raw](GraphicsBuffer.Target.Raw.html).

Additional resources: [Mesh.vertexBufferTarget](Mesh-vertexBufferTarget.html), [Mesh.GetVertexBuffer](Mesh.GetVertexBuffer.html).
