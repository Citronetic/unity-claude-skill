### Description



The [CapFunction](Handles.CapFunction.html) to use when displaying the angle control handle.





Defaults to [DefaultAngleHandleDrawFunction](IMGUI.Controls.ArcHandle.DefaultAngleHandleDrawFunction.html) for new instances of [ArcHandle](IMGUI.Controls.ArcHandle.html). No angle handle will be drawn if a value of `null` is assigned.

Additional resources: [angleHandleSizeFunction](IMGUI.Controls.ArcHandle-angleHandleSizeFunction.html).
