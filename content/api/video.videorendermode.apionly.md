### Description



Don't draw the video content anywhere, but still make it available via the VideoPlayer's texture property in the API.





You can use this render mode to play the video into a Canvas' RawImage. You can assign the [VideoPlayer.texture](Video.VideoPlayer-texture.html) directly to [RawImage texture](https://docs.unity3d.com/Packages/com.unity.ugui@3.0/manual/script-RawImage.html). This lets you use video in your UI elements or any place where the API allows a texture to be assigned.
