                    public int heightmapResolution;






### Description



The size of the [heightmap](../Manual/terrain-Heightmaps.html) in texels for both the width and height. When setting the heightmap resolution, Unity clamps the value to one of 33, 65, 129, 257, 513, 1025, 2049, or 4097.
