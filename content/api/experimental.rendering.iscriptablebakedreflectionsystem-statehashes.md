### Description



The hashes of the current baked state of the ScriptableBakedReflectionSystem.





This hash is used to check whether the baked data has changed and make sure they aren't deleted from the GI Cache. See [IScriptableBakedReflectionSystem](Experimental.Rendering.IScriptableBakedReflectionSystem.html).
