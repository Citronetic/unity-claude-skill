## Declaration

public void ResetStereoProjectionMatrices();






### Description



Reset the camera to using the Unity computed projection matrices for all stereoscopic eyes.





If you set custom projection matrices with [Camera.SetStereoProjectionMatrix](Camera.SetStereoProjectionMatrix.html), this method reverts the camera back to using projection matrices provided by the [XRDisplaySubsystem](XR.XRDisplaySubsystem.html).
