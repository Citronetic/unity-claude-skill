### Description



An enum that represents [graphics tiers](../Manual/graphics-tiers.html).





**Note:** Graphics tiers are only supported in the Built-in Render Pipeline.

Additional resources: [Graphics tiers](../Manual/graphics-tiers.html), [TierSettings](Rendering.TierSettings.html), [Graphics.activeTier](Graphics-activeTier.html), [EditorGraphicsSettings.GetTierSettings](Rendering.EditorGraphicsSettings.GetTierSettings.html), [EditorGraphicsSettings.SetTierSettings](Rendering.EditorGraphicsSettings.SetTierSettings.html).





### Properties



| Property | Description |
| --- | --- |
| Tier1 | The lowest graphics tier. Corresponds to low-end devices. |
| Tier2 | The medium graphics tier. Corresponds to mid-range devices. |
| Tier3 | The highest graphics tier. Corresponds to high-end devices. |
