### Description



Defines the size of the background.





### Properties



| Property | Description |
| --- | --- |
| Length | Determines if the size of the background image comes from the
 BackgroundSize.x and BackgroundSize.y length values. |
| Cover | Resize the background image to cover the entire container,
 even if it has to stretch the image or cut a little bit off one of the edges. |
| Contain | Resize the background image to make sure the image is fully visible. |
