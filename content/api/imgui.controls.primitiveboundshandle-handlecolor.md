                    public [Color](Color.html) handleColor;






### Description



Returns or specifies the color of the control handles.





This value is multiplied with the value of [Handles.color](Handles-color.html) at the time [DrawHandle](IMGUI.Controls.PrimitiveBoundsHandle.DrawHandle.html) is called. If [Color.a](Color-a.html) is `0` then the control handles are disabled.

Additional resources: [midpointHandleDrawFunction](IMGUI.Controls.PrimitiveBoundsHandle-midpointHandleDrawFunction.html), [SetColor](IMGUI.Controls.PrimitiveBoundsHandle.SetColor.html).
