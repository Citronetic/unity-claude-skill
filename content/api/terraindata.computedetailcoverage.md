## Declaration

public float ComputeDetailCoverage(int detailPrototypeIndex);






### Description



This function computes and returns the coverage (how many instances fit in a square unit) of a detail prototype, given its index.





Computes detail coverage. In  [DetailScatterMode.CoverageMode](DetailScatterMode.CoverageMode.html), this coverage represents the number of scattered instances per unit squared, based on the detail prototype's size and density settings. Unavailable in [DetailScatterMode.InstanceCountMode](DetailScatterMode.InstanceCountMode.html).
