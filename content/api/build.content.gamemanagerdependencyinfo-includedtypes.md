                    public ReadOnlyCollection<Type> includedTypes;






### Description



The project-wide identifiers for the game manager classes referenced in this collection of dependency information.





Note: the elements of the [managerObjects](Build.Content.GameManagerDependencyInfo-managerObjects.html) and [includedTypes](Build.Content.GameManagerDependencyInfo-includedTypes.html) lists correspond to each other. An element at a given index in one list corresponds to the same manager class as the element at the same index in the other.
