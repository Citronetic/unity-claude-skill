## Declaration

public static void SetiPhoneLaunchScreenType([iOSLaunchScreenType](iOSLaunchScreenType.html) type);






### Description



Sets the mode which will be used to generate the app's launch screen Interface Builder (.xib) file for iPhone.





The launch screen image defaults to an default colored image or it can be specified using the [PlayerSettings.iOS.SetLaunchScreenImage](PlayerSettings.iOS.SetLaunchScreenImage.html) function.
