                    public TreeInstance[] treeInstances;






### Description



Contains the current trees placed in the terrain.





Note that setting the treeInstances property will not automatically snap Tree instances onto the surface of the Terrain heightmap. To do so, use [SetTreeInstances](TerrainData.SetTreeInstances.html) instead.
