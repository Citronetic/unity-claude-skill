### Description



The configuration of the spring attached to the joint's limits: linear and angular. Used by [CharacterJoint](CharacterJoint.html) and [ConfigurableJoint](ConfigurableJoint.html).





### Properties



| Property | Description |
| --- | --- |
| damper | The damping of the spring limit. In effect when the stiffness of the sprint limit is not zero. |
| spring | The stiffness of the spring limit. When stiffness is zero the limit is hard, otherwise soft. |
