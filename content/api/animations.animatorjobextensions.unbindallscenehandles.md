## Declaration

public static void UnbindAllSceneHandles([Animator](Animator.html) animator);






### Parameters



| Parameter | Description |
| --- | --- |
| animator | The Animator instance that calls this method. |





### Description



Removes all PropertySceneHandles and TransformSceneHandles associated with the [Animator](Animator.html) instance. Use this method to manage the lifecycle of scene handles when the animated hierarchy changes.
