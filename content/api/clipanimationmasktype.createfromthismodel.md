### Description



A mask containing all the transform in the file will be created internally.





For Humanoid rig, unity will convert all the transforms animation into muscle animation, these transforms cannot be edited in the mask.
Additional resources: [ModelImporterClipAnimation.maskType](ModelImporterClipAnimation-maskType.html).
