## Declaration

public ShaderTagId(string name);






### Parameters



| Parameter | Description |
| --- | --- |
| name | The string this ShaderTagId should represent. |





### Description



Gets or creates a `ShaderTagId` representing the given string.





If `name` is an empty string, the resultant `ShaderTagId` is equal to [ShaderTagId.none](Rendering.ShaderTagId-none.html).

Additional resources: [DrawingSettings](Rendering.DrawingSettings.html), [RendererListParams](Rendering.RendererListParams.html).
