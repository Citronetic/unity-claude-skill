                    public float carvingMoveThreshold;






### Description



Threshold distance for updating a moving carved hole (when carving is enabled).





If the [NavMeshObstacle](AI.NavMeshObstacle.html) has moved a distance shorter than the threshold since last carving then the navmesh will not be updated.

Additional resources: [carving](AI.NavMeshObstacle-carving.html).
