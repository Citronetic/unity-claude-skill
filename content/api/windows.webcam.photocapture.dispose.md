## Declaration

public void Dispose();






### Description



Dispose must be called to shutdown the PhotoCapture instance.





If your PhotoCapture instance successfully called [PhotoCapture.StartPhotoModeAsync](Windows.WebCam.PhotoCapture.StartPhotoModeAsync.html), you must make sure that you call [PhotoCapture.StopPhotoModeAsync](Windows.WebCam.PhotoCapture.StopPhotoModeAsync.html) before disposing your PhotoCapture instance.
