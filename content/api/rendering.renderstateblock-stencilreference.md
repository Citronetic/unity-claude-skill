                    public int stencilReference;






### Description



The value to be compared against and/or the value to be written to the buffer, based on the stencil state.





Unity applies these values to the GPU's render state if [RenderStateBlock.mask](Rendering.RenderStateBlock-mask.html) includes a value of [RenderStateMask.Stencil](Rendering.RenderStateMask.Stencil.html).

The default value is 0.
