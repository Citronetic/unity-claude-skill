### Description



Synchronizes only height data of the heightmap texture from the GPU back to CPU memory.





This option forces the tessellation level to maximum on the modified heightmap region. Use [TerrainData.SyncHeightmap](TerrainData.SyncHeightmap.html) afterward to rectify the tessellation.
