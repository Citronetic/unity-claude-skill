## Declaration

public static void SetLightingSettingsForScenes(Scene[] scenes,
[LightingSettings](LightingSettings.html) lightingSettings);






### Parameters



| Parameter | Description |
| --- | --- |
| scenes | The array of Scene objects. If the Scene.isLoaded property is false on a Scene object, the method does not apply the settings to that object. |
| lightingSettings | The LightingSettings object. |





### Description



Applies the settings specified in the [LightingSettings](LightingSettings.html) object to an array of [Scene](SceneManagement.Scene.html) objects.





Additional resources: [Lightmapping.SetLightingSettingsForScene](Lightmapping.SetLightingSettingsForScene.html), [Lightmapping.GetLightingSettingsForScene](Lightmapping.GetLightingSettingsForScene.html).
