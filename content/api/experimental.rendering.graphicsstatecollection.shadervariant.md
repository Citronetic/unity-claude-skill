### Description



Identifies a specific variant of a shader stored in a [GraphicsStateCollection](Experimental.Rendering.GraphicsStateCollection.html).





### Properties



| Property | Description |
| --- | --- |
| keywords | Array of shader keywords to use in this variant. |
| passId | PassIdentifier to use in this variant. |
| shader | Shader to use in this variant. |
