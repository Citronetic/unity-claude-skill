### Description



Use this attribute to have the source generator generate a property bag for a given type.
 This attribute works for the specified type ONLY, it does NOT include derived types.





If you need to generate property bags for types implementing a specific interface use [GeneratePropertyBagsForTypesQualifiedWithAttribute](Unity.Properties.GeneratePropertyBagsForTypesQualifiedWithAttribute.html).





### Properties



| Property | Description |
| --- | --- |
| Type | The type to generate a property bag for. |
