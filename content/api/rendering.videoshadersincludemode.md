### Description



Video shaders mode used by [GraphicsSettings](Rendering.GraphicsSettings.html).





Additional resources: [GraphicsSettings.videoShadersIncludeMode](Rendering.GraphicsSettings-videoShadersIncludeMode.html).





### Properties



| Property | Description |
| --- | --- |
| Never | Exclude video shaders from builds. This effectively disables video functionality. |
| Referenced | Include video shaders in builds when referenced by scenes. |
| Always | Include video shaders in builds (default). |
