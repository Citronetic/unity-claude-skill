### Description



Compressed color texture format with Crunch compression for smaller storage sizes.





The ETC_RGB4Crunched format is similar to the [ETC_RGB4](TextureFormat.ETC_RGB4.html) format but with additional JPEG-like lossy compression for storage size reduction. Textures are transcoded into the ETC_RGB4 format at load time.

Additional resources: [Texture2D.format](Texture2D-format.html), [texture assets](../Manual/Textures.html).
