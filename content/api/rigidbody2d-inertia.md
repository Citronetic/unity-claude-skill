                    public float inertia;






### Description



The Rigidbody's resistance to changes in angular velocity (rotation).





Rotational inertia controls a Rigidbody's resistance to changes in [angularVelocity](Rigidbody2D-angularVelocity.html). It is similar to how [mass](Rigidbody2D-mass.html) controls a Rigidbody's resistance to changes in [linearVelocity](Rigidbody2D-linearVelocity.html).

The rotational inertia is automatically calculated based on the Rigidbody's [mass](Rigidbody2D-mass.html) position relative to the [centerOfMass](Rigidbody2D-centerOfMass.html).  It can also be specified explicitly by setting this property in the same way [mass](Rigidbody2D-mass.html) can be set.
