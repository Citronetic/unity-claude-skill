## Declaration

float brushSize);






### Parameters



| Parameter | Description |
| --- | --- |
| terrain | Terrain object. |
| brushTexture | Brush texture. |
| brushSize | Brush size. |





### Description



Helper function to display a default preview brush with no rotation or custom materials.





This method determines the position on the Terrain object under the mouse and draws a brush preview at that position using the specified texture and brush size.
                  Additional resources: [TerrainPaintUtilityEditor.DrawBrushPreview](TerrainTools.TerrainPaintUtilityEditor.DrawBrushPreview.html)
