                    public bool canSetSkipOnDrop;






### Description



Whether frame-skipping to maintain synchronization can be controlled. (Read Only)





When `true`, the value of [VideoPlayer.skipOnDrop](Video.VideoPlayer-skipOnDrop.html) can be changed. When `false`, the value cannot be changed. This value is only valid after the movie has been prepared. See [VideoPlayer.Prepare](Video.VideoPlayer.Prepare.html).
