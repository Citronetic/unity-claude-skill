                    public bool allowAlphaTestedMaterials;






### Description



Whether to allow Renderers that use alpha tested Materials.





Use [RayTracingInstanceCullingConfig.alphaTestedMaterialConfig](Rendering.RayTracingInstanceCullingConfig-alphaTestedMaterialConfig.html) to define when a Material is considered alpha tested.

If this value is false and the Mesh used by a Renderer uses alpha tested Materials then the test fails.

Additional resources: [RayTracingAccelerationStructure.CullInstances](Rendering.RayTracingAccelerationStructure.CullInstances.html).
