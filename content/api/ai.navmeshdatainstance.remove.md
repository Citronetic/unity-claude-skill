## Declaration

public void Remove();






### Description



Removes this instance from the NavMesh system.





An identical but convenient alternative to calling [NavMesh.RemoveNavMeshData](AI.NavMesh.RemoveNavMeshData.html). If the instance is not valid, e.g. has been removed before, the call has no effect.
