                    public bool rotateWithStretchDirection;






### Description



Rotate the particles based on the direction they are stretched in. This is added on top of other particle rotation.





This property only has effect when [freeformStretching](ParticleSystemRenderer-freeformStretching.html) is enabled. When [freeformStretching](ParticleSystemRenderer-freeformStretching.html) is disabled, particles are always rotated based on the direction they are stretched in, even if [rotateWithStretchDirection](ParticleSystemRenderer-rotateWithStretchDirection.html) is false.
