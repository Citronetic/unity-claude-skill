### Description



A [PropertyPathPartKind](Unity.Properties.PropertyPathPartKind.html) specifies a type for a [PropertyPathPart](Unity.Properties.PropertyPathPart.html).





### Properties



| Property | Description |
| --- | --- |
| Name | Represents a named part of the path. |
| Index | Represents an indexed part of the path. |
| Key | Represents a keyed part of the path. |
