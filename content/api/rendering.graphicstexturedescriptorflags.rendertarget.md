### Description



Allows this [GraphicsTexture](Rendering.GraphicsTexture.html) to be set as a render target and be rendered to.





Similar to [RenderTexture](RenderTexture.html), a graphics texture with the RenderTarget flag can be used to implement image based rendering effects, dynamic shadows, projectors, reflections or surveillance cameras.

A [RenderTexture's current graphicsTexture](Texture-graphicsTexture.html) will always have this flag set.

Additional resources: [Graphics.SetRenderTarget](Graphics.SetRenderTarget.html), [GraphicsTexture.active](Rendering.GraphicsTexture-active.html).
