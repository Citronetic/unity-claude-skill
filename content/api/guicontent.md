### Description



The contents of a GUI element.





This works closely in relation with [GUIStyle](GUIStyle.html). GUIContent defines `what` to render and [GUIStyle](GUIStyle.html) defines `how` to render it.

Additional resources: [GUIStyle](GUIStyle.html).





### Static Properties



| Property | Description |
| --- | --- |
| none | Shorthand for empty content. |





### Properties



| Property | Description |
| --- | --- |
| image | The icon image contained. |
| text | The text contained. |
| tooltip | The tooltip of this element. |
