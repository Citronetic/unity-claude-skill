                    public float animationScaleError;






### Description



Allowed error of animation scale compression.





Allowed error is defined in distance (in percents) between compressed and
original scale on a curve. This settings used only when animation keyframe
reduction is enabled.

Additional resources: [animationCompression](ModelImporter-animationCompression.html), [ModelImporterAnimationCompression](ModelImporterAnimationCompression.html).
