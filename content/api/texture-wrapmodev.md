### Description



Options for sampling a texture if the V texture coordinate is outside the [0, 1] range.





The V texture coordinate represents the vertical axis.

Additional resources: [TextureWrapMode](TextureWrapMode.html), [wrapMode](Texture-wrapMode.html), [Texture assets](../Manual/class-TextureImporter.html).
