                    public static int columnSelfPercent;






### Description



The percentage of the CPU time Unity spends in a sample itself, excluding the time from child samples.





The percentage is calculated from the [columnSelfTime](Profiling.HierarchyFrameDataView-columnSelfTime.html) value of the sample divided by the CPU frame time.
