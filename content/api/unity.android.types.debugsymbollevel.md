### Description



The type of debug metadata which will be packaged.





Additional resources: [UserBuildSettings.DebugSymbols.level](Android.UserBuildSettings.DebugSymbols-level.html)

Additional resources: [debugSymbolLevel](https://developer.android.com/reference/tools/gradle-api/7.3/com/android/build/api/dsl/Ndk#debugSymbolLevel())





### Properties



| Property | Description |
| --- | --- |
| None | No native debug metadata will be packaged. |
| SymbolTable | Only the symbol tables will be packaged. |
| Full | The debug info and symbol tables will be packaged. |
