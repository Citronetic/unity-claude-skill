                    public [Vector3](Vector3.html) chunkCullingBounds;






### Description



Bounds used for culling of [Tilemap](Tilemaps.Tilemap.html) chunks.





These bounds extend the boundary of Tilemap chunks and are used for culling. This helps to ensure that oversized Sprites will not be clipped during culling for the [TilemapRenderer](Tilemaps.TilemapRenderer.html).
