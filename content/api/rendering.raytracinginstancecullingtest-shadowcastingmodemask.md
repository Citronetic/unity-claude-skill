                    public int shadowCastingModeMask;






### Description



A value that indicates which [ShadowCastingMode](Rendering.ShadowCastingMode.html) values are acccepted by this testing configuration.





If a Renderer's [ShadowCastingMode](Rendering.ShadowCastingMode.html) is not matching this mask then the test fails.

If all [ShadowCastingMode](Rendering.ShadowCastingMode.html) values are accepted then use -1 for this value.
