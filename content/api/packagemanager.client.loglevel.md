### Description



Gets or sets the log level that the Package Manager uses when logging to the `Editor.log` and `upm.log` files. Defaults to [LogLevel.Info](PackageManager.LogLevel.Info.html).





For a description of the different log levels, see the documentation for the [LogLevel](PackageManager.LogLevel.html) enum.
