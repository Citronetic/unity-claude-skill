### Description



Type name of the property. (Read Only)





Returns C# type name of the property for all [SerializedPropertyType](SerializedPropertyType.html) values, except for [SerializedPropertyType.ObjectReference](SerializedPropertyType.ObjectReference.html), [SerializedPropertyType.ManagedReference](SerializedPropertyType.ManagedReference.html)  and other internal values of SerializedPropertyType, where the internal serialization type name is returned.
