### Description



Indicates a change to the heightmap data.





This flag is set when heightmap data has been changed, for instance after [TerrainData.SetHeights](TerrainData.SetHeights.html) calls. Note that [TerrainData.SetHeightsDelayLOD](TerrainData.SetHeightsDelayLOD.html) doesn't set this flag, even though the heightmap data is updated. See [DelayedHeightmapUpdate](TerrainChangedFlags.DelayedHeightmapUpdate.html).
