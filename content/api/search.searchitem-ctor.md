## Declaration

public SearchItem(string _id);






### Parameters



| Parameter | Description |
| --- | --- |
| _id | Unique ID of the SearchItem. |





### Description



Construct a search item. A search item needs to have at least a unique ID for a given search query.





SearchItem are generally created using the [SearchProvider.CreateItem](Search.SearchProvider.CreateItem.html) function.
See [SearchItem](Search.SearchItem.html) for example of items creation.
