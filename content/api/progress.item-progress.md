                    public float progress;






### Description



Returns the progress value of a progress indicator's associated task.





While the associated event is in progress, this value is usually between 0 and 1. If it is -1, progress is indefinite.
If it is -2, progress has not been reported yet.

Additional resources: [Progress.Item.Report](Progress.Item.Report.html).
