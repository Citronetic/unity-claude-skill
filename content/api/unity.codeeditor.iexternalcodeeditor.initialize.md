### Parameters



| Parameter | Description |

### Description



Callback to the [IExternalCodeEditor](Unity.CodeEditor.IExternalCodeEditor.html) when it has been chosen from the PreferenceWindow.





To check the current selected code editor when registering this instance, use [CodeEditor.CurrentEditorInstallation](Unity.CodeEditor.CodeEditor.CurrentEditorInstallation.html).
