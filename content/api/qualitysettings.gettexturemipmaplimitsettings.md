## Declaration

public static [TextureMipmapLimitSettings](TextureMipmapLimitSettings.html) GetTextureMipmapLimitSettings(string groupName);






### Parameters



| Parameter | Description |
| --- | --- |
| groupName | Name of the texture mipmap limit group to scan. |





### Returns



**TextureMipmapLimitSettings**
        Structure containing the settings for the indicated `groupName`.





### Description



Retrieves a copy of the TextureMipmapLimitSettings from a texture mipmap limit group.





Throws an exception if Unity cannot find `groupName`.

Additional resources: [TextureMipmapLimitSettings](TextureMipmapLimitSettings.html), [SetTextureMipmapLimitSettings](QualitySettings.SetTextureMipmapLimitSettings.html).
