### Description



Currently active render target.





During command buffer execution, this identifies the render target that is active "right now". During command buffer execution, the active render target might be changed by [CommandBuffer.SetRenderTarget](Rendering.CommandBuffer.SetRenderTarget.html) or
[CommandBuffer.Blit](Rendering.CommandBuffer.Blit.html) commands.

Additional resources: [CommandBuffer](Rendering.CommandBuffer.html).
