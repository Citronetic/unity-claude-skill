                    public float speedMultiplier;






### Description



The speed multiplier for this state.





A negative speed multiplier will play the animation backwards.
If no speed parameter as been set for this [AnimatorState](Animations.AnimatorState.html), the default value will be 1.

see [AnimatorState.speedParameter](Animations.AnimatorState-speedParameter.html), [AnimatorState.speedParameterActive](Animations.AnimatorState-speedParameterActive.html).
