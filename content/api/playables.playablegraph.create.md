### Description



Creates a [PlayableGraph](Playables.PlayableGraph.html).





The [PlayableGraph](Playables.PlayableGraph.html) is created without a [Playable](Playables.Playable.html) and a [PlayableOutput](Playables.PlayableOutput.html).

The `name` is optional but it can help when using editor tools, like the GraphVisualizer.
