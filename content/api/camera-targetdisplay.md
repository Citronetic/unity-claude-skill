                    public int targetDisplay;






### Description



Set the target display for this Camera.





This setting makes a Camera render into the specified display.
Maximum number of displays (eg. monitors) supported is 8.

This property has no effect on **Android** and **iOS** platforms, consider using [Camera.SetTargetBuffers](Camera.SetTargetBuffers.html).

Additional resources: [Display](Display.html) class, [Canvas.targetDisplay](Canvas-targetDisplay.html).
