## Declaration

public Object[] GetObjects();






### Returns



**Object[]**
        All the Objects within the [ContentFile](Unity.Loading.ContentFile.html).





### Description



This function can be used to access all the Objects loaded in the [ContentFile](Unity.Loading.ContentFile.html).





This method will raise an exception if when called [ContentFile.LoadingStatus](Unity.Loading.ContentFile.LoadingStatus.html) is not [LoadingStatus.Completed](Unity.Loading.LoadingStatus.Completed.html).
