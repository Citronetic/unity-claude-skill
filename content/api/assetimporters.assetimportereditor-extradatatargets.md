                    protected Object[] extraDataTargets;






### Description



An array of objects associated with each [Editor.targets](Editor-targets.html).





This array is only created when [extraDataType](AssetImporters.AssetImporterEditor-extraDataType.html) is provided and will always have the same size as [Editor.targets](Editor-targets.html). Each object has to be initialized inside [InitializeExtraDataInstance](AssetImporters.AssetImporterEditor.InitializeExtraDataInstance.html).
