                    public float maxDepth;






### Description



Sets the contact filter to filter the results to only include [Collider2D](Collider2D.html) with a Z coordinate (depth) less than this value.





This is only used if [useDepth](ContactFilter2D-useDepth.html) is true.  If the `maxDepth` is set to -[Mathf.Infinity](Mathf.Infinity.html) or [Mathf.Infinity](Mathf.Infinity.html) then the highest possible depth is used.

Additional resources: [Transform](Transform.html).
