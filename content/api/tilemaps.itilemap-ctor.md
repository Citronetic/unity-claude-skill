## Declaration

public ITilemap([Tilemaps.Tilemap](Tilemaps.Tilemap.html) tilemap);






### Parameters



| Parameter | Description |
| --- | --- |
| tilemap | The Tilemap to wrap. |





### Description



Initializes and returns an instance of [ITilemap](Tilemaps.ITilemap.html).





This will wrap the [Tilemap](Tilemaps.Tilemap.html) parameter and is passed onto [Tile](Tilemaps.Tile.html)s when information is queried from the [Tile](Tilemaps.Tile.html)s.
