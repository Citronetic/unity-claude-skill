                    public bool useSideBounce;






### Description



Should bounce be used on the platform sides?





When false, a contact on the sides uses no bounce.  When true, any existing bounce is used.  This is useful to stop bouncing of a [Collider2D](Collider2D.html) when in contact with a vertical surface.  The "sides" are defined as the edges perpendicular to the "top" surface(s) in local-space.
