                    public [Canvas](Canvas.html) rootCanvas;






### Description



Returns the [Canvas](Canvas.html) closest to root, by checking through each parent and returning the last canvas found. If no other canvas is found then the canvas will return itself.





Additional resources: [isRootCanvas](Canvas-isRootCanvas.html).
