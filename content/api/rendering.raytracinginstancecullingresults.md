### Description



A structure containing results of the culling operation performed by [RayTracingAccelerationStructure.CullInstances](Rendering.RayTracingAccelerationStructure.CullInstances.html).





Note that [RayTracingAccelerationStructure.CullInstances](Rendering.RayTracingAccelerationStructure.CullInstances.html) has already added ray tracing instances to the acceleration structure based on input parameters.





### Properties



| Property | Description |
| --- | --- |
| materialsCRC | An array of Material CRC and instance id pairs generated by RayTracingAccelerationStructure.CullInstances when using RayTracingInstanceCullingFlags.ComputeMaterialsCRC flag. |
| transformsChanged | This property is true if a Renderer in the Scene changed its Transform during the last frame. Renderers that use Ray Tracing Mode Off are not taken into account. |
