### Description



Used for specifying the type of geometry to collect. Used with [NavMeshBuilder.CollectSources](AI.NavMeshBuilder.CollectSources.html).





### Properties



| Property | Description |
| --- | --- |
| RenderMeshes | Collect meshes form the rendered geometry. |
| PhysicsColliders | Collect geometry from the 3D physics collision representation. |
