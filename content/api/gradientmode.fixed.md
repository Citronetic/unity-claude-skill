### Description



Use a constant color between the keys.





This mode returns the key color value where key time is greater than the requested evaluation time.
The resulting gradient is then a sequence of colors, not blended together.

Additional resources: [Gradient.mode](Gradient-mode.html), [Gradient.Evaluate](Gradient.Evaluate.html).
