                    public static float defaultHeight;






### Description



Default height of the header.





This height ensures there is room for the sorting arrow above the header text. If sorting is disabled with [MultiColumnHeader.canSort](IMGUI.Controls.MultiColumnHeader-canSort.html) = false, then minimumHeight can be used.

Additional resources: minimumHeight.
