                    public [Handles.SizeFunction](Handles.SizeFunction.html) midpointHandleSizeFunction;






### Description



The [SizeFunction](Handles.SizeFunction.html) to specify how large the midpoint control handles should be.





Defaults to [DefaultMidpointHandleSizeFunction](IMGUI.Controls.PrimitiveBoundsHandle.DefaultMidpointHandleSizeFunction.html) for new instances of [PrimitiveBoundsHandle](IMGUI.Controls.PrimitiveBoundsHandle.html). The midpoint handle will be drawn with a size of `0` if a value of `null` is assigned.

Additional resources: [midpointHandleDrawFunction](IMGUI.Controls.PrimitiveBoundsHandle-midpointHandleDrawFunction.html).
