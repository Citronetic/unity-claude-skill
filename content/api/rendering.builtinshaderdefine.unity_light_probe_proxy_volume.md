### Description



UNITY_LIGHT_PROBE_PROXY_VOLUME is set when **Light Probe Proxy Volume** feature is supported by the current graphics API and is enabled in the [Graphics Tier settings](../Manual/class-GraphicsSettings.html). You can only set a Graphics Tier in the Built-in Render Pipeline.





Additional resources: [LightProbeProxyVolume](LightProbeProxyVolume.html), [TierSettings.enableLPPV](Rendering.TierSettings-enableLPPV.html).
