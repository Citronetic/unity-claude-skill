### Description



[XRInputSubsystem](XR.XRInputSubsystem.html) tracks all [InputDevice](XR.InputDevice.html)s in reference to the first known location of a specific [InputDevice](XR.InputDevice.html) when set to TrackingOriginModeFlags.Device.





For mobile AR applications, the [InputDevice](XR.InputDevice.html) is the mobile device the application is running on. For head-mounted device applications, the head-mounted device acts as the root.
