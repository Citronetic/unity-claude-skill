                    public AndroidAssetPackState[] states;






### Description



Gets the states of all Android asset packs that had their status checked by this operation.





Until the operation is complete and [GetAssetPackStateAsyncOperation.isDone](Android.GetAssetPackStateAsyncOperation-isDone.html) returns true, this returns null.
Read-only.
Additional resources: [AndroidAssetPackState](Android.AndroidAssetPackState.html), [GetAssetPackStateAsyncOperation.isDone](Android.GetAssetPackStateAsyncOperation-isDone.html), [GetAssetPackStateAsyncOperation.size](Android.GetAssetPackStateAsyncOperation-size.html).
