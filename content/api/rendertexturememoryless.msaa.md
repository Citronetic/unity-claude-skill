### Description



Render texture color pixels are memoryless when [RenderTexture.antiAliasing](RenderTexture-antiAliasing.html) is set to 2, 4 or 8.





Note that memoryless render textures are only supported on iOS/tvOS 10.0+ Metal. Render textures are read/write protected and stored in CPU or GPU memory on other platforms.

Additional resources: [RenderTexture.memorylessMode](RenderTexture-memorylessMode.html), [RenderTexture](RenderTexture.html).
