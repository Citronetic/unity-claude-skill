## Declaration

public void ClearPlatformTextureSettings(string platform);






### Parameters



| Parameter | Description |
| --- | --- |
| platform | The platform whose settings are to be cleared (see below). |





### Description



Clears specific target platform settings.





Refer to [NamedBuildTarget](Build.NamedBuildTarget.html) for a list of valid platforms. To get the name of a platform as a string, use the `TargetName` property. For example, `UnityEditor.Build.NamedBuildTarget.Standalone.TargetName`.
