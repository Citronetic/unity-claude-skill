                    public string channelName;






### Description



The name of the channel this [ChannelClient](MPE.ChannelClient.html) is connected to. The name matches the route of the URL used to connect to Unity's [ChannelService](MPE.ChannelService.html). For example, 127.0.0.1:8928/<my Channel Name>.
