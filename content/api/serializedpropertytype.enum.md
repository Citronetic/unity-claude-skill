### Description



Represents an enumeration property.





[SerializedProperty.numericType](SerializedProperty-numericType.html) can be used to determine the type of the constant values of the enum used to access the enum type (typically int).
                    Use [SerializedProperty.intValue](SerializedProperty-intValue.html) to access the numeric value, unless the enum type is uint, in which case [SerializedProperty.longValue](SerializedProperty-longValue.html) should be used.
                    Additional resources: [SerializedProperty](SerializedProperty.html), [SerializedProperty.enumNames](SerializedProperty-enumNames.html).
