### Description



Define whether or not to skip the simulation if there are no active physics objects in the scene.





Skips the [SimulationStage.RunSimulation](SimulationStage.RunSimulation.html) stage if there are no active Rigidbodies, ArticulationBodies, or Colliders in the scene.
This option has no effect if the [SimulationStage.RunSimulation](SimulationStage.RunSimulation.html) stage is not specified in the [PhysicsScene.RunSimulationStages](PhysicsScene.RunSimulationStages.html) call.
