                    public string[] keywordNames;






### Description



An array containing the names of all local shader keywords in this local keyword space. (Read Only)





Use this property to retrieve the names of all local shader keywords in this `LocalKeywordSpace`.

Additional resources: [Shader variants and keywords](../Manual/shader-variants-and-keywords.html), [LocalKeyword](Rendering.LocalKeyword.html), [GlobalKeyword](Rendering.GlobalKeyword.html), [ComputeShader.keywordSpace](ComputeShader-keywordSpace.html), [Shader.keywordSpace](Shader-keywordSpace.html).
