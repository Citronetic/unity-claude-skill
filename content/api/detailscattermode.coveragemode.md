### Description



The detail map holds values that represent how much area to cover at each sample, based on the detail's density.





When you use this mode, detail prototypes have a Density slider enabled.
                    The detail map holds values between 0 and 255. The values represent how much area this detail covers at each
                    sample, based on its density setting.
