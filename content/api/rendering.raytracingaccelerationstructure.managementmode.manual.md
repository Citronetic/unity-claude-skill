### Description



Gives user control over populating and updating the RayTracingAccelerationStructure.





If the ManagementMode is set to Manual, then you must call [RayTracingAccelerationStructure.AddInstance](Rendering.RayTracingAccelerationStructure.AddInstance.html) to add an instance to the RayTracingAccelerationStructure. Call [RayTracingAccelerationStructure.UpdateInstanceTransform]] to update a given instance's transform.
