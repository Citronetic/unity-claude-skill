## Declaration

public static void ShowHelpPage(string page);






### Description



Show a help page.





`page` should be the URL of the help page, usually beginning with `file://`. If `page` starts
with `file:///unity/`, then it points to Unity help.

Additional resources: [Help.ShowHelpForObject](Help.ShowHelpForObject.html).
