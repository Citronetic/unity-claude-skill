                    public NativeArray<Plane> cullingPlanes;






### Description



Planes to cull against.





This array contains the culling planes of all the [BatchCullingContext.cullingSplits](Rendering.BatchCullingContext-cullingSplits.html). Each [CullingSplit](Rendering.CullingSplit.html) contains a starting offset index and the number of the planes in the split.
