                    public [Vector2](Vector2.html) normal;






### Description



A normalized vector that points from `pointB` to `pointA`.





The normalized vector points from [pointB](ColliderDistance2D-pointB.html) to [pointA](ColliderDistance2D-pointA.html).  When it is scaled with the [distance](ColliderDistance2D-distance.html) is produces a vector that can be used to move the [Collider2D](Collider2D.html) so that they are no longer overlapped (if the [distance](ColliderDistance2D-distance.html) is negative) or so they are touching (if the [distance](ColliderDistance2D-distance.html) is positive).
