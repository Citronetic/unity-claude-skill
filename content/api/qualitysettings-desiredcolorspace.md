                    public static [ColorSpace](ColorSpace.html) desiredColorSpace;






### Description



Desired color space (Read Only).





This is the desired color space based on player settings ([PlayerSettings.colorSpace](PlayerSettings-colorSpace.html)). Note that if the platform
or hardware does not support the given color space, the actually used color space might end up being
different. Use [activeColorSpace](QualitySettings-activeColorSpace.html) to check for that.

Additional resources: [Linear and Gamma rendering](../Manual/LinearLighting.html), [ColorSpace](ColorSpace.html), [activeColorSpace](QualitySettings-activeColorSpace.html).
