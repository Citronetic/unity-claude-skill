                    public [LayerMask](LayerMask.html) layerMask;






### Description



Sets the contact filter to filter the results that only include [Collider2D](Collider2D.html) on the layers defined by the layer mask.





This field takes effect if [useLayerMask](ContactFilter2D-useLayerMask.html) is true.
