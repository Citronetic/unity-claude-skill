## Declaration

public static string GetUniqueName(string[] existingNames,
string name);






### Parameters



| Parameter | Description |
| --- | --- |
| existingNames | A list of pre-existing names. |
| name | Desired name to be used as is, or as a base. |





### Returns



**string**
        A name not found in the list of pre-existing names.





### Description



Make a unique name using the provided name as a base.

If the target name is in the provided list of existing names, a unique name is generated by appending the next available numerical increment.





Additional resources: [GameObjectUtility.GetUniqueNameForSibling](GameObjectUtility.GetUniqueNameForSibling.html), [GameObjectUtility.EnsureUniqueNameForSibling](GameObjectUtility.EnsureUniqueNameForSibling.html).

using UnityEngine;
