### Description



Represents the choice of an end user that indicates if your application can use mobile data to download Android asset packs.





The value is received from a callback after AndroidAssetPacks.RequestToUseMobileDataAsync is called.
Additional resources: [AndroidAssetPacks.RequestToUseMobileDataAsync](Android.AndroidAssetPacks.RequestToUseMobileDataAsync.html).





### Properties



| Property | Description |
| --- | --- |
| allowed | Indicates if mobile data can be used to download Android asset packs. |
