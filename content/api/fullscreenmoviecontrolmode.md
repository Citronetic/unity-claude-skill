### Description



Describes options for displaying movie playback controls.





**Windows Store Apps**: OS doesn't provide a **Stop** button control because of this Unity will stop a video if **Escape** or **Back Button** is pressed if video is launched with [FullScreenMovieControlMode.Full](FullScreenMovieControlMode.Full.html) or [FullScreenMovieControlMode.Minimal](FullScreenMovieControlMode.Minimal.html) parameters.





### Properties



| Property | Description |
| --- | --- |
| Full | Display the standard controls for controlling movie playback. |
| Minimal | Display minimal set of controls controlling movie playback. |
| CancelOnInput | Do not display any controls, but cancel movie playback if input occurs. |
| Hidden | Do not display any controls. |
