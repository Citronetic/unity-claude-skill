## Declaration

public static [AI.NavMeshBuildSettings](AI.NavMeshBuildSettings.html) CreateSettings();






### Returns



**NavMeshBuildSettings**
        The created settings.





### Description



Creates and returns a new entry of NavMesh build settings available for runtime NavMesh building.





This is useful for creating and storing settings to use for building NavMeshes for different sized characters.

Additional resources: [NavMeshBuildSettings](AI.NavMeshBuildSettings.html).

The [NavMeshBuildSettings.agentTypeID](AI.NavMeshBuildSettings-agentTypeID.html) will be positive and unique for the created settings.
