## Declaration

public string GetName();






### Returns



**string**
        Tool name.





### Description



Retrieves the name of the custom terrain tool.





This function must be implemented. Unity calls this method to populate the terrain tool inspector.
                    To override a built-in tool with this one, you can provide the same name as the tool to override.

                    Additional resources: [TerrainPaintTool<T0>](TerrainTools.TerrainPaintTool_1.html).
