## Declaration

public void SetDepth(float minDepth,
float maxDepth);






### Parameters



| Parameter | Description |

### Description



Sets the [minDepth](ContactFilter2D-minDepth.html) and [maxDepth](ContactFilter2D-maxDepth.html) filter properties and turns on depth filtering by setting [useDepth](ContactFilter2D-useDepth.html) to true.
