                    public bool keepWaiting;






### Description



Checks if the operation is still running.





Returns `true` if the operation is still running. Otherwise, returns `false`.
Once the property returns false, [GetAssetPackStateAsyncOperation.size](Android.GetAssetPackStateAsyncOperation-size.html) and [GetAssetPackStateAsyncOperation.states](Android.GetAssetPackStateAsyncOperation-states.html) properties can be called to get results.
Read-only.
Additional resources: [GetAssetPackStateAsyncOperation.isDone](Android.GetAssetPackStateAsyncOperation-isDone.html), [GetAssetPackStateAsyncOperation.size](Android.GetAssetPackStateAsyncOperation-size.html), [GetAssetPackStateAsyncOperation.states](Android.GetAssetPackStateAsyncOperation-states.html).
