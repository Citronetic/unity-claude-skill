                    public [SoftJointLimit](SoftJointLimit.html) swing1Limit;






### Description



The angular limit of rotation (in degrees) around the primary axis of the character joint.





The limit is symmetric. For example, a value of 30 will limit the rotation between -30 and +30 degrees.
The limit is relative to the angle the two rigidbodies started the simulation out with.
