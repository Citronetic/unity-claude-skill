### Description



Enumeration of all the muscles in a leg.





These muscles are a sub-part of a human part.

Additional resources: [HumanPartDof](HumanPartDof.html).





### Properties



| Property | Description |
| --- | --- |
| UpperLegFrontBack | The upper leg front-back muscle. |
| UpperLegInOut | The upper leg in-out muscle. |
| UpperLegRollInOut | The upper leg roll in-out muscle. |
| LegCloseOpen | The leg close-open muscle. |
| LegRollInOut | The leg roll in-out muscle. |
| FootCloseOpen | The foot close-open muscle. |
| FootInOut | The foot in-out muscle. |
| ToesUpDown | The toes up-down muscle. |
| LastLegDof | The last value of the LegDof enum. |
