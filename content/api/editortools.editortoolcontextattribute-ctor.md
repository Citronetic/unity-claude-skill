## Declaration

public EditorToolContextAttribute(string displayName,
Type targetType);






### Parameters



| Parameter | Description |
| --- | --- |
| displayName | The name to display in menus. |
| targetType | Set to the type that this tool can edit. Set to null if the tool is not a Component tool. |





### Description



Registers an [EditorToolContext](EditorTools.EditorToolContext.html) as either a global tool context or a [Component](Component.html) tool context.
