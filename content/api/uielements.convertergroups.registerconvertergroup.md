## Declaration

public static void RegisterConverterGroup([UIElements.ConverterGroup](UIElements.ConverterGroup.html) converterGroup);






### Parameters



| Parameter | Description |
| --- | --- |
| converterGroup | The converter group to register. |





### Description



Registers a converter group by ID. Converter groups can be applied on a binding using local converters.





You can apply a converter group in a [DataBinding](UIElements.DataBinding.html) UXML with the `source-to-ui-converters` or
 `ui-to-source-converters` attributes.
