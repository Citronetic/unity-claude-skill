### Description



An implementation of this interface is provided while ticking an ScriptableBakedReflectionSystem. (See [IScriptableBakedReflectionSystem.Tick](Experimental.Rendering.IScriptableBakedReflectionSystem.Tick.html)).





### Public Methods



| Method | Description |
| --- | --- |
| EnterStage | Update the baking stage progress information. |
| ExitStage | Indicates that a stage is complete. |
| SetIsDone | Indicates whether the baking is complete. |
