                    public [Rendering.RasterState](Rendering.RasterState.html) rasterState;






### Description



Specifies the new raster state.





Unity applies these values to the GPU's render state if [RenderStateBlock.mask](Rendering.RenderStateBlock-mask.html) includes a value of [RenderStateMask.Raster](Rendering.RenderStateMask.Raster.html).

The default value is [RasterState.defaultValue](Rendering.RasterState-defaultValue.html).
