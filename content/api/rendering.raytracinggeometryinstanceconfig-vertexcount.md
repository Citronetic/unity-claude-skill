                    public int vertexCount;






### Description



The amount of vertices from [vertexBuffer](Rendering.RayTracingGeometryInstanceConfig-vertexBuffer.html) that defines this ray tracing geometry instance.





Use -1 to instruct Unity to use all the vertices from [vertexBuffer](Rendering.RayTracingGeometryInstanceConfig-vertexBuffer.html) when building the acceleration structure associated with the ray tracing instance.
