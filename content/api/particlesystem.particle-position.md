                    public [Vector3](Vector3.html) position;






### Description



The position of the particle.





The position is defined relative to the simulation space (ie, world space or local space) set by the simulationSpace property. You can use [Transform.TransformPoint](Transform.TransformPoint.html) and [Transform.InverseTransformPoint](Transform.InverseTransformPoint.html) to convert points between local and world space as necessary.
