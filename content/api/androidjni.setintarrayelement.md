## Declaration

public static void SetIntArrayElement(IntPtr array,
int index,
int val);






### Description



Sets the int value of one element in a primitive array.





This function is a special case of SetIntArrayRegion(), called with region size set to 1.

Additional resources: [Java Native Interface Specification (Oracle)](http://download.oracle.com/javase/1.5.0/docs/guide/jni/spec/jniTOC.html)
