### Description



A Shader Tag configuration used by [RayTracingAccelerationStructure.CullInstances](Rendering.RayTracingAccelerationStructure.CullInstances.html) to filter and classify Materials.





Additional resources: [RayTracingInstanceMaterialConfig](Rendering.RayTracingInstanceMaterialConfig.html), [Material.GetTag](Material.GetTag.html).





### Properties



| Property | Description |
| --- | --- |
| tagId | A shader tag id. Use ShaderTagId constructor to create one (e.g. ShaderTagId("RenderPipeline"). |
| tagValueId | A shader tag id value. Use ShaderTagId constructor to create one (e.g. ShaderTagId("UltraHDRP"). |
