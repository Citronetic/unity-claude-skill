### Description



Color with alpha texture format, 8-bits per channel.





BGRA32 format is used by [WebCamTexture](WebCamTexture.html) on some platforms. Each of RGBA color channels is stored as an 8-bit value in [0..1] range. In memory, the channel data is ordered this way: B, G, R, A bytes one after another.

Additional resources: [Texture2D.format](Texture2D-format.html), [texture assets](../Manual/Textures.html).
