                    public static int eyeTextureWidth;






### Description



The current width of an eye texture for the loaded device.





This value will be the product of the default eye texture size for the HMD and [XRSettings.eyeTextureResolutionScale](XR.XRSettings-eyeTextureResolutionScale.html). If XR isn't enabled this value will be zero.
