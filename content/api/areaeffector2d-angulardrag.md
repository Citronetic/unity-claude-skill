                    public float angularDrag;






### Description



The angular drag to apply to rigid-bodies.





The `angularDrag` coefficient is applied in addition to the standard [Rigidbody2D](Rigidbody2D.html) angular drag coefficient to provide additional angular drag in the effector area.
