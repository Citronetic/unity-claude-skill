### Description



Indicates the status of a progress indicator's associated task.





### Properties



| Property | Description |
| --- | --- |
| Running | Indicates that the task is still running. |
| Succeeded | Indicates that the task succeeded. |
| Failed | Indicates that the task failed. |
| Canceled | Indicates that the task was canceled. |
| Paused | Indicates that the task is paused. |
