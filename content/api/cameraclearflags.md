### Description



Values for Camera.clearFlags, determining what to clear when rendering a [Camera](Camera.html).





Additional resources: [camera component](../Manual/class-Camera.html).





### Properties



| Property | Description |
| --- | --- |
| Skybox | Clear with the skybox. |
| SolidColor | Clear with a background color. |
| Depth | Clear only the depth buffer. |
| Nothing | Don't clear anything. |
