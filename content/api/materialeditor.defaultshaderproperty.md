### Description



Handles UI for one shader property ignoring any custom drawers.





This is similar to [ShaderProperty](MaterialEditor.ShaderProperty.html) function, except it ignores any custom [MaterialPropertyDrawer](MaterialPropertyDrawer.html) objects.
