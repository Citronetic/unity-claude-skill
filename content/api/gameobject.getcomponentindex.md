## Declaration

public int GetComponentIndex([Component](Component.html) component);






### Parameters



| Parameter | Description |
| --- | --- |
| component | The component to search for. |





### Returns



**int**
        The index of the specified Component if it exists. Otherwise, returns `-1`.





### Description



Retrieves the index of the specified component in the array of components attached to the GameObject.
