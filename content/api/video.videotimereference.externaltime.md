### Description



The external reference clock the [VideoPlayer](Video.VideoPlayer.html) observes to detect and correct drift.





The VideoPlayer plays the video based on an external time source. External time sources include your own custom timers, or a system’s time. To set this, use [VideoPlayer.externalReferenceTime](Video.VideoPlayer-externalReferenceTime.html).
