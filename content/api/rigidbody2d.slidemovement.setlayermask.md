## Declaration

public void SetLayerMask([LayerMask](LayerMask.html) mask);






### Parameters



| Parameter | Description |
| --- | --- |
| mask | The layer mask to use. |





### Description



A helper method that simultaneously sets both the [Rigidbody2D.SlideMovement.layerMask](Rigidbody2D.SlideMovement-layerMask.html) to the specified `mask` but also sets [Rigidbody2D.SlideMovement.useLayerMask](Rigidbody2D.SlideMovement-useLayerMask.html) to true.





Additional resources: [Rigidbody2D.SlideMovement.useLayerMask](Rigidbody2D.SlideMovement-useLayerMask.html) and [Rigidbody2D.SlideMovement.layerMask](Rigidbody2D.SlideMovement-layerMask.html).
