### Description



Source of smoothness value used in the underlying splat material of a [TerrainLayer](TerrainLayer.html) when [TerrainLayer.diffuseTexture](TerrainLayer-diffuseTexture.html) has an alpha channel.





When [TerrainLayer.diffuseTexture](TerrainLayer-diffuseTexture.html) has an alpha channel, you can set smoothness by [TerrainLayer.smoothness](TerrainLayer-smoothness.html) or through the alpha channel of the diffuse texture.





### Properties



| Property | Description |
| --- | --- |
| Constant | Smoothness value comes from TerrainLayer.smoothness. |
| DiffuseAlphaChannel | Smoothness value comes from the alpha channel of TerrainLayer.diffuseTexture. |
