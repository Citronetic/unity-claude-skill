                    public uint rank;






### Description



The rank of a [MachineLearningTensorShape](Rendering.MachineLearningTensorShape.html).





For example, a tensor of shape (5) has a rankof 1. A tensor of shape (7, 3, 5) has a rank of 3.

Rank of 0 tensors are scalar values. To describe an empty tensor shape,  use [NullTensor](Rendering.MachineLearningTensorShape.NullTensor.html).
