### Description



A category with which to define tools that inherit from the ITerrainPaintToolWithOverlays interface.





The categories include: TerrainCategory.CustomBrushes, TerrainCategory.Foliage, TerrainCategory.Materials, TerrainCategory.NeighborTerrains, and TerrainCategory.Sculpt.





### Properties



| Property | Description |
| --- | --- |
| Sculpt | The Sculpt Terrain Tools category. |
| Materials | The Materials Terrain Tools category. |
| Foliage | The Foliage Terrain Tools category. |
| NeighborTerrains | The NeighborTerrains Terrain Tools category. |
| CustomBrushes | The CustomBrushes Terrain Tools category. |
