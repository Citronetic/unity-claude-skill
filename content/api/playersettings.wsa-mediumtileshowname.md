                    public static bool mediumTileShowName;






### Description



The application name to display on the [Medium Tile](PlayerSettings.WSAImageType.UWPSquare150x150Logo.html).





In the Editor, Unity displays this under **Tile section** in [UWP Player Settings](../Manual/class-PlayerSettingsWSA.html).

**Note**: If you do not set a logo image for [this tile size](PlayerSettings.WSAImageType.html), Unity ignores this property.
                Additional resources: [tileShowName](PlayerSettings.WSA-tileShowName.html).
