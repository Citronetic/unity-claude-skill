## Declaration

public void SetBindposes(NativeArray<Matrix4x4> poses);






### Parameters



| Parameter | Description |
| --- | --- |
| poses | The array of bind poses to assign to the Mesh. |





### Description



Sets the bind poses of the Mesh.





The bind pose at each index corresponds to the bone with the same index. Additional resources: [SkinnedMeshRenderer.bones](SkinnedMeshRenderer-bones.html).
