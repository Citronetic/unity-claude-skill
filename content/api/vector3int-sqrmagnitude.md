                    public int sqrMagnitude;






### Description



Returns the squared length of this vector (Read Only).





Calculating the squared magnitude instead of the [magnitude](Vector3Int-magnitude.html) is much faster.

Often if you are comparing magnitudes of two vectors you can just compare their squared magnitudes.

Additional resources: [magnitude](Vector3Int-magnitude.html).
