                    public [Unity.Android.Gradle.PropertyBoolean](Unity.Android.Gradle.PropertyBoolean.html) UseLegacyPackaging;






### Description



Whether to use the legacy convention of compressing all .so files in the APK. If null, .so files will be uncompressed and page-aligned when minSdk >= 23.





For more information about the element, see Android's documentation: [useLegacyPackaging element](https://developer.android.com/reference/tools/gradle-api/com/android/build/api/dsl/JniLibsPackaging#useLegacyPackaging())
