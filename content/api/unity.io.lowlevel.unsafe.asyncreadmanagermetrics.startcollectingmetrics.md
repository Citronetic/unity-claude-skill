## Declaration

public static void StartCollectingMetrics();






### Description



Begin recording metrics data for [AsyncReadManager](Unity.IO.LowLevel.Unsafe.AsyncReadManager.html) read operations.





Stop collection with [StopCollectingMetrics](Unity.IO.LowLevel.Unsafe.AsyncReadManagerMetrics.StopCollectingMetrics.html).
                You can also enable metrics collection when your program first launches using the command-line argument "-enable-file-read-metrics".
                Additional resources:: [IsEnabled](Unity.IO.LowLevel.Unsafe.AsyncReadManagerMetrics.IsEnabled.html)
