## Declaration

public static void EndSampling();






### Description



Finish the sampling of the animation clip.





[EndSampling](AnimationMode.EndSampling.html) is called after [SampleAnimationClip](AnimationMode.SampleAnimationClip.html) returns.
          This function must be called immediately following [SampleAnimationClip](AnimationMode.SampleAnimationClip.html).
          See the script example on the [AnimationMode](AnimationMode.html)
          page to see this behaviour.
