                    public bool useInstancing;






### Description



Indicates whether this detail prototype uses [GPU Instancing](../Manual/GPUInstancing.html) for rendering.





When you set this value to `true`, Unity uses the Material and Shader used by the [prototype](DetailPrototype-prototype.html) GameObject for rendering.

Currently this setting is only effective when you specify [DetailRenderMode.VertexLit](DetailRenderMode.VertexLit.html) as the [renderMode](DetailPrototype-renderMode.html).
