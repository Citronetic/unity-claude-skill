## Declaration

public void SetLayerMask([LayerMask](LayerMask.html) layerMask);






### Parameters



| Parameter | Description |
| --- | --- |
| layerMask | The value used to set the layerMask. |





### Description



Sets the [layerMask](ContactFilter2D-layerMask.html) filter property using the *layerMask* parameter provided and also enables layer mask filtering by setting [useLayerMask](ContactFilter2D-useLayerMask.html) to true.
