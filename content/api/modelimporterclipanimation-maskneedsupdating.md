                    public bool maskNeedsUpdating;






### Description



Returns true when the source AvatarMask has changed. This only happens when  [ModelImporterClipAnimation.maskType](ModelImporterClipAnimation-maskType.html) is set to [ClipAnimationMaskType.CopyFromOther](ClipAnimationMaskType.CopyFromOther.html)
To force a reload of the mask, simply set  [ModelImporterClipAnimation.maskSource](ModelImporterClipAnimation-maskSource.html) to the desired [AvatarMask](AvatarMask.html).
