                    public float animationRotationError;






### Description



Allowed error of animation rotation compression.





Allowed error is defined in angle (in degrees) between compressed and
original quaternions on a curve. This settings used only when animation keyframe
reduction is enabled.

Additional resources: [animationCompression](ModelImporter-animationCompression.html), [ModelImporterAnimationCompression](ModelImporterAnimationCompression.html).
