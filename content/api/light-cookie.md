                    public [Texture](Texture.html) cookie;






### Description



The cookie texture projected by the light.





[LightType.Point](LightType.Point.html) lights require a cube map texture. If the cookie is a cube map, the light will become a [LightType.Point](LightType.Point.html) light.

Note that cookies are displayed for pixel ("important") and baked/mixed lights, but not for vertex/SH ("not important") lights.

Additional resources: [Light component](../Manual/class-Light.html).
