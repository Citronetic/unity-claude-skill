public T AddStateMachineBehaviour();






### Returns



**T**
        The type of state machine behaviour to add.





### Description



Adds a state machine behaviour class of type T to the AnimatorState.
Note that there is no corresponding "Remove" method. To remove a state machine behaviour, use [Object.Destroy](Object.Destroy.html).
