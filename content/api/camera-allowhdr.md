                    public bool allowHDR;






### Description



High dynamic range rendering.





True if the camera is using HDR rendering and false if it is not. You can only enable HDR if it is also supported by the current [GraphicsTier](Rendering.GraphicsTier.html). You can only set a Graphics Tier in the Built-in Render Pipeline.

Additional resources: [TierSettings.hdr](Rendering.TierSettings-hdr.html), [CameraHDRMode](Rendering.CameraHDRMode.html).
