## Declaration

public void ClearRemainingTime();






### Description



Resets the computation of the progress indicator's remaining time.





If the remaining time was set manually, it reverts to its default state where it is computed automatically.

Additional resources: [Progress.ClearRemainingTime](Progress.ClearRemainingTime.html), [Progress.Item.remainingTime](Progress.Item-remainingTime.html), [Progress.Item.SetRemainingTime](Progress.Item.SetRemainingTime.html).
