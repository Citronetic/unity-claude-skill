                    public bool useOneWay;






### Description



Should the one-way collision behaviour be used?





When true, collisions are only allowed when the linear velocity, transformed into the local-space of the target [Collider2D](Collider2D.html), are less than zero.  For [Collider2D](Collider2D.html) that are not rotated in Z, this equates to a vertical velocity less than zero.

Additional resources: [useOneWayGrouping](PlatformEffector2D-useOneWayGrouping.html).
