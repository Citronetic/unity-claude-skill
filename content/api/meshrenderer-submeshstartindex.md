                    public int subMeshStartIndex;






### Description



Index of the first sub-mesh to use from the [Mesh](Mesh.html) associated with this MeshRenderer (Read Only).





This value is 0 except when using [Mesh.CombineMeshes](Mesh.CombineMeshes.html) or static batching.
