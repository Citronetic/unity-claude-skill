## Declaration

public Dictionary<SourceAssetIdentifier,Object> GetExternalObjectMap();






### Returns



**Dictionary<SourceAssetIdentifier,Object>**
        The map between a sub-asset and an external Asset.





### Description



Gets a copy of the external object map used by the AssetImporter.





Changing the map does not affect the state of the AssetImporter.

Additional resources: [AssetImporter.AddRemap](AssetImporter.AddRemap.html), [AssetImporter.RemoveRemap](AssetImporter.RemoveRemap.html).
