## Declaration

public bool TryGetInputDevices(List<InputDevice> devices);






### Parameters



| Parameter | Description |
| --- | --- |
| devices | The list of devices reported by this subsystem. |





### Returns



**bool**
        True, if the [XRInputSubsystem](XR.XRInputSubsystem.html) retrieves any devices.  Returns false otherwise.





### Description



Gets a list of all connected [InputDevice](XR.InputDevice.html)s reported by this [XRInputSubsystem](XR.XRInputSubsystem.html).
