### Description



Use to indicate that ProfilerRecorder should collect GPU timing instead of CPU.





If you use [ProfilerRecorderOptions.GpuRecorder](Unity.Profiling.ProfilerRecorderOptions.GpuRecorder.html) to create the recorder, make sure you set the MarkerFlags.SampleGpu flag for the [ProfilerMarker](Unity.Profiling.ProfilerMarker.html) it is used with.
