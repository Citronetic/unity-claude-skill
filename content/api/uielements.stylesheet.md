### Description



Style sheets are applied to visual elements in order to control the layout and visual appearance of the user interface.





The [StyleSheet](UIElements.StyleSheet.html) class holds the imported data of USS files in your project.
 Once loaded, a style sheet can be attached to a [VisualElement](UIElements.VisualElement.html) object to affect the element itself and its descendants.


              


```
public class MyEditorWindow : EditorWindow
 {
     void OnEnable()
     {
         rootVisualElement.styleSheets.Add(AssetDatabase.LoadAssetAtPath<StyleSheet>("Assets/styles.uss"));
     }
 }
```
