## Declaration

public bool TryGetAngularVelocity(out [Vector3](Vector3.html) angularVelocity);






### Returns



**bool**
        True if the angular velocity was set in the output parameter. False if the angular velocity is not available due to limitations of the underlying platform or if the node is not presently tracked.





### Description



Attempt to retrieve a Vector3 representing the current angular velocity of the tracked node.
