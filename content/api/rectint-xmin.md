                    public int xMin;






### Description



Shows the minimum X value of the `RectInt`.





Sets the minimum X value of the [RectInt](RectInt.html). If you enter a minimum value that is greater than the current maximum value, then the entered value becomes the new maximum value and the previous maximum value becomes the new minimum value. The position and size of the [RectInt](RectInt.html) is then adjusted based on the new minimum and maximum values.
