### Description



Occurs during the next update of the Editor application if it is in edit mode and was previously in play mode.





In this condition both [EditorApplication.isPlaying](EditorApplication-isPlaying.html) and [EditorApplication.isPlayingOrWillChangePlaymode](EditorApplication-isPlayingOrWillChangePlaymode.html) are `false`.
