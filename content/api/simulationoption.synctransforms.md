### Description



Define whether or not to sync modified [Transform](Transform.html) poses to the physics system.





This option has no effect if the [SimulationStage.PrepareSimulation](SimulationStage.PrepareSimulation.html) stage is not specified in the [PhysicsScene.RunSimulationStages](PhysicsScene.RunSimulationStages.html) call.
