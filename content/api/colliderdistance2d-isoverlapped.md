                    public bool isOverlapped;






### Description



Gets whether the `distance` represents an overlap or not.





The [distance](ColliderDistance2D-distance.html) can be positive indicating that the [Collider2D](Collider2D.html) are separated (not overlapped), zero indicating that they are touching (but not overlapped) or negative indicating that they are overlapped.

This property is therefore a check to see if [distance](ColliderDistance2D-distance.html) is negative which indicates the [Collider2D](Collider2D.html) are overlapped.
