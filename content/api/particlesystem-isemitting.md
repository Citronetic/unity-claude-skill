                    public bool isEmitting;






### Description



Determines whether the Particle System is emitting particles. A Particle System may stop emitting when its emission module has finished, it has been paused or if the system has been stopped using [Stop](ParticleSystem.Stop.html) with the [StopEmitting](ParticleSystemStopBehavior.StopEmitting.html) flag. Resume emitting by calling [Play](ParticleSystem.Play.html).
