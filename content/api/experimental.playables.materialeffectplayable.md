### Description



An implementation of [IPlayable](Playables.IPlayable.html) that allows application of a [Material](Material.html) shader to one or many texture inputs to produce a texture output.





NOTE: You can use [PlayableExtensions](Playables.PlayableExtensions.html) methods with MaterialEffectPlayable objects.
