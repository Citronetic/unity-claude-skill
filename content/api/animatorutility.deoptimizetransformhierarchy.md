## Declaration

public static void DeoptimizeTransformHierarchy([GameObject](GameObject.html) go);






### Parameters



| Parameter | Description |
| --- | --- |
| go | GameObject to Deoptimize. |





### Description



This function will recreate all transform hierarchy under GameObject.





A call to this function at runtime will re-initialize the animator.

Additional resources: [AnimatorUtility.OptimizeTransformHierarchy](AnimatorUtility.OptimizeTransformHierarchy.html),  [Animator.hasTransformHierarchy](Animator-hasTransformHierarchy.html).
