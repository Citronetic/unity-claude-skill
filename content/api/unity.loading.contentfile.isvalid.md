                    public bool IsValid;






### Description



Returns true if the [ContentFile](Unity.Loading.ContentFile.html) handle is valid.





This will be true immediately after the handle is returned from [ContentLoadInterface.LoadContentFileAsync](Unity.Loading.ContentLoadInterface.LoadContentFileAsync.html). It becomes false after [ContentFile.UnloadAsync](Unity.Loading.ContentFile.UnloadAsync.html) is called.
