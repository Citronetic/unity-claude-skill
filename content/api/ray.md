### Description



Representation of rays.





A ray is an infinite line starting at [origin](Ray-origin.html) and going in some [direction](Ray-direction.html).





### Properties



| Property | Description |
| --- | --- |
| direction | The direction of the ray. |
| origin | The origin point of the ray. |





### Constructors



| Constructor | Description |
| --- | --- |
| Ray | Creates a ray starting at origin along direction. |





### Public Methods



| Method | Description |
| --- | --- |
| GetPoint | Returns a point at distance units along the ray. |
| ToString | Returns a formatted string for this ray. |
