                    public bool carveOnlyStationary;






### Description



Should this obstacle be carved when it is constantly moving?





When this property is enabled, the obstacle will carve a hole only when it is stationary. There will be no hole carved when the object is moving. See [carving](AI.NavMeshObstacle-carving.html) for full description of different carving behaviors.
