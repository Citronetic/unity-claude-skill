### Description



A change of this type indicates that the structure of a [GameObject](GameObject.html) has changed. This happens when a component is added to or removed from the [GameObject](GameObject.html) using [Undo.AddComponent](Undo.AddComponent.html) or [Undo.DestroyObjectImmediate](Undo.DestroyObjectImmediate.html).
