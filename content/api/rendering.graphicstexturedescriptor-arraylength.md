                    public int arrayLength;






### Description



The number of textures in the GraphicsTexture array.





For graphics texture arrays (see [dimension](Rendering.GraphicsTextureDescriptor-dimension.html)), this variable determines the number of elements in the array. Must be 0 for non-array textures.
