                    public bool isModifiable;






### Description



Returns `true` while a [UnityWebRequest](Networking.UnityWebRequest.html)’s configuration properties can be altered. (Read Only)





Examples of configuration properties include [downloadHandler](Networking.UnityWebRequest-downloadHandler.html), [method](Networking.UnityWebRequest-method.html) and [url](Networking.UnityWebRequest-url.html). This property will return `false` after a call to [Send](Networking.UnityWebRequest.Send.html).
