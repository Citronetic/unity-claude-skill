                    public static [WebGLLinkerTarget](WebGLLinkerTarget.html) linkerTarget;






### Description



Allows you to specify the [web build format](WebGLLinkerTarget.html) that is used when you build your project.





You can choose either [asm.js](WebGLLinkerTarget.Asm.html), [WebAssembly](WebGLLinkerTarget.Wasm.html), or [both](WebGLLinkerTarget.Both.html). WebAssembly is the default linker target. asm.js is the legacy format, which should only be used as a run-time fallback or for debugging purposes.
