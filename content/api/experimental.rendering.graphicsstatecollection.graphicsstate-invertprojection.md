                    public bool invertProjection;






### Description



Flag indicating if the projection matrix is inverted in this rendering configuration.





The projection matrix may be inverted if the render texture in use was created with the [RenderTextureCreationFlags.AllowVerticalFlip](RenderTextureCreationFlags.AllowVerticalFlip.html) flag.
