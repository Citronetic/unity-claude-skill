                    public ulong size;






### Description



Gets the total size in bytes of all Android asset packs that had their status checked by this operation.





Until the operation is complete and [GetAssetPackStateAsyncOperation.isDone](Android.GetAssetPackStateAsyncOperation-isDone.html) returns true, this returns 0.
This value includes the size of both already downloaded and not yet installed Android asset packs.
Read-only.
Additional resources: [GetAssetPackStateAsyncOperation.isDone](Android.GetAssetPackStateAsyncOperation-isDone.html), [GetAssetPackStateAsyncOperation.states](Android.GetAssetPackStateAsyncOperation-states.html).
