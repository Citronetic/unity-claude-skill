### Description



The list of scenes specified in the build profile.





These scenes will be included in the build only if the build profile is active and `overrideGlobalScenes` is `true`. Additional resources: [EditorBuildSettingsScene](EditorBuildSettingsScene.html), [BuildProfile.overrideGlobalScenes](Build.Profile.BuildProfile-overrideGlobalScenes.html), [BuildProfile.GetScenesForBuild](Build.Profile.BuildProfile.GetScenesForBuild.html).
