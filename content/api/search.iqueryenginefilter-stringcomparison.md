### Description



The string comparison options of the filter.





When a filter is created with a string comparison option, this property is included with [overridesStringComparison](Search.IQueryEngineFilter-overridesStringComparison.html) to indicate [stringComparison](Search.IQueryEngineFilter-stringComparison.html) should be used instead of the [globalStringComparison](Search.QueryEngine_1-globalStringComparison.html) option.
