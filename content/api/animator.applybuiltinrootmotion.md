## Declaration

public void ApplyBuiltinRootMotion();






### Description



Apply the default Root Motion.





Applies the default root motion. Use this in [MonoBehaviour.OnAnimatorMove](MonoBehaviour.OnAnimatorMove.html) or in [StateMachineBehaviour.OnStateMove](StateMachineBehaviour.OnStateMove.html) on frames where you don't want to handle the root motion manually.
