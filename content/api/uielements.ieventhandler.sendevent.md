## Declaration

public void SendEvent([UIElements.EventBase](UIElements.EventBase.html) e);






### Parameters



| Parameter | Description |
| --- | --- |
| e | The event to send. |





### Description



Sends an event to the event handler.





The event is forwarded to the event dispatcher for processing.
 For more information, refer to [Synthesize and send events](../Manual/UIE-Events-Synthesizing.html).
