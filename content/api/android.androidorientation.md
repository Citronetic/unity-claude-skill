### Description

| --- | --- |
| Undefined | Mirrors the Android property value ORIENTATION_UNDEFINED. |
| Portrait | Mirrors the Android property value ORIENTATION_PORTRAIT. |
| Landscape | Mirrors the Android property value ORIENTATION_LANDSCAPE. |
