                    public bool reorderable;






### Description



Gets or sets a value that indicates whether the user can drag list items to reorder them.





The default value is `false` which allows the user to drag items to and from other views
 when you implement canStartDrag, setupDragAndDrop, dragAndDropUpdate, and handleDrop.
 Set this value to `true` to allow the user to reorder items in the list.
