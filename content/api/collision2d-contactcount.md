                    public int contactCount;






### Description



Gets the number of contacts for this collision.





A collision can involve multiple contact points. This property allows you to determine how many are involved. You can use this value when retrieving contacts using [GetContact](Collision2D.GetContact.html) or [GetContacts](Collision2D.GetContacts.html).
