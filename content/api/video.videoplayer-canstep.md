                    public bool canStep;






### Description



Returns `true` if the [VideoPlayer](Video.VideoPlayer.html) can step forward through the video content. (Read Only)





Stepping is done with Video.VideoPlayer.StepForwards.

This value is only valid after the movie has been prepared. See [VideoPlayer.Prepare](Video.VideoPlayer.Prepare.html).
