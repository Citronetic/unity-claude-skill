### Description



This render queue is meant for overlay effects, and is rendered last. This value corresponds to a render queue of 4000.





Anything rendered last should go here (e.g. lens flares).

Additional resources: [Material.renderQueue](Material-renderQueue.html), [Shader.renderQueue](Shader-renderQueue.html), [subshader tags](../Manual/SL-SubShaderTags.html).
