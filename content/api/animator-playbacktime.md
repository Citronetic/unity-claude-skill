                    public float playbackTime;






### Description



Sets the playback position in the recording buffer.





When in playback mode (see [StartPlayback](Animator.StartPlayback.html)), this value is used for controlling the current playback position in the buffer (in seconds). The value can range between [recorderStartTime](Animator-recorderStartTime.html) and [recorderStopTime](Animator-recorderStopTime.html)
Additional resources: [StartPlayback](Animator.StartPlayback.html), [StopPlayback](Animator.StopPlayback.html).
