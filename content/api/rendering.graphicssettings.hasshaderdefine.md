## Declaration

public static bool HasShaderDefine([Rendering.GraphicsTier](Rendering.GraphicsTier.html) tier,
[Rendering.BuiltinShaderDefine](Rendering.BuiltinShaderDefine.html) defineHash);






### Description



Returns true if shader define was set when compiling shaders for current [GraphicsTier](Rendering.GraphicsTier.html). Graphics Tiers are only available in the Built-in Render Pipeline.

## Declaration

public static bool HasShaderDefine([Rendering.BuiltinShaderDefine](Rendering.BuiltinShaderDefine.html) defineHash);






### Description



Returns true if shader define was set when compiling shaders for a given [GraphicsTier](Rendering.GraphicsTier.html). Graphics Tiers are only available in the Built-in Render Pipeline.
