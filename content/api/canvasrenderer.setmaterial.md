### Parameters



| Parameter | Description |
| --- | --- |
| material | Material for rendering. |
| texture | Material texture overide. |

### Description



Set the material for the canvas renderer. If a texture is specified then it will be used as the 'MainTex' instead of the material's 'MainTex'.
Additional resources: [CanvasRenderer.materialCount](CanvasRenderer-materialCount.html), [CanvasRenderer.SetTexture](CanvasRenderer.SetTexture.html).
