                    public static [PlayerSettings.WSAInputSource](PlayerSettings.WSAInputSource.html) inputSource;






### Description



The [input source type](PlayerSettings.WSAInputSource.html) for mouse, pen, and touch input events in a XAML app.





In the Editor, Unity displays this under **Misc** in [UWP Player Settings](../Manual/class-PlayerSettingsWSA.html).
**Note**: This option is only applicable to XAML applications that use the SwapChainPanel; XAML applications that use D3D only support the [CoreWindow](PlayerSettings.WSAInputSource.CoreWindow.html) input source.
