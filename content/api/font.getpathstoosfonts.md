## Declaration

public static string[] GetPathsToOSFonts();






### Returns



**string[]**
        An array of the file paths of all fonts installed on the machine.





### Description



Gets the file paths of the fonts that are installed on the operating system.





This function lets you get the file paths and names of all the fonts installed on the machine. You can use these paths in conjunction with the [Font](Font.Font.html)-ctor constructor to create new Font objects.
