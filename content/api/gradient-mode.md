### Description



Controls how the gradient colors are interpolated.





The default interpolation mode is [GradientMode.Blend](GradientMode.Blend.html). Note that [GradientMode.PerceptualBlend](GradientMode.PerceptualBlend.html) can often
result in a more natural looking color blend, especially between very different colors. It is slightly more expensive to
calculate than the default Blend mode.

Additional resources: [GradientMode](GradientMode.html), [Gradient.Evaluate](Gradient.Evaluate.html).
