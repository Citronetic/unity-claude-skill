                    public int cameraResolutionWidth;






### Description



A valid width resolution for use with the web camera.





This value must be set to a valid width resolution supported by the intended capture mode.
For example, when using this with PhotoCapture, you will want to query [PhotoCapture.SupportedResolutions](Windows.WebCam.PhotoCapture.SupportedResolutions.html) for a valid width.
