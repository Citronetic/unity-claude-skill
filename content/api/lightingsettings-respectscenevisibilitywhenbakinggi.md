                    public bool respectSceneVisibilityWhenBakingGI;






### Description



When Unity is precomputing or baking Global Illumination, respect the Scene Visibility setting of a [[GameObject] with a [MeshRenderer](MeshRenderer.html) or [Terrain](Terrain.html) component.





This property requires that a [SceneView](SceneView.html) be present in the editor for it to have any effect; this includes while in [batch mode](Application-isBatchMode.html). See [EditorWindow](EditorWindow.html) and [SceneVisibilityManager](SceneVisibilityManager.html) for more information.
