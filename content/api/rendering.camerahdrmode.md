### Description



The HDR mode to use for rendering.





When HDR is enabled for the current [GraphicsTier](Rendering.GraphicsTier.html) this selects the format to use for the HDR buffer. You can only set a Graphics Tier in the Built-in Render Pipeline.

Additional resources: [TierSettings.hdr](Rendering.TierSettings-hdr.html), [Camera.allowHDR](Camera-allowHDR.html).





### Properties



| Property | Description |
| --- | --- |
| FP16 | Uses RenderTextureFormat.ARGBHalf. |
| R11G11B10 | Uses RenderTextureFormat.RGB111110Float. |
