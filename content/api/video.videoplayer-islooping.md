                    public bool isLooping;






### Description



Determines whether the [VideoPlayer](Video.VideoPlayer.html) restarts from the beginning when it reaches the end of the clip.





If set to `false`, the [VideoPlayer](Video.VideoPlayer.html) will stop playback at the end of the clip and will not reset the time to the start of the clip.
