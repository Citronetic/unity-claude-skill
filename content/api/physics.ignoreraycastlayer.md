                    public static int IgnoreRaycastLayer;






### Description



Layer mask constant to select ignore raycast layer.





This can be used in the layermask field of [Physics.Raycast](Physics.Raycast.html) and other methods to select the "ignore raycast" layer (which does not receive raycasts by default).

Additional resources: [Physics.AllLayers](Physics.AllLayers.html), [Physics.DefaultRaycastLayers](Physics.DefaultRaycastLayers.html).
