                    public static [Color](Color.html) ambientEquatorColor;






### Description



Ambient lighting coming from the sides.





Trilight ambient lighing mode uses this color to affect sideways-facing object parts.

In Flat ambient lighting mode, equator color is just the single ambient color, and has the same value as [ambientLight](RenderSettings-ambientLight.html).

Additional resources: [ambientMode](RenderSettings-ambientMode.html), [ambientSkyColor](RenderSettings-ambientSkyColor.html), [ambientGroundColor](RenderSettings-ambientGroundColor.html).
