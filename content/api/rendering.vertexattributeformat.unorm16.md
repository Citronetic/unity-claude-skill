### Description



16-bit unsigned normalized number.





This format stores uniformly quantized numbers in [0..1] range, with 16 bits of precision (65536 possible different values).

Additional resources: [Mesh](Mesh.html) class, [VertexAttribute](Rendering.VertexAttribute.html) enum, [Mesh.GetVertexAttributeFormat](Mesh.GetVertexAttributeFormat.html).
