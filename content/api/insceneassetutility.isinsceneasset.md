## Declaration

public static bool IsInSceneAsset([Object](Object.html) sourceObject);






### Parameters



| Parameter | Description |
| --- | --- |
| sourceObject | The object to check. |





### Returns



**bool**
        True if `sourceObject` is a an in-scene asset.





### Description



Checks if the given object is an in-scene asset.





In-scene assets are scene objects that are referenced by one or more objects in a scene and are of an asset type. Examples of asset types include, but are not limited to, [Mesh](Mesh.html), [Material](Material.html), and [ScriptableObject](ScriptableObject.html).

Additional resources: [InSceneAssetUtility.CollectInSceneAssets](InSceneAssetUtility.CollectInSceneAssets.html).
