### Description



Support for RenderTexture to Texture copies in [Graphics.CopyTexture](Graphics.CopyTexture.html).





Not all platforms can copy from a [RenderTexture](RenderTexture.html) into a regular [Texture2D](Texture2D.html) directly. For example, Direct3D9
currently can not do this. See [CopyTextureSupport](Rendering.CopyTextureSupport.html) for an overview.
