                    public uint cullingMask;






### Description



The mask for the culling operation.





Unity copies this value from the [Camera.cullingMask](Camera-cullingMask.html) property of the Camera from which you obtained the CullingParameters object. You can override this value before performing the culling operation.

Additional resources: [Camera.cullingMask](Camera-cullingMask.html).
