### Description



Subscribe to this event to get notified when the active Scene has changed in Edit mode in the Editor.





This event is only sent in Edit mode. If the event is only needed during Play mode then use [SceneManager.activeSceneChanged](SceneManagement.SceneManager-activeSceneChanged.html).
