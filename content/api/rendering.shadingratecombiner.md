### Description



Constants that specify the shading rate combiner.





The various sources of shading rate are resolved using this model: C = A combiner B.

Additional resources:  [CommandBuffer.SetShadingRateCombiner](Rendering.CommandBuffer.SetShadingRateCombiner.html), [ShadingRateCombinerStage](Rendering.ShadingRateCombinerStage.html), [ShadingRateInfo.supportsPerImageTile](Rendering.ShadingRateInfo-supportsPerImageTile.html).





### Properties



| Property | Description |
| --- | --- |
| Keep | C = A |
| Override | C = B |
| Min | C = min(A, B) |
| Max | C = max(A, B) |
