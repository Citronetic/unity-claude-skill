## Declaration

public static double GetDuration(U playable);






### Parameters



| Parameter | Description |
| --- | --- |
| playable | The Playable used by this operation. |





### Returns



**double**
        The duration in seconds.





### Description



Returns the duration of the [Playable](Playables.Playable.html).





Use this templated extension method on any type that inherits from [IPlayable](Playables.IPlayable.html).
