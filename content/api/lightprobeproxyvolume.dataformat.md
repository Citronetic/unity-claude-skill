### Description



The texture data format used by the Light Probe Proxy Volume 3D texture.





Additional resources: [Light Probes](../Manual/LightProbes.html), [Light Probe Proxy Volume](LightProbeProxyVolume.html).





### Properties



| Property | Description |
| --- | --- |
| HalfFloat | A 16-bit half floating-point format is used for the Light Probe Proxy Volume 3D texture. |
| Float | A 32-bit floating-point format is used for the Light Probe Proxy Volume 3D texture. |
