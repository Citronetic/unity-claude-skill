## Declaration

public void DeferredEvaluate();






### Description



Schedules the [PlayableDirector](Playables.PlayableDirector.html) to perform [PlayableGraph.Evaluate](Playables.PlayableGraph.Evaluate.html) on the [PlayableGraph](Playables.PlayableGraph.html) associated with the [PlayableDirector.playableAsset](Playables.PlayableDirector-playableAsset.html) on the next update.





This only as an effect in the Editor when not in Play Mode.
