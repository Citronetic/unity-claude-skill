### Description



[XRInputSubsystem](XR.XRInputSubsystem.html) tracks all [InputDevice](XR.InputDevice.html)s in relation to a world anchor. This world anchor can change at any time, and is chosen by the runtime.





Use [XRInputSubsystem.trackingOriginUpdated](XR.XRInputSubsystem-trackingOriginUpdated.html) to be notified when the anchor has been updated.
