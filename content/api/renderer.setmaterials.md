## Declaration

public void SetMaterials(List<Material> materials);






### Parameters



| Parameter | Description |
| --- | --- |
| materials | The list of materials to assign to this renderer. |





### Description



Assigns the shared materials of this renderer using the list of materials provided.





Use this method to set the [Renderer.sharedMaterials](Renderer-sharedMaterials.html) on this renderer using a list.

Additional resources: [Renderer.sharedMaterials](Renderer-sharedMaterials.html).
