### Description



Raised when the ID of the active profile is changed.





This event is raised when the active profile is changed, e.g. when [activeProfileId](ShortcutManagement.IShortcutManager-activeProfileId.html) changes. It is not raised when the shortcut overrides of the active profile are changed, e.g. via [RebindShortcut](ShortcutManagement.IShortcutManager.RebindShortcut.html) or [ClearShortcutOverride](ShortcutManagement.IShortcutManager.ClearShortcutOverride.html).
