### Description



The Profiler Sample Name column.





The entries in this column are the names of the samples.
They usually correspond with the name of the function they sample. Alternatively, they can be defined by a [ProfilerMarker](Unity.Profiling.ProfilerMarker.html) or a [Profiler.BeginSample](Profiling.Profiler.BeginSample.html)
