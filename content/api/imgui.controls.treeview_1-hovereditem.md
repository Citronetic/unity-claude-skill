                    protected TreeViewItem<TIdentifier> hoveredItem;






### Description



Use this property to detect which TreeViewItem the mouse cursor is currently hovering over in the TreeView. This property is only valid if the [enableItemHovering](IMGUI.Controls.TreeView_1-enableItemHovering.html) property has been set to true.
