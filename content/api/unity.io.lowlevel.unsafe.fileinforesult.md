### Description



The results of an asynchronous [AsyncReadManager.GetFileInfo](Unity.IO.LowLevel.Unsafe.AsyncReadManager.GetFileInfo.html) call.





This structure reports whether the file to be queried was found, and if so, its size in bytes.





### Properties



| Property | Description |
| --- | --- |
| FileSize | Indicates the size of the file in bytes. |
| FileState | Indicates whether the file exists or not. |
