## Declaration

public [Vector3](Vector3.html) MultiplyVector([Vector3](Vector3.html) vector);






### Description



Transforms a direction by this matrix.





This function is similar to [MultiplyPoint](Matrix4x4.MultiplyPoint.html); but it transforms
directions and not positions. When transforming a direction, only
the rotation part of the matrix is taken into account.

Additional resources: [MultiplyPoint](Matrix4x4.MultiplyPoint.html), [MultiplyPoint3x4](Matrix4x4.MultiplyPoint3x4.html).
