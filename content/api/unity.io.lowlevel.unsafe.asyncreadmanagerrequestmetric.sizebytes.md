### Description



The size of the read request, in bytes.





For [AsyncReadManager](Unity.IO.LowLevel.Unsafe.AsyncReadManager.html) operations, the size reported by this metric corresponds to the value specified in the [ReadCommand.Size](Unity.IO.LowLevel.Unsafe.ReadCommand.Size.html) field.
