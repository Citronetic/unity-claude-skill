### Description



A ParseResult represents the result of a parsing operation.





<T>: Type of the result of the parsing operation.

ParseResults are used in the context of type parsers. See [QueryEngine.AddTypeParser](Search.QueryEngine_1.AddTypeParser.html) for more details.
