                    public ulong ulongValue;






### Description



Value of an integer property as an unsigned long.





Contains a valid value when [propertyType](SerializedProperty-propertyType.html) is [SerializedPropertyType.Integer](SerializedPropertyType.Integer.html).
                Suitable for accessing values when [numericType](SerializedProperty-numericType.html) is [SerializedPropertyNumericType.UInt64](SerializedPropertyNumericType.UInt64.html), and also supports smaller unsigned types (uint, ushort and byte).

                Additional resources: [longValue](SerializedProperty-longValue.html), [uintValue](SerializedProperty-uintValue.html), [numericType](SerializedProperty-numericType.html), [propertyType](SerializedProperty-propertyType.html), [SerializedPropertyType.Integer](SerializedPropertyType.Integer.html).
