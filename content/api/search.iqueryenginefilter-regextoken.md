                    public Regex regexToken;






### Description



The regular expression that matches the filter. Matches what precedes the operator in a filter (for example. "id" in "id>=2").





This regular expression token is set when you create a filter with a regular expression.  If you create a filter without a regular expression, [token](Search.IQueryEngineFilter-token.html) will be set and the regexToken will be null.
