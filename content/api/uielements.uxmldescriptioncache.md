### Description



Contains pre-processed information about UXML attribute descriptions to avoid relying on reflection.





This is used by the code generator when a control is using [UxmlElementAttribute](UIElements.UxmlElementAttribute.html) and
 [UxmlAttributeAttribute](UIElements.UxmlAttributeAttribute.html).
