### Description



Mouse left a window (Editor views only).





The user moved the mouse out of a window without any buttons being held down.  This event is sent once, as the mouse leaves the window.

Note that this event is only sent in the Editor for [EditorWindow](EditorWindow.html) windows which have [EditorWindow.wantsMouseEnterLeaveWindow](EditorWindow-wantsMouseEnterLeaveWindow.html)
set to true. Mouse enter or leave window events are never sent in the games.
