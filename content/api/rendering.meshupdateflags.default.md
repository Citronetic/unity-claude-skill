### Description



Indicates that Unity should perform the default checks and validation when you update a Mesh's data.





You can use this flag with "advanced" Mesh API, which includes the following methods: [Mesh.SetVertexBufferData](Mesh.SetVertexBufferData.html), [Mesh.SetIndexBufferData](Mesh.SetIndexBufferData.html), [Mesh.SetSubMesh](Mesh.SetSubMesh.html).

                For information about the difference between the simpler and more advanced methods of assigning data to a Mesh from script, see the notes on the [Mesh](Mesh.html) page.
