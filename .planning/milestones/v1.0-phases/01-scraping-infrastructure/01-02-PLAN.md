<task type="auto">
  <name>Task 1: Build URL discovery script and crawl all three content sources</name>
  <files>scripts/discover-urls.mjs</files>
  <action>
Create `scripts/discover-urls.mjs` that discovers URLs from all three sources. Use the browser automation approach proven in Plan 01 (import/reference the browser-test.mjs patterns).

**Source 1: Unity Learn (learn.unity.com)**
- Start from the pathways index: `https://learn.unity.com/pathways`
- Follow links to discover all pathway pages, then all unit pages, then all tutorial pages within each unit
- Also discover standalone tutorials not part of pathways
- Expected: 50-100+ tutorial pages

**Source 2: Unity Manual (docs.unity3d.com/Manual/)**
- Start from the Manual table of contents or sitemap
- Check if `https://docs.unity3d.com/Manual/sitemap.xml` exists and parse it
- If no sitemap, crawl from the Manual index page following section links
- Target sections per user decision: Working in Unity, Scripting, 2D, 3D, UI, Physics, Animation, Audio, Build
- Also include Best Practice Guides
- Expected: 500-1000+ pages

**Source 3: Unity Scripting API (docs.unity3d.com/ScriptReference/)**
- Check if `https://docs.unity3d.com/ScriptReference/sitemap.xml` exists
- If no sitemap, start from the API index page and discover all class/namespace pages
- Expected: 2000+ API reference pages

**Discovery approach (Claude's discretion, BFS recommended):**
- Use sitemaps first (fastest, most complete) -- parse XML to extract URLs
- Fall back to link crawling if sitemaps unavailable
- De-duplicate URLs (normalize trailing slashes, query params, anchors)
- Categorize each URL: "learn-tutorial", "learn-pathway", "manual", "api-reference", "best-practice", "package-docs"

The script should:
- Accept a `--source` flag to crawl one source at a time (`learn`, `manual`, `api`) or `all`
- Output progress to stdout (URLs discovered per source)
- Be idempotent: re-running merges new URLs into existing manifest without losing status of already-tracked URLs
  </action>
  <verify>
    <automated>node scripts/discover-urls.mjs --source learn 2>&1 | tail -5</automated>
  </verify>
  <done>
    - discover-urls.mjs runs and discovers URLs from at least one source
    - Script handles all three sources (learn, manual, api)
    - URL de-duplication is implemented
    - Script is idempotent (safe to re-run)
  </done>
</task>

<task type="auto">
  <name>Task 2: Generate the complete manifest.json with status tracking metadata</name>
  <files>manifest.json</files>
  <action>
Run the discovery script against all three sources to produce the full manifest.json.

**Manifest JSON structure per URL entry:**
```json
{
  "url": "https://learn.unity.com/tutorial/...",
  "source": "learn-tutorial",
  "category": "scripting",
  "status": "pending",
  "wordCount": null,
  "lastAttempt": null,
  "contentHash": null,
  "unityVersion": null,
  "contentFile": null,
  "retryCount": 0,
  "error": null
}
```

**Manifest top-level structure:**
```json
{
  "version": "1.0",
  "generatedAt": "ISO-timestamp",
  "sources": {
    "learn": { "baseUrl": "...", "urlCount": N },
    "manual": { "baseUrl": "...", "urlCount": N },
    "api": { "baseUrl": "...", "urlCount": N }
  },
  "totalUrls": N,
  "statusSummary": {
    "pending": N,
    "scraped": 0,
    "verified": 0,
    "failed": 0
  },
  "urls": [ ... ]
}
```

Per user decisions:
- Status tracking: pending/scraped/verified/failed (SCRP-04)
- Metadata: word count, timestamp, content hash, Unity version tag, category
- Must handle 2000-3000+ URLs reliably

After generating, log a summary: total URLs per source, total URLs overall, status distribution.

If any source fails to discover URLs (e.g., sitemaps unavailable and crawling blocked), document the failure in the manifest's sources section and log a warning. The manifest must still be valid JSON with whatever URLs were successfully discovered.
  </action>
  <verify>
    <automated>node -e "const m = require('./manifest.json'); console.log('Total URLs:', m.totalUrls); console.log('Sources:', Object.keys(m.sources).join(', ')); console.log('Status:', JSON.stringify(m.statusSummary)); console.log(m.totalUrls > 0 ? 'PASS' : 'FAIL')"</automated>
  </verify>
  <done>
    - manifest.json exists with valid JSON structure
    - Contains URLs from at least 2 of 3 sources
    - Every URL entry has status "pending" and all required metadata fields
    - Total URL count is logged (target: hundreds to thousands)
    - statusSummary correctly reflects all URLs as "pending"
  </done>
