<task type="auto">
  <name>Task 1: Build extraction script with tab/accordion expansion and content verification</name>
  <files>scripts/extract-page.mjs</files>
  <action>
Create `scripts/extract-page.mjs` -- the core extraction pipeline that will be used at scale in Phase 2.

**Hidden content expansion (SCRP-05):**
The script must expand all hidden content before extracting. Use the click-and-wait approach per user decision:

1. After page loads, use `evaluate_script` (or equivalent DOM manipulation) to find all expandable elements:
   - Accordion headers: look for elements with `aria-expanded="false"`, `.accordion`, `.collapsible`, `[data-toggle]`
   - Tab panels: look for tab elements (`.tab`, `[role="tab"]`, `.nav-tabs`)
   - "Show more" / "Read more" buttons
   - Unity-specific: expandable code examples, platform-specific content toggles
2. Click each expandable element programmatically
3. Wait 1-2 seconds after clicking (per user decision) for content to render
4. After all expansions, extract the full page text content

**Content extraction to Markdown:**
- Extract main content area (skip navigation, headers, footers, sidebars)
- Convert headings (h1-h6) to markdown headings
- Preserve code blocks with language annotations (C#, YAML, JSON, etc.)
- Preserve ordered and unordered lists
- Preserve bold/italic emphasis
- Strip inline styles, scripts, ads, navigation elements
- Preserve image alt text as `[Image: alt text]` placeholders

**Content verification (SCRP-06):**
- Count words in extracted content (excluding code blocks and metadata)
- If <100 words of substantive content, mark as failed with reason "insufficient content"
- Log word count for every extraction

**Script interface:**
```
node scripts/extract-page.mjs <url> [--output <filepath>]
```
- Takes a single URL, extracts content, writes to output file (or stdout if no output specified)
- Returns exit code 0 on success (>100 words), exit code 1 on failure
- Logs: URL, word count, number of tabs/accordions expanded, pass/fail status

**Retry logic (per user decision):**
- 5 retries with 10-second waits for failed/empty page loads
- Distinguish between "page load failure" (retry) and "page loaded but <100 words" (do not retry, mark as insufficient)

Use the browser automation approach from Plan 01 (import/reference browser-test.mjs patterns).
