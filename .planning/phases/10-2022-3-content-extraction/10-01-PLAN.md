6. **isInScope(url, sourceKey)**: Update scope rules:

   - For `packages` source: URL must be under `/Packages/com.unity.*` — filter for packages that exist in 2022.3 (Input System, Addressables, URP, TextMeshPro, Cinemachine, etc.). Accept any `com.unity.*` package URL found via sitemap.

11. **createUrlEntry**: Set `unityVersion: '2022.3'` as default for all discovered URLs.
