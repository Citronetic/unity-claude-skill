<task type="auto">
  <name>Task 1: Build verification script and run API/deprecation checks</name>
  <files>scripts/verify-synthesis.mjs</files>
  <action>
Create `scripts/verify-synthesis.mjs` that performs three verification passes on all synthesis/*.md files:

**Pass 1: API Name Verification (SYNTH-02)**

For each synthesis file:
1. Extract all Unity API names mentioned in the text. Match patterns like:
   - `ClassName.MethodName` (e.g., `Rigidbody.AddForce`)
   - `ClassName` when used as a Unity type (e.g., `Rigidbody`, `AudioSource`)
   - Backtick-quoted names in prose (e.g., \`GetComponent<T>\`)
   - API names in code blocks (class references, method calls)
2. Look up each API name in `synthesis/api-index.json`
3. Report:
   - VERIFIED: API name found in index
   - MISSING: API name NOT found in index (possible typo, removed API, or non-Unity type)
   - SKIP: Common C# types (string, int, List, Dictionary, etc.) and Unity types that are too generic

For MISSING items, check if it's a close match (fuzzy/Levenshtein) to suggest corrections.

Output a report: `synthesis/verification-report.json` with:
```json
{
  "timestamp": "...",
  "summary": { "verified": N, "missing": N, "skipped": N },
  "byFile": {
    "synthesis/physics.md": {
      "verified": ["Rigidbody.AddForce", ...],
      "missing": ["Rigidbody.ApplyForceAtPosition", ...],
      "suggestions": { "Rigidbody.ApplyForceAtPosition": "Rigidbody.AddForceAtPosition" }
    }
  }
}
```

**Pass 2: Deprecated Pattern Detection (SYNTH-03)**

1. Parse `synthesis/deprecated-patterns.md` to get the list of deprecated APIs and anti-patterns
2. Scan each synthesis file for any mention of deprecated APIs being RECOMMENDED (not just mentioned in a DON'T context)
3. Check that each synthesis file's DO/DON'T section covers the deprecated patterns relevant to its topic
4. Report any deprecated APIs used in code examples without a deprecation warning

Output flags:
- CLEAN: No deprecated patterns recommended
- WARNING: Deprecated pattern mentioned but has DON'T warning nearby
- ERROR: Deprecated pattern used in code example or recommended without warning

**Pass 3: Code Example Completeness (SYNTH-04)**

For each code block in synthesis files:
1. Check for `using` statements — any code block referencing Unity types should have `using UnityEngine;` or the appropriate namespace
2. Check for class context — code should be within a class declaration (MonoBehaviour, ScriptableObject, Editor, etc.) not bare methods
3. Check for language annotation — code blocks should have \`\`\`csharp not bare \`\`\`

Report incomplete code blocks with their location (file:line).

**Final output:** Print a summary to stdout:
```
=== Synthesis Verification Report ===
API Verification: X verified, Y missing, Z skipped
Deprecated Patterns: X clean, Y warnings, Z errors
Code Completeness: X complete, Y missing-using, Z missing-class
Overall: PASS / FAIL (with details)
```

Exit with code 0 if no ERRORS in any pass, exit 1 if any ERROR found.

</task>
